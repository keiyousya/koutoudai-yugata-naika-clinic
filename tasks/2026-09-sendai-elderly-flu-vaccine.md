# 仙台市 高齢者インフルエンザ定期接種（B類）の開始準備

- 起票: 2026-09-17
- 状態: **進行中**
- 関連: [インフル予防接種の広告グループ追加](../ads/docs/tasks/2026-09-flu-vaccine-ad-group.md)

## 背景

当院は令和8年度の仙台市 定期B類疾病予防接種の登録医療機関（継続）。65歳以上等の助成対象者に高齢者インフルエンザの定期接種を実施できる。

### 確認済み（さくらメールで確認）

- 2026-06-16 Googleフォームで登録申込 → 同日、仙台市医師会事務局（事業課 小川様）から受理の返信
  - 登録区分: 継続
  - 高齢者肺炎球菌・高齢者帯状疱疹・**高齢者インフルエンザ**・高齢者新型コロナ: いずれも「登録する」「名簿に掲載する」
- 2026-08-07 仙台市予防接種事業登録研修会（第1部・出席必須）: **出席済み**（欠席だと登録基準を満たさず実施不可だった）
  - 研修会資料は「①予防接種事業登録済み（継続）」区分で配布されている
- 2026-09-14 東邦薬品・中野さんからインフルエンザワクチン100人分（Meiji）確保済みの連絡
- 2026-09-16 ワクチン + 任意接種用予診票が納品済み（東邦薬品）

## やること

- [x] 医師会ニュース109号（2026-09-14発行、メンバーズルーム要ログイン）を読む → **PDFは未読（メンバーズルームのID/PW不明でアクセスできず）**。ただしメール本文に掲載項目一覧あり、接種期間等の項目名は確認済み
  - 「令和8年度仙台市高齢者インフルエンザ予防接種の接種期間について」→ 開始日・終了日を確認
  - 「高齢者インフルエンザ・高齢者新型コロナ予防接種の用紙配付について（9/16から配付開始）」→ 受け取り方法を確認
  - URL: https://www.sendai.miyagi.med.or.jp/uploads/2026/09/20260914_仙台市医師会ニュース１０９号.pdf
- [ ] **定期接種用の予診票（仙台市様式）を入手する** → 医師会に電話して確認予定（9/18カレンダー登録済み）
  - 東邦薬品・中野さんが9/16にワクチンと一緒に届けてくれた予診票は**任意接種用**
  - 定期接種用は医師会から9/16配付開始だが、PDFダウンロード可否 or 複写式用紙の受け取りが必要かは未確認
  - 厚労省の全国共通様式（様式第二）は https://www.mhlw.go.jp/bunya/kenkou/teiki-yobou/dl/08b.pdf にあるが、仙台市独自様式の可能性あり
- [x] 接種期間・自己負担額・対象者を確認し、受付・会計の運用を決める（任意接種3,300円との区別、本人確認書類など） → **仙台市公式サイトで確認済み、運用決定は予診票入手後**
  - 接種期間: 令和8年10月1日〜令和9年1月31日（9/15以降の接種も助成対象）
  - 自己負担額: 1,500円（非課税世帯等は無料）
  - 対象者: 65歳以上、または60〜65歳未満で心臓・腎臓・呼吸器・免疫機能に重度障害のある方
  - 持参物: 健康保険証等の本人確認書類
- [ ] HP の `/flu-vaccine/` と電子カルテのお知らせに、65歳以上の定期接種に対応していることを載せる（現状は13歳以上・3,300円の任意接種のみ記載）
  - 他院（仙台駅東CL、東二番丁診療所、やまと内科CL等）は既に案内掲載済み
- [ ] 広告: 定期接種を扱うので、予防接種の広告グループで「無料 / 助成 / 高齢者」は除外しない（関連タスク参照）
