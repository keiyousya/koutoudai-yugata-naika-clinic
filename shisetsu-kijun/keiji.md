# 掲示の台帳

施設基準・療担規則・医療法で求められる**院内掲示とウェブサイト掲載**を1か所で管理する。
基準ごとの詳細は各ディレクトリの README の「掲示」節に書き、ここは横断の一覧にする。

- 院内掲示物のHTMLは `notices/`（A4印刷）、ウェブサイト掲載は `frontend/src/pages/`。
- 「HP: 原則」は、自ら管理するホームページがあれば掲載が必要という意味（当院はあるので必要）。
- 基準を届け出た・算定を始めた・体制を変えたら、この表と掲示物を同時に直す。

**最終整理: 2026-10-10**（令和8年度改定後の告示・通知で確認。原文は厚労省サイトに接続できず、通知を引用している knowlety.jp で読んだ）

### 掲示不要と判断したもの

- **外来・在宅ベースアップ評価料（Ⅰ）**：個別の掲示要件なし。#1 の施設基準一覧に載せれば足りる。
- **機能強化加算**（「かかりつけ医機能」の掲示）：地域包括診療加算・地域包括診療料などの届出が前提。当院は届け出ていないので算定も掲示もしない。
- **サーベイランス強化加算**：個別の掲示要件なし。受理されたら #1 に追加する。
