# filings — 行政手続き・届出

厚生局・保健所・自治体・医師会などへ提出する届出と申請を、提出先ごとに管理する。
提出したもの（控え）と、そこに至る経緯を残すのが目的。

## ディレクトリの決まり

```
filings/
  _shared/                    使い回す素材（送付状テンプレートなど）
  <提出先>/
    README.md                 窓口情報・提出方法・口頭回答の蓄積
    YYYY-MM-<英語スラッグ>/   案件ごとに1ディレクトリ
      README.md               経緯・提出日・結果
      <提出物>.docx / .pdf    実際に提出したもの
      送付状.html
      original/               入手時の空様式・記載例（版の証跡）
```

- 案件ディレクトリは `YYYY-MM-英語スラッグ`（例 `2026-09-phone-change`）。
- **提出物のファイル名は日本語**。そのまま相手の目に触れるため。
- **提出したPDFは必ず残す**。「いつ何を出したか」は後から必ず必要になる。
- **電話で聞いた内容は日付つきで案件のREADMEに書く**。口頭回答はここにしか残らない。
- 様式は改定されるので、案件ごとに `original/` へ入手時の版を置く。次回は必ず最新版を取り直す。
