# 各論 IV 心因性めまい

- **出典**: 日本神経治療学会「標準的神経治療：めまい（2020）」神経治療 37(5):769–811, 2020 — B 各論 IV（p.802–807、執筆：清水謙祐）
- **原文**: https://www.jstage.jst.go.jp/article/jsnt/37/5/37_769/_pdf/-char/ja
- **発行**: 2020
- **確認日**: 2026-09-14

うつ病患者のうち、最初に精神科を受診するのは約1割で、**内科を最初に受診する人が64.7%と最も多い**。内科医は、めまいに併存する精神疾患と自殺リスクへの対応を求められる。執筆者は耳鼻咽喉科と精神科の両方の専門医。

---

## 1. 心因性めまいの考え方

### 定義（3つの捉え方）
1. めまい疾患に精神疾患が併存した場合（執筆者の定義）
2. 併存した精神疾患がめまい疾患と関連する場合
3. 機能性めまい（構造・細胞レベルの異常がない）、特に PPPD を心因性と考える場合

### 併存の頻度
- めまい患者の68.3%に急性の精神障害があったという報告がある。執筆者の症例では **67.8%（689/1016）** に精神疾患を認めた〔**エビデンスレベル IVa**〕

### Dieterich・Staab らの分類
| 分類 | 内容 |
|---|---|
| A 構造性・細胞性 | メニエール病、前庭神経炎、BPPV、脳梗塞など、細胞レベルの障害がある |
| B 機能性 | 細胞レベルの障害はないが機能的な障害がある（PPPD を含む） |
| C 精神性 | 精神疾患全般 |

A・B・C はそれぞれ単独でもめまいを起こし、様々な形で併存しうる。

### 心理テスト
- 不安：STAI、うつ：SDS、不安とうつ：**HADS**、認知機能：HDS-R、MMSE
- 精神疾患には重症のイメージがあり受け入れにくいので、実施前に「軽い精神的な不調がある」ことを十分に説明する

## 2. 主な病態

### PPPD（持続性知覚性姿勢誘発めまい）
- 恐怖性姿勢めまい、慢性自覚性めまい、視性めまいなどの重なる部分を整理した新しい疾患概念。**2018年に ICD-11 に収載**された、機能性めまいの中心的な疾患
- 本章での要約：①初回発作から**3か月以上** ②**1か月に15日以上**めまいがある ③**立位・体動・視覚刺激のすべてで悪化**する。ヒステリーは含まない
- 治療：前庭リハビリテーション、認知行動療法、SSRI・SNRI〔**グレード B**〕。不眠を伴えば睡眠の治療〔**C1**〕。執筆者は NaSSA をよく使う〔**C1**〕

### 片頭痛関連めまい
- 片頭痛の治療でめまいも軽くなる例がある。執筆者の症例では精神疾患の併存率が **87.5%（28/32）** と高く、めまい・頭痛・うつはよく併存する

### 内リンパ水腫（メニエール病・遅発性内リンパ水腫）
- 発症や悪化にストレスが関わり、不安障害の合併が多い〔**エビデンスレベル IV**〕。メニエール病患者で睡眠障害が脳波で確認されている
- 執筆者の症例では、内リンパ水腫の **72.9%** に精神疾患が併存（めまい全体の67.8%より高い）
- 向精神薬が効果的なことはよく知られており、睡眠障害の改善でメニエール病が良くなる例もある〔**グレード C1**〕

## 3. めまいに関連する精神疾患（ICD-10）

| 疾患 | 要点 | 治療 |
|---|---|---|
| **恐怖症性不安障害**（F40） | 最も多い。めまいへの不安は対象がある「恐怖」で、予期不安を伴う | 不安の説明、段階的な曝露療法〔B〕 |
| **全般性不安障害**（F41.1） | 対象のない漠然とした不安が6か月以上。自律神経症状 | SSRI〔B〕 |
| **パニック障害**（F41.0） | 数分のパニック発作（動悸・発汗・震え・息苦しさ・**めまい感・ふらつき・頭が軽くなる感じ**）を繰り返し、救急外来に何度も来る。放置すると自殺リスクが上がる | 適切な治療が必要 |
| 適応障害（F43.2） | ストレスによる不安・抑うつ・行動異常。抑うつが14日以上続けばうつ病の基準を満たす | 休養 |
| 身体表現性障害・解離性障害 | 身体的異常がないのに不調を訴え続ける／ストレスと身体症状が関連する | 訴えを聞きすぎないほうがよい場合がある。疾病利得があると治療に抵抗する |
| **うつ病・双極性障害** | めまいを含む様々な身体症状が出る。**抗うつ薬で躁転しうる**。軽躁は「うつが治った」と誤解されやすい | 治療が難しければ精神科に相談。**自殺念慮があればすみやかに精神科へ紹介** |

## 4. 治療

### めまい疾患の治療
- 精神疾患があっても、めまいの治療（内服・理学療法・手術・前庭リハ）の適応外にはならない
- うつ病の患者に前庭リハを行うのも禁忌ではない。前庭リハでうつ（SDS スコア）が改善した報告もある〔**IVa、C1**〕

### 精神的ケア
- 軽い不安障害は説明だけで安心することがある
- ストレスの原因を探るより、**今の状態でどう日常生活に適応していくか**に重点を置いたほうがうまくいく場合がある
- 本人の好きなこと・興味のあることを、本人のペースでできるようにしていく

### 向精神薬の使い方
- まず内科の治療を行い、それでも良くならず、精神科への紹介は不要と判断した場合に、**同意を得てから**使う
- 医師と患者が一緒に治療方針を決める **shared decision making**〔**グレード B**〕

### ベンゾジアゼピン
- **頓用でも常用量依存が起こりうる**。使うしかない場合は依存リスクを説明し、できるだけ短期間にする。高齢者はせん妄に注意
- 添付文書では、すべての抗不安薬で自動車運転をさせないよう注意喚起されている
- **整理のしかた**：多剤併用なら半減期の長い薬にまとめて種類を減らす → 2〜4週ごとに少しずつ減量 → 最後は1〜2日おきにして、様子を見ながら中止

### 抗うつ薬
- 双極性、人格障害、発達障害、自殺リスク、易怒性を見極めてから使う
- **抑うつが強くても、早口で易怒性や攻撃性があれば、抗うつ薬を単独で出さない**
- SSRI は少しずつ減らして中止する

## 外来での使いどころ（自院運用メモ）

- **慢性のふらつきの多くに精神的な要素が絡む**（めまい患者の約2/3）。器質的疾患を除外した後は、HADS などで不安・うつを評価する
- **PPPD を疑う問診**：3か月以上ほぼ毎日／立っている・歩いている・人混みやスクロール画面で悪化／きっかけとなるめまい（BPPV、前庭神経炎など）が先行。治療は前庭リハ＋SSRI（sertraline、escitalopram）が中心で、ベンゾジアゼピンは避ける
- **パニック発作としての「めまい」**：動悸・息苦しさ・震えを伴う数分の発作なら、まずこれを考える
- **自殺念慮の確認をためらわない**。あれば精神科へ紹介する
- **本章の PPPD の記載は要約版**。正式な診断基準は、日本めまい平衡医学会による Bárány 学会基準の和訳（Equilibrium Res 78:228–229, 2019）で確認する
