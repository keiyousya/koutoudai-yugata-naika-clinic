# 第12章 糖尿病性大血管症

- **出典**: 日本糖尿病学会『糖尿病診療ガイドライン2024』12章（p.243–277、うち p.261–271 文献、p.272–277 アブストラクトテーブル）
- **原文**: https://www.jds.or.jp/uploads/files/publications/gl2024/12.pdf
- **発行**: 2024-05-30
- **確認日**: 2026-09-13

構成は「リスク管理の開始時期・対象（Q12-1, 12-2）→ 生活習慣（CQ12-3）→ 血糖・SGLT2i・GLP-1RA（CQ12-4〜12-7）→ 血圧・脂質・抗血小板薬（CQ12-8〜12-10）」。

- **定義（本章）**: 大血管症＝糖尿病に伴う動脈硬化症で、**脳卒中・虚血性心疾患・末梢動脈疾患（PAD）**
- **評価指標**: 脳卒中・心筋梗塞・心血管死（**3-point MACE**）。PAD への介入評価は11章参照

## Q12-1 大血管症の予防のために必要なリスク管理をいつからどのように始めるか

**ポイント**: IGT・高血圧症・脂質異常症・肥満症・CKD を**早期に発見し包括的に管理**することが推奨される。

- 糖尿病・高血圧・脂質異常症・CKD・喫煙を**包括的に、早期から厳格に**コントロール
- **Steno-2**（微量アルブミン尿を有する2型）: 7.8年の初期介入後、21年観察で包括的管理により**寿命7.9年延伸**
- IGT・インスリン抵抗性は**糖尿病発症前から**心血管リスクを上昇させる
- リスク層別化に有効との報告: 頸動脈エコー、血流依存性血管拡張反応（FMD）、冠動脈CT
- PAD スクリーニング: **ABI・TBI は無症状の糖尿病でも推奨**

### 冠動脈疾患スクリーニング（日循・JDS 合同コンセンサスステートメント 2020）

| 対象 | 対応 |
|---|---|
| 2型で **40歳未満かつ罹病10年未満** | 喫煙・CKD・動脈硬化性疾患既往などを評価し、**ハイリスクなら** PWV/CAVI、ABI、頸動脈エコー、非造影冠動脈CT などを行う |
| **40歳以上 または 罹病10年以上** | 症状がなくとも**年1回の安静時心電図**＋上記検査を検討 |
| 検査異常あり | 循環器専門医へコンサルト。造影冠動脈CT、負荷心エコー、負荷心筋シンチで精査 |

- 実診療では狭心症症状・間欠性跛行・脳虚血前駆症状を**丹念な問診で拾い上げる**。無症候でも定期的に安静時心電図

### 心不全

- 2型糖尿病は心不全の独立したリスク。発症リスクは**男性で2倍、女性で5倍以上**
- 一般的リスク因子: 冠動脈疾患、弁膜症、高血圧、糖尿病、肥満、喫煙。2型糖尿病では年齢、インスリン使用、虚血性心疾患、クレアチニン上昇
- 多因子介入で心不全入院を**7割抑制**
- HFrEF・HFpEF ともに合併しやすい
- **スクリーニング**: 症状観察＋**年1回の胸部X線と心電図**
- **精査基準**: 症状・所見異常、または **BNP ≧100 pg/mL / NT-proBNP ≧400 pg/mL** → 循環器専門医へ

## Q12-2 リスク管理をどのような糖尿病患者に行えば大血管症の抑止に有益か

**ポイント**: **すべての糖尿病症例が対象**となり得る。ただし**高齢者や血管症の進行例では低血糖・低血圧に留意**。

- リスクファクターは肥満症を背景としたメタボリックシンドロームとして集積しやすく、集積例ほど高リスク → 厳格な包括的管理でリスク低下が期待される
- 心血管イベントリスクを上昇させる因子: **家族性高コレステロール血症、非心原性脳梗塞、PAD、細小血管合併症（網膜症・腎症）、メタボリックシンドローム、喫煙継続**
- **微量アルブミン尿**は腎症診断のみならず血管内皮障害を反映し生命予後の予測因子 → **定期測定を推奨**
- ハイリスク例対象の大規模試験では、**血管症進行例・虚弱高齢者への厳格な血糖・血圧管理が低血糖・低血圧を招き、イベントや予後を悪化**させた報告あり

## CQ12-3 生活習慣と肥満の改善は大血管症のリスクファクターの軽減に有効か

> 糖尿病患者における生活習慣と肥満の改善は主要心血管イベントのリスクファクターを軽減するため推奨される。

- **推奨グレードA**（合意率100%）
- エビデンスレベル: ステートメントに付記なし（根拠文献 Metz 2000、Esposito 2009、Look AHEAD 2010 はいずれも［レベル1］）

- リスクファクター: 耐糖能障害、高血圧症、脂質異常症、肥満症、CKD、運動不足、食塩過剰、喫煙
- 生活習慣改善で肥満症・IGT・高血圧・脂質異常症が改善し、心機能改善、心不全を含むイベント減少の報告が多い
- 一般住民コホートで関連が示された因子: 食塩摂取、魚食、地中海食、食物繊維、身体活動強度、喫煙
- 一方、より長期の追跡では**数年間の生活介入がイベント発症率に影響しなかった**との報告もあり、結論は出ていない
- **Look AHEAD**（BMI ≧25、インスリン療法中は ≧27 の2型 5,145人）: 主要評価項目（心血管死・MI・脳卒中・入院を要する狭心症）は**抑制せず**。体重・血圧・脂質は改善。サブ解析で**10%の体重減少が死亡・心不全リスクを有意に軽減**
- Steno-2、JDCS、J-DOIT3 では生活習慣改善を含む包括的介入が大血管症リスクを減らした可能性
- 高度肥満への**肥満外科治療は心血管イベントを減少** → 肥満是正も大血管症予防に有効と示唆
- 注意: 減量効果が得られずイベントが増える場合がある。**意図しない体重減少は予後を悪化**

### 根拠 RCT（アブストラクトテーブルより）

| 試験 | 対象 | 結果 |
|---|---|---|
| Metz 2000 | BMI ≧25 の脂質異常症・高血圧（183人）＋2型（119人）、52週 | 食事介入で体重・血圧・TC・LDL-C・HbA1c・QOL 改善 |
| Esposito 2009 | BMI ≧25 の未治療新規発症2型 215人、4年 | 低炭水化物地中海食で薬物治療開始率・体重・血糖・CVリスク因子が有意に減少（vs ADA 低脂肪食） |
| Look AHEAD 2010 | 上記 5,145人、4年 | 強化介入で体重・運動適応性・血糖・血圧・脂質が改善 |

## CQ12-4 大血管症に血糖コントロールは有効か

> 大血管症の発症抑制に糖尿病発症早期からの良好な血糖コントロールが推奨される。

- **推奨グレードA**（合意率100%）
- エビデンスレベル: ステートメントに付記なし（根拠文献 Roussel 2018 MA［レベル1＋］、UKPDS 35［レベル2］、DCCT/EDIC 2015［レベル1］）

### 高血糖とリスクの数値

| 知見 | 数値 |
|---|---|
| UKPDS（2型） | HbA1c 1%低下で**心筋梗塞 −14%**（ほか糖尿病関連イベント −21%、糖尿病関連死 −31%、細小血管症 −37%） |
| メタ解析 | HbA1c 1%上昇で心血管疾患 **1型 +15%、2型 +18%** |
| メンデルランダム化 | 血糖 18 mg/dL 上昇で虚血性脳卒中リスク比 **1.48** |
| 血糖降下薬 RCT のメタ解析 | HbA1c 約1%低下で**26〜33%のリスク減少** |
| Roussel 2018 MA | 推定高血糖曝露期間差と複合 CV イベントが相関（r²=0.89） |

- 強化療法: 総死亡・心血管死・脳卒中は抑制せず、**非致死的（致死的）心筋梗塞と下肢切断を低下**
- 1型でも厳格管理が心血管イベントを減らすことが示唆

### Legacy effect（metabolic memory）

- **VADT**: 5.6年の強化療法は介入直後は有意差なし → 通常治療移行後約5年で有意に CV イベント抑制
- **DCCT/EDIC**（1型 1,441人、27年追跡）: 15年までは総死亡減少なし、その後有意に減少（HR 0.67）
- 7 RCT メタ解析: **罹病期間が短く CV 既往がない患者**で MACE 抑制が顕著 → 早期介入が重要

### 低血糖

- 強化療法は低血糖リスクを上昇。**重篤な低血糖・不整脈**は総死亡/CVD の重要なリスク因子。高齢者で特に注意
- **J-DOIT3** は厳格管理でも重篤低血糖が極めて少なく、これが大血管症抑制に寄与した可能性

### 薬剤別

| 薬剤 | 大血管症への影響 |
|---|---|
| メトホルミン | 肥満2型で抑制効果（UKPDS 34）。最近のメタ解析では単独療法の効果は認めず（追跡が短いためか） |
| α-GI | 低下を示唆する報告あるが十分なエビデンスなし |
| DPP-4 阻害薬 | 大規模試験はいずれも**非劣性のみ**、低下は示さず（一部は国内用量と異なる） |
| メトホルミン＋ピオグリタゾン | 低下を示唆する報告あるが十分なエビデンスなし |
| 持効型インスリン | **ORIGIN**（境界型/早期2型 12,500人）でリスク増加なし |
| SGLT2i・GLP-1RA | CQ12-5〜12-7 参照 |

- Steno-2: 厳格な血糖管理を含む多因子介入で、21.2年追跡後に**医療費抑制**

## CQ12-5 SGLT2 阻害薬は大血管症の抑制に有効か

> 大血管症の二次予防に SGLT2 阻害薬が推奨される。

- **推奨グレードA**（合意率100%）
- エビデンスレベル: ステートメントに付記なし（根拠文献 EMPA-REG OUTCOME・CANVAS・CVD-REAL・DECLARE-TIMI 58［レベル1］、Zelniker 2019 MA［レベル1＋］）

### 主要 CVOT

| 試験 | 薬剤・対象 | 結果 |
|---|---|---|
| **EMPA-REG OUTCOME** | エンパグリフロジン、CV 高リスク2型 7,028人（二次予防） | MACE HR 0.86。心血管死 HR 0.62、心不全入院 HR 0.65、全死亡 HR 0.68 |
| **CANVAS** | カナグリフロジン、10,142人（一次予防約3割） | MACE HR 0.86。アルブミン尿進行 HR 0.73、腎複合 HR 0.60。**約7割が日本の常用量以上** |
| **DECLARE-TIMI 58** | ダパグリフロジン、17,160人（一次予防約6割） | MACE は優越性なし（HR 0.93）。**心血管死/心不全入院 −17%**（HR 0.83） |
| **CREDENCE** | カナグリフロジン、CKD 合併2型 | 心血管死・MI・脳卒中の複合、および心不全入院リスク **−20%** |
| **CVD-REAL** | 欧州6ヵ国 139万人のリアルワールド | 心不全入院 HR 0.61、全死亡＋心不全入院 HR 0.54 |

- 各試験で共通して**心不全入院を減少**
- CANVAS・CREDENCE 解析: **一次予防と二次予防で同等に有効**
- EMPA-REG・CREDENCE サブ解析: **アジア人でも有効**
- 高齢者: エンパグリフロジンは心血管死・心不全入院を減少、腎アウトカム改善。メタ解析で65歳以上でも**CV イベント −17%**（65歳未満と同等以上）
- DAPA-CKD 解析: KDIGO リスクカテゴリーにかかわらず心保護効果

### メタ解析（EMPA-REG・CANVAS・DECLARE、34,322人）

- **MACE −11%**（HR 0.89）、心血管死 −16%、心筋梗塞 −11%。効果は**動脈硬化性疾患既往例で強い**（Zelniker 2019 では既往例のみで認められた）
- 心血管死＋心不全入院 −23%（HR 0.77）。心不全・CVD 既往の有無で不変
- EMPA-REG 追加解析: 致死的/非致死的 MI −21%、冠動脈 intervention −20%、心不全入院 −42%
- **脳卒中は抑制されず**（5 RCT メタ解析でも脳梗塞サブタイプを問わず有意差なし。出血性脳卒中には保護的な可能性）
  - 機序として、動脈硬化への直接作用より体液量減少などヘモダイナミクス効果（心負荷軽減、交感神経抑制、降圧、腎保護）が想定
- ネットワークメタ解析（21試験・17万人）: **GLP-1RA と同等、DPP-4 阻害薬より CV リスク −12%**
- 日本人疫学データ: 薬剤間で循環器疾患発症率は同等 → **クラスエフェクト**を示唆

→ 一次・二次予防を問わず、CKD 3期以降、アジア人、高齢者でも CV イベント抑制に有効

### 注意

- ケトアシドーシス増加、脱水、サルコペニアの懸念
- 「高齢者糖尿病診療ガイドライン2023」: 高齢者・ADL 低下・アドヒアランス不良では**慎重投与**
- **発熱時・摂食不良時は休薬を考慮**（JDS「SGLT2 阻害薬の適正使用に関する Recommendation」）

## CQ12-6 SGLT2 阻害薬は心不全に有効か

> 心不全の進行予防に SGLT2 阻害薬が推奨される。

- **推奨グレードA**（合意率100%）
- エビデンスレベル: ステートメントに付記なし（根拠文献 DAPA-HF 関連・EMPEROR-Reduced・EMPEROR-Preserved［レベル1］、Zelniker 2019［レベル1＋］）

- EMPA-REG・CANVAS・DECLARE で心血管死・心不全入院を有意に低下。**一次・二次予防で一貫**、人種・地域サブ解析でも同様
- 欧米 GL: 心不全・CKD 合併2型に積極使用を推奨。日本の「2型糖尿病の薬物療法のアルゴリズム」（2023）でも**心不全・心血管疾患合併時に優先**

### 心不全患者対象試験（糖尿病の有無を問わない）

| 試験 | 対象 | 結果 |
|---|---|---|
| **DAPA-HF** | HFrEF（LVEF ≦40%、NYHA II〜IV、NT-proBNP 上昇）4,744例 | 心不全増悪 or 心血管死: **16.3% vs 21.2%、HR 0.74**（95%CI 0.65–0.85）。心不全増悪のみ 9.7% vs 13.4%、HR 0.70。外来での心不全悪化 −26%。虚血性/非虚血性、糖尿病有無を問わず有効 |
| **EMPEROR-Reduced** | HFrEF（LVEF ≦40%）3,730例 | 心血管死 or 心不全入院を低下（糖尿病有無を問わず） |
| **EMPEROR-Preserved** | HFpEF（LVEF >40%）5,988例 | 心血管死 or 心不全入院の複合リスクを有意に低下（糖尿病有無を問わず） |

- ダパグリフロジン・エンパグリフロジンは**慢性心不全治療薬として承認**、国内外の心不全 GL で**クラスI**
- HFpEF 13試験メタ解析: 心血管死は有意差なし、**心不全入院は有意に減少**
- ダパグリフロジンで KCCQ（心不全 QOL）が有意改善
- アメリカ心不全 GL 2022 で HFpEF 治療薬に組み込み
- 機序（未解明）: 糖代謝改善・肥満是正、細胞外容積減少、心室負荷低下、降圧、酸化ストレス・慢性炎症の改善 → リモデリング抑制の期待

## CQ12-7 GLP-1 受容体作動薬（GLP-1RA）は大血管症の進行抑制に有効か

> 大血管症の進行抑制に GLP-1RA が推奨される。

- **推奨グレードA**（合意率100%）
- エビデンスレベル: ステートメントに付記なし（根拠文献 SUSTAIN-6・LEADER・REWIND［レベル1］、Sattar 2021 MA［レベル1＋］）
- ※ 4項目判定のうち**費用は「いいえ」**（コスト削減を証明した研究なし）

### 主要 CVOT

| 試験 | 薬剤 | MACE |
|---|---|---|
| **LEADER** | リラグルチド 1.8 mg/日（9,340例） | **13.0% vs 14.9%、HR 0.87**。心血管死・全死亡も抑制 |
| **SUSTAIN-6** | セマグルチド週1回（3,297例） | **6.6% vs 8.9%、HR 0.74** |
| **REWIND** | デュラグルチド 1.5 mg 週1回（50歳以上 9,901例） | **12.0% vs 13.4%、HR 0.88**。脳卒中を抑制 |
| HARMONY Outcomes | アルビグルチド | 抑制 |
| AMPLITUDE-O | エフェグレナチド | 抑制（**Exendin-4 骨格で初のイベント抑制**） |
| ELIXA | リキシセナチド | 抑制なし |
| EXSCEL | エキセナチド | 抑制なし |
| PIONEER 6 | 経口セマグルチド | 有意差なし |

- 骨格: リキシセナチド・エキセナチド・エフェグレナチドは Exendin-4、他はヒト GLP-1
- 試験間で抑制される項目が異なる（LEADER は心血管死、REWIND は脳卒中）

### メタ解析（上記8試験、60,080人）

| アウトカム | 抑制 |
|---|---|
| MACE | −14%（HR 0.86） |
| 心血管死 | −13% |
| 心筋梗塞 | −10% |
| 脳卒中 | −17% |
| 全死亡 | −12%（HR 0.88） |
| 心不全入院 | −11%（HR 0.89） |

- 構造による差なし。**重症低血糖・網膜症・膵副作用の増加なし**
- アジア人 vs 白人の CV イベント HR **0.68 vs 0.87** → アジア人でベネフィットが大きい可能性
- 65歳以上、75歳以上でも抑制作用あり
- **SGLT2i vs GLP-1RA**: 3P-MACE に差なし。両者とも DPP-4 阻害薬よりイベント抑制。**非致死性脳卒中の低下は GLP-1RA のみ**、**重篤な腎イベント抑制は SGLT2i**
- 両薬の有用性は高齢者、アジア人、ASCVD 確立例、罹病期間が長くコントロール不良例でより顕著
- 英国データ（2型33万人）: MACE の OR は GLP-1RA 0.93、SGLT2i 0.82、**併用 0.70** → 併用が一次予防に有効な可能性
- 台湾データ: 長期使用・高用量で虚血性脳卒中入院リスク低下

## CQ12-8 大血管症に血圧コントロールは有効か

> 大血管症の抑制に血圧コントロールが推奨される。

- **推奨グレードA**（合意率100%）
- エビデンスレベル: ステートメントに付記なし（根拠文献 UKPDS［レベル2］、Emdin 2015 MA・Reboldi 2011 MA［レベル1＋］）
- ※ 4項目判定のうち**費用は「いいえ」**（日本での費用対効果報告なし）

- 糖尿病患者で**収縮期血圧 10 mmHg 低下 → 総死亡 −13%、CV イベント −11%、脳卒中 −27%**（Emdin 2015、40 RCT・10万人）
  - 開始時 140/90 以上で効果あり。140/90 未満では脳卒中のみ有意
- UKPDS 観察: SBP 10 mmHg 低下で糖尿病合併症 −12%、糖尿病関連死 −15%、MI −11%。**SBP <120 で最もリスク低**
- Reboldi 2011 MA（73,913人）: SBP 5 mmHg 低下ごとに脳卒中 −13%、DBP 2 mmHg 低下ごとに −11.5%。**MI は降圧度と関連なし**
- 最近のメタ解析: 降圧による抑制は**脳卒中でのみ**、総死亡・冠動脈疾患への影響は少ない可能性
- 脳卒中リスクは SBP 115 mmHg まで直線的に低下。その他の CVD には **J カーブ**があり、**SBP <130 でかえってリスク上昇**との報告
- **ONTARGET**: 血圧 ≧160 と <120 がいずれも CV イベント・死亡リスクと関連 → 至適血圧管理が重要

### 厳格降圧試験

| 試験 | 対象 | 結果 |
|---|---|---|
| **ACCORD-BP** | 糖尿病、SBP 120 vs 140 目標 | 大血管症発生率に差なし。サブ解析で標準血糖療法群では複合 CV 低下（HR 0.76）、強化血糖療法群では低下せず（HR 1.06） |
| **SPRINT** | 非糖尿病 | 厳格降圧で有意にリスク低下（HR 0.75）。空腹時血糖 100 以上/未満、年齢で差なし |

- → **目標値設定にはさらなるエビデンスが必要**
- 積極的降圧は**失神・低血圧を有意に増加** → 注意（詳細は14章）

## CQ12-9 大血管症に脂質コントロールは有効か

> ❶ 大血管症の一次・二次予防に LDL-C 低下療法が推奨される。

- **推奨グレードA**（合意率100%）

> ❷ 高 TG 血症または低 HDL-C 血症を合併する糖尿病患者において、フィブラート系薬・EPA の投与は心血管疾患の発症抑制に寄与し得る（CQ15-8 参照）。

- **推奨グレードB**（合意率89%）。TG 低下療法は試験で結果が一定せずサブ解析も多いため弱い推奨
- エビデンスレベル: ステートメントに付記なし（根拠文献 de Vries 2014/2012 MA［レベル1＋］、FIELD・JELIS・REDUCE-IT・Yang 2023 MA・ACCORD-LIPID サブ解析［レベル2］）
- ※ 4項目判定のうち**費用は「いいえ」**

### LDL-C 低下療法

- スタチンで **LDL-C 37 mg/dL 低下ごとに総死亡 −9%、冠動脈イベント −22%、脳卒中 −21%**。非糖尿病と同程度、**閾値は確認されていない**
- 一次予防（4 RCT・10,187人）: スタチンで主要 CV イベント **−25%**（RR 0.75）
- 二次予防（de Vries 2014）: 通常量スタチンで −15%（RR 0.85）、**高用量は通常量よりさらに −9%**（RR 0.91）
- **IMPROVE-IT**（ACS 10日以内、シンバスタチン＋エゼチミブ）糖尿病サブ解析: 7年間の CV イベント有意減少（HR 0.85）
- **維持透析中の2型糖尿病へのスタチンはエビデンスなし**
- **FOURIER**（エボロクマブ、MI・脳梗塞・PAD 既往 27,000例）: スタチンへの上乗せ効果、糖尿病有無を問わず有効
- **EMPATHY**（網膜症を有する日本人2型）: LDL-C ≦70 目標 vs 100〜120 目標で複合 CV に有意差なし。目標達成者のサブ解析では強化群で有意にリスク減少
- CARDS・Steno-2 では強化群 LDL-C 平均 81.6 / 86 mg/dL でイベント抑制 → 一次予防で **<100 mg/dL** への低下でリスク減少の知見

### LDL-C 管理目標（動脈硬化性疾患予防ガイドライン2022）

| 区分 | LDL-C 目標 |
|---|---|
| 一次予防の糖尿病で **PAD、細小血管症合併（網膜症・腎症・神経障害）、喫煙あり** | **<100 mg/dL** |
| 糖尿病を有する**冠動脈疾患二次予防** | **<70 mg/dL** |

（詳細は「糖尿病に合併した脂質異常症」の章）

### TG 低下療法（フィブラート・n-3 系脂肪酸）

| 試験 | 内容 | 結果 |
|---|---|---|
| **FIELD** | フェノフィブラート、2型 9,795人 | 主要冠動脈イベント抑制なし。非致死的 MI（HR 0.76）・血行再建は減少。スタチン併用はプラセボ17%、フィブラート群8%のみ |
| VA-HIT | ゲムフィブロジル（約3割糖尿病） | イベント −28% |
| **ACCORD-LIPID** | スタチン＋フェノフィブラート | 抑制なし。**TG ≧204 かつ HDL-C <34** のサブ解析で抑制傾向 |
| **PROMINENT** | ペマフィブラート、TG ≧200・HDL-C <40 のスタチン使用2型 10,497人 | **主要 CV イベント抑制なし** |
| ORIGIN / ASCEND | n-3 系脂肪酸 | 低下なし |
| **JELIS** | スタチン治療中高 LDL-C への EPA 追加（糖尿病/IGT サブ解析） | **冠動脈イベント −22%** |
| **REDUCE-IT** | スタチン治療中高 TG への高用量 EPA（6割糖尿病） | 複合 CV イベント有意減少（−25%） |
| **STRENGTH** | 高用量 EPA/DHA 4 g/日（7割糖尿病、13,078人） | 抑制なし |

- メタ解析: 高 TG で −12%、**高 TG＋低 HDL-C で −29%**
- コクラン: フィブラートの複合血管イベント抑制あり、脳卒中・スタチン内服例では効果なし
- 19試験・91,285人メタ解析（PROMINENT・STRENGTH 含む）: TG 低下療法で CV イベント **−9%**（HR 0.91）。脳卒中・死亡は抑制なし
- まとめ: **スタチン非使用下の高 TG・低 HDL-C ではフィブラートに期待**。スタチン内服中は ACCORD-LIPID サブ解析（フィブラート）、JELIS・REDUCE-IT（EPA）が根拠

## CQ12-10 大血管症に抗血小板薬は有効か

> 大血管症の二次予防にアスピリンの投与が推奨される。

- **推奨グレードA**（合意率100%）
- エビデンスレベル: ステートメントに付記なし（根拠文献 Antithrombotic Trialists' Collaboration MA［レベル2］）

### 二次予防

- 心血管既往者への抗血小板薬の有効性は多数の研究・メタ解析で確立
- 糖尿病のみ対象の二次予防 RCT はないが、RCT 中の糖尿病患者メタ解析で**アスピリンにより総死亡が有意に減少**
- ATT（糖尿病 17,522人）: 一次予防効果なし、**二次予防効果あり（RR 0.82）**
- ADP 受容体阻害薬（クロピドグレル・チクロピジン・プラスグレル）: CATS、TASS、CAPRIE、PRoFESS、TRITON-TIMI38 の糖尿病サブ解析はあるが**一定の結論なし**
- **シロスタゾール**: 日本人二次予防試験サブ解析で脳卒中二次予防に有益な可能性

### 一次予防 → 推奨されない

| 試験 | 結果 |
|---|---|
| **JPAD**（日本人2型、少量アスピリン） | CV イベント −20% も**有意差なし** |
| 糖尿病対象の他の3 RCT、サブ解析、メタ解析 | 一次予防効果示されず |
| **JPPP** 糖尿病サブ解析（60歳以上の日本人 14,464人中 4,903人） | 一次予防効果示されず |
| **ASCEND**（糖尿病一次予防） | CV イベントは有意減少したが**出血も有意に増加** |

- 効果ありとの報告があるサブグループ: 男性、65歳以上、食事療法のみ、高血圧例
- 糖尿病ではアスピリンによる**頭蓋外出血リスクが非糖尿病より55%高い**
- → **糖尿病患者の一次予防目的のアスピリン投与は推奨されない**

## 外来での使いどころ（自院メモ）

- **40歳以上 or 罹病10年以上**の2型は、無症状でも**年1回の安静時心電図**。PWV/CAVI・ABI・頸動脈エコーを検討し、異常あれば循環器紹介
- 心不全スクリーニングとして**年1回の胸部X線＋心電図**。BNP ≧100 / NT-proBNP ≧400 なら循環器へ
- **尿中アルブミンは定期測定**（腎症だけでなく心血管予後マーカー）
- **CVD 既往・心不全合併・CKD 合併 → SGLT2i を優先**。発熱・食事摂取不良時の休薬（シックデイ）指導をセットで
- ASCVD 既往や脳卒中リスクが気になる例、アジア人・高齢者でも **GLP-1RA は MACE 抑制が期待**できる（脳卒中抑制は GLP-1RA 側）
- LDL-C 目標: **一次予防で PAD・細小血管症・喫煙あり → <100、冠動脈疾患既往 → <70**。スタチン下で高 TG・低 HDL-C が残れば EPA/フィブラートを検討（推奨B）
- **一次予防でのアスピリンは出さない**。二次予防例で服用継続を確認
- 高齢・フレイル・血管症進行例では**厳格な血糖・降圧を追わず低血糖・低血圧・失神を避ける**
