## 1. 製剤の選択（2a・2b）

| 質問 | 推奨（要約） | 強さ・質 |
|---|---|---|
| **2a** 先発品とジェネリック | **先発品、または同じジェネリックを続ける**（「特定できる同じ製剤」を維持する）。製剤の切り替えは実投与量の変動につながりうるので原則避ける | 一般集団: Weak / Low。**フレイル・高リスク甲状腺癌・妊婦: Strong / Low**。**乳幼児期の機能低下症: Strong / Moderate** |
| **2b** ソフトゲル（グリセリンに溶かしたゼラチンカプセル） | PPI 併用時やコーヒーと一緒の服用で吸収がよいとする小規模研究はあるが、長期の対照研究がなく、**これらの状況での使用は推奨しない**。**添加物アレルギーが疑われるまれな例では切り替えを考えてよい** | Weak / Low |

解説の要点:
- FDA の同等性基準は健常人に **600 μg を単回投与**した AUC・Cmax で判定（90%CI が 80〜125%）。**TSH を評価していない**点、薬理量での判定である点が問題とされ、ATA・内分泌学会・AACE が2004年に懸念を表明
- 12.5% の用量差は薬物動態試験で区別できなかったという報告がある
- FDA は2007年から**表示力価の 95〜105%**を有効期間中保つよう要求（以前は 90〜110%）
- 小児の RCT で、FDA が互換とした先発品とジェネリックで TSH に差が出た（先天性で差）
- 推奨の根拠は「特定の製品が優れている」ことではなく「**同等とされた製品でも治療上同等とは限らず、切り替えで TSH が動きうる**」こと
- 液剤（アンプル入り）は当時米国になく、肥満手術後や朝食と一緒の服用で吸収がよいという症例報告・非対照研究があるのみ

## 2. 服薬タイミング（3a）

- **食事との同時服用は吸収を落とすので、可能なら毎日一定して「朝食の60分前」か「就寝時（夕食から3時間以上あける）」に飲む**（Weak / Moderate）
- 解説:
  - 吸収部位は空腸・回腸。空腹時の胃酸が重要
  - 食事と一緒だと吸収 64%、空腹時 80%（同位体法）
  - クロスオーバー試験の平均 TSH: **朝食1時間以上前 1.06、朝食と一緒 2.93、就寝時 2.19 mIU/L**。別の二重盲検試験では**朝食30分前より就寝時のほうが TSH が 0.9〜1.6 低い**
  - 吸収のよい順（統合すると）: **朝食60分前 > 就寝時 > 朝食30分前 > 朝食と一緒**。空腹時服用は TSH のばらつきも小さい
  - ただし**アドヒアランスが最優先**。朝食60分前が無理なら就寝時、**毎日同じ条件で続けるなら「朝食30分前」でもよい**（その場合は朝食内容を一定にし、吸収を妨げる食品を避ける）
  - 食物繊維・大豆は症例報告で吸収低下。**エスプレッソコーヒー**は LT4 を吸着して Cmax・AUC を下げる。**グレープフルーツジュースは健常人10人の RCT で大きな影響なし**（※2025 ETA は4時間あけるよう表に載せており、扱いが違う）
  - 服薬タイミングごとのアドヒアランスや長期転帰を比べた研究はない

## 3. 吸収を妨げる薬・サプリ（3b）

- **可能なら、吸収を妨げうる薬・サプリ（炭酸カルシウム、硫酸鉄など）は LT4 と時間をあける。4時間あけるのが慣例だが検証されていない。水酸化アルミニウム・スクラルファートなども同様の可能性があるが研究は不十分**（Weak / 原文表記は「Weak quality evidence」）

原文の表（薬物動態試験・臨床報告）の要点:

| 薬剤 | 原文で示された影響 |
|---|---|
| **炭酸カルシウム**（クエン酸・酢酸 Ca も同様） | 併用で TSH 1.6 → 2.7。健常人で吸収が約20%低下。酸性下で Ca に吸着 |
| **硫酸鉄** | 併用で TSH 1.6 → 5.4（14人）。T4 と鉄が複合体を作る |
| **PPI** | PPI 開始で TSH が上昇（後ろ向き研究）。一方、健常人で1週間の PPI・H2 遮断薬では吸収不変 → **長期使用で問題になる**可能性 |
| **胆汁酸吸着薬**（コレスチラミン、コレセベラム） | 吸着。コレスチラミンは **5時間あけると吸収が最もよい** |
| **リン吸着薬セベラマー** | 吸収が約50%に低下。必要量が増える |
| **アルミニウム含有制酸薬** | TSH 2.6 → 7.2（5人）。症例で 1.1 → 36 |
| **スクラルファート** | 吸収低下・遅延 |
| ラロキシフェン、オルリスタット、陽イオン交換樹脂（ポリスチレンスルホン酸 Na） | 症例報告で TSH 大幅上昇 |
| マルチビタミン | 研究はないが Ca・鉄を含むので吸収低下が予想される |

## 4. 必要量が予想よりずっと多いとき：消化管疾患（3c）

- **LT4 の必要量が予想よりずっと多い場合は、ピロリ菌関連胃炎・萎縮性胃炎・セリアック病などの消化管疾患の評価を考える。見つかって治療したら甲状腺機能と用量を再評価する**（**Strong / Moderate**）
- 解説:
  - 大量の LT4 に反応しない患者で**ピロリ除菌により TSH 30.5 → 4.2**
  - 胃炎（ピロリ・萎縮性）のある人は必要量が**最大34%多い（2.05 vs 1.5 μg/kg/日）**。除菌で TSH 低下、オメプラゾール開始で上昇
  - 抗胃壁細胞抗体陽性ほど必要量が多い。**60歳超の橋本病の45%に慢性萎縮性胃炎**という報告
  - セリアック病（グルテン除去で必要量が減る）、乳糖不耐症、ジアルジア症の症例報告
  - ほかに**加齢**と**高度肥満（BMI >40）**で吸収低下。腸管バイパス後は必要量増加の症例報告がある一方、Roux-en-Y 後も吸収は保たれていたという研究もある（主な吸収部位が回腸のため）

## 5. 製剤切り替え後の再検（3d）

- **製剤（先発・ジェネリックを問わず）を変えたら、定常状態で TSH を再評価する**（Weak / Low）
- 同じ製剤を続けていても服薬状況などで TSH は揺れる点にも注意

## 6. 代謝・結合蛋白に影響する薬（3e）

- **エストロゲン・アンドロゲンの開始/中止後は定常状態で TSH を再評価。チロシンキナーゼ阻害薬の開始時も再評価。フェノバルビタール・フェニトイン・カルバマゼピン・リファンピシン・セルトラリンの開始時も TSH の監視が望ましい**（**Strong / Low**）
- 解説:
  - **肝代謝を誘導**: フェノバルビタール、フェニトイン、カルバマゼピン、リファンピシン、セルトラリン、（イマチニブ）
  - **TKI**（イマチニブ、モテサニブ、ソラフェニブ、スニチニブ、バンデタニブ）: 全摘後患者で大幅な増量が必要になった報告。D3 活性化などが機序
  - **アミオダロン**: D2 阻害で増量が必要になった2例。ヨウ素含有量による機能低下の悪化もありうる
  - **TBG を増やす**（→必要量増）: **エストロゲン**（閉経後女性で TSH 0.9 → 約3.2、12週）、タモキシフェン、ラロキシフェン、クロフィブラート、オピオイド、ミトタン、フルオロウラシル、カペシタビン。エストロゲン以外は TSH への影響が示されていないか症例報告のみ。**体外受精での急なエストロゲン上昇でも TSH が上がる**
  - **アンドロゲン**は TBG を下げる → 減量が必要になりうる
  - 成長ホルモン補充開始時も調整が要ることがある

## 7. アレルギー・不耐（5a）

- **LT4 へのアレルギー・不耐と感じる症状は、用量や製品の変更（ソフトゲルを含む）、鉄欠乏性貧血の治療で対処できることがある。一部はアレルギー専門医へ**（Weak / Low）
- LT4 は体内と同じ分子。開始時の頭痛・動悸・不安などは、**減量してゆっくり増やす**のが妥当。鉄欠乏の是正で症状が消えた報告あり。米国では色素が原因なら **50 μg 錠（無着色）**で対処できる（※米国製品の話）

## 外来での使いどころ（自院メモ）

### 国内の製剤事情との違い（確実な範囲）

- 国内の LT4 は**チラーヂンS（錠・散）が主**。**液剤・ソフトゲルカプセルは国内未承認**なので、2b（ソフトゲル）と 2025 ETA の液剤/ソフトゲル推奨は**当院では選べない**。吸収不良を疑うときは、本GLの解説どおり「**錠剤のまま増量して TSH を追う**」か原因（胃炎・併用薬）を治す
- 「同じ製剤を続ける」（2a・3d）は国内でも当てはまる。**後発品への変更・銘柄変更・錠⇔散の変更をしたら、6週前後で TSH（と FT4）を再検**する
- 散は錠剤を飲めない人・細かい用量調整に使えるが、本GLは散剤については書いていない（米国にない剤形）

### 服薬タイミングの指導

- 基本は「**起床時に水で、朝食まで30分以上あける**」。国内の今日の治療指針も「起床時または就寝前」
- 朝が難しい人（朝食・コーヒーをすぐ摂る、朝に他の薬が多い）には**就寝前（夕食から3時間以上あけて）**を提案してよい（3a）
- **毎日同じ条件で飲むことが最優先**。「朝食後に飲んでいた」人をあわてて変えるより、条件を固定してから TSH を見る。変えたら6週前後で再検
- コーヒー・牛乳・お茶と一緒に飲まない（水で）。国内の今日の治療指針（橋本病）もコーヒー・日本茶・牛乳を避けるよう書いている

### 併用薬のチェック（当院でよく出る薬）

| 当院・他院でよく出る薬 | GLでの扱い | 当院の運用 |
|---|---|---|
| 沈降炭酸カルシウム、Ca サプリ、骨粗鬆症の Ca 製剤 | 3b（炭酸 Ca） | **4時間以上あける**（LT4 を朝、Ca を昼・夕） |
| 鉄剤（クエン酸第一鉄・フマル酸第一鉄・硫酸鉄）、鉄入りサプリ | 3b（硫酸鉄） | 4時間以上あける。鉄剤開始後は TSH を再検 |
| **PPI・P-CAB** | 3b（PPI）、3c（胃酸低下） | 長期使用で必要量が増えうる。PPI 開始・中止で TSH を再検。P-CAB は本GLの刊行後の薬で記載なし |
| **酸化マグネシウム**（便秘で多い） | 本GLに記載なし（記載はアルミニウム含有制酸薬）。2025 ETA は水酸化マグネシウムを4時間あける表に載せる | 時間をあける（LT4 を起床時、酸化 Mg を食後）。GLの直接の根拠はないので当院の判断 |
| スクラルファート、アルミ含有制酸薬 | 3b | 時間をあける |
| リン吸着薬（セベラマー、炭酸ランタン）、ポリスチレンスルホン酸 Na | 3b の表 | 透析・CKD 患者で TSH が上がったら真っ先に疑う |
| 胆汁酸吸着薬 | 3b（コレスチラミン・コレセベラム）。国内で使うコレスチミドは記載なし | できるだけ離す（コレスチラミンは5時間あけると最良） |
| エストロゲン（HRT、OC） | 3e | 開始・中止で TSH 再検 |
| カルバマゼピン・フェニトイン・フェノバルビタール・リファンピシン・セルトラリン・TKI | 3e | 開始時に TSH 再検 |

### 「増やしても TSH が下がらない」ときの順番（当院）

1. 飲み方（時間・水・食事やコーヒーとの間隔）と**実際に飲めているか**（[01](01-lt4-dosing-monitoring.md) 6e）
2. 併用薬・サプリ（上表）、昆布・ヨウ素含有うがい薬（国内特有。[今日の治療指針・橋本病](../konnichi-chiryo-2026/03-hashimoto.md)）
3. 銘柄・剤形の変更、保管（高温の車内など）
4. 体重増加、妊娠、エストロゲン開始
5. それでも **1.6〜1.8 μg/kg/日を大きく超える**なら、**ピロリ菌・萎縮性胃炎（抗胃壁細胞抗体、ガストリン、B12）・セリアック病**を考える（3c: Strong）。見つかれば治療し、治療後に TSH と用量を見直す
