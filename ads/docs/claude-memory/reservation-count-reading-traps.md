「今週の予約が少ない」と感じたときに、実際にはほぼ毎回この3つのどれかだった
（2026-08-21に検証）。広告の設定変更を疑う前にここを潰す。

**① 当日の数字は15時前だと意味がない。** 予約作成は15〜19時台に集中する。
14時時点の累計は終日の1〜2割しかない（例: 8/14金は14時まで1件→終日6件、
8/19水は1件→9件、8/20木は2件→10件）。午後イチに見て「今日は1件だけ」は常に錯覚。

**② 週の途中で週次比較すると必ず負ける。** 土日の予約が突出して多い
（8/15土26件・8/16日20件に対し平日は9〜20件）。週末が来ていない時点で
「先週の合計」と比べると当然低く出る。比較するなら月〜木など同じ曜日範囲で。

**③ 突出した日の翌日は落ち込んで見える。** 8/17(月)が20件と異常に高かったため
8/19(水)9件・8/20(木)10件が急落に見えたが、月〜木の合計は
第32週39件・第33週34件・**第34週42件**で今週が最多だった。

なお火曜は休診なので予約が一桁なのは正常（8/18は3件）。

**Why:** reservationCount は created_at ベース・キャンセル込み・全流入込みで、
そもそも広告の増分を測る指標ではない（[[procyon-ad-metrics-api]]）。
体感で下がったと感じても、まず上の3つを確認する。

**How to apply:** 予約減の相談が来たら ①同時刻までの累計で比較 ②同曜日範囲で比較
③Google Ads の change_event で実際の変更有無を確認、の順で潰す。
change_event は `gads report --query "... FROM change_event WHERE
change_event.change_date_time DURING LAST_14_DAYS ..."` で取れる（最大30日前まで）。
