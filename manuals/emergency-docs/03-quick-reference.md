# 救急セット早見表

**119番：仙台市青葉区国分町三丁目8-1 勾当台ビル4階 勾当台夕方内科クリニック（022-393-8689）**
通報後 → エレベーターを1階へ／事務スタッフは1階エントランスで救急隊を誘導

## 状況別 第一選択

| 状況 | まず取り出すもの |
|-----|----------------|
| **アナフィラキシー** | アドレナリン注0.1%シリンジ 0.5mg 大腿外側に筋注 ＋ 生食・点滴セット |
| **心肺停止（CPA）** | CPR開始 → AED → アドレナリン1mg 静注 ＋ 生食・点滴セット・**三方活栓** |
| **胸痛（狭心症疑い）** | ニトロペン舌下錠0.3mg 1錠 舌下 |
| **低血糖** | 20%ブドウ糖注射液 2A（糖8g）静注 |
| **けいれん重積** | ジアゼパム注10mg を2分以上かけ緩徐に静注（呼吸抑制注意） |
| **徐脈** | アトロピン硫酸塩注 0.5mg 静注 |
| **喘息発作** | ネオフィリン注250mg を希釈し15〜20分以上かけ点滴 |
| **ショック・低血圧** | エホチール注 ／ ドパミン点滴キット 3〜5μg/kg/分<br>ポンプなし＝**60滴/mLセット**でクレンメ調節（3μg/kg/分：50kg=20秒に1滴、70kg=14秒に1滴）／1滴あたりの秒数 = 3000÷(μg/kg/分×体重) |
