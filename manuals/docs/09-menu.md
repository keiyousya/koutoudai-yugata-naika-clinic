# 診療メニュー

## アレルゲン免疫療法（シダキュア・ミティキュア）

- **対象**: 16歳以上
- **治療内容**: 舌下免疫療法（スギ花粉症・ダニアレルギー）、3〜5年継続
- **開始時期**: スギ花粉症は**6〜11月**に開始（花粉飛散期は開始不可）。ダニアレルギーは**通年**開始可能
- **費用（3割負担の目安）**: 初回の血液検査 約700円、初回投与 約2,300円、定期通院（月1回）約700円
- **禁忌**: 重症の気管支喘息、悪性腫瘍、β阻害薬を服用中の方、妊娠中の方
- **副作用**: 口内炎・舌下の腫れ（よくある）。まれにアナフィラキシー

### 初回投与時の流れ

1. **同意書取得**
2. **ビラノア内服** → 15分待つ
3. **シダキュア1錠投与** → 30分経過観察
4. 問題なければ終了

### 継続処方

- **1週間後に再診**
- **以降月1回再診**で処方（**院外処方**）

## アフターピル（緊急避妊薬）

> **重要**: アフターピルは**性交後72時間以内**の服用が必要で、早いほど効果が高いです。**最優先で対応**してください。

- **料金**: 11,000円（税込・診察料込）、**自費診療**
- **対象**: 16歳以上（未成年でも保護者の同意は不要）。15歳以下は産婦人科へ案内
- **禁忌**: 重篤な肝障害のある方、妊娠中の方
- **院内服用**: 持ち帰りは不可。診察後、院内で服用していただきます
- **服用後**: 3週間を目安に妊娠検査を受けるよう伝えます
- **低用量ピル**: 当院では取り扱いなし。処方を希望される場合は婦人科を案内します

### 受付対応

1. **顔写真付き身分証**を確認します（**16歳以上であること**も確認します）
2. 体温測定・問診・保険確認は不要（診察室で医師が行う）
3. **すぐに診察室に案内します**
4. 看護師に「アフターピルの患者さんです」と伝えます（薬と水の準備のため）

### 診察準備（看護師）

受付から「アフターピルの患者さんです」と連絡があったら、診察前に以下を診察室に準備します：

- アフターピル（レボノルゲストレル錠）
- 紙コップ
- 水

診察後すぐに服用できるよう、準備を整えておいてください。

### 看護師の同席

アフターピルの診察には**必ず看護師が同席**してください。

- センシティブな問診内容を含むため、患者さんへの配慮として同席が必須です
- 女性患者の診察介助と同様、プライバシーに十分配慮してください

## インフルエンザ予防投与（予防内服）

同居家族がインフルエンザを発症した場合に、発症予防の目的で抗インフルエンザ薬を処方します。

- **薬剤**: オセルタミビル75mg（タミフル後発品）10日分
- **料金**: 5,500円（税込・診察料・お薬代込）、**自費診療**
- **服用方法**: 1日1回1カプセル、10日間

### 処方の5条件（すべて満たすこと）

1. **同居のご家族・共同生活者がインフルエンザを発症**していること（職場・学校のみの接触は不可）
2. **重症化リスクの高い方**であること（65歳以上 / 慢性呼吸器疾患 / 慢性心疾患 / 糖尿病などの代謝性疾患 / 腎機能障害）
3. 発症者との接触から**48時間以内**であること
4. インフルエンザの**症状がないこと**
5. **16歳以上**の方（15歳以下は小児科へ）

> ゾフルーザは耐性ウイルスの懸念があるため処方しません。オセルタミビルに限定しています。
