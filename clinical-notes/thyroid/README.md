# 甲状腺（機能亢進症・機能低下症・甲状腺炎）（自院メモ）

- **ガイドライン要約**: [thyroid/README.md](https://github.com/keiyousya/clinical-guidelines/blob/main/thyroid/README.md)
- 各資料の自院メモはこのディレクトリの下に、ガイドライン側と同じパスで置いている

## TSH異常をみたら（早見）

当院の運用メモ。各資料の要約と自院メモをつないだもので、どれか1つの GL の推奨ではない。TSH の基準範囲は**日本人成人（20〜60歳）で 0.61〜4.23 mIU/L**（ハーモナイゼーション後）。高齢者は上にずれる。

### TSH 低値

1. **FT4（＋FT3）を見る**
   - FT4 高値 → 甲状腺中毒症。2 へ
   - FT4 正常 → **潜在性甲状腺機能亢進症**。TSH <0.1 か 0.1〜下限かで分け、再検する。治療が要るのは主に **TSH <0.1 が続き、65歳以上か心疾患・骨粗鬆症・症状がある人**（[GL2019 BCQ25](https://github.com/keiyousya/clinical-guidelines/blob/main/thyroid/jts-graves-tx-gl2019/summary.md)、[ETA 2015](https://github.com/keiyousya/clinical-guidelines/blob/main/thyroid/eta-subclinical-hyper-2015/summary.md)、[ATA 2016](https://github.com/keiyousya/clinical-guidelines/blob/main/thyroid/ata-thyrotoxicosis-2016/03-subclinical-hyperthyroidism.md)）
2. **原因を分ける。治療の前に破壊性を除外する**（[診断GL 01](https://github.com/keiyousya/clinical-guidelines/blob/main/thyroid/jts-diagnosis-gl2024/01-graves.md)、[ATA 2016 01](https://github.com/keiyousya/clinical-guidelines/blob/main/thyroid/ata-thyrotoxicosis-2016/01-etiology-initial-evaluation.md)）
   - **TRAb 陽性** → バセドウ病。MMI 15 mg（FT4 ≧5 なら KI 50 mg を併用）、2ヵ月間は2週ごとに採血（[GL2019](https://github.com/keiyousya/clinical-guidelines/blob/main/thyroid/jts-graves-tx-gl2019/summary.md)、[今日の治療指針](https://github.com/keiyousya/clinical-guidelines/blob/main/thyroid/konnichi-chiryo-2026/01-hyperthyroidism.md)）
   - **頸部痛・発熱・CRP 高値** → 亜急性甲状腺炎。NSAIDs か PSL 15 mg（[診断GL 05](https://github.com/keiyousya/clinical-guidelines/blob/main/thyroid/jts-diagnosis-gl2024/05-subacute-thyroiditis.md)、[今日の治療指針](https://github.com/keiyousya/clinical-guidelines/blob/main/thyroid/konnichi-chiryo-2026/04-acute-subacute-thyroiditis.md)）
   - **痛みなし・TRAb 陰性・軽症** → 無痛性甲状腺炎（産後1年以内なら産後甲状腺炎）。β遮断薬のみで、4〜6週後に再検（[診断GL 03](https://github.com/keiyousya/clinical-guidelines/blob/main/thyroid/jts-diagnosis-gl2024/03-painless-thyroiditis.md)）
   - **お薬手帳**: アミオダロン、免疫チェックポイント阻害薬、IFN、リチウム、ヨード造影剤、甲状腺ホルモン・やせ薬サプリ（[ATA 2016 02](https://github.com/keiyousya/clinical-guidelines/blob/main/thyroid/ata-thyrotoxicosis-2016/02-thyroiditis-drug-induced.md)）
   - 結節がある → 機能性結節（プランマー病）。専門医へ紹介
3. **発熱・頻脈・意識変容・心不全**がそろえばクリーゼを疑い、その場で搬送する（[今日の治療指針](https://github.com/keiyousya/clinical-guidelines/blob/main/thyroid/konnichi-chiryo-2026/01-hyperthyroidism.md)）

### TSH 高値

1. **FT4 を見る**
   - FT4 低値 → **顕性甲状腺機能低下症**。TPOAb・TgAb で橋本病か確認する。LT4 25 μg（高齢・心疾患・長期未治療は 12.5 μg）から始め、4〜6週ごとに調整（[今日の治療指針 02](https://github.com/keiyousya/clinical-guidelines/blob/main/thyroid/konnichi-chiryo-2026/02-hypothyroidism.md)・[03](https://github.com/keiyousya/clinical-guidelines/blob/main/thyroid/konnichi-chiryo-2026/03-hashimoto.md)、[ATA 2014](https://github.com/keiyousya/clinical-guidelines/blob/main/thyroid/ata-hypothyroidism-2014/01-lt4-dosing-monitoring.md)）
   - FT4 正常 → **潜在性甲状腺機能低下症**。2 へ
2. **1〜3ヵ月後に再検する**。その間に**ヨウ素（昆布・うがい薬・造影剤）、薬剤、産後・甲状腺炎の回復期**を確認する（一過性が多い）
3. **TSH ≧10 が続く → LT4**。**<10 → 症状か LDL-C 高値があれば検討、なければ経過観察**。**80歳以上の TSH <10 は原則治療しない**（[今日の治療指針 03](https://github.com/keiyousya/clinical-guidelines/blob/main/thyroid/konnichi-chiryo-2026/03-hashimoto.md)、[ETA 2013](https://github.com/keiyousya/clinical-guidelines/blob/main/thyroid/eta-subclinical-hypo-2013/summary.md)、[ETA 2025](https://github.com/keiyousya/clinical-guidelines/blob/main/thyroid/eta-lt4-monotherapy-2025/summary.md)）
4. **妊娠中・妊娠希望**は別の基準で考える（[ATA 2026](https://github.com/keiyousya/clinical-guidelines/blob/main/thyroid/ata-pregnancy-2026/01-testing-hypothyroidism.md)、[妊娠編](https://github.com/keiyousya/clinical-guidelines/blob/main/thyroid/jts-pregnancy-subclinical-2025/summary.md)）

### TSH と FT4 の組み合わせが合わない

- **FT4 低値なのに TSH が上がらない** → 中枢性か重症疾患（低T3症候群）。**LT4 の前にコルチゾール・ACTH を測り**、専門医へ紹介（[診断GL 02](https://github.com/keiyousya/clinical-guidelines/blob/main/thyroid/jts-diagnosis-gl2024/02-hypothyroidism.md)）
- **FT4 高値なのに TSH が下がらない**、または**臨床像と検査値が合わない** → まず測定の干渉（ビオチン・異好性抗体・マクロTSH など）を疑って別の測定系で再検する。それでも同じなら TSH産生腫瘍・甲状腺ホルモン不応症を考える（[ETA 2026 干渉](https://github.com/keiyousya/clinical-guidelines/blob/main/thyroid/eta-assay-interference-2026/summary.md)）

### LT4 治療中に TSH がぶれる

- 増量の前に再検し、服薬時刻、鉄・Ca・Mg・PPI、コーヒー・牛乳、ヨウ素、銘柄の変更、体重の変化を確認する。高齢者は TSH を高めに保つ（[ETA 2025](https://github.com/keiyousya/clinical-guidelines/blob/main/thyroid/eta-lt4-monotherapy-2025/summary.md)、[ATA 2014 02](https://github.com/keiyousya/clinical-guidelines/blob/main/thyroid/ata-hypothyroidism-2014/02-absorption-formulation.md)）
- 補充中の妊娠は**すぐに増量**する（[ATA 2026](https://github.com/keiyousya/clinical-guidelines/blob/main/thyroid/ata-pregnancy-2026/01-testing-hypothyroidism.md)）
