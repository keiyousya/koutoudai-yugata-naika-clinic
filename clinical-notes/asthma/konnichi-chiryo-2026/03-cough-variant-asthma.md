# 今日の治療指針2026「咳喘息とアトピー咳嗽」（自院メモ）

- **ガイドライン要約**: [asthma/konnichi-chiryo-2026/03-cough-variant-asthma.md](https://github.com/keiyousya/clinical-guidelines/blob/main/asthma/konnichi-chiryo-2026/03-cough-variant-asthma.md)

## 外来での使いどころ（自院メモ）

長引く咳で受診する人は多い。当院は FeNO もスパイロもないので、**治療への反応で見分ける**。

1. **8週以上の咳で、喘鳴がない**。胸部X線（今は他院に依頼）で肺癌・結核などを除外する。**ACE 阻害薬**を飲んでいないか確認する
2. **夜間〜早朝の咳、かぜのあと長引く、会話や冷気で出る** → 咳喘息を考え、**中用量以上の ICS/LABA**（シムビコート 1回2吸入 1日2回など）で始める。2〜4週で判定
3. **のどのイガイガ感を伴う乾いた咳、アトピー素因あり** → アトピー咳嗽を考え、**H1 拮抗薬**（デザレックスかビラノア。運転する人にも使える）で始める。2〜4週で判定
4. ICS/LABA が効かない → LAMA（スピリーバ）か LTRA を追加、胸やけ・げっぷがあれば PPI・ボノプラザンを追加（GERD の合併）
5. それでも残る → 専門医へ（紹介先: 未定・要記入）。紹介前にゲーファピキサント（リフヌア）を試してもよい

- **鎮咳薬（デキストロメトルファンなど）は出さない**。咳喘息・アトピー咳嗽には効かない
- アトピー咳嗽に ICS を出すときは「気管支喘息」の病名が要る
- 咳喘息は**秋に悪化しやすい**。季節性がはっきりしていれば、症状のある時期だけの治療でもよい
- ICS は低用量まで減らせて1年以上症状がなければ中止を考える。再燃したら早めに受診するよう伝える
- 咳喘息の30〜40%は典型的な喘息に移るので、ICS を中心にした治療をすすめる
