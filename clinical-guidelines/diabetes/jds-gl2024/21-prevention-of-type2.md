## Q21-1 2型糖尿病の発症リスクをどのように評価するか

### ポイント

- 血糖値・HbA1c を含む複数の環境因子に重み付けして組み合わせた**発症予測モデル**が開発されている
- 2型糖尿病関連遺伝子群を環境因子モデルに付加すると予測能がさらに向上

### 血糖値・HbA1c

- 発症予測で**最も優れた因子**。いずれも**発症の10年前から**非発症者より高値
- **空腹時血糖 100〜125 mg/dL かつ HbA1c 5.7〜6.4%** の群は、両方正常群に比べ**発症リスク約30倍**
- 米国: HbA1c ≧5.7% は毎年血糖検査を推奨

### 評価すべき危険因子

- 肥満、メタボリックシンドローム、糖尿病家族歴、血圧・脂質、座位行動時間、妊娠糖尿病の既往
- 検査所見: 肝酵素上昇、脂肪肝、尿酸高値、CRP 上昇、白血球増加

### 妊娠糖尿病（GDM）の既往

- 既往なしに比べ **RR 9.51**
- 産後年数別: <3年 5.37、3〜6年 16.55、6〜10年 8.20、15年以上 7.88 → 長期に高リスク持続
- 米国: **生涯にわたり少なくとも3年毎**に血糖検査を推奨

### リスクモデル・遺伝子

- わが国のモデルは地域・職域・医療機関の健診データから開発
- GWAS で欧米人から関連遺伝子同定、わが国の研究者が **KCNQ1** を追加。アジア人の関連遺伝子も複数同定
- 臨床現場に加え、地域・職域の集団でモデルを当てはめ高リスク者を同定し早期に予防を開始することが重要

## Q21-2 肥満や体重変化は2型糖尿病の発症にどの程度関与するか

### ポイント

- BMI と発症には強固な正の関係。**アジア人は欧米人より BMI カットオフが低い**
- 小児期〜成人早期の過体重は将来リスクを上昇、特に**成人早期**の過体重と強く関連。小児期の過体重は**思春期前に解消すればリスク増加なし**
- 生活習慣改善とともに **2 kg 減量**でリスク低減。高度肥満では減量手術で大幅低下

### 詳細

- 米国: アジア系は **BMI ≧23** で血糖スクリーニングを推奨
- 出生体重は U 字型: 2,500〜4,000 g に比べ **<2,500 g で RR 1.47、≧4,000 g で 1.36**。低出生体重児は成人後に肥満するとさらにリスク上昇
- 7歳・13歳・成人早期（17〜26歳）の過体重はいずれもリスク上昇、成人早期が最も強い。7歳時の過体重は13歳時に過体重でなければ関連なし
- 他の報告: 思春期早期の過体重が最もリスク上昇、18〜24歳の体重増加は25歳以降の増加より高リスク、肥満発症年齢とリスクは負の関連
- 日本: 現在の BMI に加え、**20歳時から生涯最大までの BMI 変化量**が強く関連
- BMI 以外: ウエスト周囲長、ウエスト/ヒップ比、腹囲身長比、サルコペニア肥満
- 減量目標: 米国は **7%減量**。日本人研究では**生活習慣改善＋2 kg 減量**で大きな発症抑制
- 減量手術: **RR 0.39**
- 生涯の体重管理、特に思春期〜成人早期の適正体重維持が重要

## Q21-3 身体活動量や運動習慣は2型糖尿病の発症にどの程度関与するか

### ポイント

- 1日の総身体活動量・余暇時身体活動量とリスクは負の関係。**歩数が増えるほどリスク低下、速歩の割合が多いとさらに低下**
- 有酸素運動に加え**筋力トレーニング**もリスク低下、**両者の組み合わせで大幅に減少**
- **座位行動時間の増加はリスク上昇**し、余暇時の運動で打ち消せない

### 身体活動

- WHO「身体活動と座位行動に関するガイドライン」（2020年）: すべての身体活動は有益、できるだけ体を動かす
- 勤務中の活動量増加、**徒歩・自転車通勤**もリスク低下と関連
- 低強度〜高強度のあらゆる運動が有効。**ストレッチのような低強度運動も寄与**
- 日本人でも筋力トレーニング・活発な運動は予防に有効
- 余暇運動は活動量に応じてリスク低下し、過度な運動によるリスク上昇はみられない。ただし筋力トレーニングは総死亡・心血管疾患・癌に対し適度な量があり、過剰に注意
- 心肺持久力（日本人でも）・握力はリスクと負の関連。CT/DEXA の**筋肉量**とは関連なし → 筋の質も考慮

### 座位行動

- 定義: 座位・半臥位・臥位でエネルギー消費 **≦1.5 メッツ**のすべての覚醒行動
- 線形の関連: **座位 1時間増加ごとに 5%、テレビ視聴 1時間増加ごとに 8%** リスク増加
- 身体活動量と独立。日本でも座位時間・テレビ視聴時間との関連あり
- WHO は座位中心の生活を改めるよう推奨

## Q21-4 エネルギー量や栄養素摂取比率は2型糖尿病の発症にどの程度関与するか

### ポイント

- **総エネルギー摂取量の適正化**を主とした食事是正は日本人の発症予防に有効
- GI・GL とリスクに正の量反応関係
- **食物繊維・食事性マグネシウム**の摂取はリスク低下

### 三大栄養素

| 栄養素 | 知見 |
|---|---|
| 炭水化物割合 | J カーブ。**45〜65%で最低、70%以上で増加** |
| GI / GL | 正の量反応関係（GL = GI × 炭水化物量 ÷ 100） |
| 総タンパク / 動物性タンパク | 摂取エネルギー比 5%増ごとにリスク 9% / 12% 増 |
| 植物性タンパク | U 字、エネルギー比 **約6%で最低**。動物性→植物性への置換で炎症軽減・リスク低下 |
| 脂質 | 量より質。動物由来↑、植物由来↓。ナッツは予防的 |

- 脂肪酸: オリーブ油（オレイン酸）摂取増、リノール酸血中濃度増、魚介類由来 n-3 摂取増はリスク低下の報告。不飽和脂肪酸は地域・種類で議論あり。飽和脂肪酸は関連不明（炭素数で違いの報告）。トランス脂肪酸は関連なし/ありで意見が分かれる

### 個別の食品・栄養素

| リスク低下 | リスク上昇 |
|---|---|
| 全粒穀物、玄米、食物繊維、マグネシウム | **白米**（アジア人で関係が強い。1日 <150 g に比べ **≧450 g で増加**） |
| 大豆・大豆イソフラボン | じゃがいも（量反応関係、特にフライドポテト） |
| 乳製品（特にヨーグルト）、カルシウム | 超加工食品（スナック菓子、インスタント食品） |
| 果物・野菜、ポリフェノール | 豚肉・牛肉・加工肉、鉄 |
| 亜鉛、マンガン | 高温調理（グリル焼きなど）の肉、銅 |

- 食事性コレステロール・卵: 米国人でリスク増、アジア人では有意でない
- ビタミンD: 大規模介入研究は有意差なし、それを含む MA ではサプリメントがリスク低下と関連（議論あり）
- 葉酸: 観察研究で一部関連、サプリメントの予防効果は結論なし
- 予防的な食事スタイル: 中国の健康食、植物由来中心の食事、**地中海食**などの健康的な西洋食。アルカリ食品が少なく酸性食品が多いとリスク増の報告

### 食習慣

- **早食い**はリスク上昇
- **朝食欠食**でリスク上昇、食事回数が多いほど低下
- 朝食を8時までに比べ **9時以降**でリスク上昇
- 長期の飢餓経験でリスク増加 → 断続的断食に警鐘
- 日本では食物繊維の摂取不足が長く指摘されている

## Q21-5 アルコールや他の嗜好飲料は2型糖尿病の発症にどの程度関与するか

### ポイント

- 適量飲酒で非飲酒者よりリスクが低いという仮説は**アジア人で議論があり、リスク軽減のための飲酒は推奨されない**
- 甘味糖類のみならず**人工甘味料添加ジュースや果物ジュース**もリスク上昇
- **コーヒー、ココア製品、茶類**の習慣的摂取は予防に有効

### アルコール

- 多くの研究で J 字型だが、アジア人ではあり/なしの両報告
- 日本: **痩せ型男性（BMI ≦22）の中等量以上**の飲酒、**1回量の多い**飲酒でリスク上昇
- 心血管病でも J 字型を認めない報告。多くの癌・脳萎縮には J 字型なし → **少量でも控えるべき**

### 甘い飲料・ジュース

| 飲料 | RR |
|---|---|
| 甘味糖類添加ジュース（肥満と独立） | 1.28（アジア人でも同様） |
| 人工甘味料添加ジュース（肥満と独立） | 1.29 |
| 果物ジュース | 1.10 |

- サッカリン、スクラロース、アスパルテームは腸内細菌叢を乱してリスクを増やす可能性
- 甘味糖類・人工甘味料ジュースは心血管病、癌、総死亡も上昇 → 習慣的摂取は控える
- 果物は**そのまま食べるとリスク低下、ジュースでは増加**。甘味糖類添加と100%果汁に分けると、有意上昇は**甘味糖類添加のみ**

### 予防的な飲料

- **コーヒー**: 負の量反応関係、日本人でも確認。**カフェインの有無と無関係**
- ココア製品、お茶（日本では**緑茶**）、**水**の摂取増加もリスク低下

## Q21-6 喫煙、受動喫煙、禁煙は2型糖尿病の発症にどの程度関与するか

### ポイント

- **受動喫煙を含めた喫煙は独立した危険因子**
- 禁煙は体重増加を伴いやすく一時的にリスク上昇するが、**長期的にはリスク減少**

### 数値

| 項目 | リスク |
|---|---|
| 喫煙者 vs 非喫煙者 | RR 1.37（日本人研究 1.38） |
| 世界の2型糖尿病への寄与危険割合 | 男性 10.3%、女性 2.2% |
| 1日 <10本 / 10〜19本 / ≧20本 | +21% / +34% / +57% |
| 受動喫煙 | RR 1.22（日本でも職場・家庭の受動喫煙で増加） |
| 喫煙継続 | +37% |
| 禁煙後5年以内 | +54%（一時的に上昇） |
| 禁煙後10年以降 | +11%まで低下 |

- 人種・年齢・肥満・性別で影響に差なし。ただし**肥満者で影響がより大きい**
- 開始年齢が若く、喫煙期間が長いほどリスク増加
- 肺機能低下・COPD もリスク上昇
- 禁煙直後の上昇: 米国人は体重増加量に比例、日本人では**体重増加の少ない群でむしろ上昇**と意見が分かれる

## Q21-7 睡眠は2型糖尿病の発症にどの程度関与するか

### ポイント

- **7時間睡眠で最もリスクが低く**、短時間・長時間睡眠はともにリスク上昇
- 不眠症、睡眠時無呼吸症候群はリスクを高める
- 早寝習慣は予防的な可能性があるが、クロノタイプも考慮

### 数値

| 項目 | リスク |
|---|---|
| 睡眠時間 | U 字型、7〜8時間で最低 |
| 短時間睡眠（7時間基準、1時間減少ごと） | RR 1.09 |
| 長時間睡眠（1時間増加ごと） | RR 1.14 |
| 日本人労働者 | 7.0〜7.5時間で最低、<6.5時間で上昇 |
| 昼寝 ≧1時間/日 | RR 1.31 |
| 睡眠時無呼吸症候群 | RR 2.15 |

- 不眠症（入眠障害、中途覚醒、早朝覚醒、熟眠障害）はリスク上昇、肥満を介した関連との報告。いびきもリスク増加
- 就寝 20〜23時に比べ **午前1〜6時就寝**でリスク高い
- 交替制勤務で主に夜勤の労働者はリスク上昇、**常時夜勤では増加なし**。クロノタイプのミスマッチ（朝型が夜勤、夜型が早朝勤務）が問題との報告
- 日本人の睡眠時間は OECD 加盟国で最下位 → **質のよい睡眠を7時間**

## Q21-8 ストレスや労働環境などの心理社会的要因は2型糖尿病の発症にどの程度関与するか

### ポイント

- **うつ傾向（うつ病）・精神的ストレス**は発症リスクを上昇
- 劣悪な労働環境・社会環境も重要な危険因子となり得る

### 詳細

- うつ傾向 → 2型糖尿病 **RR 1.38**、2型糖尿病 → うつ病 **RR 1.25** → **双方向の因果関係**
- PTSD などの強いストレスでリスク上昇。日本でも「精神的ストレスが多い」と答えた人はリスク高い
- 長時間労働: 全体では関連なし、**社会経済的地位が低い群でのみ**上昇
- 職場のいじめ・暴力、雇用不安でリスク上昇。同僚・上司の支援で低下
- 社会環境: PM2.5 増加、過度な交通騒音、ビスフェノールA/S 曝露（可能性）でリスク上昇
- 社会経済的地位が低いとリスク上昇。貧困率の低い地域への転居でリスク減少、健康的な食品を買いやすく運動しやすい住環境でリスク低い
- ストレス低減のセルフケアを身につけることが望ましい

## CQ21-9 生活習慣介入によって2型糖尿病の発症は抑止できるか

> 食事や運動習慣の是正を中心とした生活習慣介入は、2型糖尿病の発症を減少させ、その効果は介入終了後も持続するため生活習慣の改善が推奨される。

- **推奨グレードA**（合意率100%）
- 根拠文献レベル: RCT 1（Kosaka 2005、Kawahara 2008、Saito 2011、および介入後追跡: Nanditha 2018、DPPOS 2015、Finnish DPS 2013、Da Qing 2014）。4項目は確実性・益害・価値観が「はい」、費用が不確か

### 有効性が示された集団

- 日本人、中国人（Da Qing）、インド人（D-CLIP）、欧米人（DPP［米国］、Finnish DPS［フィンランド］）
- **人種にかかわらず有効**。**介入セッション数が多いほど**リスク低下。食事・運動に加え喫煙・飲酒・肥満など**複数因子への積極的介入**でさらに減少

### 日本の RCT

| 研究 | 対象 | 介入 | 結果 |
|---|---|---|---|
| Kosaka 2005 | IGT 中年男性 458人、4年 | 積極介入（BMI <22 目標、週1回以上体重測定、3〜4ヵ月ごと面接）vs 通常（BMI <24 目標、6ヵ月ごと面接） | 累積発症 3.0% vs 9.3%、**RR 0.33** |
| Kawahara 2008 | IGT 426人、3年 | 1泊2日入院教育＋3ヵ月ごと面接／外来面接／パンフレットのみ | 累積発症 23.9% / 29.6% / 38.8%。RRR 42% / 27%（本文 RR 0.73） |
| Saito 2011 | IFG 641人、3年 | 高頻度面接（初回、1・3・6・12・18・24・30・36ヵ月）vs 年1回面接 | 12.2% vs 16.6%、**RR 0.56（0.36〜0.87）** |

- いずれも介入群で**平均2 kg 前後の減量**
- Sakane ら（IGT、面接介入）: 全体で有意差なし、**BMI >22.5 や HbA1c ≧5.7% の群で有意な効果**
- **J-DOIT1**（電話のみの介入）: 主解析で有意差なし、**高頻度電話介入（10回/年）で RR 0.59**

### 介入終了後の持続効果

| 研究 | 持続期間 | 結果 |
|---|---|---|
| インド人研究 | 3年 | HR 0.699（総追跡5年） |
| Finnish DPS | 7年 | 総追跡13年 RR 0.614、介入終了後 RR 0.672 |
| DPP/DPPOS | 12年 | 総追跡15年 生活習慣 RR 0.73、メトホルミン 0.82（vs プラセボ） |
| Da Qing | 24年 | 総追跡30年 HR 0.61 |

- MA: 生活習慣介入は新規発症を **39%減少**、介入終了後も**平均7.2年にわたり28%減少**
- 費用: SR で ICER 中央値 7,490ポンド（約110万円）/QALY。日本の費用対効果報告はなし

## Q21-10 2型糖尿病の発症は薬物により抑止できるか

### ポイント

- 血糖降下薬: ビグアナイド薬、α-GI、チアゾリジン薬、SGLT2阻害薬、基礎インスリン、GLP-1受容体作動薬に発症抑制効果
- 降圧薬: **ARB・ACE阻害薬はリスク低下、サイアザイド系利尿薬は上昇**
- **スタチンはリスクを上昇させるが、不利益は心血管イベント抑制効果を上回るほどではない**

### 血糖降下薬

| 薬剤 | RR | 備考 |
|---|---|---|
| メトホルミン | 0.50 | 厳格な食事運動療法と同等。米国では高リスク者に投与推奨 |
| ボグリボース | 0.60 | IGT 介入試験。**ボグリボース0.2 mg 錠が保険適用** |
| ピオグリタゾン | 0.40 | 顕著な体重増加・浮腫 |
| SGLT2阻害薬 | 0.79 | 低血糖増加なし、効果は大きくない |
| グラルギン（基礎インスリン） | 0.80 | 低血糖・体重増加 |
| リラグルチド（前糖尿病の肥満者） | 0.21 | 中止・脱落 約50%、研究の質はよくない |
| DPP-4阻害薬（ビルダグリプチン） | — | 少数例、有意差なし |

- 非無作為化試験: メトホルミン＋ピオグリタゾン＋GLP-1作動薬の併用で進行を大幅抑制

## 外来での使いどころ（自院メモ）

- **空腹時血糖 100〜125 と HbA1c 5.7〜6.4% が両方ある人は発症リスク約30倍** → 境界型として生活指導し、少なくとも年1回は再検
- **妊娠糖尿病の既往**は産後15年以上経ってもリスクが高い → 問診で必ず確認し、少なくとも3年毎に血糖検査
- 減量目標は「**まず2 kg**」で十分効果がある（日本人RCTの減量幅）。指導は1回で終わらせず、面接・電話を**繰り返すほど効く**
- 具体的指導: 歩数を増やし速歩を混ぜる、筋トレ併用、**座りっぱなしを減らす**、甘い飲料・人工甘味料飲料・ジュースをやめ水・お茶・コーヒーに、白米を減らし食物繊維を増やす、早食い・朝食抜きを避ける
- 飲酒は予防目的では勧めない。禁煙直後は一時的にリスクが上がるので体重・血糖をフォローしつつ長期的利益を説明する
- 睡眠は7時間前後、いびき・日中の眠気があれば**睡眠時無呼吸（RR 2.15）を評価**
- 境界型で薬を使う場合、**IGT にはボグリボース0.2 mg が保険適用**。ただし薬剤の効果は中止で消える
- 高血圧合併の境界型ではサイアザイドより ARB/ACE阻害薬を優先的に考える。スタチンは心血管適応があれば糖尿病リスクを理由に控えない
