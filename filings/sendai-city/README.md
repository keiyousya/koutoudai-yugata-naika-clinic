# 仙台市

医療法上の開設届・変更届は**青葉区保健福祉センター（保健所）**、制度の照会は**健康福祉局 医務薬務課 医務係**。

## 問い合わせ

**課単位のメールアドレスは一切公開していない。** 照会は「杜の都おしえてコール」の
お問い合わせフォームから担当課に取り次いでもらう（受付番号が発行される）。
https://faq.callcenter.city.sendai.jp/app/ask/

件名に「○○課△△係宛」と書き、本文冒頭で取り次ぎを依頼する。
判断を要する件は回答に日数がかかるため、急ぐときは電話。
「市民の声」フォーム（logoform）は個別の手続きの照会には使えない。

## メモ

- 診療所開設届出事項変更届出書（様式第10-1号）の「変更した事項」(1)〜(17)に**電話番号はない**。
  医療法施行令第4条第3項の法定変更事項ではないため、電話番号だけの変更届は存在しない。
- 2026-09-14に医務薬務課から「電話番号は変更届で訂正済み」と回答あり。
