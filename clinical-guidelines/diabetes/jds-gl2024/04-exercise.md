## CQ 4-1 糖尿病の管理に運動療法は有効か？

### ステートメント

| # | ステートメント | 推奨グレード | 根拠文献の最高エビデンスレベル |
|---|---|---|---|
| ❶ | 2型糖尿病の血糖コントロールに、**有酸素運動、レジスタンス運動が推奨される** | 【推奨グレードA（強い推奨）】（合意率100%） | 1+ |
| ❷ | 1型糖尿病の血糖コントロールに運動療法が有効かどうかは**一定の見解が得られていない** | 【推奨グレードU】（合意率100%） | 2 |
| ❸ | 運動療法は1型・2型にかかわらず**心血管疾患のリスクファクターを改善**させ、特に有酸素運動は心肺機能を、レジスタンス運動は骨格筋量・筋力を向上させるため推奨される | 【推奨グレードA（強い推奨）】（合意率100%） | 1+ |

- ❶❸: 推奨グレード決定の4項目（エビデンス確実性・益害・価値観・費用）すべて「はい」
- ❷: 益害・価値観・費用は満たすがエビデンス総体の確実性が不確か → U

### 2型糖尿病: 全般的効果

- 血糖改善に加え、肥満、内臓脂肪、インスリン抵抗性、脂質異常症、高血圧、慢性炎症を改善。QOL・うつ状態、認知機能障害の改善効果も示される
- 8週以上の運動療法 MA（平均 3.4回/週、18週）: **体重減少は有意でないが HbA1c −0.66%**
- Umpierre 2011（47 RCT・8,538人）: HbA1c 有酸素 −0.73%、レジスタンス −0.57%、併用 −0.51%。**週150分超 −0.89% vs 150分以下 −0.36%**。運動アドバイスは食事アドバイスと同時に行うと有効
- CGM での検討、心拍変動（CVR-R）・血管機能の改善も示される

### 有酸素運動

- 心肺機能の低下は 2型の CVD・死亡に関連
- **最大酸素摂取量の50〜75% の強度で1回約50分、週3〜4回、20週** → 最大酸素摂取量 **11.8% 増加**
- 最大酸素摂取量75% 程度までの持続的運動では、**強度が高いほど**最大酸素摂取量増加・HbA1c 改善が大きい。頻度・量と HbA1c 改善も相関
- **最新 MA（Jayedi 2022）**: 150分/週未満の **30〜100分/週でも時間依存的に血糖改善**。週30分増えるごとに HbA1c −0.22%、**100分/週で最大効果、それ以上は頭打ち**。薬剤減量の一方、低血糖は増加

### 高強度インターバルトレーニング（HIIT）

- SR: 11〜16週で HbA1c、空腹時インスリン、BMI、体脂肪率、最大酸素摂取量が有意改善
- 中強度運動との比較では体重・BMI・HbA1c・最大酸素摂取量が改善、ただし非運動対照との比較では最大酸素摂取量のみ有意
- 現状: 中強度より**心肺機能向上には効果的だが HbA1c への効果は結論が出ていない**。長期効果不明、強度が高く臨床的な対象は限られる
- 単回運動の CGM 検討: 消費エネルギーが同じなら**高強度より低強度が有効**との報告

### 現時点の推奨量（有酸素）

- **週150分以上の中等度〜強度の有酸素運動**（3日以上にわたり、活動しない日が連続2日を超えない）
- 30〜100分でも時間依存的な血糖改善が期待できる可能性
- 若年者・心肺機能の高い患者では HIIT で**75分/週**でも同様の効果の可能性

### レジスタンス運動

- 骨格筋量・筋力増加とともにインスリン抵抗性・血糖を改善
- 一般的推奨: **週2〜3日（連続しない）、主要筋群を含む5種類以上を最低1セット**、徐々に強度・セット数を増やす
- **高強度負荷（最大挙上重量の75〜100%）** のほうが血糖改善効果がよい
- 有酸素との**併用で HbA1c 低下効果が高まる**との MA あり（Schwingshackl 2014）
- レジスタンス単独の HbA1c 低下効果は**有酸素運動に劣らない**（Jansson 2022: 筋力増加が大きいほど HbA1c 低下）→ 有酸素が困難な高齢者の選択肢
- 高齢糖尿病は筋量低下が起きやすく、**サルコペニア予防**の観点でも有効。**バランス運動の併用**で転倒リスクがより軽減する可能性

### ヨガ・太極拳

- 高齢者にも導入しやすい。ヨガ: 空腹時血糖・HbA1c 改善、筋力・心肺機能向上。太極拳: 血糖値・バランス能力改善（MA）
- 研究数が限られ出版バイアスもあり、今後の検討が必要

### 1型糖尿病

- 単回運動で血糖は低下するが、長期血糖コントロールへの効果は不一致（MA 3つで改善、2つで変化なし）。インスリン分泌の残存度で個人差がある可能性
- 多くの研究で体重・BMI・LDL-C 低下、最大酸素摂取量・筋力改善
- 横断研究: 運動を多く行う群で網膜症・微量アルブミン尿の発症が有意に少なく、DKA や昏睡を伴う重症低血糖（高齢女性を除く）も少ない
- → CVD リスク減少・QOL 向上の観点から**1型でも運動療法は勧められる**
- 低血糖対策: **レジスタンス運動は運動誘発性低血糖が少ない**。有酸素と併用するときは**レジスタンスを先に**行うと低血糖が少ない
- 合併症がなくコントロール良好なら、運動前・中・後の血糖モニタリングとインスリン量・補食の調整で**いかなる種類の運動も可能**

## Q4-2 運動療法を開始する前に医学的評価（メディカルチェック）は必要か？

### ポイント

- 開始前に代謝コントロール状態、網膜症、腎症、末梢神経障害、自律神経障害、整形外科的疾患などを把握し、運動制限の必要性を検討
- **心血管疾患スクリーニング**: 無症状かつ軽度〜中強度（速歩など日常生活活動の範囲内）なら**一般的に不要**。普段より高強度の運動、CVD 高リスク患者、ほぼ座位生活の患者が中強度以上を開始する場合は、主治医によるスクリーニングと必要に応じ運動負荷試験を考慮

### 合併症別の注意

| 合併症 | 注意点 |
|---|---|
| **網膜症** | 新生血管は脆弱で硝子体出血・網膜剝離のリスク。**前増殖網膜症以上**では激しい有酸素運動、ジャンプ、衝撃の加わる活動、頭位を下げる活動、**Valsalva（息こらえ・いきみ）** が禁忌となる場合あり → 激しい運動の前に眼科チェック |
| **腎症** | 微量アルブミン尿例で運動後に一時的に尿タンパク増加しうるが腎症進行には影響しないと考えられ、身体活動はむしろ抑制的に働く可能性。**顕性腎症以上**でも基本的に身体活動を高める指導を勧めるが症例ごとに検討 |
| **末梢神経障害** | 痛覚低下で皮膚障害・感染・Charcot 関節のリスク。重度例は事前評価。一方、**適切な靴での中強度ウォーキングは足潰瘍・再潰瘍リスクを上げない**、150分/週の適度な運動はニューロパチーの転帰を改善。全員に適切な靴・毎日の足観察。**足の怪我・開放性潰瘍があれば荷重運動を制限** |
| **自律神経障害** | 循環応答低下、起立性低血圧、体温調節障害、視力障害、無自覚性低血糖で有害事象が多い。心血管自律神経障害は心血管死・無症候性心筋梗塞の独立危険因子 → 程度により運動の可否を決定 |
| **骨・関節疾患** | 整形外科と連携し、柔軟運動や疾患関節のレジスタンス運動など負荷をかけ過ぎない運動 |

### 心血管スクリーニング

- 無症状糖尿病患者の最良のスクリーニングプロトコールは未確立。ADA・ACSM は運動処方前全例のルーチン検査を推奨しない
- 高リスク例: 高コレステロール血症、喫煙者、CVD 家族歴など
- 日頃から病歴聴取、危険因子評価、**労作時胸痛・息切れ・運動耐容能低下など非典型的な冠動脈疾患の発現**に注意
- 高リスク患者は**低強度・短時間から開始し、忍容性に従って漸増**

## Q4-3 具体的な運動療法はどのように行うか？

### ポイント

- **有酸素運動**: 中強度で**週150分以上、週3回以上、運動しない日が2日間以上続かない**
- **レジスタンス運動**: **連続しない日程で週2〜3回**
- 禁忌でなければ**両方行う**

### 有酸素運動の処方

| 項目 | 目安 |
|---|---|
| 目標強度 | 中強度（**最大酸素摂取量の40〜60%**） |
| 導入時 | 最大心拍数の50〜60%、**RPE 11〜12（楽である程度）** |
| 慣れたら | 最大心拍数の60〜70%、**RPE 12〜13（ややきつい程度）**、4〜6メッツ程度 |
| 最大心拍数 | 簡易的に **220−年齢** |
| 脈拍の簡易目安 | **50歳未満 100〜120拍/分、50歳以上 100拍/分未満** |
| 時間 | 週150分程度を目標（最新 MA では100分/週でも HbA1c 改善に十分な可能性） |
| 頻度 | インスリン感受性の上昇は運動後**24〜48時間**持続 → 週3回以上、休みを2日以上続けない |
| ウォームアップ/クールダウン | 最初と最後の各5分で徐々に負荷を上げ下げ |
| 高強度・インターバル | 若年者・体力的に適合する例で週最低75分が有効な可能性（適合例は多くない） |

- 自律神経障害、高齢者、**β遮断薬内服中**では脈拍で強度を決めるのは難しい
- 最も多く行われるのは**歩行**。歩行だけでも血糖コントロール改善（MA）

### 歩数での指導

- 時間目標より**目標歩数を提示し歩数計で自己管理**したほうがアドヒアランス・血糖低下効果が良好
- MA: 歩数計・活動量計で血糖改善に有意差はないが活動量は増加
- **週150分の有酸素運動 ≒ 約15,000歩** → 毎日均等なら**1日 +2,000歩強**が目標、最終的に**1日合計 8,000歩程度**
- ゲーム・アプリ: Wii Fit 12週 RCT で空腹時血糖・HbA1c・体重・BMI 改善

### 運動タイミングと低血糖対策

- **食後**に行えば食後高血糖の改善が期待できる
- インスリン・SU 薬使用中は**空腹時の運動で低血糖**のおそれ
- インスリン療法中に食後運動する場合は**運動前の追加インスリン減量**を検討。運動前血糖が低ければ補食
- 運動の血糖低下作用は**48時間程度**続く → 基礎インスリンの減量も考慮
- 1型では強度により血糖が上昇・低下など様々 → 頻回 SMBG や CGM で個別調整

### レジスタンス運動の処方

| 項目 | 目安 |
|---|---|
| 頻度 | 週2〜3日、連続しない日程 |
| 種目 | 上半身・下半身の主要筋群を満遍なく含む5種類以上 |
| 開始時負荷 | 10〜15回反復できる程度、またはごく軽い負荷 |
| 目標 | 8〜12回で限界に達する負荷 × **1〜3セット** |
| 呼吸 | 重りを上げる（収縮）時に吐き、下げる（伸張）時に吸う。**息を止めない** |
| 器具 | マシーン、ダンベル・バーベル、バンド、自重から個々に合ったもの |

- **いきみ動作は血圧上昇 → 心血管疾患・網膜症悪化**のおそれ。開始前にメディカルチェック
- 正しいフォームで怪我予防・筋肥大効果向上
- 筋力向上が大きいほど HbA1c 改善、高強度負荷（75〜100%）が有効だが、体力・怪我リスクを考慮し適切な負荷で
- 高強度負荷を行うなら**フィットネスクラブや自治体スポーツ施設など専門指導者のいる施設**が望ましい（国内フィットネスクラブでの血糖改善・発症予防の報告あり）
- **下半身の筋肉は全身の約7割** → 時間がなければ**スクワット**など下半身中心の種目

## Q4-4 運動療法以外の身体を動かす生活習慣（生活活動）は糖尿病の管理にどう影響するか？

### ポイント

- 現在の身体活動量を評価し、**生活活動量を含めた身体活動の総量**を増加させる
- **日常の座位時間が長くならないように**し、合間に軽い活動を行う

### 根拠

- 身体活動量 = 運動 + 生活活動
- 身体不活動（起きている間に座る・横になる）は2型糖尿病リスクを増加
- 横断研究: **座位が1日1時間増えるごとに 2型糖尿病有病率 +22%、メタボリックシンドローム有病率 +39%**
- 長時間座位は身体活動量で調整しても 2型糖尿病・死亡率・CVD を増加
- **NEAT**（非運動性活動熱産生）は肥満者と標準体重者で大差があり、肥満形成に大きく影響

### 座位中断の介入研究（2型）

| 介入 | 結果 |
|---|---|
| 食後8時間、**30分ごとに3分間**の低強度ウォーキングや簡単なレジスタンス運動 | 食後の血糖・インスリン・Cペプチド・TG 低下、翌朝までの高血糖改善 |
| 1日約14時間の座位を4日間、**30分ごとに10分程度**の立位・軽歩行に置換（座位 約4.7時間/日減少） | CGM で24時間血糖・高血糖時間・インスリン感受性が改善 |

- → **座位が30分を超えたら一度中断し軽い運動**を行う
- 運動と生活活動を合わせた身体活動が高いほど CVD 発症・総死亡が低い
- 座位・臥位でのパソコン作業やテレビ鑑賞を減らし、30分以上座位を継続しない
- 余暇の活動参加・長時間座位の回避は高リスク者の2型糖尿病予防に役立ち、糖尿病患者の血糖コントロールにも役立つ可能性

## 外来での使いどころ（自院メモ）

- 基本処方は「**中強度の有酸素 週150分（週3回以上・休み2日以上続けない）＋ レジスタンス 週2〜3回**」。まず**週100分**でも効果ありと伝えハードルを下げる
- 強度は**「楽〜ややきつい」（RPE 11〜13）**、脈拍なら **50歳未満 100〜120/分、50歳以上 100/分未満**。β遮断薬内服中・自律神経障害例は脈拍でなく自覚強度で
- 数値目標は**歩数が有効**: 現状 +2,000歩/日、最終 **8,000歩/日**
- 仕事帰りの夕方受診者には**デスクワーク中の30分ごとの座位中断**（3分歩く・立つ）を具体的に指導
- インスリン・SU 薬使用者は**空腹時運動を避け食後に**。運動後48時間は低血糖に注意し、必要なら追加・基礎インスリン減量や補食
- 運動開始前チェック: **前増殖網膜症以上なら激しい運動・いきみ・頭位を下げる動作を避ける**（眼科情報を確認）、神経障害例は靴と毎日の足観察、潰瘍があれば荷重運動を制限
- 無症状で速歩程度なら**負荷心電図は不要**。座位中心の高リスク例が中強度以上を始める場合や労作時の胸部症状・息切れがあれば精査を考慮
- 高齢者には**スクワット中心の自重レジスタンス＋バランス運動**でサルコペニア・転倒予防
