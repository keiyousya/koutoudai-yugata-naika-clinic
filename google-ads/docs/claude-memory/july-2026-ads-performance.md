7月は休診(7/16-7/31)のため実質13日間の稼働。

**全体サマリ:**
- 費用: 26,461円 / 表示: 7,490 / クリック: 480 / CV: 168件
- CTR: 6.4% / 平均CPC: 55円 / **CPA: 158円**（6月の約570円から大幅改善）

**時間帯別の知見:**
- 18時台がCV最多(39件)・CPA最良(104円) — 診療開始直後の高intent帯
- 13時・16時がCV32件ずつ — 昼休み「先取り検索」の裏付けが明確
- 20時台は予算枯渇(8クリック・1CV) — 既知の課題だが日予算増は見送り

**曜日別:** 水曜CV最多(47件)、土日もCPA良好(109-120円)。木曜CPA最弱(234円)。

**キーワードTOP3:** 「内科 病院」CPA117円/52CV、「病院 近く」150円/28CV、「内科 夜」124円/15CV

**procyon APIとの照合:**
- procyon対面予約160件 vs Google Ads CV168件 — ほぼ一致
- `lineFollowGoogleAdsCount` が全て0件 → アトリビューション不具合の可能性あり（helix#1745で追跡中）

**How to apply:** CPAが大幅改善しているので、現行設定（日予算1,800円・TARGET_SPEND・既存キーワード）
は変更不要。次月も同水準なら安定運用フェーズ。
