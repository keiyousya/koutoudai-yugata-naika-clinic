# 総論 III めまい（前庭）リハビリテーション：非特異的なリハビリテーション（自院メモ）

- **ガイドライン要約**: [vertigo/jsnt-standard-2020/03-vestibular-rehabilitation.md](https://github.com/keiyousya/clinical-guidelines/blob/main/vertigo/jsnt-standard-2020/03-vestibular-rehabilitation.md)

## 外来での使いどころ（自院運用メモ）

- **前庭神経炎の急性期が過ぎたら早期に離床させ、A・D と E・I から始める。** 「安静にしていれば治る」とは説明しない
- **慢性のふらつきで、中枢性・心因性・薬剤性を除外した例**に、ホームエクササイズとして紙で渡しやすい（A・D・E・I・L が分かりやすい）
- **高齢者は転倒に注意**：閉眼や柔らかい床での練習は、壁際や手すりのそばで行うよう指導する（[加齢によるめまい](https://github.com/keiyousya/clinical-guidelines/blob/main/vertigo/jsnt-standard-2020/08-aging.md) も参照）
- **本章以降の資料**：日本めまい平衡医学会「前庭リハビリテーションガイドライン2024年版」（書籍のみ）、米国理学療法士協会の臨床ガイドライン2022年改訂版（Hall CD et al., J Neurol Phys Ther 46:118–177）。本章の出典は2016年版
