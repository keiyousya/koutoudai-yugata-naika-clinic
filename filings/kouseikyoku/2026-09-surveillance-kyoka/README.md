## 提出前にやること

1. **レセプト（UKE）を OASCIS に登録する**。2026-09-21 時点の「データ登録状況」は
   「レセプトのアップロードや JANIS 情報の連携が行なわれていません」で、**1件も登録が無い**。
   参加登録だけでデータが空のまま届け出ると実態が伴わないので、登録を済ませてから投函する。
2. **参加状況がわかる文書**（様式1の5の記載上の注意3で添付が必須）として
   `OASCIS登録情報_2026-09-21.jpg`（登録情報画面の上半分。ログインIDは写っていない）を印刷する。
   データ登録後に「データ登録状況のPDFダウンロード」で出せるPDFも添えるとよい。
   - OASCIS 登録情報の「加算区分」は 2026-09-21 に「なし」→「外来感染対策向上加算」へ変更済み。
3. 別添7の「令和　年　月　日」（提出日）を手書きで記入し、送付状の日付もそろえる。
4. 別添7＋様式1の5（2枚）＋参加状況の文書＋送付状を封入し、下記へ郵送する。**9/30までに届くように出す**。
