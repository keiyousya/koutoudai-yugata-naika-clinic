# AAO-HNSF Clinical Practice Guideline: Hoarseness (Dysphonia) (Update) 2018

- **出典**: Stachler RJ, Francis DO, Schwartz SR, et al. Clinical Practice Guideline: Hoarseness (Dysphonia) (Update). *Otolaryngol Head Neck Surg.* 2018;158(1_suppl):S1–S42. doi:10.1177/0194599817751030（PMID 29494321）

- **発行**: 2018-03-01（米国耳鼻咽喉科・頭頸部外科学会財団。2009年版 Schwartz らの改訂・置き換え）
- **版**: 2018年改訂版。5年ごとに見直す予定と書かれているが、2026-09-25 時点で後継版は見つからない。論文ページに「Correction(s) for this article」の表示あり（訂正の内容は未確認）
- **確認日**: 2026-09-25

対象は**年齢を問わず嗄声（dysphonia）を呈するすべての患者**で、利用者は**嗄声を診るすべての臨床医**（プライマリケアを含む）。作成委員には家庭医・内科医・老年科医も入っている。**嗄声の約90%は最初にプライマリケア医を受診する**という前提で書かれている。

---

## 1. 定義と前提

| 用語 | 本GLでの意味 |
|---|---|
| Dysphonia（音声障害） | 声の質・高さ・大きさ・発声努力の変化で、コミュニケーションが損なわれる、または QOL が下がる状態。**臨床医が判断するもの** |
| Hoarseness（嗄声） | 患者が訴える「声質の変化」という症状 |
| Laryngoscopy（喉頭鏡検査） | 特記しない限り**間接的な喉頭の視覚化全般**（ミラー、硬性鏡、軟性ファイバー/電子スコープ）を指す |
| Stroboscopy | 声帯振動の異常を見るための発展的な検査 |

- 有病率：生涯で約1/3が経験。成人の13人に1人が毎年声の問題を抱える。女性・70歳以上・教師・歌手・声を多く使う職業で多い
- 受診者の診断で多いのは**急性喉頭炎**、非特異的嗄声、良性声帯病変（嚢胞・ポリープ・結節）、慢性喉頭炎
- 薬剤性：**吸入ステロイド**と乾燥させる薬（抗コリン薬・抗ヒスタミン薬・うっ血除去薬・降圧薬）が特に関連。表7では**ワルファリン・血栓溶解薬・PDE5阻害薬 → 声帯血腫**、ビスホスホネート → 化学性喉頭炎、ACE阻害薬 → 咳

### 推奨の強さの定義

| 強さ | 意味 |
|---|---|
| Strong recommendation | 利益が害を明らかに上回り（反対推奨では害が上回り）、根拠が Grade A/B。明確な理由がなければ従う |
| Recommendation | 利益が害を上回るが根拠は Grade B/C。原則従うが、新しい情報と患者の希望に注意 |
| Option | 根拠が弱い（Grade D）か、方法間に明確な差がない。患者の希望の比重が大きい |

根拠の Grade は A（RCT の SR など）〜 D（症例報告・機序からの推論）、X（検証不能だが利益が明白）。

## 2. Key Action Statements（KAS）

| KAS | 内容（要約） | 推奨の強さ | 根拠 |
|---|---|---|---|
| **1** 異常な声の認識 | 声の質・高さ・大きさ・発声努力の変化でコミュニケーションや QOL が損なわれていれば、dysphonia と認識する | Recommendation | Grade C |
| **2** 原因の評価 | 病歴と身体診察で、原因と管理を変える因子を評価する | Recommendation ※ | Grade C |
| **3** ケアの格上げ（新設） | 病歴・診察で**早期の喉頭評価が必要な因子**を探す：**頭頸部・胸部の最近の手術、最近の気管挿管、頸部腫瘤、呼吸困難・喘鳴（stridor）、喫煙歴、職業的音声使用者**（これらに限らない） | **Strong recommendation** | Grade B |
| **4A** 喉頭鏡はいつでも可 | 嗄声の患者にはいつでも診断的喉頭鏡検査を行ってよい | Option | Grade C |
| **4B** 持続する嗄声の喉頭鏡 | **4週以内に改善・消失しない場合**、または**期間によらず重大な原因が疑われる場合**は、喉頭鏡を行うか、行える医師へ紹介する | Recommendation | Grade C |
| **5** 画像検査 | 声の症状が主の患者に、**喉頭を見る前に CT・MRI を撮らない** | Recommendation against | Grade C |
| **6** 抗逆流薬 | GERD や LPR を疑って、**症状だけを根拠に、喉頭を見ずに、嗄声だけの患者**に抗逆流薬を処方しない | Recommendation against | Grade B |
| **7** ステロイド | **喉頭を見る前に**ステロイドを**ルーチンに**処方しない | Recommendation against | Grade B |
| **8** 抗菌薬 | 嗄声の治療に抗菌薬を**ルーチンに**処方しない | **Strong recommendation against** | Grade A |
| **9A** 音声治療前の喉頭鏡 | 音声治療を処方する前に喉頭鏡を行う（または紹介する）。結果を言語聴覚士（SLP）に伝える | Recommendation | Grade C |
| **9B** 音声治療の推進 | 音声治療で改善しうる原因の嗄声には、**音声治療を勧める** | **Strong recommendation** | Grade A |
| **10** 手術 | 悪性疑い、保存治療に反応しない症状のある良性声帯病変、声門閉鎖不全などでは手術を選択肢として勧める | Recommendation | Grade B |
| **11** ボツリヌストキシン | 痙攣性発声障害などの喉頭ジストニアには BT 注射を提供する（または紹介する） | Recommendation | Grade B |
| **12** 教育・予防 | 嗄声の患者に、コントロールと予防の方法を伝える | Recommendation | Grade C |
| **13** アウトカム（新設） | 治療後または経過観察後に、嗄声の消失・改善・悪化、QOL の変化を記録する | Recommendation | Grade C |

※ KAS 2 は本文の推奨文・Abstract・Table 4 では「Recommendation」だが、action statement profile の Policy level 欄は「Strong recommendation」と書かれており、原文内で不一致がある。

## 3. 重要な KAS の解説の要点

### KAS 3 ケアの格上げ（早期に喉頭を見るべき患者）

- **喫煙者の新たな嗄声**は、リンパ節腫大・頸部腫瘤の有無にかかわらず、頭頸部癌除外のために喉頭の診察へ紹介する。喫煙は頭頸部癌のオッズを2〜3倍にする最大の危険因子。頸部腫瘤があればさらに懸念が強い（進行例の可能性）
- **頸部前方・心臓胸部・脳神経の手術後の新たな嗄声** → 早期に喉頭評価（術後2週〜2カ月の間に行うよう別の AAO-HNSF GL が推奨）。**抜管後の嗄声**も挿管期間によらず早期評価（声帯損傷・麻痺・誤嚥のリスク）
- **嗄声＋構音障害・嚥下障害・上位運動ニューロン徴候**は ALS などの初発症状のことがある → 早期に喉頭評価し神経内科へ
- **喘鳴（stridor）や呼吸困難を伴う嗄声は、ただちに（immediate）ケアを格上げする**
- **職業的音声使用者**：歌手・教師だけでなく、コールセンター職員、受付、看護師、医師、弁護士など**声に頼って働く人すべて**。遅れると損傷が広がったり仕事に大きく響くおそれがあるので、耳鼻科（可能なら音声専門の喉頭科医 laryngologist）への**早期紹介**を提案する。趣味で声を多く使う人（avocational）も懸念が強ければ早めに格上げしうる。原因がはっきりしなければ laryngologist への紹介が有用
- 格上げの理由をカルテに記録する

### KAS 4A・4B 喉頭鏡のタイミング

- ウイルス性上気道炎は嗄声の最も多い原因で、**ウイルス性喉頭炎の症状は通常1〜3週で自然に治る** → 新規発症の多くは**まず経過観察が妥当**
- それを超えて続く場合は、自然に治りにくい別の病態を考える。**4週か6週かで委員の意見が分かれ、投票で4週（10票対5票）**に決まった
- 「重大な（serious）」には2つの意味がある：①**寿命を縮める原因**（悪性など）、②**患者にとっての影響が大きい**こと（職業的音声使用者で仕事ができない、QOL が大きく落ちる）
- 背景データ：嗄声の約90%は最初にプライマリケアを受診。プライマリケア医の64%は慢性（6週超）の嗄声を紹介せず自分で治療すると回答。耳鼻科紹介が3カ月を超えると医療費が2倍以上。紹介後の喉頭評価で、プライマリケアでの診断（ほぼ「急性喉頭炎」か「非特異的嗄声」）が**56%で変わり**、良性声帯病変・声帯麻痺・**喉頭癌**が見つかっている
- 英国では喉頭癌疑いに14日以内の喉頭鏡を義務づける fast-track クリニックがある
- 実装上の注意として「**4週を超えて喉頭を見ずに待たせない。重大な原因が疑われれば喉頭鏡はただちに**」と明記

### KAS 6 抗逆流薬（PPI）

- 目的は、**GERD 症状（胸やけ・呑酸）がなく、喉頭も見ていない「嗄声だけ」の患者**への経験的な抗逆流薬を減らすこと
- 根拠：Cochrane では質の高い試験なし。PPI のプラセボ対照 RCT 9本のうち、改善を示したのは3本のみ。対象・診断基準・評価項目がばらばら
- 一方、**GERD 症状がある患者**では抗逆流療法で慢性喉頭炎症状（嗄声を含む）が改善しやすい。**喉頭鏡を含む診察で LPR が疑われる場合や、GERD 症状の治療に使うことは制限しない**
- 経験的 PPI は診断の見逃しと治療の遅れにつながる。長期 PPI のリスク（認知機能、腸管感染、肺炎、クロピドグレルとの相互作用、骨折、B12 低下、低 Mg、CKD）も挙げている。ただし適応のある短期使用は利益が上回るとする

### KAS 7 ステロイド

- 目的は、**喉頭を見る前の経験的なステロイド投与**をやめること。プライマリケアや急患診療で急性喉頭炎推定に経口ステロイドがよく出されているが、有効性を支持するデータはない
- 短期でも長期でも副作用がある（不眠・消化器症状、耐糖能悪化、骨折、白内障、副腎抑制 など）。**吸入ステロイドの長期使用はそれ自体が嗄声の原因**（うがい、飲水、最小用量で軽減）
- 「routine（ルーチンに）」とした理由：喉頭鏡の結果やほかの状況から、個別に正当化される場合があるため
- **使用が考えられる場面**：
  - **小児のクループ**（本 KAS の除外対象）
  - **気道狭窄**で浮腫・炎症を減らしたい場合（**原因の評価をしてから**）
  - 喉頭を侵す自己免疫疾患（SLE、サルコイドーシス、多発血管炎性肉芽腫症）
  - 演奏者のアレルギー性喉頭炎（質の低い報告のみ）
  - **声を職業・趣味で使う人の急性喉頭炎**：短期のステロイドがよく処方されるが、強い根拠はない。**診断が確定し治療の標的がはっきりしている場合に**、リスクと根拠の乏しさを説明したうえで**患者と共有意思決定**する
- 結論：**経験的には使わない**

### KAS 8 抗菌薬

- 嗄声の多くは**急性ウイルス性喉頭炎**。**急性喉頭炎は治療の有無にかかわらず、多くが7〜10日で症状が改善する**。Cochrane で、成人の急性喉頭炎に抗菌薬は客観的指標で効果がない
- 害：副作用、耐性菌、コスト、**喉頭カンジダ症の誘発・悪化**
- 例外（除外対象）：細菌・真菌・抗酸菌による嗄声。免疫不全患者の喉頭結核、吸入ステロイド使用者の非結核性抗酸菌感染、**百日咳**、黄色ブドウ球菌などによる細菌性喉頭気管炎（痂皮、咳、喘鳴、呼吸努力の増加）。**診断を確定してから**使う

### KAS 9A・9B 音声治療

- 音声治療は**喉頭で診断がついてから**始める。SLP は喉頭鏡の前に治療を始めない
- 音声治療は小児から高齢者まで有効（2歳未満は家族への指導）。**一次性 MTD** に有効（声の衛生指導単独より優れる）。手術前後、アレルギー・喘息・抗逆流療法との併用、パーキンソン病、奇異性声帯運動、声門閉鎖不全、片側声帯麻痺、肉芽腫、BT との併用などでも使われる
- 生理学的アプローチ（呼吸・発声・共鳴の再調整）は RCT で支持されている。**衛生的アプローチ（声の衛生）単独の結果は一定しない**
- 歌手では歌唱指導者との連携も有用

### KAS 10 手術（要点のみ）

- 悪性を疑う病変（血管増生、潰瘍、外向性発育）は速やかに生検。白板症は刺激の回避とカンジダ治療を先に試みる
- **良性の声帯病変（ポリープ・嚢胞・結節）は、まず保存的治療**（多くは自然軽快・可逆的）。音声治療などで満足な声にならない場合に手術。**小児の結節は発達とともに軽快することが多く、音声治療が第一**

### KAS 12 教育・予防

- 教師・歌手・高齢者など高リスクの人には特に、声の衛生を指導し、話した内容を記録する
- 表9「予防のためにすること・避けること」の要点：
  - **すること**：毎日十分に水を飲む／広く騒がしい場所では拡声器を使う／**疲労・無理・使いすぎを防ぐために声を短時間休ませる**／乾燥した環境では加湿する
  - **避けること**：喫煙・受動喫煙／**叫ぶ・大声・騒音下で話す・ささやき声（whispering）による声の使いすぎや無理な発声**／過剰な咳払い・咳／アルコール・カフェイン（乾燥）／乾燥させる薬
- 根拠：教師422人で水分摂取なしは嗄声リスク60%増。**アマチュア歌手で水分補給と声の休息期間により声の疲労が減った**。拡声は多用時の声質を保つ。声の衛生教育の RCT は小規模で推測統計ができていない

### KAS 13 アウトカム

- 新規の嗄声は**発症後数週以内に**状態と消失を記録し、消失しなければ喉頭鏡（KAS 4A/4B）。紹介の理由も記録する。フォローは電話でもよい

## 外来での使いどころ（自院運用メモ）

当院は**喉頭を観察できない**（喉頭鏡も間接喉頭鏡もない）。できるのは問診、咽頭・鼻の視診、頸部の診察（リンパ節・甲状腺・腫瘤）、呼吸状態と神経所見の確認まで。このGLの「喉頭鏡を行うか、行える医師へ紹介する」は、**当院ではすべて「耳鼻科へ紹介する」と読む**。

### 1. 救急サイン（その場で救急要請・救急外来へ）

- **吸気性喘鳴（stridor）・呼吸困難を伴う嗄声**（KAS 3：ただちに格上げ）
- **急性喉頭蓋炎を疑う所見**：**GL記載なし**（本GLにも日本のGLにも、急性喉頭蓋炎の診療の記載はない。日本のGLは分類表に病名があるだけ）。以下は一般的な臨床知識としての当院メモ：
  - 強い咽頭痛・嚥下痛のわりに**口腔咽頭所見が軽い**
  - こもった声（含み声）、**唾が飲み込めない・流涎**、前かがみで座る姿勢、吸気性喘鳴、呼吸困難、発熱
  - → 舌圧子で無理に咽頭を診ない、臥位にしない、**救急要請して救急外来・耳鼻科のある病院へ**。当院で経過を見ない
- 急な頸部の腫脹、外傷後の嗄声・皮下気腫、異物誤嚥の疑いも同様に当日対応

### 2. 耳鼻科紹介の基準（当院）

| 緊急度 | 状況 | 根拠 |
|---|---|---|
| **当日〜翌日** | 急な発症（とくに**歌唱・叫声・強い咳の最中に突然**）、**声域の低下（高い声が出ない）・声の裏返り**、声がほぼ出ない → **声帯出血（声帯血腫）を疑う**。抗凝固薬・抗血小板薬・PDE5阻害薬の内服があればさらに疑う | 声帯出血の初期対応は**GL記載なし**（日本のGLは分類表と薬剤表のみ、本GLは薬剤表の「声帯血腫」のみ）。職業的音声使用者の早期紹介（KAS 3）と「重大な原因の疑い」（KAS 4B）を当院の判断で当てはめた |
| **早めに（数日以内）** | **歌手・俳優・教師・保育士・コールセンターなど声の職業使用者**、趣味でも声が重要な人（ボーカル、合唱、ライブ予定）で本人の懸念が強い | KAS 3（Strong）、KAS 4B |
| **早めに** | 喫煙者（とくに中高年）の新たな嗄声、頸部腫瘤・リンパ節腫大、血痰、嚥下障害・嚥下痛、耳痛、体重減少、増悪傾向、免疫不全 | KAS 3、日本GL CQ3 |
| **早めに** | 頸部・甲状腺・胸部・心臓の手術後、最近の全身麻酔（挿管）後の嗄声 | KAS 3 |
| **早めに（神経内科と並行）** | 構音障害・嚥下障害・筋力低下・線維束性収縮などの神経症状 | KAS 3 |
| **定期的に** | 上記がなく、**2〜4週たっても改善しない**嗄声 | KAS 4B（4週）。当院では2週で改善傾向がなければ紹介を提案し、遅くとも4週で紹介する |

- **紹介までの間に CT・MRI を撮らない**（KAS 5）。画像は耳鼻科が喉頭を見てから判断する
- 紹介状には、発症日と様式、声の使い方（職業・予定）、喫煙歴、手術・挿管歴、内服薬（抗凝固薬・吸入ステロイドなど）、GERD 症状、当院での所見（咽頭・頸部・MPT など）を書く

### 3. 喉頭観察前の薬の扱い

| 薬 | 当院の方針 | GLの位置づけ |
|---|---|---|
| **ステロイド**（内服・吸入） | **ルーチンに出さない**。声の職業使用者に「明日のために」と求められても、喉頭所見なしには出さない。使うのは、気道狭窄を疑い搬送までのつなぎとして判断する場合や、原疾患（アレルギー・自己免疫疾患など）の治療に限る | KAS 7：Recommendation against（Grade B）。使用を考えるのは「診断が確定し標的が明確な場合」の共有意思決定。日本GL CQ9：限られた疾患を除き有効性のエビデンスなし |
| **抗菌薬** | **出さない**。溶連菌陽性の咽頭炎、細菌性副鼻腔炎、百日咳など、**別の診断で適応がある場合だけ** | KAS 8：**Strong recommendation against**（Grade A）。急性喉頭炎は7〜10日で改善する |
| **PPI** | 嗄声だけの患者には出さない。**胸やけ・呑酸など典型的な GERD 症状があれば GERD として治療してよい**。「逆流のせいかも」で PPI を出して様子を見ることはしない | KAS 6：Recommendation against（Grade B）。日本GL は喉頭所見に基づく文脈で PPI（診断的治療を含む）を肯定 |
| **トラネキサム酸** | 日本では声帯出血・声帯の発赤に慣用されるが、**根拠は限定的**。出すかどうかより、**発声を控えさせ早く耳鼻科で喉頭を見てもらう**ことを優先する | 日本GL：「投与されることが多い」と慣用を記載するのみ（研究の引用なし、推奨度なし）。**本GL（AAO-HNS）には記載なし** |
| 対症療法 | 咽頭痛にはアセトアミノフェンなど、痰がらみにはカルボシステインなど。加湿・水分 | 日本GL第5章で補助的に記載（推奨度なし）。KAS 12 の水分・加湿 |

### 4. 声の安静・ささやき声

- **GLに書かれていること**
  - 本GL（KAS 12・表9）：予防として「**疲労・無理・使いすぎを防ぐために声を短時間休ませる**」、避けることとして「叫ぶ・大声・騒音下で話す・**ささやき声**」。アマチュア歌手で水分と声の休息により声の疲労が減ったという研究を引用
  - 日本GL：沈黙の記載は**声帯手術後**のみ（沈黙3日と7日の比較で3日で十分、早く音声治療を始めた方が回復が早い）
- **GLに書かれていないこと**：急性喉頭炎や声帯出血のときに**何日声を休ませるか**、完全沈黙が必要か、は**どちらのGLにも記載なし**
- **当院の説明の仕方**：
  - 「声を出さない時間を増やし、話すときは**ささやかず、小さめの普通の声で短く**」（ささやき声は AAO-HNS で避けるべき行為に入っている）
  - 大声・叫ぶ・歌うのを控える、咳払いを減らす、水分をとる、加湿、禁煙・飲酒を控える
  - 声帯出血が疑われる場合は、耳鼻科で喉頭を見てもらうまで**歌唱・大声は中止**するよう強く勧める（GL記載なし。当院の判断）

### 5. 実例：「ライブ前日の20歳男性、1週間続く嗄声」での判断の流れ

（仮想例。個人を特定する情報は含めない）

1. **救急サインを確認**：喘鳴・呼吸困難・流涎・強い嚥下痛・高熱がないか → あれば救急（上の1.）
2. **発症様式を聞く**
   - 感冒症状（鼻汁・咽頭痛・咳）に続いて徐々に → **急性ウイルス性喉頭炎**の可能性が高い。通常1〜3週で自然に治る（KAS 4B・8）
   - 歌唱中・叫んだ後に**突然**、**高い声が出ない・裏返る・声域が狭くなった** → **声帯出血や声帯病変**を疑う（喉頭を見ないと区別できない）
3. **危険因子を確認**：喫煙、頸部腫瘤、手術・挿管歴、抗凝固薬・抗血小板薬・PDE5阻害薬、神経症状、GERD 症状、吸入ステロイド。20歳で危険因子がなければ悪性の可能性は低いが、**ゼロにはしない**
4. **位置づけ**：ライブで歌うボーカルは**職業的・趣味的な音声使用者**に当たり、KAS 3（Strong）の「早期の喉頭評価」の対象。KAS 4B の「重大」には「患者にとって影響が大きい」ことも含まれる → **4週を待たず、ライブ前に耳鼻科（できれば音声外来）で喉頭を見てもらうよう勧める**。夕方外来なので当日は難しいことが多く、**翌日午前の耳鼻科受診**を具体的に案内する
5. **当院での処方**
   - 抗菌薬：出さない（細菌感染の別の根拠がなければ）
   - ステロイド：**喉頭を見ないまま「ライブのために」は出さない**。本人が強く希望する場合は、根拠が乏しいこと、副作用、**声帯出血だった場合には効かず、歌うことで悪化しうること**を説明し、耳鼻科で喉頭を見たうえで判断してもらうよう伝える（KAS 7 の共有意思決定は「診断が確定したうえで」が前提）
   - PPI：GERD 症状がなければ出さない
   - トラネキサム酸：当院からは原則出さない（根拠が限定的。出血を疑うなら耳鼻科での評価を優先）
   - 対症療法と声の衛生：水分、加湿、咳払いを減らす、ささやかない、ライブまで話す量を減らす
6. **ライブに出てよいか**：**GL記載なし**。喉頭所見なしに当院で可否を判断しない。「突然の発症・声域低下・裏返り」があれば出血の可能性を説明し、耳鼻科受診までは歌唱を控えるよう強く勧める。最終判断は耳鼻科の所見を踏まえて本人が決める
7. **記録と再診**：発症様式、声の使用予定、説明した内容（ステロイドを出さなかった理由を含む）、紹介の理由をカルテに残す（KAS 3・13）。ライブ後も続く、または発症から2〜4週で改善しなければ、耳鼻科未受診でも必ず紹介する
