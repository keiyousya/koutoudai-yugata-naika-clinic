## 提出方法

すべての申請書・届出書は、**窓口持参または郵送**（Q&A Q1-3）。メール提出の案内はない。
ただしベースアップ評価料の報告書のように、手続きによっては県別の専用メールアドレスへ
Excelを添付して出すものもある。手続きごとに案内を確認する。

申請・届出様式の一覧（様式は改定されるので毎回ここから取り直す）
https://kouseikyoku.mhlw.go.jp/tohoku/shido_kansa/hokenniryoukikannsinnsei.html

## 問い合わせ

**お問い合わせ（ご質問）フォーム**を使う。回答は入力したメールアドレスに届く。
本文1000文字以内、半角カナ・特殊文字は不可。
https://kouseikyoku.mhlw.go.jp/form/pub/kousei02/tohoku_inquiry2

**県別の疑義照会フォームは、診療報酬の解釈以外に使わない。**
「疑義照会専用」「メールアドレスは入力しない」「回答は電話で行う」と明記されている。
対象は算定・施設基準・DPC・その他の4項目のみ。
