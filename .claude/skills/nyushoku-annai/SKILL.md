# 入職案内（LINE WORKS）

対象: $ARGUMENTS

このリポジトリは公開リポジトリなので、Google Drive のリンクや応募者の個人情報はここに書かない（Drive のリンクは memory の `staff-onboarding` を参照）。

## 前提

- 内定連絡はさくらメール（`tamurakeito@koutoudai-yugata-naika.clinic`）で送り、そこで LINE WORKS の招待リンクを案内している。過去の内定メールは `INBOX.Sent Messages` を「採用内定のお知らせ」で検索すると出る
- 本人が LINE WORKS に登録したら、トークルーム「◯◯さん個別連絡」（田村慧人・田村さつき・本人）を作る
- トーク送信は WORKS MCP ではできない（Bot API なし）ので、Chrome で `https://talk.worksmobile.com/` を操作する
- **送信は取り消せない。Enter（＝送信）や転送の確定は、ユーザーが「送信して」と言うまで押さない**。入力欄に入れたところで止めて見せる

## 1. 入職案内を入力する

冒頭に `@本人` のメンションを付ける（メンションは入力欄で `@` を打って候補から選ぶ必要があるので、ユーザーに付けてもらうか、既に付いていればメンションノードを残したまま後ろだけ差し替える）。

文面（2026-10 遠藤さんに送った版。初回出勤前の来院 → その際の書類、の順にすると自然）:

```

初回出勤の前に一度、書類のご提出とクリニックのご説明のためにお越しいただきたいと考えております（1時間程度）。
```

## 2. 制服写真・サイズ表を転送する

- 元は「勾当台夕方内科クリニック🌙」に 2026-03-20 に田村さつきが投稿した画像6枚。過去の個別連絡（例: 星さん個別連絡 2026-04-28、遠藤さん個別連絡 2026-10-23）に「転送」として残っている
- その転送メッセージの「︙」→「転送」→ そのメッセージだけにチェック →「転送 (1)」→ 宛先に本人の個別連絡だけを選ぶ →「転送」
- 案内文で「制服写真、サイズ表をご確認いただき」と書くので、**案内文の後に転送する**のが自然（ユーザーの指示があれば先でもよい）

## 3. 初回出勤日の候補を出す

WORKS MCP の `calendar_list_events` で「看護師シフト」「受付事務シフト」を読む（カレンダーIDは `/lineworks-shift` スキル参照。範囲は最大31日・UTC 指定）。

- 初回出勤日の候補: **平日で、看護師も受付事務も田村さつき1人の日**（17:00〜21:00）。新人に付けるため
- 書類提出・説明の来院を別日にする場合の候補: 平日で、看護師は田村さつき1人・受付事務はいる日
- 12月以降などシフト未登録の月は出せないので、その旨を伝える

文面例:

```
追加でご連絡です。
初回出勤日について、下記の日程からご都合の良い日を教えていただけますでしょうか（いずれも17時〜21時です）。

・10/29（木）
・11/5（木）

また、書類のご提出とクリニックのご説明を初回出勤日とは別日にされる場合は、下記の日程でも大丈夫です。

・10/26（月）
・10/28（水）

お手数ですが、ご確認よろしくお願いいたします。
```

## 入職が決まったら

- シフト管理DBの `shift_staff` に追加（管理画面のスタッフ管理）
- LINE WORKS の「看護師シフト」「受付事務シフト」両カレンダーの共有に本人を追加（「予定の詳細を閲覧」）
- `staff/採用者リスト.html` に追記

## Chrome 操作のコツ（トーク）

- 入力欄は `.editor_input.message-input`（Lexical エディタ）。`execCommand('insertText')` だと改行が消えるので、`DataTransfer` に `text/plain` を入れて `ClipboardEvent('paste')` を dispatch すると改行付きで入る
- 既存の文面の一部だけ差し替えるときは、対象テキストノードに Range を張って `selectionchange` を発火させてから paste する（メンションノードは残る）
- 下書き中のルームで別ルームを開くと入力が消えることがあるので、他ルームを見るときは別タブで開く
- 過去のトークは、メッセージ一覧のスクロール要素を `scrollTop = 0` に繰り返して読み込み、`innerText` で読む
