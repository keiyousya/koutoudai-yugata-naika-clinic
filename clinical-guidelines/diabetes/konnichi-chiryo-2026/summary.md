## ニュートピックス

- 災害時糖尿病診療マニュアル2024 に改訂
- JDS が2024-05、リアルタイムCGM の指針と FreeStyleリブレ（isCGM）の見解を統合し「**持続グルコースモニタリングデバイス適正使用指針**」に改訂
- 保険適用外での isCGM 使用について「**選定療養**」の運用が示された
- CGM デバイスの**施設要件が撤廃**された

## 治療のポイント

- 血糖だけでなく血圧・脂質・体重・禁煙を**包括的に管理**し、合併症阻止・健康寿命・QOL を目指す
- 食事・運動療法で目標未達 → 血糖降下薬。経口薬の組み合わせでも不十分 → GLP-1RA・インスリンなど注射へ
- 急性代謝失調・重症感染症では**最初から強化インスリン療法**

## 病態と診断

- 2型はインスリン分泌不全（絶対的）と抵抗性（相対的）で生じる。**抵抗性だけでは発症せず、分泌で代償できなくなって発症**する
- 分泌不全の本態は β細胞のグルコース感知不全。罹病が長いと β細胞量そのものが減る
- 合併症は細小血管症・大血管症に加え、**心不全、脂肪性肝疾患、老化関連疾患（認知症・サルコペニア）** まで含めて捉える
- 診断: 糖尿病型を別の日に2回（HbA1c のみでは不可）。1型・遺伝子異常・内分泌疾患・肝硬変・膵癌などを除外
- **急な血糖悪化 → 感染症・悪性腫瘍を探す**。初診時に合併症を評価

## 治療方針

### A. インスリンがすぐ必要な場合（内因性分泌の著減、急性代謝失調、重症感染症）

- ためらわずインスリン。重症例は専門医と連携。SMBG が必要
- **持効型 1日1回から**（デグルデク、グラルギン。4〜10単位程度で開始し朝食前血糖で調整）
- 次に各食直前の**超速効型を追加**した強化療法（GL2024 推奨グレード B）
  - **カーボカウント**: 超速効型 1単位でおおむね糖質 10〜15 g
  - **補正インスリン**: 超速効型 1単位でおおむね血糖 50 mg/dL 低下
- 注意点
  - 調整しても乱高下する不安定型（brittle）→ インスリンポンプを考慮
  - インスリンによる低血糖・体重増加は心血管疾患・死亡リスクと関連
  - **同じ部位への注射で脂肪増生・アミロイド沈着 → 吸収低下**。乱高下したら注射部位を見て、広くローテーションするよう指導

### B. インスリンがすぐには不要な場合

**1. 基本**: 生活・食習慣の是正と運動
- 食事: 早めの夕食後、翌朝まで間食しない**時間制限食（time-restricted eating）** が導入しやすい
- 運動: 有酸素・無酸素とも有効。**高強度インターバルトレーニング**は短時間で効果があり、時間制限食による筋萎縮も防ぎうる

**2. 低血糖を起こさないファーストライン**（いずれか、または併用）

| 薬 | 処方例 | 要点 |
|---|---|---|
| メトホルミン | 500 mg 錠、1日最大 2,250 mg、1日1〜3回 | 肝糖産生抑制に加え、腸管・腸内細菌叢・GLP-1 分泌・十二指腸-中枢-肝臓軸など多面的に作用。**肥満の有無を問わず有効**。**血管合併症・悪性腫瘍を抑制するエビデンスあり**。高齢・腎機能低下・脱水は乳酸アシドーシスのリスクなので少量から |
| イメグリミン | 1回 1,000 mg 1日2回 | 構造はメトホルミンに類似するが**乳酸アシドーシスのリスクは低い**。肝糖産生抑制は弱く、インスリン分泌刺激作用がある。**効果発現まで3〜6ヵ月**。2021年発売でエビデンスは不十分 |
| DPP-4阻害薬（例: テネリグリプチン 20 mg） | 1日1回 | 血糖依存性の分泌促進で単独では低血糖なし。**アジア人で特に有効だが、腎・心血管合併症の抑制エビデンスはない**。まれに類天疱瘡・**RS3PE症候群**などの自己免疫関連疾患 |

**3. 心不全・蛋白尿・腎不全の合併 → SGLT2阻害薬か GLP-1RA をファーストライン**
- エンパグリフロジン 10 mg、カナグリフロジン 100 mg、ダパグリフロジン 5 mg（いずれも1日1回）: GL2024 推奨グレード A
- GLP-1RA: 腎症に推奨グレード B、大血管症の進行抑制に推奨グレード A
- 尿路・性器感染症がある人には SGLT2阻害薬を控える。**分泌不全状態や糖質制限下ではケトーシスを招きやすい**

**4. MASLD（代謝機能障害関連脂肪性肝疾患）の合併**
- トホグリフロジン 20 mg、イプラグリフロジン 50 mg、または GLP-1RA

**5. 肥満症の合併 → 薬物か外科治療**
- 経口セマグルチド 3 mg → 4週以上あけて 7 mg → 14 mg。飲み方の制約（空腹時、水120 mL以下、30分〔できれば1〜2時間〕飲食しない）が守れないなら**週1回注射の方がかえって便利**
- セマグルチド注 0.25 mg 週1回 → 0.5 mg → 最大 1.0 mg
- チルゼパチド注 2.5 mg 週1回 → 5 mg → 2.5 mg ずつ増量、最大 15 mg
- 急性膵炎・胆石症・膵癌の既往には慎重に
- 肥満外科治療: BMI ≧35 の治療抵抗性肥満症（代謝合併症あり）でスリーブ状胃切除術・スリーブバイパス術が保険適用。スリーブ状胃切除は BMI ≧32 でも合併症2つ以上（糖尿病は HbA1c ≧8.0%）なら適用。減量より先に糖代謝が改善する。**肥満症専門病院へ紹介**

**6. それでも不十分なときの追加**
- アナグリプチン/メトホルミン配合錠（DPP-4i とメトホルミンを1錠にまとめる）
- ミチグリニド/ボグリボース配合錠（食後高血糖。服用1〜2ヵ月は腹部膨満、開腹・腸閉塞の既往は慎重）
- グリクラジド（半減期が比較的短く、朝1回で日中を抑えたいとき）
- グリメピリド 0.5 mg から最大 3 mg（空腹時血糖を抑えたいとき。**DPP-4i 併用・腎不全・高齢で低血糖に注意**）
- インスリングラルギン/リキシセナチド配合注（5〜10ドーズから最大20ドーズ）
- 強化インスリン療法（細小血管症の抑制に推奨グレード B）
- **グリニド以降へのステップアップは低血糖リスクを上げる**

**7. 境界型**
- 食事・運動療法。境界型自体が心血管リスクなので、動脈硬化の精査と血圧・脂質・肥満の厳格管理
- 高血圧・脂質異常症を合併する境界型に**ボグリボースの保険適用あり**

### C. 治療強化のタイミング

- 目標未達と知りながら現行治療を続ける **clinical inertia** を避け、ためらわずステップアップするか専門医と連携

## 専門医へのコンサルト

- DKA・高血糖高浸透圧症候群・分泌著減・急性代謝失調・重症感染症（入院で強化インスリン＋補液＋感染症治療）
- 初診時の合併症評価
- 急な血糖悪化（感染症・悪性腫瘍の精査）、合併症の急な進行
- 外科手術・化学療法
- **長期に管理不良だった人の急な血糖降下は網膜症悪化・有痛性神経障害を起こしうる** → 専門医と連携してゆっくり下げる
- 強化療法でも不安定な brittle diabetes（ポンプの適応検討）

## 帰してはいけない患者

- DKA・高浸透圧状態・急性代謝失調・重症感染症
- 原因不明の急な血糖悪化
- **長時間作用型 SU薬（グリメピリドなど）の低血糖**: 糖を入れて回復しても遷延するので、ルートを確保して入院

## 患者説明のポイント

- 診断に落ち込む人には「体質の1つ」と伝えてよい。**倹約遺伝子仮説**（少ないエネルギーで血糖を保てる体質ほど、過栄養の現代では破綻しやすい）を紹介し、「劣っているのではなく環境に合っていないだけ」と前向きに理解してもらう
- 肥満のある人には「減らした分だけ良くなる余地が大きい」と伝え、精神論でなく具体的な提案を少しずつ出して燃え尽きを防ぐ
- **通院中断は予後不良因子**。血糖が悪くても通い続けること自体に意味がある。中断理由（向き合うのが怖い、痛くないので不要と思う、医療費）を理解し、脅しではなく安心できる説明で通院を続けてもらう

## 服薬指導・薬剤情報

| 薬 | 指導の要点 |
|---|---|
| メトホルミン | 乳酸アシドーシスの初期症状（強い倦怠感、吐き気、下痢、筋肉痛）ですぐ連絡。eGFR <30 は禁忌、高齢者は腎・肝機能に注意 |
| SGLT2阻害薬 | インスリン・SU薬と併用するときはそれらを減量し低血糖教育。脱水予防。**血糖が良好でもケトアシドーシス**が起こりうる |
| DPP-4阻害薬 | SU薬併用時は SU を減量（特に65歳以上、Cr ≧1.0）。**水疱性類天疱瘡は紅斑に乏しい非炎症型も多い**。肥満・多量飲酒者は急性膵炎に注意 |
| GLP-1RA・チルゼパチド | SU薬併用で低血糖。投与初期の胃腸症状。**経口セマグルチドは胃から吸収されるため、胃切除後は効果が不十分** |
| SU薬 | 遷延性の重症低血糖（特に高齢者）。症状が出たらブドウ糖か砂糖、α-GI 併用中はブドウ糖。5分で回復しなければ繰り返す |
| ピオグリタゾン | 浮腫（特に女性）、貧血、LDH・CPK 上昇。女性・高齢者は 7.5〜15 mg から |
| α-GI・グリニド | 必ず食直前。食後では効かない |
| イメグリミン | 1日2回、食前・食後どちらでも可。インスリンを含め全ての血糖降下薬と併用可だが、**GLP-1RA 併用では効果が減る**。**ビグアナイド併用で投与初期の消化器症状が多い** |
| インスリンイコデク（週1回基礎インスリン、2025-01発売） | 軽い低血糖（54〜70未満）が多い。在宅医療やアドヒアランスに問題がある人で検討。切り替え時は従来の1日量の7倍を週量の目安にし、**初回のみその1.5倍** |

## ほかの資料との違い（自院メモ）

| 項目 | 今日の治療指針2026 | マニュアル2026 / GL2024 |
|---|---|---|
| ファーストライン | **メトホルミン・イメグリミン・DPP-4i を並列**（いずれか、または併用） | マニュアル: メトホルミン固定、次に SGLT2i/DPP-4i/経口GLP-1RA。イメグリミンはステップ3のオプション。GL2024: 固定の第一選択なし |
| 合併症別の選択 | 心不全・蛋白尿・腎不全 → SGLT2i か GLP-1RA、**MASLD → トホグリフロジン・イプラグリフロジン・GLP-1RA**、肥満 → 経口/注射セマグルチド・チルゼパチド | マニュアル: 注射 GLP-1RA・チルゼパチドの導入は専門医へ紹介 |
| イメグリミン | 乳酸アシドーシスのリスクは低い、効果発現まで3〜6ヵ月 | GL2024: 動物実験でメトホルミンより低リスク、臨床試験で重大な副作用なし |
| メトホルミンのエビデンス | 血管合併症に加え**悪性腫瘍の抑制**も挙げる | GL2024: 癌リスク低減は結論未確定 |
| DPP-4i の副作用 | 類天疱瘡に加え **RS3PE症候群** | GL2024: 類天疱瘡、バセドウ病増悪 |

### 外来での使いどころ

- 処方例と服薬指導の要点がそろっているので、**薬を出すときの説明の確認**に使う
- MASLD 合併、肥満合併などの「合併症別のファーストライン」は、マニュアル2026 のステップ（固定順）を補う視点として参照する
- 急な血糖悪化 → 感染症・悪性腫瘍、長く管理不良だった人 → ゆっくり下げる、は紹介判断のチェックポイントにする
- 通院中断を防ぐ説明（倹約遺伝子仮説、脅さない）は初診時の説明に取り入れる
- 「糖尿病の食事指導」「糖尿病の運動療法」の項は未作成
