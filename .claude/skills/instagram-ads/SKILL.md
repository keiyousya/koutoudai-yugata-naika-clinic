# Instagram広告（画像作成 → 出稿）

依頼内容: $ARGUMENTS

初回の実例は 2026-09-28 のインフル予防接種広告（`instagram/flu-vaccine.html`、キャンペーン「インフル予防接種2026_トラフィック」）。迷ったらこれに合わせる。

## 1. 材料を集める

- 料金・時間・対象・予約方法は `frontend/src/pages/*.astro` と `frontend/src/components/*.astro` を正とする。Instagramの過去投稿とHPが食い違うことがあるので、食い違いは報告する
- 配信対象は若い世代（18〜64歳）が前提。65歳以上の定期接種など、対象外の情報は画像・本文に入れない
- 流行状況など根拠が要る表現は入れない（医療広告。ユーザーにも外すよう言われた）

## 2. 画像を作る（`instagram/*.html`）

- 1ファイルに `.post.feed`（4:5 = 1080×1350）と `.post.story`（9:16 = 1080×1920）を並べる。`instagram/flu-vaccine.html` をひな形にする
- デザインはHPに合わせた明るくポップな可愛い路線: クリーム地 `#fff5eb`、コーラル `#f08c5a`、ターコイズ `#3eb8c8`、イエロー `#FBC96B`、文字は濃紺 `#1e3a5f`、フォントは M PLUS Rounded 1c。ロゴは `frontend/src/assets/logo.svg`
- 一番伝えたいこと（例: 平日19時まで・土日OK）を大きな丸などで一発で目に入るようにする
- ストーリーズ／リールのセーフゾーン（Meta公式）: 上14%・下35%・左右6%に文字やロゴを置かない。背景や飾りは置いてよい。下の空白はビル街イラストなどで埋める。はみ出しを許容したときはCSSコメントに理由を書く
- 要素の位置は Playwright で `getBoundingClientRect()` を測って確認する（目視だけにしない）
- ユーザーの指示どおりに変える。サイズや間隔を勝手に縮めない。制約（セーフゾーン等）でできないときは、変える前に理由を言う

### PNG書き出し

- Meta推奨解像度: フィード 1440×1800、ストーリーズ 1440×2560 → `deviceScaleFactor: 4/3` で各 `.post` をスクリーンショット
- Playwright は scratchpad に入れ、ブラウザはインストール済みの Chrome を使う（`chromium.launch({ channel: 'chrome' })`）
- 書き出したPNGはユーザー用に `~/Desktop/insta-flu/` のようなフォルダへコピーする。PNGはリポジトリに入れない

## 3. 本文（キャプション）

クリニックのInstagram（`koutoudai.yugata.naika.clinic`）の過去投稿の文体に合わせる。過去投稿は各投稿ページの `og:description` を fetch すると読める。

```
・
勾当台夕方内科クリニックです🌙

【見出し💉】

🕖 平日は夜19時まで
📅 土日も14〜17時に接種できます

✅ 当日のご予約もOK
✅ …

💰 料金：3,300円（税込）
📍 勾当台公園駅から徒歩2分・市役所となり

…早めの接種をご検討ください🍀

皆さまのご来院をお待ちしております🌙
```

- 広告ではハッシュタグを付けない（タップで広告から離脱するため）
- 見出し（Headline）は短く。例:「平日19時まで・土日も接種できます」

## 4. 広告マネージャで作る（下書きまで）

- URL: https://adsmanager.facebook.com/adsmanager/ （広告アカウントは既存の1つ）。未ログインならユーザーにログインしてもらう
- 予算・期間・地域・年齢・リンク先はユーザーに確認してから作る（AskUserQuestion）
- 作成: 「+ 作成」→ 目的「トラフィック」→「手動のトラフィックキャンペーン」

**キャンペーン**: 名前を付ける。予算は広告セット側

**広告セット**
- コンバージョンの場所: ウェブサイト。パフォーマンス目標: ランディングページビュー（ピクセル不要）
- 日予算・開始日時・終了日
- 地域: 住所検索は効かない。「勾当台公園」で検索して選び、半径をマイルの整数で指定（5km ≒ 3mi）
- 年齢の上限を守るには「オーディエンスをさらに絞る」→「限定したオーディエンスに届ける」で Advantage+ オーディエンスを外し、「目安として使用」のチェックも外す
- 配置: 「その他の設定を表示」→ プラットフォームを Instagram のみ（Messenger・Threads を外す）。「除外した配置に限定的に予算を使う」もオフ。Instagramフィード・発見タブ・ストーリーズ・リールが入っていることを確認

**広告**
- 名前。Facebookページは選べるものが無くても、Instagramアカウントが入っていれば公開できた
- リンク先URLにUTMを付ける: `?utm_source=instagram&utm_medium=paid_social&utm_campaign=<キャンペーン名>`。表示リンクはドメインだけ
- クリエイティブの設定 → 画像広告 → メディアで2枚アップロード（下の「画像アップロード」参照）
- 「その他の縦横比」に自動の切り抜き版・AI拡張版が付くので、すべて選択を外す
- テキスト: 本文と見出しを入力。CTAは既定の「詳細を見る」
- 自動加工（Enhancements）: Visual touch-ups・Add music・Add overlays・Text improvements をオフ
- 「メディアをカスタマイズ」→ 画像ごとの「配置」で、フィード用はフィード（Instagramフィード・発見タブ）だけ、ストーリーズ用はストーリーズ・リールだけにする
- プレビューの「Review defaults」→ 編集で、Enhance CTA・明るさとコントラストの調整・Show spotlights も外す（関連コメントは残してよい）
- 「確認（Review）」タブで全体を確認し、スクリーンショットを撮ってユーザーに見せる

## 5. 公開

- **「公開」はユーザーの明示的なOKをもらってから押す**（費用が発生する）
- 公開後、Meta の審査中は「処理中」表示。数時間〜1日で配信開始
- `#1357045 システムエラー` が出たら、ページを再読み込みして下書きのままか確認 → ヘッダーの「確認して公開」から再公開すれば通った。二重作成になっていないかを広告タブで確認する

## 広告マネージャ操作の落とし穴

- **入力欄は三連クリックで全選択されず、値が追記される**（日予算が 20,001,000円 になったことがある）。必ずクリック → `cmd+a` → 入力 → 表示・注記（「1日あたり約◯円」）で確認する
- 画面がスクロールでずれて別の場所をクリックしやすい。名前などの入力欄は `find` で ref を取ってからクリックする
- 画像アップロードは file input が DOM に無く、「アップロード」を押すとOSのファイル選択が開く。次のように回避する:
  1. `javascript_tool` で `HTMLInputElement.prototype.click` を差し替え、type=file の input を `document.body` に追加して aria-label を付け、クリックは握りつぶす
  2. 「アップロード」をクリック → `find` でその input の ref を取る → `file_upload`
  3. 終わったら `click` を元に戻し、追加した input を削除する
  - アップロード元はセッションで読めるパスのみ（`~/Desktop` は不可。scratchpad の書き出し元を使う）
- 本文の改行は `shift+Enter`。絵文字は `type` でそのまま入る
- トグルのクリック直後にツールチップが重なり、クリックが効かないことがある。`zoom` で状態を確かめ、効いていなければもう一度押す
