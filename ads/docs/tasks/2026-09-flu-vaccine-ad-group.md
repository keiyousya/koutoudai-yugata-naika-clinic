## 背景

インフルエンザ予防接種を 2026-09-16(水) から開始した（13歳以上・1回3,300円・予約なし可、LP は `/flu-vaccine/`）。

### 予防接種系の検索は既に来ているが、取れていない

- 予防接種向けのキーワードは **0件**。「内科 病院」等の部分一致経由で汎用の内科広告（リンク先トップ）が出ているだけ
- 9/14〜17 の予防接種系クエリ: **約200表示・6クリック・CV0**
- 「料金」「費用」「安い」「予約なし」「ネット予約」付きの検索が多く、汎用広告文では応えられていない
- 除外KWで弾いているわけではない

### 9/16(水) の CPA が悪化した

| | 費用 | CV | CPA |
|---|---|---|---|
| 9/16(水) | 7,727円 | 3（LINE1＋電話2） | **2,576円** |
| 8月平日平均（7/20〜8/31） | 41,937円 | 27 | 1,553円 |

- 表示回数が8月水曜の約1.7倍（インフル季節の検索増）。消化は日予算4,000円の1.93倍で上限に到達し、`search_budget_lost_impression_share` は **56.5%**（8月はほぼ0）
- **12〜13時台で2,990円（39%）を使いCV0**。8/17〜31 でも昼枠は CPA 約4,000円と最も非効率
- 18時台までの累計で7,537円に達し、19〜20時台はほぼ配信されず。効率の良い夕方枠を昼が食っている
- ただし CV3件なので1件の差で CPA は1,900円台になる。構造の問題として扱い、1日の数字で過剰反応しない

## やること

### 1. 広告グループ「インフル予防接種」を新設（新キャンペーンは作らない）

平日・土日の **既存2キャンペーンの中にそれぞれ** 追加する。予算・配信時間・地域・入札は既存キャンペーンのものを引き継ぐ。
`gads` に広告グループ作成コマンドが無いので、API を叩くスクリプトを `scripts/` に作る（冪等に）。
最初は **PAUSED で作成 → オーナーが広告文を確認 → 有効化**。

- リンク先: `https://koutoudai-yugata-naika.clinic/flu-vaccine/`
- キーワード（フレーズ一致。地域は半径6kmで絞っているので地名は付けない）
  - インフルエンザ 予防接種
  - インフルエンザ ワクチン
  - インフル 予防接種
  - インフル ワクチン
- RSA 見出し案
  - インフルエンザ予防接種 3,300円
  - 平日夜21時まで接種可
  - 土日も接種できます
  - 予約なしでも接種OK
  - 勾当台公園駅すぐ
  - ※「安い」等の比較・誇大表現は医療広告ガイドラインに触れるので使わない
- 広告グループ単位の除外KW
  - 調べもの系: 症状 / 潜伏期間 / 効果 期間 / 治療
  - 対象年齢外（13歳以上のみ）: 子供 / 小児 / 幼児 / 赤ちゃん
  - （65歳以上の定期接種を扱わない場合）無料 / 助成 / 高齢者
- 既存の内科広告グループに「予防接種」「ワクチン」を除外追加し、予防接種の検索を新グループへ寄せる

### 2. 平日キャンペーンの昼枠の入札を下げる（×0.7 程度）

予算額は据え置きのまま、昼枠の消化を抑えて夕方へ回す。土日で導入済みの傾斜と同じ考え方。
張り替えは `scripts/set_ad_schedule_gradient.py`。

- 予約なし来院・電話予約は CV に乗らないので、予防接種の成果は過小に見える
