# 総論 I めまいの鑑別診断：初療時の鑑別診断

- **出典**: 日本神経治療学会 ガイドライン作成委員会「標準的神経治療：めまい（2020）」神経治療 37(5):769–811, 2020 — A 総論 I（p.773–778、執筆：城倉 健）
- **原文**: https://www.jstage.jst.go.jp/article/jsnt/37/5/37_769/_pdf/-char/ja
- **発行**: 2020（緒言の日付は2020年9月）
- **確認日**: 2026-09-14

**要旨**：臨床では末梢性めまいが圧倒的に多いが、中枢性めまいは頻度が低い一方で重篤な疾患によることが多い。**診察所見が決め手**で、中枢性は「めまい以外の神経症候」で、末梢性は「眼振」で診断する。

---

## 1. 問診

| 項目 | ポイント |
|---|---|
| **性状** | 回転性か浮動性かで、中枢性と末梢性は区別できない。脳血管障害でも回転性は多く、前庭神経炎も時間がたてば浮動性で受診する |
| **発症様式** | 急性の単発（初回）めまいは、中枢性・末梢性すべての疾患を念頭に置く（反復する疾患も最初は単発で来る）。反復性なら問診である程度絞れる：頭位変換で数十秒〜数分 → BPPV、蝸牛症状を伴い数十分〜数時間 → メニエール病 |
| **誘因の落とし穴** | 「頭を起こした」ときのめまいは起立性低血圧のこともある |
| **随伴症状** | 嘔吐は鑑別の役に立たない。蝸牛症状は内耳性を示唆するが、**前下小脳動脈（AICA）の梗塞でも出る**。頭痛を伴えば椎骨動脈解離や小脳出血を考える（ただし末梢性でも緊張型頭痛は続発しやすい）。片頭痛の部分症状のこともある。複視・構音障害・麻痺・感覚障害があれば脳血管障害の可能性が高い |

問診で見当はつくが、**診断の決め手はあくまで診察所見**。

---

## 2. 診察所見

### 2-1. めまい以外の神経症候（中枢性の鑑別で最重要）

中枢性めまいの特徴は「めまい以外の神経症候を伴う」「視覚や深部感覚による補正が効きにくい」の2点。責任病巣は脳幹か小脳。

**表1 中枢性めまいの鑑別の指標となる神経症候**

| 神経症候 | 主な責任病巣 |
|---|---|
| 眼球運動障害 | 中脳、橋 |
| 眼球偏倚（特に skew deviation） | 延髄 |
| Horner 症候群 | 延髄 |
| 眼振（特に注視誘発眼振） | 小脳 |
| 構音障害 | 延髄、小脳 |
| 顔面麻痺 | 橋 |
| 上下肢麻痺 | 中脳、橋、延髄 |
| 感覚障害 | 視床、橋、延髄 |
| 肢節運動失調（協調運動障害） | 小脳（上小脳動脈・AICA 領域） |
| 体幹失調（小脳性平衡障害） | 小脳（後下小脳動脈〔PICA〕領域） |

- 通常は **眼球運動障害・眼球偏倚、構音障害、麻痺・感覚障害、四肢の協調運動障害、体幹失調** を確認すれば十分。Horner 症候群や skew deviation に注目してもよい〔**エビデンスレベル VI、グレード C1**〕
- 図1の基本診察：視標の追視、「パタカ」の反復、Barré 徴候、指鼻試験、起立・歩行の安定性
- **PICA 領域の障害では体幹失調が唯一の神経症候になることがある。** 小脳性の体幹失調は視覚で補正できないので、開眼で足を踏ん張っていても分かりやすい
- 立位が困難な患者は**ベッド端座位**で確認する。膝を閉じ、手で支えずに座位を保てれば、中等度以上の体幹失調はないと判断できる

### 2-2. 眼振

末梢性の眼振は注視で抑えられて目立たなくなるため、診察には **Frenzel 眼鏡が必要**。

**表2 末梢性めまいを示唆する眼振**

| 眼振 | 原疾患 |
|---|---|
| Dix–Hallpike test で誘発される回旋性眼振 | 後半規管型 BPPV（ごくまれに前半規管型） |
| Supine head–roll test で誘発される方向交代性眼振 | 外側半規管型 BPPV（向地性なら半規管結石症、背地性ならクプラ結石症） |
| 自発性の方向固定性水平性眼振 | 一側末梢前庭障害（BPPV 以外の末梢性めまい） |

**表3 中枢性めまいでしか出ない眼振**

| 眼振 | 主な責任病巣 |
|---|---|
| 注視誘発眼振（右を見ると右向き、左を見ると左向き） | 小脳 |
| 純粋な垂直性眼振（上眼瞼向き） | 中脳、延髄 |
| 純粋な垂直性眼振（下眼瞼向き） | 小脳 |
| 純粋な回旋性眼振 | 延髄 |

- **Dix–Hallpike test**：座位から患側下の懸垂頭位へ倒す。右後半規管型なら、右下懸垂頭位で右向き回旋性眼振（上眼瞼向き成分が混じる）、座位に戻すと逆向き
- **Supine head–roll test**：仰臥位で右下・左下頭位にする。向地性眼振は、眼振が強い頭位で下になった側が患側。背地性眼振は、眼振が強い頭位で上になった側が患側
- **一側末梢前庭障害**：頭位や眼位によらず向きが一定の水平性眼振（通常は健側向き）。眼振の向きを注視すると強まる（Alexander の法則）
- 注意点
  - 極端な側方視では健常人にも眼振が出る（極位眼振）
  - 垂直性・回旋性眼振が中枢性を示すのは、**頭を起こした状態の自発眼振**として見られた場合
  - 方向固定性水平性眼振や方向交代性背地性眼振は、**中枢性でも出ることがある**。眼振を細かく見れば区別できるが、神経症候（特に体幹失調）に注目したほうが容易

### 2-3. 診察のまとめ（図5）

```
急性発症のめまい
  ↓
めまい以外の神経症候を確認
  眼球運動障害／構音障害／顔面・上下肢の麻痺／感覚障害／上下肢の協調運動障害
  ／体幹失調（眼振の確認の後で）
  ↓
眼振を確認
  末梢性：方向固定性の自発眼振／head-roll test で方向交代性水平性眼振／Dix-Hallpike で回旋性眼振
  中枢性：注視誘発眼振／自発性の垂直性眼振／自発性の回旋性眼振
```

眼振で多くの末梢性めまいが診断できるので、**体幹失調の確認を眼振の後に回す**と効率がよい。

## 3. 検査所見

### 末梢性
- BPPV 以外では半規管機能が低下していることが多く、**温度刺激検査・video head impulse test（vHIT）** が有用。現在は侵襲が少なく短時間の vHIT が主流になりつつある。肉眼で catch-up saccade を見る head impulse test もある程度有用
- VEMP（耳石器機能）や自覚的視性垂直位（SVV）は中枢性の障害でも異常になり、解釈が難しい
- これらの検査は、**診察で得た末梢性の診断を確認する**意味合いが大きい

### 中枢性
- CT・MRI で病変が見つかれば確定するが、**画像が正常でも中枢性は否定できない**
- 脳出血：テント上なら CT の感度は高いが、**後頭蓋窩は骨のアーチファクトで見逃しやすい**
- 脳梗塞：MRI 拡散強調画像の感度は高いが、**発症1〜2時間以内の超急性期は写らないことが多く、脳幹・小脳（後方循環）の梗塞は偽陰性が多い**
- 発症まもない急性めまいでは画像が決め手になるとは限らないため、**画像は診察で見つけた中枢性めまいを確認する検査**と位置づける

## 外来での使いどころ（自院運用メモ）

- **診察の型をこれに統一する**：神経症候（パタカ・追視・Barré・指鼻）→ 眼振 → 立位・歩行（無理なら膝閉じ端座位）。所要時間は数分
- **「画像で異常なし」を安全の根拠にしない**：MRI が当日撮れても、発症早期と後方循環の梗塞には偽陰性がある。神経症候や体幹失調があれば、画像結果にかかわらず脳卒中として紹介する
- **CT だけで帰さない**：後頭蓋窩の出血や梗塞は CT で見えにくい
- **Frenzel 眼鏡がない場合**：自発眼振は見逃しやすい。一方、注視誘発眼振・純粋な垂直性や回旋性の眼振は裸眼でも見える中枢性サインなので、必ず確認する
