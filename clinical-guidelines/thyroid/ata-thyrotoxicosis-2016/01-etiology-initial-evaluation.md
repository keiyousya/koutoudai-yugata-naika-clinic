## 1. 用語と原因（[A1]）

- **甲状腺中毒症（thyrotoxicosis）**: 組織での甲状腺ホルモン作用が過剰な臨床状態の総称
- **甲状腺機能亢進症（hyperthyroidism）**: そのうち、**甲状腺がホルモンを作りすぎている**もの
- 顕性: TSH 低値（通常は測定感度以下）＋ FT4 か T3（または両方）高値。潜在性: TSH 低値で FT4・T3 とも基準内
- 発生機序は4つ: ① 甲状腺の刺激（TRAb、hCG、TSH）② 自律性の亢進（結節） ③ **貯蔵ホルモンの漏出（破壊性：自己免疫・感染・薬剤・機械的）** ④ 甲状腺外のホルモン（卵巣甲状腺腫、機能性転移、外因性摂取）
- 米国の内因性亢進症の原因はバセドウ病が最多。中毒性結節性甲状腺腫は高齢・ヨウ素欠乏で増え、高齢者ではバセドウ病より多いこともある。**軽症バセドウ病は無治療で最大30%が寛解**したという報告がある
- 無痛性甲状腺炎の頻度は地域差が大きい（中毒症のうちデンマーク0.5%、トロント6%、ウィスコンシン22%）。リチウム・インターフェロンα・チロシンキナーゼ阻害薬・産後で起こる。**アミオダロン服用者の5〜10%に破壊性甲状腺炎**

## 2. 重症度の評価（[B1]）

- 症状の強さは FT4・T3 の高さと強くは相関せず、**年齢と逆相関**（高齢者ほど症状が乏しい）
- 高齢者では心エコー・心電図・ホルター等の心評価が要ることがあるが、**評価のために治療を遅らせない**。心房細動では抗凝固が必要なことがある
- 脈拍・血圧・呼吸数・体重、甲状腺の大きさ・圧痛・左右差・結節、心肺・神経筋、浮腫・眼症状・前脛骨粘液水腫を診る

## 3. 生化学的評価（[B2]）

- **スクリーニングは TSH 単独**が最も感度・特異度が高い。強く疑うときは**初回から TSH＋FT4＋総T3**を測ると診断精度が上がる
- 顕性亢進症の TSH は第3世代測定で通常 **<0.01 mU/L**
- **T3 トキシコーシス**: FT4 正常で T3 だけ高い。バセドウ病や機能性結節の初期のことがある
- 米国では FT3 測定の頑健性が FT4 より劣るとして**総T3 がよく使われる**
- **TSH が正常なら、TSH 産生腫瘍・甲状腺ホルモン不応症・測定干渉がない限り中毒症は否定できる**

### 見かけの異常（測定上の落とし穴）

| 原因 | 何が起こるか | 対応 |
|---|---|---|
| 結合蛋白の異常（TBG・トランスサイレチン増加、家族性異アルブミン血症性高T4血症など） | 総T4（しばしば総T3）が高いが中毒症ではない（euthyroid hyperthyroxinemia）。遊離ホルモン推定値も誤ることがある | TSH を見る |
| TBG 増加の原因 | 遺伝性（X連鎖）、妊娠・エストロゲン、肝炎、急性間欠性ポルフィリン症、5-FU、ペルフェナジン、一部の麻薬 | |
| T4→T3 変換阻害 | アミオダロン、高用量プロプラノロール。ほかに急性精神病、極端な高地、アンフェタミン乱用 | |
| ヘパリン | 試験管内でリポ蛋白リパーゼが働き、遊離脂肪酸が T4 を追い出して **FT4 が見かけ上高値** | |
| 異好性抗体 | FT4 や TSH の見かけ上の高値 | 別キットで再測定、段階希釈、HAMA 測定 |
| **高用量ビオチン** | ストレプトアビジン–ビオチン法で、**TSH（サンドイッチ法）は見かけ上低値、FT4（競合法）は見かけ上高値** → バセドウ病に似る | **ビオチンを中止し、少なくとも2日後に再検** |

- 見かけの異常を除外したうえで **ホルモン高値なのに TSH が正常〜高値** → TSH 依存性。TSH 産生下垂体腺腫（MRI で病変、α サブユニット/TSH 比が高い）と甲状腺ホルモン不応症（家族歴、*THRB* 遺伝子検査）を区別する

## 4. 原因の決定（[B3]）

### 推奨1（強・中）

**甲状腺中毒症の原因は必ず決める。** 臨床像と初期検査で明らかでなければ、施設で可能な範囲で ① **TRAb**、② **放射性ヨウ素摂取率（RAIU）**、③ **エコーの甲状腺血流** のいずれかを行う。中毒性腺腫・中毒性多結節性甲状腺腫が疑われれば 123I か 99mTc シンチを撮る。

- **対称性の甲状腺腫＋最近発症した眼症＋中等症〜重症の亢進症** → バセドウ病でほぼ確実。それ以上の原因検索は不要
- **結節がなく眼症も明らかでない** → TRAb か RAIU で区別する。米国の費用モデルでは、TRAb を使うと RAIU より費用47%減・診断が46%早い

### 摂取率で原因を2群に分ける（表3）

| 摂取率 正常〜高値 | 摂取率 **ほぼゼロ** |
|---|---|
| バセドウ病 | 無痛性甲状腺炎（産後を含む） |
| 中毒性腺腫・中毒性多結節性甲状腺腫 | アミオダロン誘発性甲状腺炎 |
| 絨毛性疾患（hCG） | 亜急性甲状腺炎 |
| TSH 産生下垂体腺腫 | 触診甲状腺炎 |
| 甲状腺ホルモン不応症（臨床的に中毒症とは限らない） | 医原性・外因性（甲状腺ホルモン摂取） |
| | 卵巣甲状腺腫、急性甲状腺炎、濾胞癌の広範な転移 |

注: **ヨウ素誘発性（アミオダロン1型を含む）は亢進症でも摂取率が低いことがある。**

### 各検査の要点

| 検査 | ポイント |
|---|---|
| **TRAb** | 陽性なら最多の原因（バセドウ病）が確定するので費用対効果がよい。**陰性でも他の原因を区別できず、ごく軽症のバセドウ病では陰性のことがある**。第3世代の TRAb が使えない場合は RAIU を優先。顕性中毒症での新しい結合法・バイオアッセイの感度 96〜97%、特異度 99% |
| TRAb の測定法 | 第3世代 TBII（結合阻害法）は刺激型・阻害型を区別できない。TSI バイオアッセイは刺激型だけを検出する |
| **RAIU** | 通常24時間値（Tc 摂取率は20分値）。バセドウ病で高値、結節性で正常〜高値。破壊性・外因性・最近のヨウ素過剰で**ほぼゼロ**。**ヨード造影剤から1〜2ヵ月以内や、海藻スープ・ケルプなどヨウ素の多い食事**で低くなる。ただし**1%未満はアミオダロンのような持続的なヨウ素曝露でない限りまれ**。予想より低ければ尿中ヨウ素（スポット尿のクレアチニン補正か24時間尿）。妊娠中は禁忌、授乳中も通常行わない |
| シンチ | 結節があれば撮る。バセドウ病はびまん性、中毒性腺腫は結節に集積し周囲・対側が抑制、多結節性は集積と抑制が混在。自律性が広範だとバセドウ病と区別しにくい。バセドウ病と非中毒性結節性甲状腺腫の合併もある |
| **エコー（カラードプラ）** | 専門性があれば、**血流増加（亢進症）と破壊性甲状腺炎を区別**できる。定量評価は甲状腺内動脈や下甲状腺動脈の収縮期最高血流速度。**妊娠・授乳中で RI 検査ができないとき特に有用**。AIT の病型鑑別にも使われる |
| **T3/T4 比** | シンチができないとき有用。亢進した甲状腺は T3 を多く作るので、**亢進症では T3 の上昇が T4 より大きく、甲状腺炎では T4 の上昇が T3 より大きい**。1研究で **総T3(ng/dL)/総T4(μg/dL) 比が >20 ならバセドウ病・結節性、<20 なら無痛性・産後甲状腺炎**。外因性 LT4 では T4/T3 比が高い |
| サイログロブリン | 亜急性・無痛性・触診甲状腺炎では上昇、**外因性ホルモン摂取では抑制**。外因性の診断は **Tg 低値＋RAIU ほぼゼロ＋（LT4 なら）T3/T4 比 <20**。抗Tg抗体で Tg が測れなければ糞便中 T4（普及していない） |

- 治療の選び方も検査に影響する: MMI で寛解を目指すなら TRAb は**治療開始時のベースライン**になる。RAI を選ぶなら RAIU は投与量計算にも使える
- **亜急性と無痛性の区別**は多くの場合むずかしくない: 亜急性は痛みがあり、硬く、**赤沈は通常 >50 mm/h、ときに >100 mm/h**。産後1年以内の無痛性（産後甲状腺炎）は本人・家族に自己免疫性甲状腺疾患の既往が多く、**抗TPO抗体が陽性**のことが多い

## 5. 対症療法（[B4]）

### 推奨2（強・中）

**症状のある甲状腺中毒症にはすべて β遮断薬を使う。** 特に**高齢者、安静時心拍数 >90/分、心血管疾患の合併**。

- RCT: MMI 単独と MMI＋β遮断薬の比較で、4週後に心拍数・息切れ・倦怠感・SF-36 の身体機能が改善
- 推奨用量の β遮断薬は β1 選択性が十分でないため、**気管支攣縮性の喘息には原則禁忌**。落ち着いた喘息で心拍数管理が必須な場合、軽い閉塞性肺疾患、症状のあるレイノー現象では、相対的 β1 選択薬を呼吸状態を見ながら慎重に
- たいていは低〜中用量で十分。まれに大量が必要
- β遮断薬が使えなければ **ベラパミル・ジルチアゼム（経口）** で心拍数を管理できる

### β遮断薬の選び方（表4の要点）

| 薬剤 | 用量・回数 | 特徴 |
|---|---|---|
| プロプラノロール | 10〜40 mg、1日3〜4回 | 非選択性。経験が最も長い。高用量で T4→T3 変換を抑える可能性。**妊婦・授乳婦で第一選択** |
| アテノロール | 25〜100 mg、1日1〜2回 | 相対的 β1 選択性。服薬遵守がよい。**妊娠中は避ける** |
| メトプロロール | 25〜50 mg、1日2〜3回 | 相対的 β1 選択性 |
| ナドロール | 40〜160 mg、1日1回 | 非選択性。経験が最も少ない |
| エスモロール | 静注 50〜100 μg/kg/分 | ICU での重症中毒症・クリーゼ |

- いずれも心血管疾患で承認された薬で、**甲状腺中毒症の適応は（米国でも）ない**

## 外来での使いどころ（自院メモ）

### 国内資料との違い・補える点

| 論点 | ATA 2016 | 国内資料 |
|---|---|---|
| 原因検索の道筋 | **推奨1（強・中）で「原因を必ず決める」**、手段は TRAb・RAIU・エコー血流のどれか（施設次第） | 診断GL2024 は疾患ごとの診断基準のみ（[バセドウ病](../jts-diagnosis-gl2024/01-graves.md)・[無痛性](../jts-diagnosis-gl2024/03-painless-thyroiditis.md)・[亜急性](../jts-diagnosis-gl2024/05-subacute-thyroiditis.md)）。検査の順番は書かれていない |
| ホルモン比 | **総T3/総T4 比**（ng/dL ÷ μg/dL）で **20** を境にする | 診断GL2024 は **FT3(pg/mL)/FT4(ng/dL) 比**（数値の基準なし）。**単位も測定対象も違うので ATA の「20」を FT3/FT4 比に当てはめてはいけない** |
| β遮断薬 | 推奨2（強・中）。**心拍数 >90/分**・高齢・心疾患で特に。プロプラノロール・アテノロール・メトプロロール・ナドロール | [今日の治療指針](../konnichi-chiryo-2026/01-hyperthyroidism.md)はビソプロロール 2.5 mg。ATA の表にビソプロロールはない。国内でも甲状腺中毒症は適応外 |
| ビオチン | **TSH 偽低値＋FT4 偽高値でバセドウ病に似る → 中止して2日以上あけて再検** | 国内まとめには記載なし |

### 当院での進め方

1. **TSH 低値をみたら、FT4・FT3 を同時に**（強く疑うときは最初から3項目）。顕性なら TSH はほぼ測定感度以下のはず。**TSH が感度以上・基準未満**なら破壊性や潜在性を考える（[無痛性甲状腺炎](../jts-diagnosis-gl2024/03-painless-thyroiditis.md)の付記と同じ）
2. **見かけの異常を先に除く**: サプリ（**ビオチン＝「ビタミンH」「髪・爪のサプリ」**）、ヘパリン投与中、妊娠・エストロゲン、アミオダロン。FT4 高値なのに TSH が下がっていない → 測定干渉を除いてから TSH 産生腫瘍・不応症として専門医へ
3. **原因検索は当院では TRAb ＋ エコー血流 ＋ FT3/FT4 比 ＋ 経過**で行う（RAIU・シンチは院内でできないため、必要なら紹介）
   - TRAb 陽性 → バセドウ病（[治療は04](04-graves-treatment.md)）
   - TRAb 陰性・血流増加なし・FT4 優位・症状軽い → 破壊性を考え、**抗甲状腺薬は出さず β遮断薬のみで 4〜6週後に再検**（[02](02-thyroiditis-drug-induced.md)）
   - TRAb 陰性でも**ごく軽症のバセドウ病はありうる**（ATA）。再検で下がってこなければ再評価
   - 結節を触れる・エコーで結節 → 機能性結節の可能性。シンチ目的で紹介
4. **薬歴を必ず見る**: アミオダロン、リチウム、インターフェロン、チロシンキナーゼ阻害薬、甲状腺ホルモン製剤、最近の**ヨード造影剤**（[02](02-thyroiditis-drug-induced.md)）。**免疫チェックポイント阻害薬は ATA 2016 には記載がない**ので、国内の ICI 内分泌障害GL（README の一覧）を参照
5. 紹介先でシンチ・摂取率を予定するときは、**昆布などヨウ素の多い食事や1〜2ヵ月以内の造影剤で摂取率が下がる**ことを紹介状に書いておく
6. **β遮断薬**: 動悸・振戦があれば原因が決まる前から使ってよい（推奨2）。**安静時心拍 >90/分**を目安にする。喘息があれば使わない（ベラパミル・ジルチアゼムを検討）。妊娠・授乳中はプロプラノロール
7. 高齢者は症状が乏しくても心房細動・心不全を起こしうるので、**心電図を取る**
