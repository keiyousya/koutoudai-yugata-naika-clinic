# AASM 2026：成人の慢性不眠障害に対する併用療法（CBT-I＋睡眠薬）（自院メモ）

- **ガイドライン要約**: [insomnia/aasm-combination-2026/summary.md](https://github.com/keiyousya/clinical-guidelines/blob/main/insomnia/aasm-combination-2026/summary.md)

## 外来での使いどころ（自院メモ）

### 国内事情との違い（確実な範囲）

- 本 GL の根拠試験の薬のうち、**ロルメタゼパム（エバミール／ロラメット）、ゾルピデム（マイスリー）、ゾピクロン（アモバン）、トラゾドン（デジレル／レスリン）**は国内にもある。**テマゼパムは国内未発売**
- **DORA（ベルソムラ・デエビゴ・クービビック）やラメルテオン（ロゼレム）と CBT-I を組み合わせた試験は無い**。当院でよく使う薬との併用効果は、この GL からは言えない（BZ 系での結果を外挿しているだけ）
- 米国の dCBT-I（Somryst・SleepioRx）は国内では使えない。CBT-I を専門に行う心理職・睡眠外来は仙台でも限られる前提で考える

### 当院で取り入れること

1. **慢性不眠（週3回以上・3か月以上、日中の支障あり）で初めて相談された人には、まず行動療法の要素を出す**。夕方〜夜の短い外来なので、フルの CBT-I（4〜8回）ではなく、**刺激制御**（眠くなってから床に入る／眠れなければ床を出る／起床時刻を毎日そろえる／昼寝をしない）と**睡眠日誌**を最低限渡す。**睡眠衛生の注意書きだけを渡して薬を出すのは、この GL の考え方に合わない**
2. **薬を出すなら「薬だけ」にしない**（推奨1）。薬と一緒に刺激制御・睡眠日誌を始め、次回受診で日誌を見る
3. **併用を選んでよい人**をはっきりさせる: 睡眠時間の短さそのものがつらい人、運転・夜勤など睡眠不足が危険な仕事の人、早く楽になりたい人。この人たちには最初から薬＋行動療法でよい
4. **すでに他院から睡眠薬が出ている人**（当院の初診でよくある）には、**行動療法を足す**のが有益（推奨1からの外挿）。減薬・中止のために CBT-I を使うことはこの GL の範囲外なので、減薬の進め方は国内の [睡眠薬の適正な使用と休薬のための診療ガイドライン](https://github.com/keiyousya/clinical-guidelines/blob/main/insomnia/jssr-hypnotics-gl2013/) 側で確認する
5. **行動療法 → 薬の順のほうが寛解率が高い**という逐次 RCT（Morin 2020）がある。急がない人には**行動療法を2〜4週先行し、効果不十分なら薬を足す**順番を基本にする（推奨ではなく、本文で紹介された1試験に基づく当院の判断）
6. **併用で朝の眠気が増える**可能性（1試験、確実性 very low）と、**睡眠制限療法と睡眠薬を組み合わせると日中の眠気が強まりうる**こと（系統的レビューの今後の研究課題に記載）を説明する。運転する人には特に伝える
7. **認知機能の落ちた高齢者**など行動療法に乗れない人は、薬単独でもやむを得ないと GL も認めている。ただし薬の選び方は [aasm-pharmacologic-2017](https://github.com/keiyousya/clinical-guidelines/blob/main/insomnia/aasm-pharmacologic-2017/summary.md) の自院メモ（高齢者は BZ 系を避ける）に従う

### 原文で確認できなかった・注意する点

- **推奨は2つとも Conditional・確実性 Low**。試験は10論文で、ほぼすべて BZ 受容体作動薬。**DORA・ラメルテオンでの併用の効果は不明**のままで、GL 自身も「研究ギャップが埋まれば推奨が変わりうる」と書いている
- 推奨2の **TST +13.8分は CMT（+10分）を超えるが CI がゼロをまたぐ**。Remark（TST を重視する人は併用可）の根拠はこの不確かな数字である
- 系統的レビューの推奨1の日中アウトカムの段落に「CBT-I 単独群と比べて」という一文があるが、文脈上は「**薬単独群と比べて**」の誤記と思われる
- 推奨2の個別アウトカムでは「不眠の重症度」「日中症状」の確実性が moderate とされているが、全体の確実性は low（リスクオブバイアスと不精確さ）
- **逐次治療・減薬目的の CBT-I は評価対象外**。実臨床で一番多い場面について直接の推奨はない
- 雑誌の DOI が従来の `10.5664/jcsm.*` から **Springer の `10.1007/s44470-*`** に変わっている（JCSM の出版社移行と思われる）。引用時に DOI を取り違えない
- 国内で承認された不眠症治療用アプリ（dCBT-I）の有無・保険適用・当院での導入可否は本 GL の範囲外で、未確認
