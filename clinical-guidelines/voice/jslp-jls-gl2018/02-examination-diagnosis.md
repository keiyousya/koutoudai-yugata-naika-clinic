# 第4章 音声障害の検査と診断法（＋CQ1〜6）

- **出典**: 日本音声言語医学会・日本喉頭科学会 編「音声障害診療ガイドライン 2018年版」金原出版 — 第4章（p.15–37）、第6章 CQ1〜CQ6（p.50–69）
- **原文**: http://www.larynx.jp/images/onsei_guideline_2018.pdf （Minds: https://minds.jcqhc.or.jp/summary/c00460/ ）
- **発行**: 2018-03-01
- **確認日**: 2026-09-25

第4章は、問診、聴覚心理的評価（GRBAS）、自覚的評価（VHI・V-RQOL）、内視鏡検査、空気力学的検査、ボイスプロファイル、音響分析、喉頭筋電図の8節で構成される。当院で実施できるのは**問診と自覚的評価（質問紙）まで**。

## 1. 問診（第4章①）

聞くこと：受診の動機、症状、**発症のきっかけと経過**、随伴症状、既往歴、生活歴、声の使い方、服薬。

| 項目 | 要点 |
|---|---|
| 発症のきっかけ | 上気道炎、喉頭・頸部の外傷、**声の酷使**、心理的ストレス |
| 経過 | 声質の変化、日内変動、いつまで正常だったか、**今も正常な声が出ることがあるか** |
| 声の使い方 | 誤った発声習慣（誤用）と不適切な発声行動（濫用）。騒音下での会話、電話の頻度。**歌手・アナウンサーなど声を職業にする人は、軽い症状でも大きな障害になりうる**。カラオケ・スポーツなど趣味も聞く |
| 喫煙・飲酒 | 喫煙はポリープ様声帯・慢性喉頭炎、喫煙・飲酒は頭頸部癌の原因になりうる |
| 手術歴・挿管歴 | 甲状腺・頸部・心臓・大動脈・縦隔/胸部・食道癌の手術（反回神経・上喉頭神経麻痺）。気管挿管の既往 |
| 外傷 | 比較的軽い打撲でも音声障害が起こりうる |
| 既往 | 脳血管障害、神経・筋疾患（パーキンソン病、多発性硬化症、重症筋無力症など）、膠原病、喉頭が照射野に入る放射線治療、肺機能低下 |

## 2. 聴覚心理的評価：GRBAS 尺度（第4章②、CQ1）

- 嗄声の程度 G（総合）と、R（粗糙性）・B（気息性）・A（無力性）・S（努力性）の5項目を、0（正常）〜3（重度）の4段階で評価する。記載例は G0R0B0A0S0
- 持続母音で評価する。痙攣性・振戦性の声、声の翻転（裏返り）、二重声、失声など**断続的な現象は GRBAS の対象外**なので別に記載する
- 検者間・検者内の再現性は熟練度に左右される
- **CQ1「GRBAS 尺度による音声評価は有用か？」→ 強く推奨する**

## 3. 自覚的評価：VHI・V-RQOL（第4章③、CQ2）

- **VHI**（Voice Handicap Index）：30項目、各0〜4点、合計0〜120点（高いほど障害が大きい）。機能・身体・感情の3側面。短縮版 **VHI-10** あり
- **V-RQOL**：10項目、1〜5点で回答し、換算式で0〜100点（**低いほど障害が大きい**）。治療効果への反応性が高いとされる
- 日本音声言語医学会が日本語推奨版（2014）を公開している（質問紙は本GL表4-3・4-4 に収載）
- **CQ2「自覚的評価 VHI と V-RQOL は有用か？」→ 強く推奨する**（VHI・VHI-10・小児版 pVHI・V-RQOL の日本語版は多施設研究で信頼性・妥当性が示されている）

## 4. 内視鏡検査（第4章④、CQ3・CQ4）

- 喉頭の視診は**音声障害診療の基本的な検査**。検診や一般外来のスクリーニングでは間接喉頭鏡、詳細な観察・記録には経鼻軟性鏡（ファイバー・電子内視鏡）や硬性鏡を使う。ストロボスコピーで声帯振動と粘膜波動を観察できる
- 目的：①原因と病態を明らかにする、②治療効果の判定と継続の判断
- 観察項目：披裂部・声帯の運動性と形状、発声時の声門閉鎖、レベル差、緊張状態。ストロボでは振動・粘膜波動の振幅、左右対称性、位相差
- 注意：鼻出血、喉頭反射の誘発に注意。画像と音声を記録しておくと経過の比較に使える

### CQ3 喉頭内視鏡検査は有用か？ → **強く推奨する**

- **推奨の要旨**：喉頭所見の観察は重要であり、症状の経過と患者背景を踏まえ、**適切なタイミングで**喉頭内視鏡検査を行う。硬性鏡と軟性鏡の特徴を理解して使い分ける
- **検査のタイミング（解説。2009年の AAO-HNS ガイドラインを引用）**
  - 悪性疾患の診断の遅れは予後に影響するため、**3カ月以上続く音声障害には内視鏡検査を行う**
  - 期間が短くても、次の場合は**早期に行う**：①喫煙歴・飲酒歴、②頸部腫瘤、③外傷後の発症、④血痰・嚥下障害・耳痛・気道症状、⑤神経症状、⑥体重減少、⑦増悪傾向、⑧免疫不全、⑨異物誤飲の可能性、⑩新生児、⑪気管挿管後・頸部手術後
  - **声を職業的に使う人**、QOL を著しく損なっている人も**3カ月待つ必要はない** → 可及的速やかに検査
  - > 注：この「3カ月」は 2009年版の基準。**2018年の AAO-HNS 改訂版では「4週間で改善しなければ」に短縮**されている（[AAO-HNS 2018 KAS 4B](../aao-hns-hoarseness-2018/summary.md)）
- 小児：声帯疾患のある小児のうち主訴が嗄声だったのは約56%のみ。親が記録する Glottal Function Index（努力性発声、発声後の違和感・痛み、声が弱くなる・割れる など）で約70%を拾えたという報告があり、嗄声以外の症状も考慮する
- 検査法の比較（2012年のレビュー引用）：**間接喉頭鏡は視野・機能評価に限界があり、約半数が検査に耐えられず、記録もできない**。硬性鏡は80%以上で施行でき診断精度が高い。軟性鏡は画質で劣るが苦痛が少なく費用対効果が最も高い。軟性鏡は感度が高いが特異度が低い可能性がある。米国GLでは方法の選択は医師の裁量とされる

### CQ4 喉頭ストロボスコピーは有用か？ → **推奨する**

- 粘膜波動の観察で病変の性状・深達度を評価でき、とくに**悪性腫瘍の診断と経過観察に有用**。一方、声帯振動にストロボが同期できない（基本周波数が不安定な声）など限界もある

## 5. 空気力学的検査・音響分析ほか（第4章⑤〜⑧、CQ5・CQ6）

| 検査 | 要点 |
|---|---|
| **最長発声持続時間（MPT）** | 楽な高さ・強さで /a/ をできるだけ長く。3回の最長値。**健常者の平均は20秒以上**（男性の方が長い）。**10秒未満では日常会話に支障が出ることが多い**。声門閉鎖不全で短縮。全身状態・肺機能の影響を受ける |
| 発声時平均呼気流率（MFR） | 声門閉鎖不全で高値、過緊張性発声障害で低値 |
| 声域・声の強さ | キーボードで最低音〜最高音、最大音圧 |
| 声門下圧 | 気流阻止法で近似値を測る |
| ボイスプロファイル | 声の高さ・強さ・呼気流率を同時に測る。楽な発声では正常でも、負荷をかけた発声で異常が出ることがある。同じ患者の経時比較向き |
| 音響分析 | サウンドスペクトログラム、周期・振幅のゆらぎ（PPQ・APQ）、喉頭雑音（HNR・NNE）、ケプストラム（CPP）で嗄声を定量化。**CQ5 → 推奨する**（とくに治療効果の評価に有用。ソフトウェアや録音環境に左右されることに注意） |
| 喉頭筋電図 | 針電極を内喉頭筋に刺し、喉頭筋と支配神経の活動を評価する |

- **CQ6「空気力学的検査は有用か？」→ 推奨する**（発声動態・発声効率の評価、治療効果判定に有用）

## 外来での使いどころ（自院運用メモ）

- **当院でできる評価の範囲**：喉頭鏡（間接喉頭鏡も含む）がないため、第4章のうち実施できるのは**問診、GRBAS の聴覚的な印象（参考程度）、VHI-10 などの質問紙、MPT（ストップウォッチで /a/ の持続時間を測る）**まで。喉頭所見に基づく診断はできない
  - MPT は器具なしで測れる。**男性で明らかに10秒未満**なら声門閉鎖不全（声帯麻痺など）を疑う材料になる。ただし肺機能や努力の影響が大きいので、単独で判断しない
  - 声の性状のメモ：息漏れ（B）が目立つ → 声帯麻痺・声門閉鎖不全を疑う。力んだ・詰まる声で途切れる → 痙攣性発声障害を疑う。高い声が出ない・裏返る → 声帯病変・出血を疑う。紹介状に書く
- **問診はこのGLの表4-1 と表4-2 をそのまま使える**。とくに内科で見落としやすいのは：
  - 抗凝固薬・抗血小板薬・PDE5阻害薬（声帯血腫）
  - 吸入ステロイド（喘息・COPD 患者の嗄声。うがいの徹底、用量・デバイスの見直し）
  - 甲状腺・頸部・胸部の手術歴、最近の全身麻酔（挿管）
- **咽頭・鼻の視診と頸部診察で見るもの**：咽頭・扁桃の発赤や腫脹（咽頭痛が強いのに咽頭所見が軽い場合は喉頭蓋炎を疑う）、後鼻漏、**頸部リンパ節腫大・頸部腫瘤・甲状腺腫大**、吸気性喘鳴、構音障害・嚥下障害などの神経所見
- **喉頭の観察が必要なら耳鼻科へ**：当院では CQ3 の「適切なタイミングで喉頭内視鏡検査」を**紹介のタイミングの判断**に読み替える。紹介基準は [AAO-HNS 2018 のまとめ](../aao-hns-hoarseness-2018/summary.md#外来での使いどころ自院運用メモ) に集約した。**本GLの「3カ月」ではなく、2018年AAO-HNSの「4週間」（当院では2〜4週）を採用する**
