# 仙台市子ども医療（社保分）の取り下げ・併用での再請求

タスク管理: agent-mail issue 6

## 経緯

- 2026-10-24: 仙台市子ども医療費助成（法別83、負担者番号 830409xx）の社保分が、社保＋83の併用レセプトでなく社保単独で支払基金に出ていたと判明
  - 令和4年12月診療分から、仙台市の子の社保分は「社保＋83の併用レセプト（保険種別 22併）→支払基金」だけ。紙の連記式請求書（国保連あて）は使えない（支払基金宮城支部 事務連絡 2022-09-30）
  - 原因: ORCAで公費 183「乳食負有」として登録していた。183は「レセプト請求＝国保又は広域連合との併用に限り印刷」なので、社保では83がレセプトに載らない。社保併用には 253「子負無」/353「子負有」を使う
- 2026-10-24: WebORCAで洗い出し。取り下げ対象は14件（6月1・7月1・8月7・9月5）
- 方針（10月診療分）: 10月診療がすべて終わってから、11/10の請求までに、10月に受診した仙台市の社保の子の公費を253に付け替える
- 方針（取り下げ）: 11月に入ってから、9月診療分も含めた全部の月をオンライン請求システムでまとめて取り下げる。返戻が戻ったら公費を253に直し、43 請求管理で返戻と紐付けて再請求する
