# ATA 甲状腺機能低下症治療ガイドライン（2014）②：製剤の選択・服薬タイミング・吸収阻害・相互作用（自院メモ）

- **ガイドライン要約**: [thyroid/ata-hypothyroidism-2014/02-absorption-formulation.md](https://github.com/keiyousya/clinical-guidelines/blob/main/thyroid/ata-hypothyroidism-2014/02-absorption-formulation.md)

## 外来での使いどころ（自院メモ）

### 国内の製剤事情との違い（確実な範囲）

- 国内の LT4 は**チラーヂンS（錠・散）が主**。**液剤・ソフトゲルカプセルは国内未承認**なので、2b（ソフトゲル）と 2025 ETA の液剤/ソフトゲル推奨は**当院では選べない**。吸収不良を疑うときは、本GLの解説どおり「**錠剤のまま増量して TSH を追う**」か原因（胃炎・併用薬）を治す
- 「同じ製剤を続ける」（2a・3d）は国内でも当てはまる。**後発品への変更・銘柄変更・錠⇔散の変更をしたら、6週前後で TSH（と FT4）を再検**する
- 散は錠剤を飲めない人・細かい用量調整に使えるが、本GLは散剤については書いていない（米国にない剤形）

### 服薬タイミングの指導

- 基本は「**起床時に水で、朝食まで30分以上あける**」。国内の今日の治療指針も「起床時または就寝前」
- 朝が難しい人（朝食・コーヒーをすぐ摂る、朝に他の薬が多い）には**就寝前（夕食から3時間以上あけて）**を提案してよい（3a）
- **毎日同じ条件で飲むことが最優先**。「朝食後に飲んでいた」人をあわてて変えるより、条件を固定してから TSH を見る。変えたら6週前後で再検
- コーヒー・牛乳・お茶と一緒に飲まない（水で）。国内の今日の治療指針（橋本病）もコーヒー・日本茶・牛乳を避けるよう書いている

### 併用薬のチェック（当院でよく出る薬）

| 当院・他院でよく出る薬 | GLでの扱い | 当院の運用 |
|---|---|---|
| 沈降炭酸カルシウム、Ca サプリ、骨粗鬆症の Ca 製剤 | 3b（炭酸 Ca） | **4時間以上あける**（LT4 を朝、Ca を昼・夕） |
| 鉄剤（クエン酸第一鉄・フマル酸第一鉄・硫酸鉄）、鉄入りサプリ | 3b（硫酸鉄） | 4時間以上あける。鉄剤開始後は TSH を再検 |
| **PPI・P-CAB** | 3b（PPI）、3c（胃酸低下） | 長期使用で必要量が増えうる。PPI 開始・中止で TSH を再検。P-CAB は本GLの刊行後の薬で記載なし |
| **酸化マグネシウム**（便秘で多い） | 本GLに記載なし（記載はアルミニウム含有制酸薬）。2025 ETA は水酸化マグネシウムを4時間あける表に載せる | 時間をあける（LT4 を起床時、酸化 Mg を食後）。GLの直接の根拠はないので当院の判断 |
| スクラルファート、アルミ含有制酸薬 | 3b | 時間をあける |
| リン吸着薬（セベラマー、炭酸ランタン）、ポリスチレンスルホン酸 Na | 3b の表 | 透析・CKD 患者で TSH が上がったら真っ先に疑う |
| 胆汁酸吸着薬 | 3b（コレスチラミン・コレセベラム）。国内で使うコレスチミドは記載なし | できるだけ離す（コレスチラミンは5時間あけると最良） |
| エストロゲン（HRT、OC） | 3e | 開始・中止で TSH 再検 |
| カルバマゼピン・フェニトイン・フェノバルビタール・リファンピシン・セルトラリン・TKI | 3e | 開始時に TSH 再検 |

### 「増やしても TSH が下がらない」ときの順番（当院）

1. 飲み方（時間・水・食事やコーヒーとの間隔）と**実際に飲めているか**（[01](https://github.com/keiyousya/clinical-guidelines/blob/main/thyroid/ata-hypothyroidism-2014/01-lt4-dosing-monitoring.md) 6e）
2. 併用薬・サプリ（上表）、昆布・ヨウ素含有うがい薬（国内特有。[今日の治療指針・橋本病](https://github.com/keiyousya/clinical-guidelines/blob/main/thyroid/konnichi-chiryo-2026/03-hashimoto.md)）
3. 銘柄・剤形の変更、保管（高温の車内など）
4. 体重増加、妊娠、エストロゲン開始
5. それでも **1.6〜1.8 μg/kg/日を大きく超える**なら、**ピロリ菌・萎縮性胃炎（抗胃壁細胞抗体、ガストリン、B12）・セリアック病**を考える（3c: Strong）。見つかれば治療し、治療後に TSH と用量を見直す
