# 新型コロナウイルス予防接種

新型コロナウイルス予防接種には**任意接種**（13歳以上・16,500円）と**定期接種**（65歳以上・自己負担8,000円）の2種類がある。使用する予診票・書類・会計が異なるので注意する。

> **定期接種は10月1日（木）から**。9月30日（水）までは、65歳以上の方も**任意接種（16,500円・当院の予診票）**になる。

- 使用ワクチン: **ダイチロナ筋注**（第一三共、オミクロン株NB.1.8.1対応）
- 前回の新型コロナワクチンから**3か月以上**あいていることが条件。予診票の問3（前回の接種日）で必ず確認する
- 一度も接種したことがない方は、約4週間あけて2回接種
- 12歳以下のお子さまの接種は行っていない。中学生は保護者同伴（予診票に保護者の署名が必要）

## 予診票の印刷

| 接種の種類 | 予診票 | 場所 |
|---|---|---|
| 任意接種 | 当院の様式（HP掲載） | https://koutoudai-yugata-naika.clinic/forms/covid-vaccine-yoshinhyo.html |
| 定期接種 | 仙台市の様式 | （要確認） |

- A4縦・**両面印刷（長辺とじ）**。事前に複数枚印刷してストックしておく
- 患者が自分で印刷して持参する場合もある

## ワクチンの取り扱い

- **冷蔵庫（2〜8℃）で保管**。凍結させない。外箱を開けたら光に当てない
- **1バイアル＝1人分（0.6mL）**。1本を1人に使い切る
- 使う前に冷蔵庫から出して**常温に戻す**。取り出してから**12時間以内**に使う
- 使わなかった場合、再度冷蔵庫に戻せるのは**1回だけ**（戻してから最大24時間）
- **振らない**。白く均一になるまで、ゆっくり上下にひっくり返して混ぜる（転倒混和）
- 変色や異物があるものは使わない

## 任意接種の流れ

対象: 13歳〜64歳の方（65歳以上でも、9月30日までの接種や仙台市に住民票がない方はこちら）

### 受付

1. 受付で**体温測定**を行う
2. **任意接種の予診票**を渡し、記入してもらう
   - 中学生は保護者に署名してもらう
3. 書き終わったら受付に渡してもらう

### 看護師の準備

受付から予診票を受け取ったら、以下を**ビニールをかけた膿盆**に入れて診察室に持っていく。

- ワクチン（常温に戻して転倒混和し、0.6mLを吸って**筋注用の針**を装着した状態）（針の規格は要確認）
- アルコール綿
- 絆創膏
- 予診票

### 診察室（医師）

1. 予診票を確認し、診察・問診を行う（特に**前回の接種日**・**抗凝固薬**・**過去の副反応**）
2. ワクチンを接種する（**三角筋に筋肉注射、0.6mL**）
3. **カルテに接種時間を記録する**
4. 予診票の接種記録欄にLot No.を記入する
5. 予診票を診察室に置く（看護師が回収する）

### 接種後

1. 患者に**待合で15分間**経過観察のため待っていただく（過去にアナフィラキシーを起こした方などは30分間）
2. カルテに記録された接種時間を確認し、**15分経過後**に体調を聞く
3. 問題なければ**会計**（16,500円）→ 帰宅
4. 帰る前に「数日以内に**胸の痛み・動悸・息切れ**が出たら受診してください」と伝える

### 予診票の処理

1. 診察室から予診票を回収する
2. **スキャンしてカルテに貼る**
3. **原本は予診票ファイルに挟んで保管する**

## 定期接種の流れ

対象: 仙台市に住民票のある65歳以上の方（または60〜64歳で心臓・腎臓・呼吸器・免疫機能に重度障害がある方）

接種期間: **令和8年10月1日（木）〜令和9年1月31日（日）**、期間中1回

> 仙台市の予診票・済証など定期接種の書類の様式と記入方法は**要確認**。書類が揃ったらこの節を更新する。基本の流れはインフルの定期接種と同じ。

### 受付

1. **本人確認書類**（マイナンバーカード・健康保険証など）で対象者であることを確認する
   - 60〜64歳の方は身体障害者手帳も確認する
2. **自己負担金の免除書類**を持っているか確認する（下記参照）
   - 免除書類があれば預かって記載内容を確認する
   - **免除書類の提示がなければ自己負担8,000円**。後日提示されても返金はできない
3. 受付で**体温測定**を行う
4. **定期接種の予診票**（仙台市様式）を渡し、記入してもらう
5. 書き終わったら受付に渡してもらう

#### 自己負担金免除の確認書類

インフルの定期接種と同じ。

| 対象者 | 確認書類 |
|---|---|
| 生活保護世帯 | 生活保護費支給票 |
| 市民税非課税世帯 | 令和8年度 仙台市**介護保険料決定通知書**（「市町村民税非課税世帯」の記載があるものに限る）、または**確認通知書**（「自己負担金免除対象者です」の記載があるものに限る） |
| 中国残留邦人等支援給付制度受給者 | 同制度の本人確認証 |

- 確認書類を持っていない人には「区役所または仙台市HPから免除申請 → 確認通知書が届く（10日程度）」と案内する

### 看護師の準備・診察室・接種後

任意接種と同じ。加えて以下を行う。

- 定期接種の書類（予診票・済証など）を仙台市の様式に従って記入する
- **済証を患者に渡す**（「予防接種の記録になるので大切に保管してください」と伝える）
- **会計**は自己負担8,000円（免除対象者は0円）
- 予診票の原本は**請求に使用する**ので、スキャン後に予診票ファイルで保管する

## インフルエンザとの同時接種

- 医師が認めれば**同じ日に両方接種できる**。LINE予約の問診では「インフルエンザ・新型コロナ予防接種希望」と書かれてくる
- 予診票は**それぞれの様式を1枚ずつ**記入してもらう
- **左右の腕を分けて**接種する（コロナは筋肉注射、インフルは皮下注射）
- カルテにはどちらの腕に何を打ったかを記録する
- 会計は合計（任意接種同士なら 16,500円 + 3,300円 = **19,800円**）

## 定期接種と任意接種の早見表

| | 任意接種 | 定期接種 |
|---|---|---|
| 対象 | 13歳以上 | 65歳以上（仙台市） |
| 期間 | 通年 | 10/1〜1/31 |
| 料金 | 16,500円（税込） | 自己負担8,000円（免除あり） |

| 本人確認 | 不要 | 必要（保険証等） |

| 請求 | 当日会計のみ | 仙台市医師会へ月次請求（要確認） |
