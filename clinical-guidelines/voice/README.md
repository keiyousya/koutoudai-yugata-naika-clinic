## 使い分け

- **内科外来での初期対応（紹介のタイミング、喉頭を見る前の薬の扱い、声の安静、救急サイン、声の職業使用者の実例）** → [AAO-HNS 2018 のまとめ](aao-hns-hoarseness-2018/summary.md) の「外来での使いどころ」。当院の運用はここに集約した
- **原因の洗い出し（問診票・原因薬剤・分類）** → 日本GL [01 分類・疫学](jslp-jls-gl2018/01-classification-epidemiology.md)、[02 検査と診断](jslp-jls-gl2018/02-examination-diagnosis.md)
- **日本で使われている薬（トラネキサム酸・カルボシステイン・PPI・ステロイド）の位置づけ** → 日本GL [03 薬物療法](jslp-jls-gl2018/03-pharmacotherapy.md)
- **耳鼻科・ST が行う治療（音声治療・手術・ボツリヌストキシン）を患者に説明するとき** → 日本GL [04 音声治療・手術](jslp-jls-gl2018/04-voice-therapy-surgery.md)

### 2つのGLで食い違う点

| 論点 | 日本GL 2018 | AAO-HNS 2018 |
|---|---|---|
| 喉頭内視鏡のタイミング | CQ3 解説で 2009年米国GL を引用し「3カ月以上続けば」＋危険因子・職業的音声使用者は早期 | **4週で改善しなければ**、重大な原因の疑い（職業的音声使用者を含む）なら期間によらず |
| 抗菌薬 | 細菌感染が考えられる場合は推奨（慎重に） | ルーチン投与に**強く反対**（Grade A） |
| PPI | GERD が原因なら推奨、疑い例の診断的治療も許容（喉頭所見のある文脈） | 喉頭を見ずに嗄声だけへの投与に反対 |
| ステロイド | 吸入・内服とも限られた疾患以外で有効性のエビデンスなし | 喉頭を見る前のルーチン投与に反対 |
| トラネキサム酸 | 声帯出血・発赤に「投与されることが多い」と記載（推奨度なし） | 記載なし |

当院は喉頭を観察できないため、**喉頭観察前の判断はAAO-HNS 2018 に合わせる**。
