## 2. 定義と分類（第2章）

- **定義**: 2009年の米国 AAO-HNS ガイドラインの定義を引用。声の質・高さ・大きさ・発声努力の変化によって、コミュニケーションが損なわれる、または声に関わる QOL が低下する状態
- **国内で一般的な二分法**: 喉頭所見を基に、器質的異常（運動障害を含む）があれば**器質性**、なければ**機能性**。「機能性発声障害」には、非器質性全般を指す使い方と、誤った発声習慣による障害（ASHA 分類の筋緊張性発声障害 MTD）を指す使い方が混在している
- **本GLの分類表（表2-1）**: 米国言語聴覚協会（ASHA）の Classification manual for voice disorders-I を基に、日本の診療に合わせて改変した

### 表2-1 音声障害分類表（大分類と、外来で遭遇しやすい小分類の抜粋）

| 大分類 | 主な中分類・小分類（抜粋） |
|---|---|
| 1000 喉頭の組織異常 | 腫瘍性病変・異形成（白板症、**喉頭悪性腫瘍**、乳頭腫）／声帯粘膜の異常（**声帯結節・声帯ポリープ**・声帯嚢胞・ポリープ様声帯・瘢痕・溝症・肉芽腫）／**声帯の血管病変（声帯出血・血管拡張性病変）**／先天性・加齢（加齢性声帯萎縮など）／瘢痕・狭窄 |
| 2000 喉頭の炎症性疾患 | 輪状披裂関節炎／**喉頭粘膜の急性炎症（急性喉頭炎・急性声門下喉頭炎・急性喉頭蓋炎）**／咽喉頭逆流症／喉頭知覚過敏（irritable larynx）／その他 |
| 3000 喉頭の外傷 | 喉頭粘膜外傷（挿管性を含む）、披裂軟骨脱臼症、喉頭枠組みの外傷 |
| 4000 全身性疾患 | 内分泌・代謝（**甲状腺機能低下症**・亢進症、性ホルモン障害など）／免疫（上気道アレルギー、膠原病など）／筋骨格系／脱水症 |
| 5000 呼吸器・消化器疾患 | 気管支喘息、COPD、**胃食道逆流症**、肺炎・結核・真菌症など |
| 6000 心理的疾患・精神疾患 | **心因性発声障害**（DSM-5 準拠の名称）、うつ病、性別違和など |
| 7000 神経疾患 | 上喉頭神経麻痺、**片側・両側声帯麻痺**、重症筋無力症／痙攣性発声障害（内転型・外転型・混合型）、音声振戦、パーキンソン病など |
| 8000 その他（機能性発声障害を含む） | **筋緊張性発声障害**（過緊張性・低緊張性）、変声障害、仮声帯発声、奇異性声帯運動 |
| 9000 原因不明の音声障害 | ― |

- ASHA 分類からの主な変更点：急性喉頭蓋炎・急性声門下喉頭炎を「呼吸器・消化器疾患」から「喉頭の炎症性疾患」へ移動、転換性障害を「心因性発声障害」に改称、声帯麻痺の不全・完全麻痺を統合、など
- 分類表は**病名の整理**であり、各疾患の診断基準や治療は書かれていない（急性喉頭炎・声帯出血・結節・ポリープの個別の記述は本GLにはない）

## 3. 疫学（第3章）

| 項目 | 内容 |
|---|---|
| 国内の頻度 | **国内のまとまった有病率データはない** |
| 米国の頻度（引用） | 人口の約1/3が生涯で音声障害を経験し、約7%が現在何らかの音声障害をもつ。約7%が過去1年に声の問題で仕事を休んだ |
| リスクが高い集団 | 逆流性食道炎の合併、女性、**声を職業的に使う人**（エアロビクスインストラクター、教師など）。教師の約6割が音声障害の経験あり |
| 高齢者 | 年齢とともに非特異的な嗄声と**声帯麻痺**が増え、良性声帯病変と急性・慢性喉頭炎は減る。男性は喉頭癌・声帯麻痺、女性は急性喉頭炎・非特異的音声障害の割合が高い |
| 国内の教師 | 音声障害の自覚は 8.5〜54%。担当授業数が多い、低学年担当、国語・音楽担当で多い |

- 急性喉頭炎・声帯出血・声帯結節・ポリープといった**疾患別の頻度や自然経過は、本GLには記載がない**（急性喉頭炎の自然経過は [AAO-HNS 2018](../aao-hns-hoarseness-2018/summary.md) の KAS 4B・8 を参照）

## 外来での使いどころ（自院運用メモ）

- **分類表の使い方**：当院では喉頭を観察できないため、器質性か機能性かを当院で決めることはできない。分類表は、**問診で拾うべき原因の一覧**として使う（全身性疾患＝甲状腺機能低下症・膠原病、呼吸器＝喘息・COPD と吸入ステロイド、消化器＝GERD、神経＝パーキンソン病・術後の反回神経麻痺、心因性）
- **内科で拾える原因**：甲状腺機能低下症（TSH）、吸入ステロイドによる嗄声（うがい・吸入手技・デバイスや用量の見直し）、GERD 症状の有無、神経疾患の随伴症状（構音障害・嚥下障害）。これらは当院で評価し、紹介状に書く
- **急性喉頭蓋炎は分類表に名前が載っているだけで、診療上の記載は本GLにない。** 救急サインの扱いは [AAO-HNS 2018 のまとめ](../aao-hns-hoarseness-2018/summary.md#外来での使いどころ自院運用メモ) にまとめた
- **声を職業にする人は有病率が高い**（第3章）。歌手・教師・保育士・コールセンター勤務などは問診で必ず確認する
