## 喘息を疑ったら（早見）

当院の運用メモ。各資料の要約と自院メモをつないだもので、どれか1つの GL の推奨ではない。

1. **問診で疑う**: 繰り返す喘鳴（特異性が高い）、夜間〜早朝の咳・息苦しさ、かぜ・運動・冷気・会話・においでの誘発、運動後の悪化。アレルギー性鼻炎・アトピー・家族歴。**NSAIDs で悪化した既往**（アスピリン喘息）。喫煙歴（pack-year）（[今日の治療指針 01](https://github.com/keiyousya/clinical-guidelines/blob/main/asthma/konnichi-chiryo-2026/01-bronchial-asthma.md)）
2. **ほかの病気を除外する**: 胸部X線（**今は他院に依頼**）。採血で血算（好酸球）・総 IgE・特異的 IgE。心不全を疑えば心電図・エコー・BNP。40歳以上の喫煙者は COPD・ACO を考える（[04-aco](https://github.com/keiyousya/clinical-guidelines/blob/main/asthma/konnichi-chiryo-2026/04-aco.md)）
3. **診断的治療（PGAM の流れ）**: 中用量の ICS/LABA を始め、**3〜7日で良くなれば臨床診断**。スパイロがないので、症状の変化と、できればピークフローの記録で判断する。良くならなければ診断を見直す
   - 咳だけなら咳喘息かアトピー咳嗽 → [03-cough-variant-asthma.md](konnichi-chiryo-2026/03-cough-variant-asthma.md)
4. **長期管理**: コントロールを見ながら上げ下げする（[01-bronchial-asthma.md](konnichi-chiryo-2026/01-bronchial-asthma.md)）
5. **紹介**: 中用量〜高用量の ICS/LABA（＋LAMA）でもコントロール不良、経口ステロイドが年2回以上要る、診断に迷う、職業性を疑う、喫煙者で COPD と区別がつかない（スパイロがないため）。紹介先: 未定・要記入

GINA は「治療前に客観的検査で確かめる」ことを重視している（[GINA 2026](https://github.com/keiyousya/clinical-guidelines/blob/main/asthma/gina-2026/summary.md)）。当院は今はスパイロがないので PGAM の診断的治療で進めるが、**良くならない人、喫煙者、診断に迷う人はスパイロのできる施設で一度確かめてもらう**。

## 設備導入の検討メモ

- **胸部X線**（見積もり中）: 喘息に限らず、器質的疾患の除外に使う。PGAM の診断の流れの前提で、入ると院内で完結できる
- **スパイロ**: 次に入れるならこれ。可逆性試験で喘息の確定、COPD・ACO の区別、治療効果の評価に使える。小型（10〜30万円）なら1回330点（判断料込み）で約60〜90件で回収できる計算（2026-10 の概算。見積もりは取っていない）
- **FeNO**: 慢性咳嗽が多ければ検討する（咳喘息とアトピー咳嗽・GERD の区別、ICS をやめるかの判断）
