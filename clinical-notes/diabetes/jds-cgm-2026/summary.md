# CGM（FreeStyleリブレ）の処方（自院メモ）

- **ガイドライン要約**: [diabetes/jds-cgm-2026/summary.md](https://github.com/keiyousya/clinical-guidelines/blob/main/diabetes/jds-cgm-2026/summary.md)（学会の適正使用指針 2026-04-01 改訂と、選定療養の運用 2024-07-01）
- 算定は令和8年度改定後の**告示・留意事項通知の原文**で確かめた（2026-10-15）。出典は末尾

## まとめ（当院でできること）

| 患者 | リブレの出し方 | 患者負担の目安 |
|---|---|---|
| **インスリンを1日1回以上自己注射**（1型・2型とも。週1回のイコデクも含む） | **保険**: C101 在宅自己注射指導管理料 ＋ C150-7（1,250点/月） | 3割で月 約6,000円（管理料込み。下の計算） |
| インスリンを使っていない2型（内服のみ・食事療法のみ） | **選定療養**（センサー代を自費、診察は保険）。始めるには届出・掲示が要る | 料金は当院で決める（1,250点相当 = 12,500円/月 が標準） |
| GLP-1 受容体作動薬の注射だけ | 区分7は「インスリン1日1回以上」が条件。GLP-1 だけの人は**原則、選定療養で扱う**（下の「要確認」） | 同上 |
| リアルタイムCGM（C152-2、Dexcom などのポンプ連動・アラート前提） | **当院では出せない**（ポンプ治療をしていて、常勤の糖尿病専門医＋ポンプ経験2年以上のスタッフがいる施設が条件）。必要な人は専門施設へ紹介 | ― |

施設基準の届出は C150-7 には**不要**。ただし**医師の要件がある**（次の節）。

## 前提: 医師の要件（保険でも選定療養でも必要）

- 留意事項 C150(4): 区分7は「**糖尿病の治療に関し、専門の知識及び5年以上の経験を有する常勤の医師**又は当該専門の医師の指導の下で糖尿病の治療を実施する医師」が血糖管理を行った場合に算定する
- 選定療養も、**この人員要件を満たす医療機関に限られる**（選定療養の留意事項 第28項(2)）
- 「専門医資格が必須」とは書いていない。**当院の常勤医が「専門の知識及び5年以上の経験」に当たるかは、経歴をもとに院長が判断する**。迷うなら東北厚生局に問い合わせてから始める（**未判断・要記入**）
- 他院の専門医の指導の下で当院の医師が管理する形は、疑義解釈で認められていないとする解説がある（未確認）。当院の常勤医が要件を満たす前提で考える

## 保険で出す（C150-7）

### 算定（令和8年度）

| 項目 | 点数 | メモ |
|---|---|---|
| C101 在宅自己注射指導管理料 | 1 複雑な場合 1,230点／2 それ以外 月27回以下 650点・月28回以上 750点 | インスリンの人は既に算定しているはず |
| C101 注2 導入初期加算 | 580点（初回指導月から3月まで） | インスリン導入と同時なら |
| **C150-7 血糖自己測定器加算（間歇スキャン式）** | **1,250点** | 注3: インスリン自己注射1日1回以上の外来患者に、血糖自己測定値に基づく指導のために使った場合 |

- 計算例: C101-2（月27回以下）650点 ＋ C150-7 1,250点 ＝ 1,900点 → **3割で 約5,700円/月**（再診料・処方料などは別）
- **センサー・リーダーなどの費用はすべて所定点数に含まれる**（留意事項 C150(1)）。センサーは当院が仕入れて患者に渡す。仕入れ値が実質の持ち出しになる
- C150-7 を算定する月は、**指先穿刺の SMBG（区分1〜6）は別に算定できない**（留意事項(5)）。SMBG のチップも1,250点に含まれる
- **3か月分をまとめて算定できる**: 在宅療養指導管理材料加算は「3月に3回」まで。連続する3か月の前後の月の分を併せて算定してよい（ただし対象月の重複は不可）（第2款 通則1・留意事項 第2款 2）。**3か月ごとに受診する人には、3か月分のセンサー（6個）を渡して C150-7 を3回分算定**できる
- 週1回のインスリン イコデクは「1日1回以上」に準じて算定できる（留意事項(8)、令和8年度に明記）

### 生活習慣病管理料との関係

- 糖尿病が主病で、**インスリン・GLP-1 などの糖尿病の注射薬を使って C101 を算定している月は、生活習慣病管理料(Ⅰ)(Ⅱ)を算定できない**（告示 B001-3・B001-3-3 注1。「別に厚生労働大臣が定める薬剤」の中身は解説記事で確かめたもので、告示の別表は見ていない）
- インスリンの人はもともと C101 で算定しているはずなので、リブレを足しても変わるのは C150-7 の分だけ

### 外来での流れ

1. 対象を選ぶ: インスリン使用中で、**低血糖が心配・血糖の振れが大きい・HbA1c が下がらない・インスリンの量を調整中**（学会指針の患者像）
2. 初回: センサーの貼り方（上腕、14日）、スマホアプリ（FreeStyleリブレLink）の設定、**表示値と症状が合わないときは SMBG で確かめる**ことを説明。テープかぶれ・はがれの対処も
3. 当院の LibreView に患者をつなぐ（クリニックのアカウント作成は**未・要対応**）
4. 受診時: AGP レポートで TIR（70〜180 mg/dL）・TBR（70未満）・TAR・%CV を見る。目標の目安は TIR 70%以上（[GL2024 2章の自院メモ](../jds-gl2024/02-treatment-goals.md)）。日本人の目標値はまだ検証中（学会指針）
5. 低グルコースアラートは最初 60〜70 mg/dL、高グルコースアラートは慣れるまで使わない（学会推奨）

## 選定療養で出す（インスリンを使っていない人）

### 学会がよい適応としているもの

- 食事・運動療法の評価
- 内服薬の評価、**内服薬を増やす・足す・切り替えるときの評価**
- **健診で保健指導判定値を超えた人の食後高血糖の評価**

当院では、内服で HbA1c が下がりきらない人や、生活習慣の振り返りをしたい人に、**2週間（センサー1個）だけ付けてもらって次回一緒に AGP を見る**使い方が合いそう。

### 始めるまでにやること（選定療養の留意事項 第28項）

- [ ] 医師の要件を満たすか判断する（上の節）
- [ ] **料金を決める**。標準は C150-7 の1,250点相当（＝12,500円/月、センサー2個分）。2週間だけの人向けにセンサー1個の料金も決めるか検討
- [ ] **別紙様式22で東北厚生局に報告**（料金を決めたとき・変えるときはその都度）
- [ ] **院内に掲示し、ホームページにも載せる** → `notices/` に掲示物、`shisetsu-kijun/keiji.md` にも1行足す
- [ ] 患者への説明と同意（十分な情報提供と、患者の自由な選択と同意が条件）。同意書のひな形を作るなら `internal-forms/`
- [ ] **領収書は保険分と選定療養分を分ける**（WebORCA で選定療養の自費項目をどう入れるかは**未確認**）
- [ ] **毎年、実施状況を東北厚生局に報告**（時期・様式は未確認）

選定療養でも、診察・検査・処方は保険のまま。センサー代の部分だけが自費になる。

### 生活習慣病管理料(Ⅰ)の血糖自己測定指導加算（参考）

- 生活習慣病管理料(Ⅰ) 注3: インスリンを使っていない2型で、HbA1c が NGSP 8.4%以上（算定月か前月）の人に SMBG を月20回以上させて指導した場合、**年1回 500点**（留意事項 B001-3 (13)(14)）

## 要確認・未判断

- **当院の常勤医が C150 の医師要件に当たるか**（院長判断。必要なら東北厚生局に照会）
- **GLP-1 注射だけの人に区分7を算定できるか**: 留意事項(3) は GLP-1 週1回以上の人を「インスリン製剤の自己注射を行っている者に準じて」算定できるとしているが、区分7の告示は「インスリン製剤の自己注射を1日に1回以上」と書いている。区分7まで準じられるかは通知だけでは読み切れない（解説記事でも「事前に地方厚生局等に確認すべき」としている）。当院では、確認が取れるまで選定療養で扱う
- 選定療養の留意事項は人員要件を「C150 の(5)に規定する要件」と引いているが、令和8年度の留意事項では医師要件は(4)にある（番号がずれているだけで中身は同じと読んだ）
- センサーの仕入れ先と仕入れ値（アボットか医療機器ディーラーか。東邦薬品で扱えるか）
- 選定療養の年次報告の時期・様式、WebORCA での入力方法
