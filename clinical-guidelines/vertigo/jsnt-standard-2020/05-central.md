# 各論 II 中枢疾患によるめまい

- **出典**: 日本神経治療学会「標準的神経治療：めまい（2020）」神経治療 37(5):769–811, 2020 — B 各論 II（p.792–798、執筆：工藤洋祐、城倉 健）
- **原文**: https://www.jstage.jst.go.jp/article/jsnt/37/5/37_769/_pdf/-char/ja
- **発行**: 2020
- **確認日**: 2026-09-14

めまいだけを主訴とする外来患者が中枢性である確率は **1.7〜3%** と高くない〔**エビデンスレベル IVa**〕。ただし嘔気・嘔吐で詳しい診察がしにくいことが多いため、効率よく鑑別するポイントを押さえる。

## 1. HINTS

| 項目 | 中枢性を示唆する所見 | 注意点 |
|---|---|---|
| **H**ead Impulse test | **正常**であること | 肉眼で見る方法は covert saccade を捉えられず感度が低い（vHIT でないと判定が難しい）。**AICA 領域梗塞など中枢性でも異常になりうる** |
| **N**ystagmus | 注視誘発眼振、純粋な垂直性・回旋性眼振 | 注視方向性眼振は、高度な小脳障害でないと出ない |
| **T**est of **S**kew | skew deviation（上下の眼位のずれ） | 視診で分かりにくければ alternate cover test。滑車神経麻痺との区別が必要。仰臥位では目立たない |

- 3項目のうち1つでも陽性なら中枢性を示唆する
- **対象は「急性発症で24時間以上続くめまい（acute vestibular syndrome）」があり、脳血管障害の危険因子を1つ以上もつ患者**。この集団で高い感度・特異度が示されている〔**グレード C1、レベル IVa**〕
- HINTS に「急性の聴力低下」を加えた **HINTS plus** も有効という報告がある
- head impulse test を単独で判断すると末梢性と誤診しうる。HINTS を別にすれば、**中枢性の鑑別で最も重要なのは、めまい以外の神経症候を見つけること**

| 部位 | 特徴 |
|---|---|
| **中脳** | 眼球運動障害が多い。**上下方向の眼球運動障害や眼瞼下垂**は中脳病変を強く示唆 |
| **橋** | 単眼の内転障害（MLF）、水平注視麻痺（PPRF・外転神経核）、one-and-a-half 症候群は橋背側病変を示唆。軽い片麻痺や半身の感覚障害を伴うことも。**AICA 閉塞では、めまいに加えて患側の聴力障害・肢節運動失調・顔面麻痺（AICA 症候群）** |
| **延髄** | 前庭神経核があり、高頻度にめまいが出る。**外側梗塞（Wallenberg）**：構音・嚥下障害、患側の顔面温痛覚障害・肢節運動失調・Horner 症候群、健側の頸部以下の温痛覚障害。内側梗塞（Dejerine）：患側の舌運動障害と健側の片麻痺 |
| **小脳** | SCA・AICA 領域：構音障害と患側の肢節運動失調が目立つ。**PICA 領域：構音障害や肢節運動失調は目立たず、起立・歩行障害（体幹失調）が唯一の神経症候になる**。視覚で代償できないので、立位や座位で診察すれば分かりやすい |
| **大脳** | 存在自体に議論はあるが、前庭皮質（島皮質後部など）を含む血管障害で急性めまいを起こした症例報告は散見される |

## 3. 末梢性と誤診しやすい中枢性めまい

### 前庭神経炎に似る：pseudo-vestibular neuritis
- PICA 内側枝領域（小脳小節近傍）の障害で、**患側向きの方向固定性水平性眼振**が出ることがある。構音障害や肢節運動失調を伴わないので、前庭神経炎と区別しにくい
- 鑑別の手がかり
  - vHIT は中枢性なら正常パターンが多い
  - **眼振が最も目立つ頭位で、眼振が向地性なら前庭神経炎、背地性なら pseudo-vestibular neuritis を考える**〔**エビデンスレベル V**〕
- 症例（図3）：56歳女性。頭位によらない右向きの方向固定性眼振があり、左前庭神経炎が疑われた。しかし起立・歩行障害（左への体幹の傾き）があり、CT で右小脳に小出血が見つかった

### BPPV に似る：central paroxysmal positional vertigo（CPPV）
- PICA 内側枝領域に限局した梗塞や出血で、**方向交代性背地性眼振**（外側半規管型クプラ結石症に似る）が出ることがある
- CPPV のほうが、頭位変換から眼振の向きが変わるまでの潜時が短い傾向〔**エビデンスレベル IVb**〕。健側下頭位でより目立つ

### 共通点
- どちらも PICA 領域の障害なので**体幹失調を伴う。体幹失調に注目すれば鑑別は比較的容易**

### 図4 中枢性めまいを見逃さない診療の流れ
```
急性発症のめまい
 ├ 麻痺・感覚障害・構音障害・眼球運動障害・失調のいずれかが明らか ──────────→ 中枢性めまい
 └ いずれも明らかでない／わからない
      ├ 蝸牛症状あり → 内耳疾患（メニエール病・突発性難聴）
      └ 蝸牛症状なし
           ├ 頭位・頭位変換眼振あり → BPPV
           ├ 方向固定性水平性眼振あり → 前庭神経炎（末梢前庭障害）
           └ どちらもない → 起立歩行障害
                 ├ あり → 中枢性めまい
                 └ なし → その他
```
順番の考え方：①まず脳幹・小脳上部の障害を探す → ②頻度の高い末梢前庭由来を探す → ③最後に念のため小脳下部（PICA）の障害を探す

## 4. 急性めまいをきたす中枢性疾患

| 疾患 | 要点 | 治療（エビデンス） |
|---|---|---|
| **脳血管障害** | 危険因子があり、めまい以外の神経症候を伴えば第一に考える。**疑ったらただちに画像検査。病巣は脳幹・小脳が多いので、可能なら MRI を優先** | 梗塞：argatroban などの抗凝固〔II・B〕、aspirin などの抗血小板〔I・A〕、急性期の血栓溶解〔II・A〕、血管内治療〔I・A〕（ただし後方循環では前方循環ほど有効性が確立していない）。出血：降圧・止血。小脳出血は血腫が脳幹を圧迫すれば手術〔IV・C1〕。めまい自体は制吐薬・抗ヒスタミン薬で対症療法 |
| **椎骨脳底動脈循環不全** | **数分のめまい発作を反復し、蝸牛症状はない**。多くは椎骨動脈の動脈原性塞栓による後方循環の TIA。来院時には改善していて MRI も陰性で、診断が難しい。**危険因子を複数もつ人の数分のめまい反復で想起** | 切迫梗塞なので、脳幹・小脳梗塞に準じて治療 |
| 鎖骨下動脈盗血 | 上肢の血圧に左右差。患側の上肢運動でめまいなど後方循環の虚血症状 | 症候性なら血管内治療を考慮〔IVa・C1〕 |
| Bow hunter 症候群 | 頭を大きく回すと、椎骨動脈が骨棘などに圧迫されて虚血症状（C1–2 レベルが多い） | 誘発動作の回避、手術、血管内治療〔IVa・C1〕 |
| 脱髄・炎症性疾患 | 多発性硬化症、視神経脊髄炎、神経ベーチェット、神経サルコイドーシス。両側の核間性眼筋麻痺は MS、持続する吃逆・嘔気は NMO（延髄最後野）を示唆 | ステロイドパルスなど（MS には〔I・B〕） |
| Fisher 症候群 | 先行感染後、急性のふらつき＋運動失調・腱反射低下・外眼筋麻痺（複視）。髄液の蛋白細胞解離、抗 GQ1b 抗体 | 基本は予後良好で、免疫治療が回復を早めるエビデンスはない〔IVb・C〕。Bickerstaff 脳幹脳炎や GBS への進展が疑われれば積極的に免疫治療〔VI・C1〕 |
| **Wernicke 脳症** | アルコール、飢餓、妊娠悪阻などで B1 欠乏。めまい・ふらつき・失調＋外眼筋麻痺・意識障害・認知低下 | **疑った時点で、糖質輸液より先にビタミン B1 を静注**。初期 200 mg×3回/日の報告あり〔VI・C〕 |
| **片頭痛（前庭性片頭痛）** | めまいは発作性に反復し、頭痛発作と同期することが多い。頭痛がなく光過敏・音過敏だけのこともある | RCT で確立した予防薬はない。片頭痛に準じて propranolol などの β 遮断薬、valproate、amitriptyline〔VI〕 |
| 緊張型頭痛 | めまいを伴うことがある（頸部筋からの異常入力）。特異的な所見はない | 頸部の理学療法、筋弛緩薬（tizanidine、eperisone）、抗不安薬、amitriptyline（緊張型頭痛の予防として〔II・A〕） |
| 急性小脳炎 | 感染後または特発性の急性小脳失調。成人は特発性が多い。髄液で単核球増多、MRI で小脳腫脹 | 特定の病原体があればその治療、症状が強ければステロイドパルス。多くは2〜3か月で軽快するが、水頭症やヘルニアの危険もある〔V〕 |

**前庭性片頭痛の診断基準（Bárány 学会・国際頭痛学会 2012、本文の記載）**
- A：C と D を満たす発作が少なくとも5回
- B：現在または過去に片頭痛（前兆の有無は問わない）
- C：5分〜72時間続く、中等度〜高度の前庭症状
- D：発作の少なくとも50%が片頭痛の徴候に伴う
- E：他の頭痛や前庭疾患の診断に当てはまらない

> 前庭性片頭痛の診断基準は、Bárány 学会が2022年に改訂版（J Vestib Res 32:1–6）を出している。本章の記載は2012年版。

## 5. 慢性めまい・ふらつきをきたす中枢性疾患

| 疾患 | 要点 | 治療 |
|---|---|---|
| **脳血管障害慢性期** | 多発性脳梗塞や大脳白質病変のある人の慢性めまい・ふらつき（感覚統合不全、反射の脱抑制）。画像所見は参考になるが特異的ではなく、他疾患の除外が必要 | 血管拡張薬：**cilostazol〔II・B〕**、ibudilast、ifenprodil |
| 延髄外側梗塞後 | 他の症状が回復した後も慢性のめまいが残る例がある〔IVb〕 | 反復経頭蓋磁気刺激が試みられている（レベル V、保険適用外） |

| 発作性失調症 | 発作性の失調・回転性めまい。国内は EA2（CACNA1A）が多い | acetazolamide |
| CANVAS | 両側前庭障害＋小脳失調＋感覚神経障害。50歳代発症、慢性咳嗽を伴うことも。RFC1 遺伝子のリピート延長 | ― |
| Opsoclonus–myoclonus 症候群 | 全方向への急速な眼球振動＋四肢のミオクローヌス。傍感染性・傍腫瘍性など | 免疫治療（特発性のほうが反応良好）〔IVb・C1〕 |
| 傍腫瘍性亜急性小脳変性症 | 亜急性の小脳失調。抗 Yo・Hu・Ri・Tr・VGCC・mGluR1 抗体。乳癌・卵巣癌・小細胞癌・リンパ腫 | 腫瘍の早期発見と治療が重要。抗体陽性なら半年ごとに腫瘍検索を続ける〔VI・C1〕 |
| グルテン失調症 | 純粋な小脳失調。消化器症状は10%未満。抗グリアジン抗体、抗 DGP 抗体、抗 TG6 抗体 | 無グルテン食、無効なら IVIg〔II・B〕 |
| 抗 GAD 抗体関連小脳失調 | 中高年女性に多く、**1型糖尿病を合併しやすい**。高力価（2000 U/mL 以上）が多い | 免疫治療〔IVa・C1〕 |
| 小脳失調型橋本脳症 | 抗甲状腺抗体陽性、ステロイド反応性。抗 NAE 抗体。画像で小脳萎縮は少ない | 免疫治療〔IVb・C1〕 |
| アルコール性小脳変性症 | 小脳虫部上部の萎縮。体幹失調が主体 | 禁酒で進行が止まる |
| 脳腫瘍 | 数週〜数か月で悪化する亜急性・慢性の経過。腫瘍内出血で急に悪化することも | 病理に応じた治療。脳浮腫にステロイド・濃グリセリン |

## 外来での使いどころ（自院運用メモ）

- **HINTS は「急性で持続性（24時間以上）のめまい」に使う検査。** BPPV のような頭位性や、発作が治まった反復性めまいには当てはまらない
- **HINTS の読み方は逆に覚える**：head impulse test が**正常**なら危険（持続性めまいがあるのに前庭反射が保たれている＝中枢性の可能性）
- **肉眼の head impulse test は感度が低い**：HINTS が末梢性パターンでも、体幹失調があれば中枢性として扱う
- **紹介の閾値を下げる状況**
  - 血管危険因子があり、蝸牛症状のない**数分のめまいを繰り返す**（椎骨脳底動脈の TIA ＝切迫梗塞）
  - 頭痛や頸部痛を伴う急性めまい（椎骨動脈解離・小脳出血）
  - 立てない・座位を保てない
  - 急性めまい＋急な難聴（AICA 梗塞を否定できない）
- **内科で見落としやすい中枢性の原因**
  - 飲酒歴・低栄養 → Wernicke 脳症（疑えば B1 を先に）
  - 1型糖尿病＋小脳失調 → 抗 GAD 抗体
  - 橋本病＋小脳失調 → 橋本脳症
  - 亜急性の小脳失調 → 傍腫瘍性（婦人科癌・肺癌の検索）
- **片頭痛のある反復性めまい**は前庭性片頭痛を考え、片頭痛の予防薬を検討する（診断基準は2022年改訂版で確認）
