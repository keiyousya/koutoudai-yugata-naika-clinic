# G-MIS・医療情報ネット

厚労省の医療機能情報提供制度の報告システム。制度の話は県、システム操作はG-MIS事務局、
という切り分け。事務局の対応は平日9〜17時で、システム内の**お問合せ機能**から起票する
（問合せ番号が発行される）。

ログインは Med-Login から。ID・パスワードの在処は agent-mail のメモリを参照。

## メモ

- 案内用電話番号は、医療機能情報提供制度の**新規報告**の【1.(1)基本情報】で入力する。
  電話番号だけを直す変更メニューはない。
- 2026-09-14に全30画面の新規報告を提出済み。県の確認完了後、約4時間で医療情報ネットに反映される。
- かかりつけ医機能報告の初回は2026年度分（2027年1〜3月に報告、実績は2026年4月〜2027年3月）。
- 入力の癖：電話は `(022)393-8689` 形式、時刻は `hhmm`（1700）。
