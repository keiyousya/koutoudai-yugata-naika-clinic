# 第19章 高齢者の糖尿病（認知症を含む）

- **出典**: 日本糖尿病学会『糖尿病診療ガイドライン2024』19章（p.419–446）
- **原文**: https://www.jds.or.jp/uploads/files/publications/gl2024/19.pdf
- **発行**: 2024-05-30
- **確認日**: 2026-09-13

構成は「特徴 → CGA評価 → 血糖目標（CQ）→ 老年症候群との関係 → 食事・運動（CQ）→ 薬物療法の注意 → 血圧・脂質 → 介護施設」。外来で頻用するのは CQ19-3（目標値）と Q19-7（薬剤ごとの注意）。

## Q19-1 高齢者糖尿病はどのような特徴があるか

- **65歳以上の糖尿病を高齢者糖尿病**とする
- 耐糖能低下の原因: 加齢に伴うインスリン分泌低下、体組成変化（筋肉量↓・内臓脂肪↑）、身体活動量低下による抵抗性増大
- **食後高血糖**をきたしやすい
- 低血糖は自律神経症状（発汗・動悸・振戦）が出にくく**非典型的** → 見逃され重症化しやすい。加齢とともに重症低血糖が増加
- 重症低血糖は**転倒・骨折、認知症、心血管疾患、死亡**のリスクファクター。低血糖は負担感・うつ・QOL低下も招く
- 腎機能・肝代謝・肝血流量の低下と多剤併用 → 薬物蓄積・有害事象が起こりやすい
- 脳梗塞・虚血性心疾患・下肢PADが多く、**無症候性**も多い
- 高齢者でも高血糖は網膜症・腎症・心血管疾患・脳卒中・心不全のリスク
- 老年症候群（認知機能障害、うつ、ADL低下、サルコペニア、転倒、骨折、フレイル、尿失禁、低栄養、ポリファーマシー）を**約2倍**きたしやすい
- **75〜80歳以上**で ADL低下・認知症・腎機能低下・重症低血糖・脳卒中・心不全が増える → **75歳以上と機能低下のある一部の65〜74歳**が特に注意すべき対象
- 個人差が大きい。合併症・併存症に加え身体機能・認知機能・社会経済状況を常に考慮

## Q19-2 高齢者糖尿病はどのように評価すべきか

- 多職種で **CGA（高齢者総合機能評価）**: ①身体機能 ②認知機能 ③心理状態 ④栄養状態 ⑤薬剤 ⑥社会・経済状況
- 退院前 CGA で退院3〜12ヵ月後の施設入所が減少
- **DASC-8** は認知機能と ADL を同時に簡易スクリーニングでき、血糖目標のカテゴリー分類に使える

### 評価項目とツール

| 領域 | 知見 | 評価法 |
|---|---|---|
| ADL | BADL低下 1.82倍、IADL低下 1.65倍。**IADL低下は死亡の危険因子** | BADL: Barthel Index／IADL: Lawton 尺度、老研式活動能力指標 |
| サルコペニア | 高血糖で筋量・筋力・身体能力が低下 | 下腿周囲長（**男<34 cm、女<33 cm で陽性**）、SARC-F → 握力・歩行速度・筋肉量（AWGS 2019） |
| 転倒 | 糖尿病で約1.4〜4倍 | — |
| フレイル | 高血糖でなりやすい | CHS、J-CHS（体重減少・疲労感・握力・歩行速度・活動量の5項目）、CSHA、基本チェックリスト（KCL） |
| 認知機能 | **アルツハイマー病 約1.5倍、血管性認知症 約2.5倍** | MMSE、HDS-R、DASC-21。MCI には MMSE・MoCA-J。**Mini-Cog の時計描画**は遂行機能を反映し、インスリン自己注射可否の指標になるとの報告 |
| うつ | ADL・QOL低下、認知症、大血管症、死亡と関連 | GDS-15 |
| 栄養 | 低栄養は感染症・転倒骨折・フレイル・認知症リスク。BMI低値・体重減少は死亡リスク。BMI 30以上やサルコペニア肥満は ADL低下リスク | GLIM 基準、MNA®-SF。Alb・Hb・TC 低値はリスク所見 |
| 薬剤 | 多剤併用になりやすい。減薬は利益>害の可能性があるがエビデンス不十分 | 重症低血糖リスク、肝腎機能、相互作用、アドヒアランス |
| 社会・経済 | 同居人・近隣とのつながり・経済状況を把握 | LSNS-6（社会的孤立） |

- **GLIM**: 表現型基準（意図しない体重減少／BMI低値／骨格筋量減少の1つ以上）かつ病因的基準（食事量減少・吸収能低下／疾患負荷・炎症）のいずれか → 低栄養
- CGA の結果と患者・介護者の希望に基づき治療計画を立て、介護保険などの社会サービス導入が望ましい

## CQ19-3 高齢者糖尿病の血糖コントロールは血管合併症の発症・進行抑制に有効か

> 高齢者でも高血糖・低血糖は血管合併症と関係し、**低血糖予防に十分配慮しながら適切に高血糖是正**を行うことは血管合併症の発症・進行抑制に寄与し得る。

- **推奨グレード B**（合意率100%：投票20、賛成20、反対0、欠席1）
- エビデンスレベル: ステートメント自体への記載なし。引用文献はアブストラクトテーブルで Mattishent 2021 MA［レベル1+］、Crabtree 2022 MA［レベル1+］、Araki 2012 J-EDIT 事後解析［レベル2］、Tancredi 2015 コホート［レベル2］、Ohkuma 2021 ADVANCE サブ解析［レベル2］
- 判定根拠: 高齢者のみ対象の血糖単独介入 RCT なし（確実性:いいえ）、益>害（はい）、価値観一様（はい）、費用対効果不明（いいえ）

### 高血糖とリスク

- 高血糖は網膜症・腎症・大血管症・死亡のリスクファクター
- **75歳以上では関連が弱まる**: スウェーデン研究で75歳未満は HbA1c 上昇とともに全死亡増加、75歳以上は **HbA1c 7.9%以上で初めて心血管死亡 1.15倍**
- 75歳以上でも罹病期間5年未満では HbA1c と死亡・心血管死亡に関連あり

### 介入試験の知見

| 試験・研究 | 結果 |
|---|---|
| 系統的レビュー（Crabtree 2022） | 厳格コントロールで細小血管症・大血管症は減少、**死亡は不変、重症低血糖は増加** |
| ADVANCE | 心血管死亡・全死亡低下、腎転帰改善。ただし**65歳以上では複合イベントに有意差なし**（腎症は抑制、重症低血糖は増加） |
| J-EDIT 強化治療群 | 大血管症は減らず、腎機能悪化を抑制 |
| ACCORD | 65歳以上でも死亡・大血管症・細小血管症は減らず、重症低血糖による死亡リスク上昇 |
| SGLT2阻害薬・GLP-1RA | 高齢者でも心血管・腎イベント抑制が SR やサブ解析で示される |
| 多因子介入（非RCT） | HbA1c 7%前半＋血圧・脂質で合併症減少 |

### Jカーブ

- Diabetes and Aging Study: **HbA1c <6.0% と ≧10.0%** で死亡増加
- 英国80歳以上: **<6% と ≧8%** で死亡増加
- J-EDIT: **<7.2% と ≧8.8%** で脳卒中増加

### 高齢者糖尿病の血糖コントロール目標（HbA1c）

日本糖尿病学会・日本老年医学会合同委員会の目標を本文記述から再構成（図そのものは本章PDFに収載なし。カテゴリーの詳細定義も本章本文には記載なし）。

| | カテゴリーⅠ | カテゴリーⅡ | カテゴリーⅢ |
|---|---|---|---|
| DASC-8 合計点の目安 | **≦10点** | **11〜16点** | **≧17点** |
| 重症低血糖が危惧される薬剤**なし** | **<7.0%**（強化困難なら <8.0%） | **<7.0%**（強化困難なら <8.0%） | **<8.0%**（<8.5% まで緩和可） |
| 重症低血糖が危惧される薬剤**あり**（インスリン・SU薬・グリニド薬など） | **65〜75歳: 6.5〜7.5%未満**／**75歳以上: 7.0〜8.0%未満** | **7.0〜8.0%未満** | **7.5〜8.5%未満** |

> **補足（本章外）**: カテゴリー定義は合同委員会「高齢者糖尿病の血糖コントロール目標（HbA1c値）」（2016）の図による。
> Ⅰ = 認知機能正常 かつ ADL自立／Ⅱ = 軽度認知障害〜軽度認知症 または 手段的ADL低下・基本的ADL自立／Ⅲ = 中等度以上の認知症 または 基本的ADL低下 または 多くの併存疾患や機能障害。
> 原図: https://www.jds.or.jp/modules/important/index.php?content_id=66

- 薬剤なしの場合は**下限を設けない**
- カテゴリーⅢで 8.5%未満への緩和が許容されるのは: 多剤併用による有害作用、重篤な併存疾患、社会的サポートが乏しい場合
- カテゴリーの進行とともに死亡リスク上昇
- 目標設定は カテゴリー＋年齢＋低血糖の危険性＋サポート体制 を考慮

#### 数値の根拠

- **上限 8%（カテゴリーⅡまで）**: HbA1c ≧8.0% で合併症に加え認知機能低下・認知症・転倒・フレイルが増える
- **上限 8.5%（カテゴリーⅢ）**: HbA1c ≧9.0% で感染症、HHS などの急性合併症、死亡リスク上昇
- **下限を置く理由**: ①<6.0% でも死亡減少せず ②<6.0% は転倒・死亡のリスク ③経口薬による重症低血糖は **HbA1c <7.0% で指数関数的に増加**
- **カテゴリーⅢの下限 7.5%**: 重症低血糖を起こしやすく弊害大、余命が短く血糖管理の意義が相対的に小さい。7%未満より 8.0%以上のほうが死亡・ADL低下が少ない報告あり
- **エンドオブライフ**: カテゴリーⅢの目標を参考に、著しい高血糖・脱水・急性合併症の予防を重視。患者・家族の希望に見合った無理のない管理

## Q19-4 高血糖・低血糖は認知機能低下・認知症・ADL低下・うつのリスクファクターか

- 高血糖・重症低血糖は認知機能低下／認知症のリスク
- 高血糖は ADL低下・サルコペニア・転倒・うつ、低血糖は転倒・骨折のリスク
- **血糖を下げて認知症・ADL低下を予防できる明確なエビデンスは少なく、その目的で厳格コントロールは行わない**

### 認知機能

| 知見 | 数値 |
|---|---|
| 70〜79歳、HbA1c ≧7% vs <7% | 9年間の認知機能低下速度が大きい |
| MCI のある65歳以上、HbA1c ≧7% | 認知症移行 1.3倍 |
| 平均血糖 190 vs 160 mg/dL | 認知症 1.4倍 |
| 75歳以上糖尿病 vs 非糖尿病 | MCI→認知症 2.87倍 |
| 低血糖あり vs なし | 認知症 1.5倍 |
| 認知症あり vs なし | 重症低血糖 1.61倍 → **悪循環** |

- 他のリスク: 大きな血糖変動、食後高血糖、インスリン抵抗性、多発性脳血管障害、収縮期高血圧、脂質異常症
- **ACCORD-MIND**（HbA1c <6% vs 7〜7.9%）: 脳容積は大きいが認知機能に差なし
- **Look AHEAD Brain**: 白質病変28%少ないが、脳・海馬体積と認知機能に差なし
- telemedicine で HbA1c <7%（余命短い・重症無自覚性低血糖では <8%）目標の強化療法 → 5年間の認知機能低下が緩徐との報告

### ADL・フレイル・転倒

- HbA1c <7% または <8% を維持した患者は身体能力維持。一方 J-EDIT（6年）では高血糖と BADL/IADL 低下に関連なし
- 施設入所フレイル高齢者: **HbA1c <7% より 8%台のほうが BADL低下・死亡が少ない**
- インスリン抵抗性改善薬使用者では四肢除脂肪量が減りにくい
- HbA1c ≧7% で身体機能低下、**≧8% でフレイル・歩行速度低下**
- フレイルリスク: 平均血糖 <150（HbA1c 6.9%）で 1.41倍、≧180（HbA1c 8.2%）で 1.34倍 → **低値・高値ともリスク**
- 施設入所の高齢糖尿病の転倒リスクは非糖尿病の4倍以上
- HbA1c ≧8.0% で転倒 1.76倍
- インスリン使用者: **HbA1c ≦6% で転倒 3.78倍**（>8% 比較）
- 低血糖イベントあり: 転倒関連骨折 1.7倍、転倒関連イベント約2倍

### うつ

- 糖尿病でうつ新規発症 1.15倍（MA）。双方向の関係
- HbA1c ≧7.0% でうつ発症・再発増、**HbA1c 1%上昇ごとに 1.17倍**
- 低血糖でうつ 1.73倍（年齢とともに増大）

## Q19-5 高齢者糖尿病において食事療法は血糖コントロールに有効か

- 適正なエネルギー量とバランスの食事療法は高齢者でも高血糖・脂質異常症・肥満の是正に有効
- **Look AHEAD**（65〜76歳 vs 45〜64歳）: 体重減少は高齢者でより大きく、身体活動・HDL-C 増加、HbA1c・腹囲減少は中年と同様
- 減量効果は BMI 30以上の65〜74歳で確認、**80歳以上はエビデンスなし**

### 目標体重・エネルギー

- 総死亡最低の BMI は 22〜25（MA）
- JDCS＋J-EDIT、75歳以上の死亡リスク（BMI 22.5〜24.9 基準）: **<18.5 で 8.1倍**、18.5〜22.4 で 1.57倍、≧25 で 0.9倍 → 痩せでリスク高、肥満で上昇なし
- **目標体重: 65歳以上は［身長(m)］²×22〜25**。75歳以上は現体重に基づき、フレイル・ADL・合併症・体組成・身長短縮・摂取状況で判断
- エネルギー係数: 軽い労作 25〜30／普通 30〜35／重い労作 35〜 kcal/kg目標体重
- 75歳以上は外出困難者（低い）と自立者（普通）に大別
- サルコペニア・フレイル・低栄養（リスク）では**やや多めのエネルギーとタンパク**
- 食品交換表が難しければ簡易な指導媒体も可
- 低栄養に注意: スペインの入院患者で低栄養リスク39.1%、低栄養21.2%
- J-EDIT 摂取量: 男 1,802±396 kcal/日（31±6.8 kcal/kg標準体重）、女 1,661±337 kcal（33.7±6.8）。BMI <18.5 では 27.7±7.6 kcal/kg と低値

### 栄養素

- 炭水化物:脂質:タンパク質 = **50〜60 : 20〜30 : 15〜20 (%)**
- 炭水化物エネルギー比 ≧65% で中性脂肪高値
- 全野菜 ≧200 g/日 または緑黄色野菜 ≧70 g/日で HbA1c・TG 低値
- 75歳以上で野菜・魚の多い食事は肉・脂肪の多い食事より死亡が少ない

## CQ19-6 高齢者糖尿病において運動療法は血糖コントロールやADL、認知機能の維持に有効か

> 高齢者糖尿病において、運動療法は血糖コントロールや ADL、認知機能の維持のために推奨される。

- **推奨グレード A**（合意率100%：投票20、賛成20、反対0、欠席1）
- エビデンスレベル: ステートメント自体への記載なし。引用文献はアブストラクトテーブルで Espeland 2013 Look AHEAD［レベル1］、Espeland 2017 RCT［レベル1］、Carmichael 2020 RCT［レベル1］、Lee 2017 MA［レベル1+］、Rodriguez-Mañas 2019 MID-Frail［レベル2］
- 判定根拠: レベル1 RCT あり（はい）、益>害（はい）、価値観一様（はい）、費用対効果不明（いいえ）

### 効果

- 代謝異常是正に加え、生命予後・健康寿命・ADL維持・認知機能低下抑制に有効
- 身体活動量が多いほど心血管疾患、特に脳卒中が少ない。70〜90歳で**週4時間以上**の活動で死亡リスク低下
- **Look AHEAD**: 高齢者でも代謝・身体/認知機能改善、併存疾患数・薬剤数減少（身体機能の低い患者は除外）。8年後まで身体機能維持
- Espeland 2017（70〜89歳、座りがち、2年）: 糖尿病患者で歩行速度と認知機能（全般・言語性記憶）が改善

### 運動の種類

| 種類 | 知見 |
|---|---|
| 有酸素運動 | 体重減少・耐糖能改善。慢性心疾患、肥満、変形性膝関節症で困難ならレジスタンスが選択肢 |
| レジスタンス | HbA1c・収縮期血圧改善、筋量↑脂肪↓、ADL改善（Lee 2017 MA: HbA1c低下・筋力増加） |
| MID-Frail（70歳以上フレイル/プレフレイル、1年） | レジスタンス＋栄養指導で SPPB 改善、費用対効果あり（dropout 多い） |
| GREAT2DO（週3回×12ヵ月） | 骨格筋量増加ほど HbA1c 改善。**低強度では代謝改善につながらず** |
| バランス | 歩行＋レジスタンス＋バランス 週2回×12週で歩行速度・バランス・下肢筋力改善。レジスタンス＋バランス 週3回×6週で転倒リスク低減。バランス週2回×8週でも改善 |

- **1日30分以上**の身体活動で BADL・IADL・バランス改善、4年目以降さらに効果増
- 薬剤管理にとどまらず、日常生活の身体活動を高める持続的関与と地域・環境への配慮が必要

## Q19-7 高齢者糖尿病の血糖降下療法で注意すべき点は

- 低血糖などの有害事象を防ぐため、病態・薬剤特性・相互作用に配慮
- ポリファーマシーはアドヒアランス低下につながり、**処方の単純化**を勧める

### 低血糖症状

- 自律神経症状より**中枢神経症状**（くらくら、ふらふら、めまい、脱力、ぎこちない動作、ろれつ不良、目のかすみ）が出やすい
- 注意力・記録障害、情報処理速度低下。**血糖正常化後も認知機能障害が遷延**することがある
- 精神症状（せん妄・錯乱・意欲低下）や神経症状（片麻痺）は**認知症と間違われやすい** → 患者・介護者教育が不可欠

### 重症低血糖のリスクファクター

長時間作用型SU薬、インスリン、HbA1c 低値、長期罹病、神経障害、肝疾患、冠動脈疾患、脳卒中、**退院直後**、高齢、認知機能低下/認知症、うつ、ADL低下、腎機能低下、食事摂取量低下、感染症、多剤併用、介護施設入所

- 経口薬による低血糖は **HbA1c ≦7% または空腹時血糖 ≦110 mg/dL** で指数関数的に増加
- **インスリン療法では HbA1c ≧8% でも無自覚性・夜間低血糖**が少なくない
- 対策: ブドウ糖携帯、柔軟な目標、SMBG、シックデイ等の減量・中止をあらかじめ指示

### ポリファーマシー

- 他院処方を確認し重複・相互作用をチェック
- 服薬回数、剤形、タイミング、服薬管理者を確認。**残薬大量 → 服薬管理不能のサイン**、家族・社会的サポートと処方単純化

### 薬剤別の注意

| 薬剤 | 注意点 |
|---|---|
| **SU薬** | 腎排泄で蓄積 → 重症低血糖。慎重かつ少量。**グリベンクラミドは使用を控える**。グリメピリド・グリベンクラミドは重症・遷延性低血糖をきたしやすく、グリクラジドは比較的少ない。腎障害で減量、**eGFR <30 で禁忌**。**ニューキノロン、クラリスロマイシン、ST合剤**併用で重症低血糖リスク↑ |
| **メトホルミン** | 低血糖少なく、高齢者・中等度腎機能低下でも死亡・心血管疾患を減少。乳酸アシドーシス頻度は非投与と同等、日本で高齢/非高齢の乳酸濃度に差なし。慎重投与、**体調不良時は中止**。**eGFR <30 禁忌、eGFR 45〜60未満で 500 mg/日以下**。長期でビタミンB12欠乏性貧血 |
| **DPP-4阻害薬** | 低血糖少ないが **SU薬併用で重篤な低血糖**。まれに**水疱性類天疱瘡**（加齢・2型・開始3ヵ月間でリスク↑） |
| **SGLT2阻害薬** | 低血糖少なく**心不全抑制**、心不全併存では使用が勧められる。一方、正常血糖DKA、性器感染症、低栄養・サルコペニアが懸念 → 有効性と副作用のバランス |
| **GLP-1RA／GIP/GLP-1RA** | 低血糖少ないが SU薬・インスリン併用で増加。消化器症状・体重減少に注意。チルゼパチドは著明な血糖低下・体重減少 |
| α-GI | 消化器症状、開腹術後の腸閉塞、内服回数の負担 |
| チアゾリジン | 特に女性で浮腫・心不全・骨折 |
| グリニド | 食後高血糖に適するが低血糖に注意 |
| イメグリミン | ビグアナイド併用で消化器症状。SU・インスリン・グリニド併用で低血糖 → 減量検討 |
| **インスリン** | 経口薬で不十分なら導入。頻回注射困難なら GLP-1RA や経口薬併用で**注射回数を減らし介護負担軽減**。経口薬＋持効型は中間型より低血糖が少ない |

### シックデイ

- 高齢者は発熱・下痢・嘔吐・食欲不振でシックデイに陥りやすく脱水になりやすい
- 水分補給、薬の調整、緊急受診について**患者・介護者にあらかじめ説明**
- **SU薬・メトホルミン・SGLT2阻害薬は食事摂取できなければ中止**

## Q19-8 高齢者糖尿病の高血圧、脂質異常症はどのように管理すべきか

- 高血圧管理は細小血管症と大血管症、脂質管理は大血管症の抑制に有効

### 高血圧

- 高血圧は微量アルブミン尿増加と関連。RENAAL・ADVANCE サブ解析で高齢者でも ARB/ACE阻害薬が腎症進行抑制
- MA: 厳格降圧で脳卒中・MACE 低下、全死亡・心血管死亡・非致死性MI・PAD とは関連なし
- VALUE 高齢者解析: **<140/90 で全イベント抑制、<130/80 ではむしろ上昇**
- 日本の研究では 130/80 前後までの降圧で心血管・脳卒中抑制
- **J-EDIT**: 収縮期 ≧147 mmHg、LDL-C ≧136 mg/dL で大血管症リスク最大。**血圧 127〜136、LDL 99〜116** でリスク低値。75歳以上や冠動脈・両側頸動脈有意狭窄では低すぎるとリスク上昇（Jカーブ）

| 対象 | 降圧目標（高血圧治療GL2019） |
|---|---|
| 75歳未満 | <130/80 mmHg |
| 75歳以上 | <140/90 mmHg（初期管理目標） |

- CKD では収縮期 <110、有意な冠動脈狭窄では拡張期 <70 に注意（過降圧）

### 脂質異常症

- SR で高齢者でもスタチンが心血管イベント抑制。**65〜74歳は RCT で有効性・安全性明らか**、75歳以上の一次予防（閉塞性動脈硬化症なし）はエビデンス不十分
- **EWTOPIA75**（75歳以上高LDL-C、糖尿病25%含む）: **エゼチミブ 10 mg で心血管複合イベント 34%抑制**、有害事象増加なし

| 対象 | LDL-C 管理（動脈硬化性疾患予防GL2022） |
|---|---|
| 75歳未満 一次予防 | <120 mg/dL |
| 75歳未満 二次予防 | <100 mg/dL |
| 75歳以上 二次予防 | エビデンス不十分だがスタチン有効と考えられる |
| 75歳以上 一次予防 | 個別に総合判断 |

## Q19-9 介護施設に入所している高齢者糖尿病はどのように管理するか

- 糖尿病患者は施設入所率 1.5倍。入所者では急性期入院・救急受診 1.39倍、褥瘡 1.56倍、薬剤数も多い
- 血糖 <70 mg/dL の頻度が高く、**SU薬・インスリン使用で HbA1c <7%** では低血糖・救急受診・ADL低下・転倒・死亡が多い
- **HbA1c 8%台が最も ADL低下・死亡が少ない**。75歳以上では HbA1c ≧9% で感染症増加
- 米国: HbA1c ≧8% で ADL中等度障害者は入院増、高度障害（施設入所など）は死亡・入院リスク上昇
- 転倒: 65〜74歳は HbA1c が高いほど、**85歳以上は低いほど**増加。ADL中等度以上障害では **SU薬開始で転倒増加**
- 薬剤選択の結論なし。認知症合併例でインスリンアナログ（超速効型・持効型）は重症低血糖が少なく、SU薬で増加。低単位持効型 vs 経口薬の RCT では血糖・低血糖・救急受診・入院・死亡に差なし
- 本邦に明確な指針なし → 個別に目標設定。**シックデイ・低血糖症状の情報を介護スタッフと共有**し、負担をかけ過ぎない管理

## 外来での使いどころ（自院メモ）

- 65歳以上は **DASC-8 でカテゴリー判定**し、インスリン・SU・グリニド使用の有無と合わせて HbA1c の上限と**下限**を決める（例: 75歳以上カテⅠでSU使用なら 7.0〜8.0%未満）
- SU・インスリン使用中の高齢者で **HbA1c が下限を下回ったら「良好」ではなく減量のサイン**。グリベンクラミドは切り替える
- 高齢者の「ふらつき・ろれつ不良・せん妄・急な物忘れ」は**まず低血糖を疑う**。家族・介護者にも説明
- 75歳以上は痩せのほうが死亡リスクが高い → **過度な食事制限をしない**。体重減少・下腿周囲長（男<34/女<33 cm）で低栄養・サルコペニアを拾う
- 他院処方と残薬を確認し、SU薬とニューキノロン・クラリスロマイシン・ST合剤の併用に注意。服薬回数を減らす方向で単純化
- メトホルミンは eGFR 45〜60未満で 500 mg/日以下、<30 で中止。**SU・メトホルミン・SGLT2阻害薬は食べられない日は休薬**を事前に書面で指示
- 運動は歩行＋レジスタンス＋バランスを勧める（低強度では代謝改善しにくい）
- 75歳以上の降圧目標は <140/90、LDL 一次予防は個別判断（75歳以上へのエゼチミブは EWTOPIA75＝食事療法との比較で有効が根拠）
