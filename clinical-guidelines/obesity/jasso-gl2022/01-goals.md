## 1. 肥満症の概念と診断・治療

### 基本的な考え方

- 日本肥満学会は **2000年** に「肥満症」の概念を提唱。BMI のみで治療対象を決めるのではなく、**健康障害の合併や内臓脂肪蓄積に基づいて抽出**する考え方は国際的にも先駆的
- 2022年版でも**肥満・肥満症の定義は2016年版と同じ**
- BMI の単位（kg/m²）は本文中省略

### 表1-1 肥満の定義、肥満症の定義と診断

| 項目 | 内容 |
|---|---|
| **肥満の定義** | 脂肪組織に脂肪が過剰に蓄積した状態で、BMI（体重[kg]/身長[m]²）**≧25** のもの |
| 肥満度分類の判定 | 表1-3 のとおり。**BMI≧35（≧肥満3度）を高度肥満** とする |
| **肥満症の定義** | 肥満に起因ないし関連する健康障害を合併するか、その合併が予測され、医学的に減量を必要とする疾患 |
| **肥満症の診断** | 肥満（BMI≧25）のうち、①表1-2 の1「肥満症の診断に必要な健康障害」を合併する場合、または ②「内臓脂肪型肥満」と診断される場合（現在健康障害を伴っていなくても）に肥満症と診断 |
| 内臓脂肪型肥満の診断 | ウエスト周囲長のスクリーニングで内臓脂肪蓄積を疑われ、腹部CT等で**内臓脂肪面積 ≧100 cm²** が測定されれば内臓脂肪型肥満と診断 |

### 表1-2 肥満に起因ないし関連する健康障害

**1. 肥満症の診断に必要な健康障害（11疾患）**

1. 耐糖能障害（2型糖尿病・耐糖能異常など）
2. 脂質異常症
3. 高血圧
4. 高尿酸血症・痛風
5. 冠動脈疾患
6. 脳梗塞・一過性脳虚血発作
7. 非アルコール性脂肪性肝疾患
8. 月経異常・女性不妊
9. 閉塞性睡眠時無呼吸症候群・肥満低換気症候群
10. 運動器疾患（変形性関節症: 膝関節・股関節・手指関節、変形性脊椎症）
11. 肥満関連腎臓病

※ 2026-09時点の注記: 7 の NAFLD は、国際的に MASLD（代謝機能障害関連脂肪性肝疾患）へ名称変更され、国内学会も日本語名を公表している。本GLの記載は旧名称のまま。

**2. 肥満症の診断には含めないが、肥満に関連する健康障害**

1. 悪性疾患: 大腸がん・食道がん（腺がん）・子宮体がん・膵臓がん・腎臓がん・乳がん・肝臓がん
2. 胆石症
3. 静脈血栓症・肺塞栓症
4. 気管支喘息
5. 皮膚疾患: 黒色表皮腫や摩擦疹など
6. 男性不妊
7. 胃食道逆流症
8. 精神疾患

- 1群は「減量によりその予防や病態改善が期待できるというエビデンスが一定程度以上蓄積されている」もの

### 表1-3 肥満度分類

| BMI (kg/m²) | 判定 | WHO基準 |
|---|---|---|
| <18.5 | 低体重 | Underweight |
| 18.5≦BMI<25 | 普通体重 | Normal range |
| 25≦BMI<30 | 肥満（1度） | Pre-obese |
| 30≦BMI<35 | 肥満（2度） | Obese class I |
| 35≦BMI<40 | 高度肥満・肥満（3度） | Obese class II |
| 40≦BMI | 高度肥満・肥満（4度） | Obese class III |

### 図1-1 肥満症診断のフローチャート（要点）

1. 肥満（BMI≧25）→ まず**二次性肥満**（内分泌性・遺伝性・視床下部性・薬物による）を鑑別。二次性肥満は原疾患への対応が必要なことが多い（常に念頭に。詳細は第2章 p.14）
2. 原発性肥満を **25≦BMI<35** と **BMI≧35** に分ける
3. 各群で「表1-2 の1の健康障害あり、または内臓脂肪蓄積あり」かを判定

| | 健康障害・内臓脂肪蓄積ともになし | 健康障害あり、または内臓脂肪蓄積あり |
|---|---|---|
| 25≦BMI<35 | **肥満** | **肥満症** |
| BMI≧35 | **高度肥満** | **高度肥満症** |

### 図1-2 肥満症治療指針

| | 肥満症（高度でない） | 高度肥満症 |
|---|---|---|
| 減量目標 | **現体重の3%以上** | **現体重の5〜10%**（合併する健康障害に応じて設定） |
| 肥満症治療食 | **25 kcal/kg × 目標体重/日 以下** | **20〜25 kcal/kg × 目標体重/日 以下** |
| 共通 | 行動療法を併用、運動療法の導入 | 行動療法を併用、運動療法の導入（食事療法による減量を優先し、適切な範囲の運動療法を選択） |
| 評価 | 経時的な体重・ウエスト周囲長の計測、合併する健康障害の評価（**3〜6ヵ月を目安**に治療成果を評価） | 同左 |
| 目標達成 | 目標の再評価・治療の継続 | 同左 |
| 目標未達成 | 肥満症治療食の強化 → **薬物療法の導入（健康障害≧2）** | 肥満症治療食の強化（超低エネルギー食の導入も含む）→ 薬物療法の導入／**外科療法** |

- 目標体重: **BMI 22 × 身長(m)²** を標準体重とし、年齢などを考慮して設定
- 薬物療法は添付文書上の用法、作用機序、有効性、安全性などを総合的に判断して決定
- **BMI<35 でも**、合併する健康障害の種類や程度によっては外科療法が適切な場合がある
- 3% の根拠: 3%以上の減量で複数の健康障害が改善するというわが国のエビデンス
- 目標（3%／5〜10%）を達成しても、健康障害の状態をふまえて目標を再設定し治療を継続
- **減量は治療の目的ではなく手段**。体重・腹囲の変化だけでなく健康障害の改善状況を全経過で評価する
- 注意点: 高齢者のフレイル、やせ妊婦の低体重児出産など、過剰な減量ややせが健康障害につながりうる
- 精神疾患は肥満関連健康障害のひとつ。特に高度肥満症ではメンタルヘルス上の問題をもつ患者が少なくない → 必要に応じメンタルヘルス評価・心理的サポート

※ 2026-09時点の注記: 本GL発行時点で国内の肥満症治療薬はマジンドール（高度肥満症のみ、短期）程度であったが、その後セマグルチド 2.4 mg（ウゴービ、2024-02 発売）、チルゼパチド（ゼップバウンド、2025-04 発売）が肥満症で使用可能になっている。保険適用の要件（BMI・健康障害数・施設要件など）は [最適使用推進GL 2026年改訂版](../mhlw-optimal-use-2026/summary.md) を参照。

## 2. 肥満症治療の目的と、日本肥満学会が目指すもの

### 治療の目的（図1-3）

- 他疾患と同様、**寿命や健康寿命に加え QOL が肥満症によって損なわれるのを防ぐ**こと
- 図1-3 の構造: 肥満 → 肥満症 → 肥満症治療（食事・運動・行動療法を土台に、薬物療法・外科療法で**減量**）→ **健康障害・健康障害リスクの改善** → **肥満・肥満症をもつ個人の QOL の改善**
  - 治療の両脇に「メンタルヘルス評価と心理的サポート」「過剰な減量ややせへの留意」
  - 外周に社会的アプローチ: 肥満・肥満症の正しい知識の普及 → スティグマ・差別・社会的不利益の解消／領域を超えた連携・行政や社会への対応 → 肥満・肥満症の予防

### オベシティスティグマ

- 肥満の発症にはジェネティック/エピジェネティックな要因、生育・発達要因、社会的要因など多様な要因が関与するのに、必要以上に**個人の生活習慣に帰せられる傾向**がある
- 「自己管理能力が低い」という偏見（**社会的スティグマ**）と、肥満を自分の責任と考える**個人的スティグマ**がある。医療者と患者の治療認識の差の原因にもなる
- スティグマは心理的負担・社会的不利益に加え、「自己管理の問題であって医療を受ける対象ではない」という誤解を生み、**適切な治療機会を奪う**
- 生活習慣の変容に大きく依存する治療以外の選択肢が乏しかったことも、スティグマ形成に影響した可能性。外科療法の普及や有効性の高い治療薬の開発はスティグマ解消に役立つ可能性がある
- 科学的知識の普及によるスティグマ解消が QOL 改善につながる

### 社会的・政策的な位置づけ

- 肥満症の治療と予防は、個人の健康増進・QOL だけでなく**医療財政など社会的な面からも推進すべき課題**
- メタボリックシンドローム: 2005年に日本肥満学会が内科学会など **8学会** と共同で診断基準を策定。**2008年開始の特定健診・特定保健指導**に取り入れられ、社会に広く認識された
- 一方、肥満に起因・関連するさまざまな健康障害の病態は十分に認識されておらず、**肥満症の疾患概念の認知度は低い**。幅広い健康障害に目を向けた枠組みが必要
- **神戸宣言2018**: 日本肥満学会が日本医学会連合所属の **23 の関連学会** とともに、疾患領域を超えて肥満症対策に取り組む重要性を発出。社会を含めた多面的協力・連携の重要性を指摘

### コラム: J-ORBIT

- 厚労省の電子的診療情報交換推進事業（SS-MIX2）を活用した**診療録直結型肥満症データベース**（Japan Obesity Research Based on electronic healTh record）
- 肥満症診療テンプレートを電子カルテに組み込み、病歴・症状・身体所見などの「非構造化データ」を構造化データに変換して検査・処方と一緒に蓄積
- 2022年5月時点で神戸大学・東京大学・国立国際医療研究センターの3施設に導入。今後5年程度で20程度の施設・数万人規模を目指す
- 糖尿病の J-DREAMS テンプレートと相互転記機能をもつ

## 補足: 肥満症の診断に必要な健康障害（表1-2 の1）の診断基準

各学会GL（本GL発行時点の版）に基づく判定基準の抜粋。詳細は第9章。

### 1. 耐糖能障害（糖尿病治療ガイド 2022-2023）

| 区分 | 基準 |
|---|---|
| 糖尿病型 | ①空腹時血糖 ≧126 mg/dL ②75gOGTT 2時間値 ≧200 mg/dL ③随時血糖 ≧200 mg/dL ④HbA1c ≧6.5% のいずれか |
| 正常型 | 空腹時血糖 <110 mg/dL かつ 75gOGTT 2時間値 <140 mg/dL |
| 境界型 | 糖尿病型にも正常型にも属さないもの |

- 別の日の検査で糖尿病型が再確認できれば糖尿病（初回・再検査の少なくとも一方で血糖値が基準を満たすことが必要。HbA1c のみの反復は不可）
- 血糖値と HbA1c が同時に糖尿病型なら初回検査のみで診断可
- 血糖値が糖尿病型で、口渇・多飲・多尿・体重減少などの典型症状、または確実な糖尿病網膜症があれば初回で診断可

### 2. 脂質異常症（動脈硬化性疾患予防ガイドライン2022年版）

| 区分 | 基準 |
|---|---|
| 高LDL-C血症 | LDL-C ≧140 mg/dL |
| 低HDL-C血症 | HDL-C <40 mg/dL |
| 高TG血症 | 空腹時 ≧150 mg/dL、随時 ≧175 mg/dL |
| 高non-HDL-C血症 | non-HDL-C ≧170 mg/dL |

### 3. 高血圧（高血圧治療ガイドライン2019）

| 測定法 | 基準（収縮期 かつ/または 拡張期） |
|---|---|
| 診察室血圧 | ≧140 / ≧90 mmHg（少なくとも2回以上の異なる機会） |
| 家庭血圧 | ≧135 / ≧85 mmHg（朝・晩それぞれの平均） |
| 24時間 ABPM | ≧130 / ≧80 mmHg |
| 昼間 | ≧135 / ≧85 mmHg |
| 夜間 | ≧120 / ≧70 mmHg |

- 診察室と家庭で診断が異なる場合は**家庭血圧を優先**

※ 2026-09時点の注記: 高血圧は JSH2025（高血圧管理・治療ガイドライン2025）が発行されている。診断閾値の扱いは同GLで要確認。

### 4. 高尿酸血症・痛風（高尿酸血症・痛風の治療ガイドライン第3版）

- 高尿酸血症: 血清尿酸値 **>7.0 mg/dL**

### 5. 冠動脈疾患

- 心筋梗塞: トロポニン／CK-MB の上昇・低下＋（症状、異常Q波、虚血性 ST 変化、冠動脈造影の形成術、病理所見）のうち1つ以上。陳旧性は新たな異常Q波や病理所見
- 狭心症（慢性虚血性心疾患）: 胸痛発作＋安静時／負荷心電図、Holter、負荷心筋シンチ、負荷心エコー、冠動脈造影または MDCT の所見のいずれか（負荷心電図は水平/下降型 ST 低下 0.1 mV 以上など）

### 6. 脳梗塞・TIA

- 脳梗塞: 局所神経脱落症候が24時間以上持続し、CT/MRI で責任病巣を確認
- TIA: 局所脳・網膜の虚血による一過性の神経機能障害で、急性梗塞の所見がないもの。症状は長くとも24時間以内に消失

### 7. 非アルコール性脂肪性肝疾患（NAFLD）

- 組織診断または画像診断で脂肪肝を認め、アルコール性肝障害など他の肝疾患を除外。飲酒量はエタノール換算で**男性30 g/日、女性20 g/日未満**
- NAFL（非進行性）と NASH（進行性、肝硬変・肝がんの原因）に分類。NASH の最終診断は肝生検
- スクリーニング（NAFLD/NASH 診療ガイドライン2020、NASH・NAFLD の診療ガイド2021）: **FIB-4 index**、**NAFLD fibrosis score** は肝線維化進行例の診断能が高い

### 8. 月経異常・女性不妊

- 原発性無月経: 満18歳で初経なし／続発性無月経: 月経が3ヵ月以上停止／月経不順: 周期が標準を逸脱。肥満者では排卵障害による無月経が多い

### 9. 閉塞性睡眠時無呼吸症候群・肥満低換気症候群

- OSA: 睡眠1時間あたりの無呼吸・低呼吸・RERAs の総数 ≧5（AHI≧5）
- OSAS: OSA に臨床症状や合併症があり PSG／PM で1時間あたり5回以上の主として閉塞性呼吸イベント、または症状にかかわらず15回以上
- 重症度: 軽症 5≦AHI<15、中等症 15≦AHI<30、重症 AHI≧30
- 肥満低換気症候群: **BMI≧30** で覚醒時 **PaCO₂ >45 Torr**、睡眠呼吸障害があり、PaCO₂ 上昇をきたす他疾患がない

### 10. 運動器疾患

- 変形性関節症（膝・股関節など）: 自覚症状（関節の不快感・重圧感、労作時の荷重関節の疼痛）、他覚所見（腫脹・熱感・水腫・可動域制限）、X線所見（関節裂隙狭小化、軟骨下骨硬化、骨棘形成）
- 変形性脊椎症: 腰痛・下肢しびれ（脊柱管狭窄）、X線で椎体骨棘・圧迫変形・椎体狭小化

### 11. 肥満関連腎臓病（海外文献を参考）

- 高度肥満症（BMI≧35）で多い
- 血尿なし〜軽度で、非ネフローゼ域の蛋白尿が多い
- ネフローゼ域の蛋白尿でも血清アルブミンは **3.0 g/dL 以上**に保たれていることがある
- **減量で蛋白尿が改善**する
- 病理: 糸球体肥大（≧250 µm）、巣状分節性糸球体硬化。糖尿病・高血圧合併例ではそれぞれの所見も

## 本GLの推奨グレード・エビデンスレベル

出典: 本GL「肥満症診療ガイドライン2022の作成方法」「エビデンスレベルと推奨グレードについて」（p.vii、gl_03.pdf）

- 作成主体: 日本肥満学会（理事会・ガイドライン作成委員会中心）。委員長の下17名の委員。2019年9月から統括委員会で方針検討
- 章ごとに正・副責任者、各項目は原則2名の査読。2022年8月作成委員会で整合性確認 → 同9月パブリックコメント → 同10月ガイドライン検討拡大学術委員会で最終決定
- 大規模研究・RCT のエビデンス、特に国内のものが十分でないため、**エビデンスレベルは細分せず3段階**とした
- 肥満症・高度肥満症の診療では**推奨グレードAまたはB**の採用を求めている

### エビデンスのレベル

| レベル | 定義 |
|---|---|
| **Level I** | 無作為化比較試験や大規模疫学調査、メタアナリシスに基づくデータがある |
| **Level II** | 小規模の無作為化比較試験や非無作為化研究がある |
| **Level III** | 専門家の合意（コンセンサス）、あるいは標準的治療 |

- III は支持する研究が少ないが、必ずしも I・II に劣るわけではなく、今後実証されれば I・II に引き上げられる可能性がある

### 推奨グレード

| グレード | 定義 |
|---|---|
| **Grade A** | 行うよう強く勧められる（その治療に対してエビデンス、もしくは一般的合意がある） |
| **Grade B** | 行うよう勧められる（その治療に対して種々の意見があるが、どちらかというと有用性がある） |
| **Grade C** | 科学的根拠に乏しい、もしくは一般的合意がないので勧められない |
| **Grade D** | 行うべきではない |

- Grade A は通常エビデンスレベルの高いものが多いが、長い臨床経験から得られた一般的合意もこのグレードに含まれることがある
- 本まとめでは、ステートメントのグレード・レベルを原文どおり【Grade A】【Level I】の形で記す
- 糖尿病GL（JDS 2024）と異なり、合意率の記載はない

## 外来での使いどころ（自院メモ）

- **BMI≧25 を見たら「肥満」で止めず、11疾患チェック**: 当院の生活習慣病外来の患者（糖尿病・脂質異常症・高血圧・高尿酸血症）は、BMI≧25 であればほぼ自動的に「肥満症」に該当する。病名は「肥満症」をつけ、減量を治療目標として明示する
- 11疾患のうち当院で拾いやすいもの: 耐糖能障害、脂質異常症、高血圧、高尿酸血症、脂肪肝（腹部エコー／FIB-4）、OSAS（いびき・日中の眠気を問診）、変形性膝関節症（問診）。月経異常・肥満関連腎臓病（蛋白尿）も問診・検尿で忘れずに
- **健康障害の数を数えてカルテに残す**: 図1-2 の薬物療法導入条件（健康障害≧2）や、GLP-1系肥満症治療薬の適用要件の判断に直結するため
- **減量目標は「まず3%」**: 体重80 kg なら 2.4 kg。3〜6ヵ月ごとに体重・腹囲・検査値で評価する。達成しても健康障害が残れば目標を再設定する
- 食事指示の目安: 肥満症は 25 kcal × 目標体重（例: 身長165 cm → 目標体重 約60 kg → 1,500 kcal/日以下）、高度肥満症は 20〜25 kcal × 目標体重
- 二次性肥満の除外を最初に1回やる: TSH・FT4、服薬歴（向精神薬・ステロイド・インスリン・SU薬・チアゾリジン）、クッシング徴候（中心性肥満・満月様顔貌・皮膚線条・高血圧・低K）、若年発症・急速な体重増加
- スティグマへの配慮: 「自己管理ができていない」という言い方を避け、「肥満症は治療対象の病気」と説明する。高度肥満症・精神疾患合併例ではメンタル面の評価と紹介先を意識する
- GLP-1/GIP-GLP-1 による肥満症治療は、最適使用推進ガイドラインの施設要件（学会の教育研修施設・常勤管理栄養士など）を当院は満たさない → 適応がある患者は要件を満たす施設へ紹介する（[最適使用推進GL 2026年改訂版](../mhlw-optimal-use-2026/summary.md)、自院判断）
- 高齢者（特に75歳以上）ではフレイル・サルコペニアを悪化させないよう、減量よりも筋量維持・たんぱく質摂取を優先する場面がある（第8章参照）
