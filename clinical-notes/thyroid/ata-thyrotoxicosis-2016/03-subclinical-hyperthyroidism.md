## 外来での使いどころ（自院メモ）

### 国内資料との違い・補える点

| 論点 | ATA 2016 | 国内資料 |
|---|---|---|
| TSH <0.1 の治療適応 | 推奨73（強・中）: 65歳以上、心血管リスク・心疾患・骨粗鬆症、**エストロゲン/ビスホスホネートなしの閉経後女性**、症状 | [GL2019 BCQ25](https://github.com/keiyousya/clinical-guidelines/blob/main/thyroid/jts-graves-tx-gl2019/summary.md): 65歳以上、または65歳未満で心血管リスク・心疾患・骨粗鬆症・症状 → **ほぼ同じ**。ATA は閉経後女性を明記 |
| TSH <0.1・65歳未満・無症状 | **治療を考慮**（推奨74、弱・中） | 記載なし |
| **TSH 0.1〜基準下限** | **65歳以上・心疾患・骨粗鬆症・症状なら治療を考慮（推奨75）**、若年無症状は経過観察（推奨76） | 記載なし（[GL2019 まとめ](https://github.com/keiyousya/clinical-guidelines/blob/main/thyroid/jts-graves-tx-gl2019/summary.md)の自院メモで「経過観察が基本」） |
| 再検 | 高リスクは **2〜6週**、他は **3〜6ヵ月**で持続を確認。若年の 0.1〜下限は **6〜12ヵ月ごと** | 記載なし |
| 基準下限 | 表10は **0.4 mU/L** を下限として例示 | 国内のハーモナイズ後の基準範囲は **0.61〜4.23 mIU/L**（README）→ **当院では「0.1〜0.61」を ATA の「0.1〜下限」の帯として読む** |

### 当院での進め方

1. **FT4・FT3 正常で TSH だけ低い**ときは、まず除外: **LT4 服用（過量なら減量）**、最近の急性疾患、TSH を下げうる薬、下垂体疾患の手がかり、**ビオチン**（[01](https://github.com/keiyousya/clinical-guidelines/blob/main/thyroid/ata-thyrotoxicosis-2016/01-etiology-initial-evaluation.md)）
2. **再検の時期**: 心疾患・心房細動・高齢でフレイル → **2〜6週**で TSH＋FT4。それ以外 → **3ヵ月後**（ATA は3〜6ヵ月）。一過性の甲状腺炎ならこの間に戻る
3. **持続していたら原因を調べる**: TRAb、エコー（結節の有無・血流）。結節があり高齢なら TMNG・機能性腺腫を考え、**シンチ目的で専門医へ**（治療の中心は RAI で、院内ではできない）
4. **治療適応の判断**（上の表）: 
   - TSH <0.1 持続 ＋（65歳以上 / 心疾患・心血管リスク / 骨粗鬆症 / 閉経後で骨の薬なし / 症状） → **治療する**。バセドウ病なら MMI（[04](https://github.com/keiyousya/clinical-guidelines/blob/main/thyroid/ata-thyrotoxicosis-2016/04-graves-treatment.md)）、結節性なら紹介
   - TSH 0.1〜0.61 持続 ＋ 65歳以上・心疾患・骨粗鬆症・症状 → 治療を**相談**（弱い推奨）。まず原因検索と心電図・骨密度
   - 65歳未満・無症状・TSH 0.1〜0.61 → **6〜12ヵ月ごとに TSH**。<0.1 になったら再評価
5. 治療しない高齢者でも、**心電図で心房細動を確認**し、骨粗鬆症の評価をしておく。動悸・頻脈があれば β遮断薬で様子を見る選択肢もある
6. 若年のバセドウ病による潜在性は自然寛解がある → **3〜6ヵ月ごとに検査して経過観察**も可。本人の希望で MMI も可
7. 欧州の ETA 2015 潜在性甲状腺機能亢進症GL（README の一覧、未作成）も ATA と概ね一致すると ATA 本文に書かれている
