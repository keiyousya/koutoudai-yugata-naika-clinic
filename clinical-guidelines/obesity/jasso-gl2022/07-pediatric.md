## 前提・定義

- 「小児肥満症」の語は、2000年の日本肥満学会「新しい肥満の判定と肥満症の診断基準」を受け、2002年「小児肥満症判定基準」で初出。2014年 第35回日本肥満学会「小児肥満症 UPDATE」でコンセンサス → **小児GL2017** 作成
- 本章の「小児」は**就学してから18歳未満**と定義（修学前の幼児で健康障害を有する者は少なく予防が中心、わが国では肥満度による体格評価が 17歳11ヵ月まで行われるため）

## 1 小児肥満の判定法

### 肥満度

- 日本の小児は BMI ではなく**肥満度**で判定（学校保健安全法に基づく）
  - **肥満度(%) = (実測体重 − 標準体重) / 標準体重 × 100**
- 標準体重: 6歳以上18歳未満は性別・年齢別の身長の一次式、身長70 cm以上120 cm未満の幼児は性別の身長の二次式。**2000年データに基づく標準体重**を用いる（2000年以降、身長・成熟の長期的傾向に変化がないため）
- 諸外国は BMI の Zスコア／パーセンタイルだが、日本の学校保健・日常臨床ではほとんど使われず学術利用に限られる

|---|---|---|---|
| +30% ≦ 肥満度 | ふとりすぎ | +50% ≦ 肥満度 | 高度肥満 |
| +20% ≦ 〜 < +30% | ややふとりすぎ | +30% ≦ 〜 < +50% | 中等度肥満 |
| +15% ≦ 〜 < +20% | ふとりぎみ | +20% ≦ 〜 < +30% | 軽度肥満 |
| −15% < 〜 < +15% | ふつう | −20% < 〜 < +20% | 普通 |
| −20% < 〜 ≦ −15% | やせ | −30% < 〜 ≦ −20% | 軽度やせ |

- 要するに **幼児は ±15%、児童生徒は ±20%** が「肥満」「やせ」の境界

### 内臓脂肪面積・ウエスト周囲長・ウエスト身長比

| 指標 | 成人 | 小児 |
|---|---|---|
| 臍高CTの内臓脂肪面積（内臓脂肪型肥満） | ≧100 cm² | **≧60 cm²** |
| ウエスト周囲長（臍の高さ） | — | **≧80 cm** で腹部肥満 |
| ウエスト身長比（腹囲cm/身長cm） | — | **≧0.5** で腹部肥満 |

### 身長体重の成長曲線

- 小児は成長過程にあるのが最大の特徴 → **身長・体重の成長曲線を描いてパターン認識**することが極めて重要
- 成長曲線・肥満度曲線を描くソフトウェアで成長パターン分類も自動化。**原発性肥満と二次性肥満の鑑別**、治療効果判定にも応用可
- 食事摂取基準2020年版でも、幼児・小児のエネルギー摂取量の過不足評価に成長曲線が推奨

## 2 小児肥満症・小児期メタボリックシンドロームの診断

### 小児肥満症の定義（小児GL2017）

- 「肥満に起因ないし関連する健康障害（医学的異常）を合併するか、その合併が予測される場合で、**医学的に肥満を軽減する必要がある状態**をいい、疾患単位として取り扱う」
- 成人の「医学的に**減量**を必要とする」→ 小児では「肥満を**軽減**する」に変更。成長期は生理的な体重増加が必要で、**身長が伸びれば体重は現状維持でも肥満度が下がる**ため
- 適用年齢は **6歳以上18歳未満**。幼児期は肥満予防上重要だが判定基準が異なり健康障害の合併も稀 → 「幼児肥満ガイド」を参考にする

### 表7-2 小児肥満症診断基準 2017年版（要点）

| 項目 | 内容 |
|---|---|
| 肥満小児の定義 | 肥満度 **+20%以上**、かつ体脂肪率が有意に増加した状態。有意な増加 = **男児: 年齢を問わず25%以上／女児: 11歳未満 30%以上、11歳以上 35%以上** |
| 適用年齢 | 6歳から18歳未満 |
| 肥満症診断 | (1) **A項目を1つ以上** (2) 肥満度 **+50%以上**で**B項目1つ以上** (3) 肥満度 **+50%未満**で**B項目2つ以上**（参考項目は**2つ以上でB項目1つと同等**） |

#### 肥満に伴う健康障害と具体的な閾値（図7-1より）

**A項目（肥満治療を必要とする医学的異常）**

| 項目 | 閾値 |
|---|---|
| 1) 高血圧 | 小1〜3年: SBP ≧130 かつ/または DBP ≧80 mmHg／小4〜6年・中学女子: SBP ≧135 かつ/または DBP ≧80／中学男子・高校生: SBP ≧140 かつ/または DBP ≧85 |
| 2) 睡眠時無呼吸など換気障害 | 睡眠中にいびきや閉塞性呼吸障害を伴う**5秒以上の呼吸停止が1時間に1回以上** |
| 3) 2型糖尿病・耐糖能障害 | ①空腹時血糖 ≧126 ②随時血糖 ≧200 ③75gOGTT で境界型か糖尿病型 ④HbA1c ≧6.5%。**①②に④がある場合、または③がある場合** |
| 4) 内臓脂肪型肥満（腹囲でもCTでも判定可） | 腹囲 **小学生 ≧75 cm、中高生 ≧80 cm** かつ/または ウエスト身長比 ≧0.5／臍高CTで内臓脂肪面積 ≧60 cm² |
| 5) 早期動脈硬化（測定法を問わず基準値超） | baPWV ≧1,200 cm/秒、%FMD ≦8.0、総頸動脈 stiffness β ≧5.0、平均IMT ≧0.55 mm |

**B項目（肥満と関連が深い代謝異常）**

| 項目 | 閾値 |
|---|---|
| 1) 非アルコール性脂肪性肝疾患（NAFLD） | ALT > AST、ALT が 25 IU/L で画像診断推奨（原文の表記どおり。「以上」の明記はない）。画像で脂肪肝所見あり |
| 2) 高インスリン血症 かつ/または 黒色表皮症 | 空腹時インスリン ≧15 μU/mL。黒色表皮症は頸部で判定 |
| 3) 高コレステロール血症 かつ/または 高non-HDL-C血症 | 随時採血で TC ≧220 かつ/または non-HDL-C ≧150 mg/dL |
| 4) 高TG血症 かつ/または 低HDL-C血症 | 空腹時採血で TG ≧120 かつ/または HDL-C <40 mg/dL |
| 5) 高尿酸血症 | 小学生・中学女子: 尿酸 ≧6.0／中学男子・高校生: ≧7.0 mg/dL |

**参考項目（身体的因子・生活面の問題。2つ以上でB項目1つと同等）**

1. 皮膚線条などの皮膚所見
2. 肥満に起因する運動器機能障害（運動器検診で運動器機能障害と診断、肥満に伴う骨折や関節障害の既往、運動器の問題で体育の授業に参加できない、のいずれか）
3. 月経異常（続発性無月経が1年6ヵ月以上持続）
4. 肥満に起因する不登校、いじめなど
5. 低出生体重児または高出生体重児（出生時体重 2,500 g未満 または 4,000 g以上）

- 腹囲・血圧・NAFLD・高non-HDL-C・高TG・高尿酸などの閾値は**成人の基準値と異なる**点に注意

### 表7-3 成人と小児の肥満症診断に必要な健康障害の違い

- 成人の11疾患のうち**冠動脈疾患・脳梗塞・肥満関連腎臓病は小児の基準に含まれない**
- 小児では**早期動脈硬化**、**肥満に起因する不登校・いじめ**、胎児期の栄養状態を反映する**低出生体重児/高出生体重児**が加わる

### 小児期メタボリックシンドロームの診断

- 2007年、厚労科研（循環器疾患等生活習慣病対策総合研究事業）で小児期MetS診断基準が作成。小児期からの過剰な内臓脂肪蓄積が早期動脈硬化を生じさせる報告 → 心血管イベント予防上重要
- 成人同様、**(1) 腹部肥満を必須**とし、(2)〜(4) のうち**2つ以上**で MetS

| 項目 | 小児の閾値 |
|---|---|
| (1) 腹部肥満（必須） | ウエスト周囲長 **≧80 cm**（ウエスト身長比 ≧0.5、または**小学生では腹囲 ≧75 cm**でも「あり」） |
| (2) 血清脂質異常 | TG **≧120** mg/dL かつ/または HDL-C **<40** mg/dL |
| (3) 血圧高値 | SBP **≧125** mmHg かつ/または DBP **≧70** mmHg |
| (4) 空腹時高血糖 | 空腹時血糖 **≧100** mg/dL |

## 3 小児肥満症の治療

### 原則

- 原発性肥満では小児肥満症と小児期MetSが治療対象。**二次性肥満は原因疾患の治療を優先**
- 治療原則: **正常な発育を妨げず**、肥満に起因した健康障害の程度や数を改善する
- 食事療法・運動療法・行動療法・その他。単独で行うことは稀で、**食事運動療法に認知行動療法を併用**することが多い

### 食事療法

- 成長期のため**強いエネルギー制限は行わない**
- 食事摂取基準2020年版の性別・年齢別・身体活動レベル別の推定エネルギー必要量を参考に、**推定エネルギー必要量の約90%**を指示
- エネルギー比率: **蛋白質 約20%、脂肪 25〜30%、糖質 50〜55%**
- 過不足は身長・体重の成長曲線パターンで判断。身長が伸びる年齢では**体重は現状維持、身長は成長曲線の基準線に沿って伸びる**パターンを目指す
- **極端な糖質制限はむしろ有害**
- 夜間喫食・早食いは肥満を生じやすい → 1日3食ほぼ定刻、食事に集中してよく噛んでゆっくり、家族揃って楽しく食べる指導

### 運動療法

- 長いスクリーンタイム（TV・ゲーム・PC・タブレット・スマホ）や運動不足は肥満の原因の一つで、正常な成長発達に不利益
- 計画された運動療法は肥満・糖代謝異常・脂質代謝異常の改善、アディポサイトカインバランスの適正化をもたらす
- 実際: まず**スクリーンタイムを1日2時間以内に制限**し、アクティブチャイルドプログラム（日本体育協会〔現 日本スポーツ協会〕）などを参考に**毎日60分以上体を動かす**ことから開始
- 肥満小児は下肢の怪我や熱中症を生じやすい → 事前にメディカルチェック、予防に努める

### 行動療法

- 継続通院が大切。**食事運動療法単独より認知行動療法を併用した方が治療成績がよい**
- 目標設定 → セルフモニタリング（毎日の体重測定と記録、生活自己管理チェックリスト）
- 生活習慣チェックリストのオリジナル7項目: 朝食を食べる／給食でおかわりしない／夜食を食べない／ジュースを飲まない／おやつの量を守る／スクリーンタイムの制限／家での手伝い。早寝早起きなど生活リズムや運動習慣の項目を加える場合も
- 体重はグラフ化、チェックリストは点数化して本人・保護者に見える化し、改善の兆しがあれば**タイミングよく褒める**

### その他の治療（薬物・外科）

- 日本で肥満に用いられる薬剤: マジンドール（サノレックス®）、防風通聖散
  - **サノレックスは BMI ≧35 の高度肥満成人に3ヵ月を限度**に処方される場合があるが、**小児適用はない**
  - 防風通聖散は薬効機序は証明されているが小児への使用例は稀
- 海外: 12〜18歳の肥満小児を対象としたリラグルチドの RCT（NN8022-4180）を基に、**2020年 FDA が12歳以上の肥満小児にリラグルチドを承認**
- 外科療法: 米国の小児肥満症GLでは、思春期（Tanner 4〜5）以降、BMI ≧35 で著明な肥満合併症を有し通常の内科治療で改善がないケースに考慮。**日本では肥満小児への外科療法は現時点で行われていない**

> ※ 2026-09時点の注記: 本GL発刊後、海外ではセマグルチド 2.4 mg の思春期（12歳以上）への適応拡大などがあった。国内でもウゴービ（2023-11 薬価収載）・ゼップバウンド（2025-03 薬価収載）が使用可能になったが、小児（18歳未満）への国内適応の有無は最新の添付文書・最適使用推進ガイドラインで確認すること（本ファイルでは断定しない）。[../jasso-drug-statement-2025/summary.md](../jasso-drug-statement-2025/summary.md) も参照。

## 4 小児肥満症診療ガイドラインの活用

- 学校保健安全法で児童・生徒の健康診断（身長・体重・肥満度による体格評価）が義務付け
- 1987年「小児成人病予防健診」開始 → 2002年の小児肥満症判定基準を反映し「**小児生活習慣病予防健診**」として各地で実施
- 小児GL2017 策定により、ウエスト周囲長・HbA1c・ALT などを含めた包括的な健診内容に変化
- 学校保健・行政の健康支援・医療機関の小児肥満症/MetS 診療の**共通プラットフォーム**としての活用が望まれる

## 外来での使いどころ（自院メモ）

- 当院は成人内科中心だが、**高校生（〜18歳未満）の受診**や保護者（肥満症・糖尿病で通院中の親）からの相談で本章が必要になる。小児の肥満判定は **BMI ではなく肥満度（+20%以上）**、腹囲は **80 cm（小学生75 cm）・ウエスト身長比0.5**、血圧・脂質・尿酸の閾値も成人と違う点を押さえる
- 学校健診の「肥満度」結果を持参された場合は表7-1で程度を確認し、A項目（高血圧・睡眠時無呼吸・耐糖能障害・内臓脂肪型肥満）があれば小児肥満症として、原則は**小児科（小児内分泌）へ紹介**する方針
- 小児の食事指導は「減量」ではなく**体重維持で身長の伸びを待つ**（肥満度を下げる）発想。推定エネルギー必要量の約90%、極端な糖質制限は勧めない
- 家族単位の介入が効く: 親の肥満症・糖尿病診療の中で「子どものスクリーンタイム2時間以内・毎日60分の運動・朝食・夜食なし・ジュースなし」を家庭の共通ルールとして話題にできる
- **GLP-1 受容体作動薬（ウゴービ・ゼップバウンド・リベルサス等）やサノレックスを18歳未満に自院で処方しない**。自費の「メディカルダイエット」目的の未成年の相談も受けない（適応外かつ成長への影響が不明）
- 若年発症の高度肥満・低身長を伴う肥満は、成長曲線を確認し**二次性肥満（内分泌・遺伝性など）**を疑って専門施設へ
