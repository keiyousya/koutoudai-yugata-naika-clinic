# 第20章 糖尿病における急性代謝失調・シックデイ（感染症を含む）

- **出典**: 日本糖尿病学会『糖尿病診療ガイドライン2024』20章（p.447–465）
- **原文**: https://www.jds.or.jp/uploads/files/publications/gl2024/20.pdf
- **発行**: 2024-05-30
- **確認日**: 2026-09-13

構成は「DKA → HHS → 乳酸アシドーシス → 低血糖 → 感染症（特徴・血糖管理・予防接種）→ シックデイ」。本章は全て Q（CQ なし）。外来で頻用するのは Q20-4（低血糖）、Q20-7（ワクチン）、Q20-8（シックデイ）。

## Q20-1 糖尿病性ケトアシドーシス（DKA）の診断と治療

### 病態・誘因

- インスリン欠乏＋拮抗ホルモン増加
- 1型（劇症1型含む）の初発症状。1型での感染症・心血管病併発、**摂食不良時のインスリン減量・中止（マネジメントエラー）**、大量飲酒
- 薬剤: ステロイド、サイアザイド、ペンタミジン、向精神薬（オランザピン、アリピプラゾール、リスペリドン、クエチアピン、クロザピンなど）、免疫チェックポイント阻害薬
- 2型でも**ソフトドリンクケトーシス**。DKA の約20〜30%が2型との報告

### 診断

- 臨床: **1〜2日の経過**で口渇・多飲・多尿・倦怠感 → 脱水、意識障害、体重減少。腹痛・悪心（**急性腹症と誤診**されうる）、Kussmaul 呼吸、アセトン臭、口腔粘膜乾燥、低血圧、頻脈

| 項目 | 基準 |
|---|---|
| 血糖 | **>250 mg/dL** |
| ケトーシス | β-ヒドロキシ酪酸増加 |
| 動脈血 pH | **≦7.30** |
| HCO₃⁻ | **≦18 mEq/L** |

- β-ヒドロキシ酪酸 **成人 ≧3,800 μmol/L、小児 ≧3,000 μmol/L** が HCO₃⁻ <18 に相当
- 妊婦は発症頻度が高く、低い血糖値で DKA になりやすい
- **正常血糖DKA**: 血糖 ≦250（または200）mg/dL の DKA。**SGLT2阻害薬服用中・妊娠中**、飢餓、低炭水化物食、敗血症、慢性飲酒、肝疾患が背景

### 治療

- 推定欠乏量: **水分 体重の10%、Na 7〜10 mEq/kg、K 3〜5 mEq/kg**
- モニター: **血糖 1時間ごと、電解質 2時間ごと**

| 項目 | 内容 |
|---|---|
| 輸液 | 生理食塩水 **500〜1,000 mL/hr（15〜20 mL/kg/hr）で開始** → 循環動態に応じ 250〜500 mL/hr |
| 血糖 250〜300 到達 | ブドウ糖含有低張電解質輸液へ（脳浮腫予防） |
| 血糖目標 | 浸透圧正常化・意識改善まで **250〜300 mg/dL** 維持、その後 150〜200 mg/dL |
| インスリン | 速効型を生食に混注し**少量持続静注**。**成人 0.1 単位/kg/hr**、小児 0.05〜0.1 単位/kg/hr。血糖低下 **50〜75 mg/dL/hr** を期待し調節 |
| ボーラス | 成人で効果は証明されず。**小児は脳浮腫リスクのため行わず、輸液開始後少なくとも1時間後**にインスリン持続開始 |
| 正常血糖DKA | インスリン **0.05（0.02〜0.1）単位/kg/hr** ＋5%ブドウ糖液持続。低血糖なら10%へ |
| カリウム | 治療で低下するため **4.0〜5.0 mEq/L** に維持。**K <3.3 ならインスリン開始・増量せず**、20〜30 mEq/hr で ≧3.3 まで補充してから |
| 重炭酸・リン | 投与・補充が予後や病態を改善する報告なし（アシドーシス補正は原則行わない） |

- 十分量のインスリンとブドウ糖で β-ヒドロキシ酪酸の正常化が早まる報告

## Q20-2 高浸透圧高血糖状態（HHS）の診断と治療

### 病態・診断

- 著明な高血糖＋浸透圧利尿による高度脱水（DKA より高度）。インスリンは**相対的欠乏**のためケトーシスは軽度
- **死亡率 16.0%**
- インスリン分泌が保たれた2型に、急性感染症、脳血管障害、心血管障害、手術、高カロリー輸液、利尿薬・ステロイドなどが加わって発症。**高齢者は渇中枢機能低下**で悪化しやすい
- 症状: 多飲・多尿・体重減少・倦怠感、意識障害、**中枢神経症状（片麻痺、一側性腱反射亢進、病的反射）**、低血圧・頻脈・皮膚粘膜乾燥

### DKA と HHS の比較

| 項目 | DKA | HHS |
|---|---|---|
| 血糖 | >250 mg/dL（正常血糖DKAあり） | **>600 mg/dL** |
| 有効浸透圧 | — | **>320 mOsm/kg** |
| 動脈血 pH | ≦7.30 | >7.30 |
| HCO₃⁻ | ≦18 mEq/L | >18 mEq/L |
| ケトーシス | β-ヒドロキシ酪酸増加 | あっても軽度 |
| 典型的背景 | 1型、SGLT2阻害薬、清涼飲料 | 2型高齢者、感染症・脳心血管障害・医療行為 |
| 経過 | 1〜2日で急激 | — |

- **有効浸透圧 = 2×血清Na(mEq/L) ＋ 血糖(mg/dL)/18**

### 治療

- 基本: 脱水補正・電解質補充・インスリン・**誘因除去**。血糖1時間ごと、電解質2時間ごと
- 輸液: 心不全リスクがなければ生食 **500〜1,000 mL/hr（15〜20 mL/kg/hr）** で開始 → 循環安定まで調整
  - 補正Na **≦135**: 生食 250〜500 mL/hr 継続
  - 補正Na 135〜145 または **≧146**: 低張電解質輸液
- K 対応は DKA に準ずる
- **脱水補正のみで 75〜100 mg/dL/hr の血糖低下**が見込まれる。十分補正しても **<50 mg/dL/hr** ならインスリン少量持続静注開始
- インスリン: **成人 0.1 単位/kg/hr**、小児 0.025〜0.05（DKA合併時 0.05〜0.1）。**50〜100 mg/dL/hr** の低下を目安に調整
- **血糖 300 mg/dL** でブドウ糖含有低張電解質輸液に変更し、250〜300 に維持（浸透圧・意識改善まで）→ その後 **200〜300 mg/dL**
- 合併症: 肺炎、消化管出血、腎不全、脳血管障害、心筋梗塞、肺動脈血栓症、低K血症など。**大量輸液による肺水腫**に注意

## Q20-3 乳酸アシドーシスの診断と治療

- 定義: **血中乳酸 ≧5.0 mmol/L（45 mg/dL）かつ血液 pH <7.35**。HCO₃⁻ 低下、AG 上昇、乳酸/ピルビン酸比上昇も参考
- 死亡率は従来約50% → 最近約25%
- 症状: 過呼吸、消化器症状、意識障害、しばしばショック

### メトホルミンとの関係

| 集団 | 発症率（10万人・年あたり） |
|---|---|
| メトホルミン使用（海外） | 3〜10 |
| メトホルミン使用（日本人2型） | 4.3〜6.0 |
| メトホルミン非使用2型 | 4.8〜9.9 |

- 両者に差はないとされる（ただし低頻度で有意差が出にくい可能性）。糖尿病では非糖尿病より頻度が高い
- eGFR ≧30 では血中メトホルミン濃度は治療域内、乳酸濃度に影響しない
- ビグアナイド関連例の**大半は禁忌・慎重投与例**で、肝腎障害、心血管・呼吸障害、感染症、外傷、悪性腫瘍などを併発
- 20万人規模研究: **eGFR <60、>2 g/日**でリスク上昇。日本人で CKD 合併は約7倍
- **日本の153例分析**: 約30%が75歳以上、平均投与量約1,000 mg/日だが **500 mg/日以下の低用量が約30%**。発症前 eGFR 判明例の50%が <45、72%が <60、**大半に急性腎機能悪化・脱水**
- 乳酸濃度・メトホルミン濃度の増加は死亡率増加と関連

### ビグアナイド薬適正使用 Recommendation（要約）

1. 経口摂取困難・寝たきりなど全身状態が悪い患者には投与しない（大前提）
2. **eGFR <30 禁忌**、30〜45 はリスク・ベネフィットを勘案し慎重投与
3. 脱水、脱水が懸念される下痢・嘔吐などの胃腸障害、過度のアルコール摂取で禁忌。**シックデイは服薬中止**
4. 高度の心血管・呼吸機能障害、外科手術前後は禁忌。軽度〜中等度肝障害は慎重投与
5. 高齢者は慎重投与、**75歳以上はより慎重に**

### 治療

- ショック改善、組織循環・酸素供給確保（酸素、人工呼吸、細胞外液、昇圧薬）、基礎疾患治療
- HCO₃⁻ 静注を支持するエビデンスなし
- ビグアナイド関連例では**血液透析が有効**との報告

## Q20-4 低血糖にはどう対応するか

- **症状がある、または血糖 <70 mg/dL** で低血糖と診断し対応（≧70 でも症状があれば適宜対応）
- 重症低血糖 = **回復に他者の援助を要する**低血糖

### 疫学・予防

- 厳格コントロール群で重症低血糖増加（海外試験）
- 日本の救急搬送例の特徴: **70歳以上、CKD ステージ3〜5、SU薬内服**
- JDS 調査委員会: 重症低血糖は年間救急搬送の **0.34%**。1型約30%、2型約60%。2型の治療薬はインスリン約60%、SU薬約30%
- 予防: 体系だった患者教育と個別目標。**CGM は深夜・早朝の低血糖把握に有効**
- 重症低血糖の既往は主要心血管イベント・認知症リスク増加と関連

### 症状と血糖値の目安

| 段階 | 血糖目安 | 症状 |
|---|---|---|
| 交感神経症状（警告症状） | 約55 mg/dL | 発汗、振戦、動悸、悪心、不安感、熱感、空腹感、頭痛 |
| 中枢神経症状 | 約50 mg/dL | 眠気、脱力、めまい、疲労感、集中力低下、霧視、見当識低下／不安、抑うつ、攻撃的変化、不機嫌 |
| 大脳機能低下 | 約30 mg/dL | 痙攣、意識消失、一過性片麻痺、昏睡 → 放置で死亡。小児はてんかん発作 |

- 夜間低血糖は交感神経症状が出にくく、**悪夢や起床時頭痛**で疑う
- 高齢者は中枢神経・精神症状が前面に出て**認知症と間違われる**。低血糖反復例は高齢後の認知機能低下が顕著との報告

### 対応

| 状況 | 処置 |
|---|---|
| 可能なら | SMBG／医療機関では POCT で血糖確認 |
| 経口摂取可 | **ブドウ糖 5〜10 g** を中心とした糖質。ブドウ糖以外は効果発現が遅れることあり。**α-GI 服用中は必ずブドウ糖** |
| 経口摂取不可 | **グルカゴン 1 mg 筋注** または **グルカゴン点鼻粉末 3 mg** → 速やかに搬送。意識回復後に炭水化物摂取 |
| 医療機関 | **ブドウ糖 10〜20 g 静注**（小児 200〜300 mg/kg）、症状と血糖上昇を確認 |

- 本人だけでなく**家族にも指導**
- 重症例は一旦回復しても**再発・遷延**あり → 注意深い経過観察と再発予防
- 経口薬以外の原因薬剤: **シベンゾリンなどの抗不整脈薬、ニューキノロン、β遮断薬、ACE阻害薬**
- インスリン自己免疫症候群: チアマゾールなど -SH基薬、健康食品の**αリポ酸・コエンザイムQ10**

### 無自覚性低血糖・問題のある低血糖

- 無自覚性: 自覚症状なく意識消失などに至る。コントロール不良、高齢者、自律神経障害で症状発現閾値が変化
- **HAAF**: 頻回低血糖で拮抗ホルモン反応低下と無自覚化。**約3週間低血糖を回避**するとアドレナリン反応・自律神経症状が回復との報告
- **問題のある低血糖**: 過去1年間に2回以上の重症低血糖、または無自覚性低血糖・極端な血糖不安定性・精神的問題のいずれかを伴う1回以上の低血糖
- 4段階の対応: ①体系だった低血糖教育 ②SMBG併用CSII または rtCGM 併用強化インスリン療法 ③SAP ④膵島移植・膵臓移植

### 運転

- 重篤な低血糖既往者は交通事故リスクが高い
- **2014年6月改正道路交通法**: 低血糖で運転に支障の可能性がある患者が免許取得・更新時に虚偽申告すると罰則
- **近距離でも運転前に血糖測定**を指導。危険作業・機器操作も注意

## Q20-5 糖尿病に特徴的な感染症にはどのようなものがあるか

- 糖尿病が基礎疾患であることが多い: 気腫性胆嚢炎、内臓・軟部組織膿瘍、鼻脳ムコール症、悪性外耳道炎、気腫性膀胱炎、気腫性腎盂腎炎、壊死性筋膜炎、フルニエ壊疽、足感染症に続発する骨髄炎
- **極めてまれで糖尿病にほぼ特有**: 悪性外耳道炎、気腫性腎盂腎炎、気腫性胆嚢炎、鼻脳ムコール症

| 感染症 | ポイント |
|---|---|
| 悪性外耳道炎 | 外耳道結合織炎 → 側頭骨骨髄炎。多くは緑膿菌 |
| 尿路感染 | 頻度高い。気腫性膀胱炎・腎盂腎炎、腎乳頭壊死、腎膿瘍、腎周囲膿瘍 |
| 気腫性腎盂腎炎 | **85〜90%が糖尿病**。通常の腎盂腎炎と鑑別困難 → X線・CT・エコーでガス確認 |
| 気腫性胆嚢炎 | 通常の胆嚢炎より穿孔リスク数十倍、死亡率約10倍 |
| 皮膚・軟部組織 | 蜂窩織炎、フルンケル、皮下膿瘍。足感染症は骨髄炎・切断に至る。主に黄色ブドウ球菌、MRSA・大腸菌・嫌気性菌の混合も少なくない |
| 壊死性筋膜炎 | 致死率約25%。糖尿病では多くがグラム陰性桿菌＋嫌気性菌（バクテロイデス、クロストリジウム）の混合感染。**水疱、緊満した浮腫、皮膚変色、感覚・運動障害**で疑う。握雪感・画像でガス像。クロストリジウムやガス像で重症化。**早期の広範デブリードマン＋広域抗菌薬静注** |
| V. vulnificus | 淡水・海水曝露で疑う。壊死性筋膜炎を合併しうる、致死率高い |
| フルニエ壊疽 | 陰嚢・陰茎・会陰の急速な壊疽。壊死性筋膜炎に準ずる |
| 肺結核 | リスク高。**2021年新規登録の15.4%が糖尿病**。HbA1c 高値で発病リスク高、LTBI リスクも軽度上昇 |
| 性器感染症 | SGLT2阻害薬でリスク増加 |

## Q20-6 感染症時の血糖コントロールはどのようにするか

- 感染症は日本人糖尿病の**死因第2位（17.0%）**（1位は悪性新生物）
- 好中球の遊走能・接着能・貪食能・殺菌能が低下 → 特にコントロール不良で遷延・重症化
- 肺炎入院時の高血糖は合併症・死亡リスク上昇
- 血糖管理が感染リスクを減らす可能性は高いがエビデンス不足（DCCT 強化療法で膣・足感染症減少、コホートで尿路感染・抗菌薬使用減少。関連なしの研究もある）
- その他の寄与因子: 血流不全、自律神経障害（皮膚乾燥、神経因性膀胱、胆嚢収縮異常）、疼痛閾値低下、透析、アルコール多飲、肝硬変
- COVID-19 の感染リスク増加をもたらすかは現時点で不明確
- 血糖悪化機序: ①サイトカインによる抵抗性上昇 ②カテコールアミン・コルチゾール増加 ③脱水によるブドウ糖排泄障害

### 血糖目標

| 状況 | 方針 |
|---|---|
| 敗血症など重症、血糖 ≧180 | **インスリン持続静注、140〜180 mg/dL** に維持 |
| 強化療法（<110 mg/dL） | 死亡率改善せず低血糖大幅増 → **推奨されない** |
| 軽〜中等症入院 | インスリンで、低血糖なく可能なら**空腹時 <140、随時 <180 mg/dL** |

- 重症感染症はインスリンで管理。輸液・インスリンに加え、**病初期から感染部位・起因菌の同定と適切な抗菌薬**
- 敗血症 = 感染による SIRS。菌血症が証明されなくても強く疑えば早急に対応

### SIRS（4項目中2項目以上）

1. 体温 >38℃ または <36℃
2. 心拍数 >90/分
3. 呼吸数 >20/分 または PaCO₂ <32 Torr
4. WBC >12,000/μL または <4,000/μL、あるいは未熟型 >10%

- 抗菌薬開始前に**血液培養2セット以上**
- 認識から抗菌薬までが短いほど死亡率が低い → **診断後1時間以内の経験的抗菌薬投与**

## Q20-7 糖尿病患者に予防接種は推奨されるか

- **インフルエンザ、肺炎球菌、COVID-19 ワクチンの接種を推奨**

### インフルエンザ

- 糖尿病では65歳未満でもインフルエンザ関連入院が多い。2009 H1N1 で重症化リスク高。日本の新型インフルエンザ入院（15歳以上）で糖尿病保有率は慢性呼吸器疾患に次ぎ2番目
- 合併症は肺炎が最多（高齢者は細菌性肺炎: 肺炎球菌、インフルエンザ桿菌、黄色ブドウ球菌）。心筋炎・心内膜炎もまれでない。高齢者は発熱など臨床所見に乏しい
- MA: **18〜64歳**で全入院・インフルエンザ/肺炎入院を減少（死亡・ILI は減らさず）、**65歳以上**では全て減少
- 大規模コホート: 脳卒中・心不全・肺炎/インフルエンザ入院、死亡を減少
- 禁忌がなければ**毎年**接種。日本人糖尿病で抗体応答上昇
- 手洗い・マスク、疑わしい症状で速やかに受診を指導。流行状況により重症化リスクの高い者や家族に**抗インフルエンザ薬の予防投与**を考慮し得る

### 肺炎球菌

- コントロール不良で肺炎球菌肺炎入院が増加。侵襲性肺炎球菌感染症 **OR 1.4〜4.6**
- 接種で肺炎球菌感染症・肺炎全体は減るが、総死亡への効果は報告により分かれる
- 糖尿病限定の効果検討はないが ADA は強く推奨
- 日本人高齢者（糖尿病含む、ナーシングホーム）の RCT で3年間の肺炎・肺炎球菌肺炎・死亡が減少。日本人高齢糖尿病で抗体上昇
- **2014年から65歳以上に PPV23 定期接種**

### COVID-19

- 糖尿病で死亡リスク約1.5〜2倍
- ICU入院・人工呼吸・死亡の複合で **HR 1.59**。死亡 2.12倍、重症化 2.45倍、ARDS 4.64倍
- 日本の入院3,376例レジストリ: 重症化 OR 単回帰 2.52、重回帰 1.34
- 日本感染症学会: 「インスリンや飲み薬で治療中の糖尿病または他の病気を併発している糖尿病」を優先接種対象に

### その他（米国 ACIP）

- **B型肝炎**: 19〜59歳の糖尿病は診断後速やかに接種、60歳以上未接種は主治医判断（血糖測定機器の共用による血液曝露が理由）
- MMR: 罹患歴がなければ接種。水痘: 罹患歴に関わらず接種

## Q20-8 シックデイにはどう対応するか

- 定義: 発熱・下痢・嘔吐・食欲不振で食事が摂れず、脱水・ケトーシスになりやすく通常のコントロールが困難な状態。拮抗ホルモン増加で**高血糖になることが多い**

### 平素からの指導

- シックデイに**相談できる体制**を確立
- **自己判断でインスリン・経口薬を中断しない**（中断で著明な高血糖）
- 食事困難なら**早期に医療機関へ連絡**し指示を受ける
- 十分な水分、摂りやすい形（**お粥、麺類、果汁**など）で糖分・エネルギー補給
- SMBG・ケトン体測定をできるだけ頻回に
- **毎日体重測定**しておくと脱水の程度を推定できる

### 速やかに受診すべき状況

1. 発熱、消化器症状が強い
2. **24時間**経口摂取ができない／著しく少ない
3. **血糖 ≧350 mg/dL の持続**、血中ケトン体高値、尿ケトン強陽性
4. 意識状態の悪化

- 来院時は**必ず血中・尿中ケトン体を測定**

### 薬剤別対応（例。実際は病状・普段のコントロール・摂取状況などから個別指示）

| 薬剤 | 対応 |
|---|---|
| **インスリン** | **中間型・持効型は継続が原則**。追加インスリンは食事量（主に糖質）・血糖・ケトン体で調整。頻回に血糖/ケトン体測定 |
| SU薬・グリニド | 食事摂取不良なら医療機関に連絡が望ましい。診察時に中止・減量を判断 |
| α-GI | 消化器症状が強いとき中止 |
| **ビグアナイド** | **シックデイ中は中止**するよう普段から指導。受診時に投薬変更を考慮 |
| チアゾリジン | 中止可能 |
| インクレチン関連薬 | コンセンサスなし。GLP-1RA は SMBG を参考にインスリン切り替えも含め対応 |
| **SGLT2阻害薬** | **シックデイ中は中止**するよう指導 |
| イメグリミン | 明確でないが、メトホルミン類似でミトコンドリア呼吸鎖に作用、腎障害で濃度上昇するため**中止が望ましい** |

## 外来での使いどころ（自院メモ）

- SGLT2阻害薬内服中の倦怠感・嘔気・腹痛は**血糖が高くなくても正常血糖DKAを疑い**、血中ケトン・血液ガスを確認して搬送判断
- 高齢2型の意識障害・片麻痺は脳卒中だけでなく **HHS と低血糖**を鑑別（血糖・Na から有効浸透圧を計算）
- 処方時に**シックデイ指示を薬剤別に書面で渡す**: メトホルミン・SGLT2阻害薬・イメグリミンは休薬、SU/グリニドは連絡、基礎インスリンは継続。「24時間食べられない／血糖350以上持続／意識変化」で受診
- 低血糖指導は「ブドウ糖5〜10 g、α-GI 内服中は必ずブドウ糖」。インスリン・SU使用で独居・高齢者には**グルカゴン点鼻 3 mg** の家族指導を検討。院内ではブドウ糖10〜20 g 静注を準備
- 低血糖を起こした患者には**運転前の血糖測定**を指導し、原因として併用薬（シベンゾリン、ニューキノロン、β遮断薬など）も確認
- メトホルミンは eGFR <30 禁忌、30〜45 慎重。**脱水・急性腎障害時が危険**で低用量でも発症しうる。75歳以上はより慎重に
- 糖尿病患者には**毎年のインフルエンザワクチン、PPV23（65歳以上定期）、COVID-19** を勧奨
- 足・会陰の発赤腫脹に水疱・変色・握雪感があれば壊死性筋膜炎を疑い即紹介。発熱＋SIRS 2項目以上は血培2セットと早期抗菌薬
