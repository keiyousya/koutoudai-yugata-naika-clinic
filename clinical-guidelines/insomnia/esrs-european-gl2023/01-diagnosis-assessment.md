## 1. 定義と診断基準（3章、表2・3）

- DSM-5、ICSD-3、**ICD-11（7A00 慢性不眠症）**の基準はほぼそろった。ICD-11 は「器質性／非器質性」の区別を根拠がないとして廃止し、「慢性不眠症」と「短期不眠症」に整理した。**一次性／二次性不眠という上下関係も廃止**（身体疾患を治せば不眠も消えるという想定は証明されなかった）
- 慢性不眠症の要点（ICSD-3 の A〜F をまとめると）
  - **夜の症状**（1つ以上）: 入眠困難、中途覚醒（睡眠維持困難）、早朝覚醒
  - **日中の障害**（1つ以上）: 疲労・倦怠、注意・集中・記憶の低下、社会・職業機能の低下、気分の障害・易刺激性、眠気、意欲低下、ミス・事故を起こしやすい、睡眠への不満・心配 など
  - 眠る**時間と環境が十分にある**のに起こる（機会不足・環境不良では説明できない）
  - **週3回以上、3ヵ月以上**
  - ほかの睡眠障害でうまく説明できない
- **日中の障害がない「眠れない」は不眠症と診断しない**（ICD-11）
- 入眠潜時・睡眠時間・覚醒回数の**数値基準は不要**。病歴と自己申告だけで診断する
- 他の睡眠覚醒障害・精神疾患・身体疾患・物質による不眠でも、**不眠そのものが独立して治療の対象になるとき**は慢性不眠症と診断する

## 2. 診断の手順（表4）

| 項目 | 内容 | 推奨度 |
|---|---|---|
| **一般の病歴と診察** | 過去・現在の身体・神経・精神疾患／性格、仕事・家庭、対人関係の問題／**物質（薬、アルコール、カフェイン、ニコチン、違法薬物）**／必要なら身体診察／必要なら検査（**血算、甲状腺、肝・腎機能、CRP、Hb、フェリチン、ビタミンB12**。必要なら心電図、脳波、CT/MRI、概日指標）／必要なら介護者からも聴取 | A |
| **睡眠の病歴** | 不眠と日中機能の経過／**同床者・介護者の情報（いびき、無呼吸、睡眠中の周期性四肢運動、夜間の落ち着きのなさ、異常行動）**／勤務時間・概日要因（**交代勤務・夜勤、位相の前進・後退**）／昼寝を含む睡眠覚醒パターン（**睡眠日誌、質問票**） | A |
| アクチグラフィ | 不規則な睡眠覚醒・概日リズム睡眠覚醒障害が疑われるとき | A |
| | 睡眠中の周期性下肢運動が疑われるとき | A |
| | 活動量の定量（A）、睡眠指標の評価（C） | A / C |
| **PSG** | **他の睡眠障害の併存が疑われるとき** | A |
| | **治療抵抗性の不眠** | A |
| | 主観と PSG の睡眠の大きな乖離が疑われるとき | B |

要約では「アクチグラフィは不眠の**ルーチン評価には勧めない**（C）が、鑑別には有用（A）」とまとめている。

### 睡眠日誌と質問票

- **睡眠日誌を7〜14日以上**つけてもらう（コンセンサス睡眠日誌 Carney 2012）
- **ISI（不眠重症度質問票、0〜28点）**: 8〜14 閾値下、15〜21 中等度、22〜28 重度。地域集団では**10点**を不眠ありのカットオフ、**8.4点の低下**を中等度改善の目安とする。毎週の経過観察には**2項目版**がある
- **SCI（Sleep Condition Indicator、8項目）**: DSM-5 準拠で ISI の代わりになる。2項目版あり。信頼できる変化は7点
- **PSQI**（0〜21点、>5 で臨床的な睡眠障害）は全体像の把握に役立つが、**不眠症の尺度ではない**（他の睡眠障害の症状も拾う）
- 睡眠と日中障害を一度に測れる、臨床用の検証済み質問票はまだない

### アクチグラフィ・ウェアラブル

- 医療用アクチグラフは**普段の就床・睡眠時刻とそのばらつき**を安く長期間見られ、**概日リズム睡眠覚醒障害の疑い**で特に役立つ
- 多くの機器は PSG より**睡眠時間を長く、障害を軽く見積もる**。不眠症と健常者を区別できなかった報告もある。睡眠段階は分からない
- 腕時計型などの市販機器は**不眠診断での妥当性が示されていない**。かえって睡眠行動を悪くするという指摘もある。CBT-I の章では「PSG との検証が出るまで、不眠患者には睡眠トラッカーを**一般に勧めない**」とまで書いている

### PSG の位置づけ

- **不眠の診断そのものに PSG は不要で、それだけでも不十分**
- 適応: **周期性四肢運動障害（PLMD）・睡眠関連呼吸障害（OSA など）の疑い**、**さまざまな治療（CBT-I・睡眠薬）に反応しない**（隠れた睡眠障害を探す）、**職業運転手など眠気による事故リスクがある人**（睡眠不足の程度を測る）、**主観と客観の大きな乖離**が疑われる人
- 不眠症では PSG 上も睡眠効率・総睡眠時間・徐波睡眠・REM が減るが、**主観ほどの差はなく特異度も低い**

## 3. 併存症と寄与因子（3.5、表5）

| 区分 | 主なもの |
|---|---|
| 精神 | うつ病、双極性障害、不安症、境界性パーソナリティ障害、PTSD、統合失調症、物質使用障害 |
| 身体 | **心血管疾患、糖尿病、CKD、COPD**、リウマチ性疾患、慢性疼痛、悪性腫瘍、**睡眠関連呼吸障害／OSA** |
| 神経 | 神経変性疾患、脳血管疾患、頭部外傷、多発性硬化症、**RLS/PLMD**、致死性家族性不眠症 |
| 物質 | **アルコール、ニコチン、カフェイン**、大麻、オピオイド、危険ドラッグ、コカイン、アンフェタミン |

- ほぼどんな身体疾患も不眠の原因・寄与因子になりうる。**慢性不眠はうつ病・不安症の独立した危険因子**であり、「不眠は単なる症状」という古い見方は否定された。脳卒中・認知症の危険因子でもある
- 糖尿病・心血管疾患・高血圧でも不眠が多く、**双方向の関係**がある → 併存症があっても不眠を**評価し積極的に治療する**
- 精神疾患は偏見から自分では言わないことが多い → **不眠の評価では精神疾患を必ず能動的に聞く**
- **COMISA（不眠と睡眠時無呼吸の併存）**: 不眠の**30〜40%に OSA**、OSA の**30〜50%が不眠の基準を満たす** → **不眠の評価には OSA スクリーニング（STOP-Bang など）を必ず入れる**。逆に OSA 疑いの全員に不眠スクリーニング。スクリーニング陽性なら**簡易検査（在宅睡眠時無呼吸検査）か PSG**で診断する
- **RLS**: 不眠の重要な原因。重症度は IRLSSG 評価尺度で測る。RLS は臨床診断、**PLMD は PSG が必要**
- 不眠と「他の睡眠障害」は**同時に治療する**ことが多い
- **アルコール**: 入眠・中途覚醒の自己治療として使われやすい → 飲酒量を必ず聞く
- 不眠を起こす処方薬: **副腎皮質ステロイド、β遮断薬、β刺激薬、抗菌薬、抗認知症薬、SSRI** など多数
- 原因がはっきりしていても、**「眠れない不安・夜の反すう・過覚醒・床で長く過ごす」という悪循環**がすでにできていることが多く、それ自体を治療の対象にする
- **CBT-I でも薬でも、治療の前に診断と鑑別を済ませる**

## 4. 臨床アルゴリズム（図1）の流れ

1. 入眠困難・中途覚醒・早朝覚醒 ＋ 日中の障害 → **臨床的に意味のある障害か**。なければ心理教育・予防
2. **睡眠パターンが概日リズムとずれているか** → ずれていれば概日リズムへの介入
3. **睡眠に影響する物質を使っているか** → 薬の変更、断酒・断薬、睡眠薬依存なら離脱
4. **他の睡眠障害・身体疾患の併存** → **併存症と不眠の両方を治療**
5. なければ **CBT-I（対面またはデジタル）が第一選択**。効かなければ薬物療法（[03](03-pharmacotherapy.md)）

## 外来での使いどころ（自院メモ）

### 当院の状況との関係

- 当院は**夕方〜夜の内科外来**で、**会社員・交代勤務者**が多い。図1の2番目（**概日リズムのずれ**）と3番目（**カフェイン・アルコール・夜遅くのスマホ／残業**）で説明がつく人が多いはずなので、睡眠薬の前に必ずここを聞く
- 日本では「眠れない」の訴えで**一般内科を受診する**ことが多い。GL も一般医向けに書かれている
- 糖尿病・高血圧の通院患者は不眠の高リスク群（表5）。生活習慣病の定期受診で睡眠を聞く機会を作る

### 初診の聞き取り（最小セット）

1. **不眠のタイプ**（入眠・中途・早朝）、**期間**（3ヵ月以上か）、**週何回か**、**日中の困りごと**（日中の障害がなければ「不眠症」として薬は出さない）
2. **就床・起床時刻（平日と休日）**、**床にいる時間**、**昼寝**、**夜勤・シフト** → 床にいる時間が長すぎる人、休日の朝寝坊が大きい人が多い
3. **カフェイン（夕方以降のコーヒー・エナジードリンク・緑茶）、飲酒（寝酒）、喫煙**
4. **いびき・無呼吸の指摘、日中の眠気**（STOP-Bang）。**脚のむずむず**（RLS）
5. **気分の落ち込み・不安**（PHQ-2 などで能動的に聞く）
6. **併用薬**: ステロイド、β遮断薬、β刺激薬、SSRI、抗菌薬など。他院からの睡眠薬・抗不安薬（お薬手帳）
7. 可能なら **ISI** と **1〜2週間の睡眠日誌**を持ち帰ってもらい、次回の受診で一緒に見る（[02](02-cbt-i.md) の簡易 CBT-I の材料になる）

### 検査

- 表4の採血項目（**血算、TSH、肝・腎機能、CRP、フェリチン、B12**）は、当院の通常の採血で揃う。**フェリチン**は RLS の評価にも使える（RLS では鉄欠乏が関与。GL 本文は RLS の鉄に触れていない）
- **OSA 疑い**（いびき・無呼吸・肥満・高血圧・日中の眠気）は、睡眠薬の前に**簡易睡眠検査（携帯型）**を考える。BZ 系を先に出さない
- PSG は当院ではできない。GL の適応（他の睡眠障害の疑い、治療抵抗性、職業運転手）に当てはまれば睡眠専門施設へ紹介する
- スマートウォッチの睡眠記録を持参する人には、「精度が確かめられていないので、それで不安になるなら見ないほうがよい」と伝える（GL は一般に勧めない立場）

### 原文で確認できなかった・注意する点

- 表1の「1c（all or nothing）→ B」は、一般的な体系（1c → A）と違う。本文の抽出テキストで確認した値をそのまま載せた
- 表4のアクチグラフィの推奨度（A）と要約の「ルーチン評価には勧めない（C）」は書き方が違う（表は「適応があるとき」、要約は「ルーチンには」）。矛盾ではなく対象の違いと読んだ
- GL は**急性・短期不眠を扱わない**。受診の多い「最近眠れない（数週間）」への推奨はこの GL にはない
- 国内の診断・薬物療法の基準は、日本睡眠学会ほか「睡眠薬の適正な使用と休薬のための診療ガイドライン」（2013）が別にある（本 GL では扱っていない）
