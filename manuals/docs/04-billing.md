# 会計業務

## 使用機器について

| 機器 | レセコン |
| --- | --- |
| 受付用デスクトップPC | 使用可 |
| 処置室ノートPC | 使用不可 |

- **レセコンは受付用デスクトップPCからのみ操作可能**
- 処置室ノートPCからはレセコンを直接開けません

## 基本の流れ

1. レセコンで医師が入力した診療行為を登録し、会計金額を患者にお伝えします
2. 決済方法を確認し、レセコンに入力します
3. レセコンで会計を確定し、領収証明細書を印刷します
4. 領収証明細書を提示し、改めて金額をお伝えします
5. それぞれの決済方法に従って決済を行っていただきます

## 現金決済

> 当院は電子レジ端末を導入していないため、手動計算ではミスが発生しやすい状況です。患者さんへの不利益を防ぐため、**必ず電卓を使用**してください。

1. レセコンで診療行為を登録し、会計金額をお伝えします
2. 決済方法を確認し、「現金」でレセコンに入力します
3. レセコンで会計を確定し、**領収証明細書**を印刷します
4. **会計額を電卓に打ち込み、患者さんに提示します**
5. 現金を受け取り、**電卓でお預かり金額から会計額を引きます**
6. **お釣り額を電卓で患者さんに提示し、お釣りをお渡しします**

## 対面キャッシュレス決済

1. レセコンで診療行為を登録し、会計金額をお伝えします
2. 決済方法を確認し、「キャッシュレス」でレセコンに入力します
3. レセコンで会計を確定し、**領収証明細書**を印刷します
4. 領収証明細書を提示し、改めて金額をお伝えします
5. キャッシュレス端末で支払いを完了します
6. キャッシュレス端末から発行される**売上票**と**領収証明細書**を合わせてお渡しします

## LINEクレジットカード決済

1. レセコンで診療行為を登録し、会計金額をお伝えします
2. 決済方法を確認し、「LINEクレカ決済」でレセコンに入力します
3. レセコンで会計を確定し、**領収証明細書**を印刷します
4. 領収証明細書を提示し、改めて金額をお伝えします
5. カルテから「LINEクレカ決済」を実行し、支払い完了を確認します
6. **領収証明細書**をお渡しします

> **注意**: エラーで支払いが完了しない場合は、対面での支払い（現金またはキャッシュレス）をお願いします。

## 処方箋のお渡し

- 処方箋がある場合は会計時にお渡しします
- 当院は原則**院外処方**（近隣の調剤薬局で受け取り）
- 近隣薬局が閉まっている時間帯に限り、急性疾患の一部薬剤は院内でお渡しする場合があります
- 慢性疾患の薬（降圧薬・糖尿病治療薬等）は必ず院外処方とします

> **重要**: 処方箋の有効期限は**4日間**。期限が切れると無効になるため、お早めに薬局で受け取るようお伝えします。

### 調剤薬局のご案内

> **重要**: 院外処方の患者さんには、**会計時に必ず全員**調剤薬局のご案内を行います。薬局の案内は受付で統一して行い、漏れのないようにします。

受付に**周辺調剤薬局の一覧とマップ**（平日・土曜・日曜別）のラミネートを用意しています。患者さんにお見せしながら、現在空いている薬局をご案内してください。

**注意点**:
- 「〇〇薬局に行ってください」と**特定の薬局を指定することは法律で禁止**されています（医薬品医療機器等法・療養担当規則）
- あくまで「近くだと、この時間は〇〇薬局と△△薬局が開いています」のように**選択肢を提示する**にとどめてください

**マツモトキヨシ クリスロード店の調剤について**:
- 店舗自体は22時まで営業していますが、**調剤は21時で閉まる**ため、夜間にご案内する際は注意してください
- 調剤直通の電話番号: **022-721-1675**

### かかりつけ薬局について

> 毎回全員に確認する必要はありません。複数の医療機関にかかっている患者さんには、近隣薬局を案内しつつ「かかりつけの薬局があればそちらでも大丈夫です」程度に伝えてください。

**かかりつけ薬局のメリット**（患者さんに聞かれた場合の説明用）:
- 複数の医療機関の処方薬を一元管理し、**飲み合わせ（相互作用）をチェック**してもらえる
- **薬の重複**を防げる
- 体質やアレルギー歴を把握した上で、継続的な**服薬指導**を受けられる

## お薬手帳のお渡し

> お薬手帳は**会計時に受付からお渡しします**。

- **お薬手帳をお持ちの患者さん**: お薬手帳を再度お預かりし、印刷したシールを**貼付してからお渡し**します
- **お薬手帳をお持ちでない患者さん**: 一言添えて、**明細書と合わせてお渡し**します
  - 「ご自宅にお薬手帳はありますか？」
  - 「帰られてから貼り付けてください」
  - 「もし今後お薬手帳を作る際は、最初に貼ってください」

## 処方箋の再発行

- 処方箋の再発行は実費**660円**です

## 領収証の再発行

- **原則**: 領収証の再発行はできません
- **再発行が必要な場合**: 1枚につき実費**550円**で発行します
- **年間の支払い証明書**: 1通**550円**で発行可能です

> 領収証は大切に保管いただくようお伝えしましょう。

## 一般名処方・リフィル処方箋について

- 当院では**一般名処方**を行っています。一般名処方とは、特定の商品名ではなく有効成分名で処方することで、ジェネリック医薬品を含め、患者さんが薬局で選択できるようになるものです
- **長期処方**（28日以上）および**リフィル処方箋**（最大3回繰り返し）に対応しています。患者さんから問い合わせがあった場合は「医師の判断により対応しています」とお伝えください
