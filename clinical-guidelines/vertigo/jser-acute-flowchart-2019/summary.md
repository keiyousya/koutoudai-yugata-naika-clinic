# 急性期めまいの診療フローチャート

- **出典**: 日本めまい平衡医学会 学会のあり方委員会「急性期めまいの診療フローチャート」Equilibrium Res 78(6):607–610, 2019
- **原文**: https://www.memai.jp/wp-content/uploads/2021/06/kyuseikimemaiflowchart.pdf
- **発行**: 2019（学会サイト「ガイドライン等」一覧では「急性めまいの診療フローチャート」の名称で掲載）
- **版**: 初版。2026-09-14 時点で改訂版なし（学会ガイドライン等一覧で確認）
- **確認日**: 2026-09-14

主に耳鼻咽喉科での初診を想定しているが、救急・脳神経内科・総合内科などでの使用も念頭に置いて作られている。構成は「1. 問診 → 2. 診察 → 3. 診断基準（注記）」の3段。

---

## 全体の考え方（表1の要約）

1. **問診**：発症様式・誘因と合併症・蝸牛症状・中枢症状から、中枢性か末梢性かの見当をつける
2. **診察**
   - 2-1 頻度は低くても**致死性疾患の除外が最優先**
     - ショックや失神を「めまい」と訴えることがある → 血圧・眼瞼結膜を確認。**低血圧はショック、高血圧は脳卒中のサイン**
     - 脳卒中の確認 → 眼球運動障害・構音障害、顔面・上下肢の麻痺と感覚障害、小脳症状
   - 2-2 致死性疾患を除外したら、**眼振所見**で振り分ける
     - 方向固定性眼振 → 一側内耳障害の可能性が高い。音叉やストップウォッチでの簡易聴力検査が有用
     - 方向交代性眼振（または懸垂頭位での回旋性眼振） → BPPV の可能性が高い
     - 中枢所見も眼振もないのに急性めまいを訴える → **起立・歩行を確認**。異常があれば改めて脳卒中を考える
3. **診断基準**：BPPV、メニエール病、めまいを伴う突発性難聴、前庭神経炎、その他のめまい

## 図1 問診チャート

| 発症様式 | 誘因・合併症 | 蝸牛症状（難聴・耳鳴・耳閉感） | 念頭に置く疾患 |
|---|---|---|---|
| 単発性（初回） | なし | あり | めまいを伴う突発性難聴 |
| 単発性（初回） | なし | なし | 前庭神経炎 |
| 単発性（初回） | 高血圧・心疾患・糖尿病 | ― | **脳卒中** |
| 再発・反復性 | なし | あり | メニエール病 |
| 再発・反復性 | 頭位変換で誘発 | ― | BPPV |
| 再発・反復性 | 起立で誘発 | ― | 起立性調節障害・起立性低血圧・神経調節性失神など |
| 再発・反復性 | 高血圧・心疾患・糖尿病 | ― | **椎骨脳底動脈循環不全（VBI）** |

- 危険因子があれば全例が脳卒中・VBI という意味ではなく、「念頭に置くべき疾患」を示したもの
- 脳卒中・VBI を疑ったら、**複視、呂律が回らない、顔面・手足のしびれや動かしにくさ**を追加で問診する

## 図2 診察チャート

```
1. 血圧・眼瞼結膜（貧血）・徐脈性不整脈
      └ 所見あり → ショック・失神発作 → 静脈路確保・輸液、循環器コンサルト

2. 眼球運動障害・構音障害・顔面/上下肢の運動麻痺・感覚障害・上下肢の小脳症状
      ├ あり → 脳卒中によるめまい
      └ なし → 眼振
              ├ 方向交代性、または懸垂頭位で回旋性 → BPPV
              ├ 方向固定性 → 簡易聴力検査
              │       ├ 難聴あり → 内耳性めまい（メニエール病・めまいを伴う突発性難聴）
              │       └ 難聴なし → 前庭神経炎
              └ なし → 起立歩行障害
                      ├ あり → 脳卒中によるめまい
                      └ なし → その他のめまい
```

- 方向交代性眼振：頭位によって向きが変わる眼振
- 方向固定性眼振：頭位を変えても向きが一定の眼振

## 注記：診断基準（フローチャート掲載分の要点）

| 疾患 | 要点 |
|---|---|
| **BPPV** | 特定の頭位で回転性（ときに動揺性）めまい。起床・就寝、上を向く・洗髪で下を向く、寝返りで誘発されやすい。数秒の潜時の後に増強・減弱し、持続は数秒〜数十秒。同じ頭位を繰り返すと軽減する。**聴覚症状も、めまい以外の神経症状も伴わない**。メニエール病・突発性難聴・前庭神経炎の経過中にも起こりうる |
| **メニエール病** | 確実例：聴覚症状（難聴・耳鳴・耳閉感）を伴うめまい発作を反復する。非定型例は蝸牛型（聴覚症状のみ反復）と前庭型（めまい発作のみ反復、難聴は固定性で発作と連動しない） |
| **めまいを伴う突発性難聴** | 突然の高度難聴（多くは一側・原因不明）。めまいは難聴と同時か前後に生じ、**発作は反復しない**。第8脳神経以外の神経症状なし。眼振は初期は患側向き、その後健側向きになり消失する |
| **前庭神経炎** | 突発的なめまい発作で、大きな発作は通常1回。その後ふらつき・頭重感が続く。蝸牛症状なし。7〜10日前の上気道感染が先行することが多い。発作時は方向固定性水平性眼振（通常は健側向き）。前庭神経以外の神経障害所見なし |
| **その他のめまい** | 眼振が誘発されない自覚症状のみの BPPV、心因性めまい（パニック障害・うつ・全般性不安障害） |

> 注記の出典は、BPPV診療ガイドライン（医師用）2009、メニエール病診療ガイドライン2011年版、診断基準1987・2017年版。いずれも後継版が出ている（BPPV → 2023年版、メニエール病 → 2025年版）。**診断基準の詳細は [診断基準2017年改定のまとめ](../jser-criteria-2017/summary.md) を参照。**

## 外来での使いどころ（自院運用メモ）

- **初診の順番をこのまま使う**：①血圧・脈・結膜 → ②神経症候 → ③眼振 → ④起立・歩行。「眼振なし＝安心」ではなく、眼振がなければ必ず立たせる・歩かせる
- **問診で聞くことを固定する**：初回か反復か／誘因（頭位・起立）／蝸牛症状／血管危険因子（高血圧・心疾患・糖尿病）／複視・構音障害・しびれ
- **当日紹介を考える所見**
  - 神経症候がある、または起立・歩行ができない
  - 血管危険因子があって、初回の持続性めまい
  - 低血圧・徐脈・貧血所見（ショック・失神の可能性）
  - 急な難聴を伴う（突発性難聴として耳鼻科へ急いで送る）
- **フレンツェル眼鏡や赤外線 CCD カメラがない場合**、注視下では末梢性の眼振は抑えられて見えにくい。この場合、眼振で振り分ける段階の信頼度は下がる。神経症候と起立・歩行の確認に重みを置き、判断に迷えば紹介する
- **このフローチャートにない要素**：HINTS（head impulse test・注視眼振・skew）の使い方は [標準的神経治療：めまい 総論](../jsnt-standard-2020/01-differential-diagnosis.md) と [中枢疾患](../jsnt-standard-2020/05-central.md) を参照
