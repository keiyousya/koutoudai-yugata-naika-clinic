# 欧州不眠症ガイドライン2023（ESRS）：CBT-I とその他の非薬物療法

- **出典**: Riemann D, Espie CA, Altena E, et al. The European Insomnia Guideline: An update on the diagnosis and treatment of insomnia 2023. *J Sleep Res.* 2023;32(6):e14035. doi:10.1111/jsr.14035（PMID 38016484）— 本ファイルは 4.1 非薬物療法（表6〜10）、4.5 の減薬、表16の CBT-I・その他の療法の推奨
- **原文**: https://onlinelibrary.wiley.com/doi/10.1111/jsr.14035 （open access、CC BY）。日本語全訳（古川由己 訳）: https://yukifurukawa.jp/european-insomnia-guideline-2023/
- **発行**: 受理 2023-08-21、J Sleep Res 2023年12月号。2026-10 時点で後継版は見当たらない
- **確認日**: 2026-10-02

位置づけ: GL の治療の柱。**慢性不眠症の第一選択は、年齢・併存症を問わず CBT-I（対面でもデジタルでも）**で、薬は CBT-I が十分に効かないときに使う、という骨格を2017年版から引き継いだ。今回の更新点は、**睡眠制限と刺激制御が最も効く成分**と位置づけたこと、**デジタル CBT-I（dCBT-I）の扱い**を大きく広げたこと、副作用（睡眠制限の眠気）を明記したこと。推奨度 A〜D の定義は [01](01-diagnosis-assessment.md)。原文の転載はせず要点のみ。

## 1. 推奨（表16のうち治療全般・CBT-I・その他）

| 推奨（要約） | 推奨度 |
|---|---|
| 不眠症は、**どんな場面で見つかっても積極的に治療する** | A |
| 併存症があるときは、**不眠と併存症のどちらを先に治療するか、同時に治療するかを臨床判断で決める** | A |
| **CBT-I を、年齢・併存症を問わず成人の不眠症の第一選択**とする | A |
| CBT-I は**対面でもデジタルでもよい** | A |
| **睡眠制限と刺激制御が CBT-I の最も有効な成分** | B |
| 植物製剤は根拠不十分のため勧めない（[03](03-pharmacotherapy.md)） | A |
| **光療法と運動は CBT-I の補助として有用なことがある** | B |

治療方針は**共同意思決定（shared decision-making）**で決めることを強く勧めている。

## 2. CBT-I の構成要素（4.1.1）

通常は**多成分の治療を4〜8回**、個別または集団で、資格のある専門職（主に臨床心理士・心理療法を行う医師）が行う。

| 成分 | 内容 | 単独での効果 |
|---|---|---|
| **心理教育** | 睡眠の役割、加齢による変化、睡眠の調節（**2過程モデル**: 睡眠恒常性と概日リズム）。単独ではなく他の成分に組み込む。例:「眠れなかった夜の次はよく眠れることが多い」を恒常性で説明し、睡眠制限・刺激制御の理屈を補強する | — |
| **睡眠衛生** | 寝室環境（温度・光・音・寝具）と習慣（**カフェイン、アルコール、規則正しい生活、時計を見ない**）。**単独では根拠のある治療ではない**。RCT では「プラセボ」役に使われるほど。患者によっては**「眠るための安全行動」になり、かえって不安を強める** | **単独は勧めない** |
| リラクセーション | 短縮版の漸進的筋弛緩法、自律訓練法、イメージ法。どれが優れるかは不明 | 有効 |
| **睡眠制限療法（SRT）** | 床で過ごす時間（昼寝を含む）の延長が不眠を維持する（Spielman）。**床にいる時間を制限して睡眠圧を高め、睡眠をまとめて規則化する**。**睡眠効率が85%か90%を超えたら、通常は週単位で床にいる時間を延ばす**。初期の床時間の決め方、**最低床時間（4.5・5・6時間など）**、睡眠時間帯の位置、延ばし方は研究によって違う | **有効（最も有効な成分の1つ）** |
| **刺激制御療法（SCT）** | 「寝床＝起きている場所」という誤った条件づけを断ち、「寝床＝眠る場所」を取り戻す（Bootzin）。**7つの基本指示**からなる（GL は個々の指示を列挙していない） | **有効（最も有効な成分の1つ）** |
| 認知療法 | **認知コントロール**（寝る前に「一日をしまう」）、**逆説志向**（眠ろうとする努力をやめ、起きていようとする）、**イメージ訓練**（反すうを手放す）、**認知再構成**（ソクラテス式問答・行動実験） | 逆説志向は単独で有効 |

### エビデンスの要点

- CBT-I（併存症なし）のメタ解析は1994年以降**25本**。**不眠の重症度に大きな効果**、**1年後までの追跡でも小〜中の効果**。ただし初期の研究は待機群対照が多く、効果を過大に見ている可能性がある
- **ネットワークメタ解析では睡眠制限と刺激制御が最も有効**。ただし**取り組むのが大変**で、意欲と、初期の**日中の眠気・疲労の増加**（安全面）を患者と話し合ってから行う
- **1〜2回の短期療法でも一定の効果**がある（brief behavioural therapy）
- 睡眠以外にも、**閾値下の抑うつ・不安・日中の眠気・疲労・睡眠についての非機能的な考え・心配・QOL** を改善する
- **併存症があっても有効**（メタ解析15本）: **うつ病、PTSD、アルコール依存**（中〜大の効果）、**耳鳴り、慢性疼痛、がん、睡眠時無呼吸（COMISA）、頭部外傷・脳卒中・パーキンソン病**。精神疾患では**併存症そのものの症状も改善**する。**双極性障害・精神病性障害は根拠不十分**
- 効果は長続きする（**最長10年の追跡**あり。徐々に薄れることがあり、ブースターが要ることも）。**薬と違い、終了後の再燃・反跳が報告されていない**
- ただし**半数以上は睡眠効率が正常化しない**。寛解は約半数にとどまる

## 3. デジタル CBT-I（dCBT-I）・セルフヘルプ

- **個別・集団の対面、ビデオ・電話（遠隔）、支援つきの読書療法**が最も効果が大きい（ネットワークメタ解析）
- **dCBT-I は中等度の効果**。**専門職の支援つき（メール・電話）が、完全自動よりやや優れる**
- **スマートフォンで行う CBT-I は対照に対して有意な効果を示さなかった**（同じネットワークメタ解析）
- 完全自動のものは**脱落が多い（50%超）**
- 欧州では RCT の裏づけがある dCBT-I が5言語で利用でき、**半数近くが公的保険で償還**される（表9）。最も研究が多いのは英国の **Sleepio**（RCT 13本、プラセボ対照試験を含む）
- 品質管理の基準として **WHAT 基準**（Work: 事前登録された十分な検出力の RCT で効く／Help: 臨床的に意味のある改善／Accessible: 実社会で安全に広く使える／Trusted: 医療機器ソフトとしてのガバナンス・個人情報保護）を挙げる。「**CBT-I に基づいている（evidence-informed）だけでは、根拠がある（evidence-based）ことの代わりにならない**」
- 重い精神疾患が急性期にある併存不眠では慎重に。どの形式にするかは専門職が判断する
- 精度の低い**睡眠トラッカーは一般に勧めない**（PSG との検証が出るまで）

## 4. 副作用・禁忌

- **睡眠制限・刺激制御は、最初の数週間に眠気・疲労を増やし、客観的な覚醒度も下がる**（その眠気が効果の中心かもしれない）
- dCBT-I の大規模試験（1,711人）では、睡眠衛生より**強い眠気、疲労、集中困難、意欲低下、頭痛、記憶の問題、いらいら**が多かった。副作用は主に**行動療法（SRT・SCT）**に由来する
- 看護師が行う SRT の試験（642人）では、**転倒・労災・交通事故・ニアミス・運転中の居眠り**は睡眠衛生と差がなかった
- → **開始前に適否を評価し、治療中は眠気と運転への影響を確認する**
- **禁忌**: 部分断眠になりうる刺激制御・睡眠制限は、**てんかん**と**睡眠不足で悪化しうる状態**には使わない
- CBT-I に**乱用・依存・増量・耐性・反跳性不眠の報告はない**（薬に対する大きな利点）

## 5. CBT-I と薬の併用・減薬（4.1.1、4.5）

- 急性期は CBT-I ＋ 薬（テマゼパム・ゾルピデム）で相乗効果があるが、**治療後は CBT-I 単独のほうが併用より良い**（Morin 1999・2009）
- **行動療法を先に行い、効かなければゾルピデムを加える逐次治療**が、1年後の反応率・寛解率で最も良かった（Morin 2020）
- CBT-I は睡眠薬をやめた後のほうが効きやすいという根拠はあるが、実際には難しいことがある。**CBT-I 開始前に睡眠薬をすべて減らすか、重ねてよいかは未解決**
- BZ/BZRA の減薬には成功した漸減スケジュールがある（Gould 2014）。依存の専門家との連携を勧める
- 急性精神病・躁病などで、離脱時の不眠の悪化が併存症を悪くしそうなら、**減薬しない判断もありうる**

## 6. その他の非薬物療法（4.1.2〜4.1.3）

| 治療 | GL の評価 |
|---|---|
| **マインドフルネス** | メタ解析2本で明らかな効果。ただし研究数が少なく長期効果は未検証 |
| **ACT（アクセプタンス＆コミットメント・セラピー）** | 小規模 RCT のみ。能動対照より優れるが CBT-I には劣る。CBT-I の認知療法部分を ACT に置き換えても上乗せなし |
| 催眠療法 | 一部効果の報告があるが、元の研究の質が低い |
| 集中睡眠再訓練（intensive sleep retraining） | PSG 監視が必要な新しい行動療法。データ不足で推奨なし |
| **運動** | ある程度の根拠。**太極拳**は直近のメタ解析で有効とされるが質の高い研究が必要。CBT-I に加えると効果の維持を助けた（RCT 1本） |
| **光療法** | 小さな効果。**概日リズム睡眠覚醒障害の併存が多い**ので有望。CBT-I に加えると効果の維持を助けた（RCT 1本） |
| 音楽 | 効果の可能性はあるが研究が少なく質も低い |
| 非侵襲的脳刺激（rTMS、tDCS/tACS、迷走神経刺激、脳冷却） | 盲検・偽刺激の不備で効果は過大評価の可能性。**推奨しない（推奨できない）** |

→ いずれも**単独の治療として勧めるのは時期尚早**。**運動と光療法は CBT-I に組み込むと上乗せがありうる**（B）。

## 外来での使いどころ（自院メモ）

### 国内で CBT-I を受けられる道（2026-10 時点）

- **対面の CBT-I**: 2026年度診療報酬改定で「認知療法・認知行動療法」（I003-2）の対象に不眠症が加わったと報じられている。ただし対象は**うつ病・不安障害を併存する不眠症**か、**睡眠薬を2種類以上使っても効果不十分**な患者に限られる（30分超、8回まで）。この区分は従来、**精神科の届出医療機関**向けで、当院（内科）が算定できるかは未確認 → 当院で「CBT-I を保険で提供する」とは考えず、**必要な人は睡眠専門外来・精神科へ紹介**する
- **デジタル CBT-I**: サスメドの**不眠障害用アプリ「Medcle」**（旧称 Med CBT-i。2023-02 承認、2026-06-01 保険収載）。報道によると対象は**睡眠薬を飲んでいない・精神疾患がない・中等度以上の身体疾患がない・交代勤務／夜勤でない**軽症〜中等症の外来患者で、処方医は**6時間以上の研修修了**が必要、算定は**1患者1回**（9週間のプログラム）。当院で使うかは研修と対象患者数を見て別途判断する（**交代勤務・夜勤の人は対象外**なので、当院で該当する人の割合を見て判断する）
- GL のいう dCBT-I（Sleepio など）は日本語版がなく、国内では使えない。**一般のスマホ睡眠アプリは「CBT-I に基づく」と言っても根拠があるとは限らない**（GL の WHAT 基準）

### 内科外来でできる簡易 CBT-I（当院の運用案）

GL は「単独の睡眠衛生指導は勧めない」「**睡眠制限と刺激制御が最も効く**」「**1〜2回の短期療法でも効果がある**」としている。これを踏まえ、診察の中で次の3点に絞って伝える。具体的な数字は GL 本文ではなく、一般的な CBT-I の手順（GL が参照する Baglioni 2022 の教科書など）に基づく当院の目安。

1. **睡眠日誌（1〜2週間）**: 就床・入眠・覚醒・離床の時刻をつけてもらい、**平均睡眠時間**と**睡眠効率（睡眠時間 ÷ 床にいた時間）**を計算する
2. **睡眠制限（簡易版）**
   - **起床時刻を毎日（休日も）固定**する
   - **床にいる時間 ＝ 日誌の平均睡眠時間**（ただし**5時間を下限**、GL の例示は4.5〜6時間）にして、就床時刻を逆算して遅らせる
   - **1週間ごとに睡眠効率を見て、85〜90%を超えたら15〜30分ずつ床時間を延ばす**
   - **昼寝はしない**か、短く（GL は昼寝も床時間の延長に含めている）
   - **最初の数週は日中眠くなる**と必ず伝える。**職業運転手・危険作業の人には慎重に**（GL: 眠気と運転の確認）。**てんかんの人には行わない**（GL の禁忌）。双極性障害は断眠で躁転しうるので行わない（当院の判断）
3. **刺激制御**（GL は7つの指示の中身を書いていないので、一般的な内容）
   - **眠くなってから床に入る**
   - **寝床は眠る（と性生活）以外に使わない**（スマホ・テレビ・考えごとをしない）
   - **眠れないまま長く（目安15〜20分）床にいたら、いったん寝床を出て**、眠くなってから戻る
   - 起床時刻は一定、昼寝をしない
4. **睡眠衛生は補足にとどめる**: 夕方以降のカフェイン（コーヒー・エナジードリンク・緑茶）、寝酒、寝る前の明るい画面、**時計を見ない**。ただし「睡眠衛生だけ」で終わらせない。完璧に守ろうとして不安が強まる人には、ルールを減らす（GL の「安全行動」の指摘）
5. **運動と朝の光**: 補助として勧める（GL: B）。夕方〜夜診療の患者層では、**朝起きたら光を浴びる**のが概日リズムのずれ（夜型化）にも効く

- 再診で日誌を見て床時間を調整する。2〜4回の再診で効果が出なければ、薬（[03](03-pharmacotherapy.md)）か専門外来への紹介を考える
- 説明用の資料（睡眠日誌の用紙、睡眠制限・刺激制御の説明）は、院内帳票として作れば使い回せる（作るなら `internal-forms/`）

### 原文で確認できなかった・注意する点

- **睡眠制限の具体的な数字**（初期の床時間、下限、延長幅）と**刺激制御の7つの指示**は GL に書かれていない。上の数字は一般的な手順に基づく当院の目安
- 2026年度改定の「不眠症に対する認知療法・認知行動療法」の**施設基準・算定できる医師の要件**、Medcle の算定要件は**報道ベースで確認した**（厚労省の告示・通知の原文は未確認）。導入を検討するときは通知で確かめる
- GL は**スマホアプリの CBT-I が有意な効果を示さなかった**というネットワークメタ解析を引いている。一方で国内は**スマホアプリ（Medcle）が保険収載**された。アプリ単体の効果は製品ごとの RCT で判断する
- 運動・光療法の推奨度 B は「CBT-I の補助として」であり、単独治療としての推奨ではない
