# 無痛性甲状腺炎の診断ガイドライン

- **出典**: 日本甲状腺学会「甲状腺疾患診断ガイドライン2024」無痛性甲状腺炎の診断ガイドライン
- **原文**: https://www.japanthyroid.jp/doctor/guideline/japanese.html
- **発行**: 2024-11-21 改定
- **確認日**: 2026-10-01

位置づけ: 「甲状腺中毒症 ≠ 甲状腺機能亢進症」の代表。ホルモンを作りすぎるのではなく、**甲状腺が壊れて貯蔵ホルモンが漏れ出す（破壊性）**ため、抗甲状腺薬は効かない。

---

## 定義

痛みを伴わない**破壊性甲状腺炎による甲状腺中毒症**。

## 特記事項（経過）

- 自己免疫機序が示唆されている。**橋本病や寛解したバセドウ病の経過中**に起こる
- 甲状腺中毒症は**通常約3ヵ月以内に自然に改善**する
- **回復期に機能低下症になることが多く**、少数は永続性の低下症になる
- **出産後数ヵ月**でしばしば発症する（産後甲状腺炎）

## 診断基準

| 区分 | 項目 |
|---|---|
| 臨床所見 | ① 甲状腺痛を伴わない甲状腺中毒症 ② 甲状腺中毒症の自然改善 |
| 検査所見 | ① FT4高値（さらに FT3高値） ② TSH低値 ③ **TRAb陰性** ④ 放射性ヨウ素（またはTc）**摂取率低値** |
| 除外規定 | 甲状腺ホルモンの過剰摂取（サプリメント・処方 LT4 の飲みすぎ） |

| 判定 | 条件 |
|---|---|
| 確実例 | 除外規定を満たし、臨床所見・検査所見のすべて |
| **疑い例** | 除外規定を満たし、臨床所見のすべて ＋ 検査所見①〜③ |

→ 摂取率を測らない場合、**「自然に改善した」ことを確認して初めて疑い例**になる。初診時点では確定できない。

## 付記の要点

- 中毒症状は軽いことが多い
- 急性期の中毒症が見逃され、**あとの一過性の機能低下症で気づかれる**ことがある
- **TSHは測定感度以上・基準値未満**のことが多い（バセドウ病では感度以下が多いのと対照的）
- まれに TRAb 陽性例がある

## 外来での使いどころ（自院メモ）

- 鑑別のポイント（[01-graves.md](01-graves.md) の付記と合わせて）

  | | 無痛性甲状腺炎 | バセドウ病 |
  |---|---|---|
  | TRAb | 陰性（まれに弱陽性） | 陽性 |
  | TSH | 感度以上・基準値未満が多い | 感度以下が多い |
  | FT3/FT4比 | 低め | 高め |
  | エコー血流 | 増えない | 増える |
  | 経過 | 約3ヵ月で自然に改善 | 持続 |

- **抗甲状腺薬は使わない**。動悸・振戦がつらければ β遮断薬で対症療法のみ
- 鑑別に迷えば、**4〜6週後に FT4・TSH を再検**して自然に下がってくるかを見る（下がればこちら）
- 回復後に機能低下期が来るので、**改善後もしばらく（目安は数ヵ月〜半年）TSH を追う**。低下が続けば LT4 を検討
- **産後1年以内の女性の動悸・体重減少・倦怠感**ではこれを考える。再発しやすく、次の出産後にも起こりうる
- 免疫チェックポイント阻害薬・アミオダロン・インターフェロンなどの薬剤でも同じ型の破壊性甲状腺炎が起こる（ATA 2016 にまとめる予定）
