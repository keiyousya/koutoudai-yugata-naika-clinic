# 2026 ETA guideline on interference in immunoassay measurements used in assessment of thyroid function

- **出典**: Campi I, Feldt-Rasmussen U, Gruson D, Halsall D, Raverot V, van den Berg S, Moran C. 2026 ETA guideline on interference in immunoassay measurements used in assessment of thyroid function. *Eur Thyroid J.* 2026;15(4):ETJ260011. doi:10.1530/ETJ-26-0011（PMID 42466561、PMC13482799）
- **原文**: https://pmc.ncbi.nlm.nih.gov/articles/PMC13482799/ （CC BY 4.0 で無料公開）／ https://doi.org/10.1530/ETJ-26-0011
- **発行**: 2026-07-17 先行公開（受理 2026-07-16）、2026年8月号（欧州甲状腺学会 ETA）。同テーマの ETA 指針は初版。2026-10-01 時点で ETA HP のガイドライン一覧にはまだ載っていない
- **確認日**: 2026-10-01

位置づけ: TSH・FT4/FT3・甲状腺自己抗体・サイログロブリン・カルシトニンの**免疫測定法で起こる見かけの異常値（干渉）**の原因・見つけ方・確認後の扱いをまとめた ETA の指針。内分泌医3名と臨床検査医4名の作成。後半（検査法の詳細）は検査室向けで、外来で使うのは**「臨床像と検査値が合わないときに何を疑い、検査会社に何を頼むか」**の部分。原文の転載はせず要点のみ。

## 推奨度の表記

- エビデンスの質: **ØØØØ** = 高（RCT・メタ解析）、**ØØØO** = 中、**ØØOO** = 低（症例対照・症例集積）、**ØOOO** = 非常に低（症例報告・専門家意見）
- 推奨の強さ: **S** = strong（推奨）、**W** = weak（提案）
- 全30推奨のエビデンスは**すべて「低」か「非常に低」**。強さは大半が S

## 1. なぜ干渉が起こるか（測定法の基本）

| 項目 | 測り方 | 干渉の向き |
|---|---|---|
| **TSH** | **サンドイッチ法**（捕捉抗体と標識抗体で挟む。信号は濃度に比例） | 試薬抗体どうしを橋渡しする抗体・マクロTSH → **偽高値**。捕捉抗体や標識抗体に結合する抗体 → **偽低値** |
| **FT4・FT3** | **競合法**（検体中のホルモンと標識ホルモン/類似体が抗体を取り合う。信号は濃度に反比例）。1ステップ法と、洗浄を挟む2ステップ法がある | **多くは偽高値**。結合蛋白と遊離ホルモンの平衡を乱すもの（置換薬・結合蛋白の変異）、抗T4/T3 自己抗体、試薬への抗体。弱い置換薬では偽低値もある |

- 干渉の起こりやすさは**メーカー・機種ごとに違い**、試薬の改良で年々変わる
- TSH は基準測定法がなく完全な標準化はできない。IFCC のハーモナイゼーションで測定系間の差は縮んだが、**干渉の問題は解決しない**
- 第3世代 TSH 測定の定量下限は 0.01 mIU/L。**TSH の免疫測定はフック効果を起こしにくい**

## 2. 干渉の種類

| 原因 | 影響する項目と向き | 頻度など | 見分け方（原文の記載） |
|---|---|---|---|
| **ビオチン**（サプリ・治療薬） | ビオチン-ストレプトアビジン系の測定で偽高値・偽低値。**FT4・FT3 は偽高値**、**TRAb 偽高値**、TSH・Tg にも影響 | ― | **中止後に再採血**（最も簡単）。ビオチンの影響を受けない測定系 |
| **異好性抗体・HAMA**（ヒト抗動物抗体） | **TSH の過大・過小評価**、TT3/FT3 の過大評価、カルシトニン偽高値、Tg・TPOAb にも影響 | 現行試薬では減ったが予測できない | 別の測定系（抗体のエピトープ・動物種が違うもの）、希釈直線性、異好性抗体ブロッキングチューブ（TSH ではあまり効かないことが多い） |
| **試薬成分への抗体**（抗ストレプトアビジン・抗ルテニウム抗体） | TSH の過大・過小評価、**FT4・FT3 偽高値**、TRAb 偽高値 | TSH の抗試薬抗体は 0.4% | 別の測定系 |
| **マクロTSH**（抗 TSH 自己抗体と TSH の複合体。生物学的に不活性） | **TSH 偽高値** | **0.6〜1.6%**。測定系で感度が違う（Abbott Alinity は影響が小さく、Roche Cobas は大きいと例示） | **PEG 沈殿**（ただし干渉がなくても TSH の最大70%が沈殿するので、施設・機種ごとのカットオフが必要）、ゲル濾過。**母体のマクロTSH が胎盤を通り、新生児の一過性先天性甲状腺機能低下症に見える**ことがある。**どの測定系でも正しい TSH が得られない場合がある** |
| **TSHβ 変異**（生物活性は保たれる） | 一部の測定系で **TSH 偽低値** | 南アジア系で約1% | 別の測定系、TSHB の遺伝子検査 |
| **抗T4/T3 自己抗体（THAA）** | 1ステップ法で **FT4 偽高値**（標識体に結合）。抗T3 抗体で FT3/TT3 過大評価。2ステップ法は受けにくい | 一般人口の約1%、**自己免疫性甲状腺疾患の最大40%**が持つが、実際に干渉するのは 1〜2% | 2ステップ法で再測定、放射免疫沈降法 |
| **家族性異アルブミン性高サイロキシン血症（FDH）** | 間接法で **FT4 偽高値**（程度は測定系次第）。アルブミン codon 218・222 の変異では **FT3・TT3 も偽高値** | アルブミン変異は人口の最大1.8% | 家族の TSH・FT4・FT3、**遺伝子検査で確定**、平衡透析 |
| **トランスサイレチン異常（TTH）**、**TBG 変異** | TTH は測定系依存で、病気の時に変動しうる。TBG 変異は主に TT4、**TBG 欠損で FT4 偽高値**のことがある | TTH 1:6,300、X連鎖性 TBG 変異 約1:5,000 | 家族の測定、遺伝子検査 |
| **ヘパリン** | 採血後の試験管内でリポ蛋白リパーゼにより遊離脂肪酸ができ、T4 を置換して **FT4 偽高値** | ― | 薬歴の確認。TT4 は置換では正常のまま。**平衡透析でも高く出る**（試験管内で本当に高くなるため） |
| 高度の遊離脂肪酸上昇、**高用量フェニトイン・フロセミド** | FT4 の誤った値（測定中に結合平衡が組み直される測定系で） | 遊離脂肪酸はリパーゼ活性が正常なら干渉する濃度にはなりにくい | 薬歴、TT4 |
| **抱水クロラール** | 甲状腺ホルモン・**FT3 偽高値** | ― | 薬歴 |
| **TRIAC・DITPA**（甲状腺ホルモン類似体） | FT3・TT3 測定で交差反応 | ― | 薬歴 |
| **M蛋白（パラプロテイン）** | FT4・FT3 などの干渉 | 干渉による不一致例の最大8% | **血清蛋白電気泳動・免疫固定法** |
| **リウマトイド因子** | TT3/FT3 過大評価、カルシトニン偽高値、Tg・TPOAb にも影響 | ― | 別の測定系 |
| **ヨウ素造影剤投与直後** | TSH の過小・過大評価（非特異的） | ― | ― |
| 治療用モノクローナル抗体・免疫グロブリン静注 | 抗体干渉のリスク（影響なしとの報告もある）。IVIG には TgAb が含まれうる | ― | ― |
| 採血管の界面活性剤 | **TT3 偽高値**（採血前の要因） | ― | ― |

### 測定系間の差（アッセイ間差）

- **FT4 の免疫測定は機種間の差があり、特に高値域で大きい**。1ステップ競合法は平衡透析・限外濾過より干渉を受けやすい
- TT4・TT3 は結合蛋白の影響を強く受け、**妊娠・重症疾患では当てにならない**
- **Tg**: 国際標準品 CRM457 導入後も測定系間差は約60%→約30%までしか縮んでいない。最も多い干渉は **TgAb**（女性の最大15〜20%が陽性）
- **TgAb・TPOAb**: 測定系間差が大きく、基準上限は方法ごとに違う。TPO と MPO の構造類似による交差反応がありうる
- **Tg・カルシトニン**: 極端な高値で**フック効果（偽低値）**が起こりうる

## 3. 臨床像と検査値が合わない時の確認手順

原文 Fig. 1 と推奨6〜9・20〜26 を外来向けに並べ直したもの。

1. **干渉を疑う**: TSH・FT4・FT3 が**臨床像と合わない、または互いに合わない**（例: **T4 高値なのに TSH が基準内**）とき（推奨6、ØØOO, S）
2. **診察で確認する**（推奨9、ØØOO, S）
   - 甲状腺の症状、**家族歴**、TH に影響する生理的状態（**妊娠・重症疾患**）
   - **薬とサプリ（特にビオチン、アミオダロン）**
   - **甲状腺腫と甲状腺機能の所見**
   - ここで**どの項目がおかしそうか**（TSH か FT4 か）見当をつけると、検査側に伝える情報になる
3. **検査室（検査会社）に相談**し、次の検査を決める（推奨7、ØØOO, S）
4. **TSH の干渉を疑うとき**（推奨20、ØØOO, S）: **別の測定系で TSH**、**希釈試験**。施設によってははじめから専門検査室へ（抗体中和、PEG 沈殿、ゲル濾過）
5. **FT4/FT3 の干渉を疑うとき**（推奨22、ØØOO, S）: **別の測定系（1ステップ法なら2ステップ法）**、**TT4/TT3 の測定**、専門検査室
   - **薬（ビオチン・置換薬）が疑わしければ、可能なら中止して再検**（推奨23、ØØOO, S）
   - **遺伝性（FDH・TTR・TBG 異常）が疑わしければ家族の TSH・FT4・FT3**、**遺伝子検査で確定**（推奨24、ØØOO, S）
   - TT3 と FT3 の両方を測り直すのも有用（FT4 偽高値120例で、FT3 も高かったのは71例だが TT3 は95%超で正常）
6. **甲状腺ホルモン不応症（RTHβ）・TSH 産生下垂体腫瘍の精査は、検査医が干渉を明確に否定してから**（推奨26、ØØOO, S）

### 干渉が確かめられたら

| 干渉のある項目 | 甲状腺機能の評価に使うもの | 推奨 |
|---|---|---|
| **FT4/FT3** | **臨床所見と TSH**。必要なら別の測定系・2ステップ法・平衡透析後の FT4/FT3、質量分析の TT4/TT3 | 推奨25（ØOOO, W） |
| **TSH** | **臨床所見と FT4**、±別の測定系の TSH。**マクロTSH などでは信頼できる TSH が得られないことがあり、その場合は臨床所見と FT4・FT3 のみ** | 推奨21（ØOOO, W） |

- 干渉があったことを**文書で、かかりつけ医・紹介元と患者本人に伝える**（推奨16、ØOOO, S）。どの項目（TSH か FT4 か）が信頼できるかも伝える（推奨17、ØOOO, W）。カルテにも記録
- **遺伝性の干渉が見つかれば第一度近親者にスクリーニングを提案**（推奨19、ØOOO, S）
- 測定系が変われば干渉が消えることもある → **将来、甲状腺疾患を思わせる所見が出たら改めて評価**

## 4. その他の甲状腺関連検査（推奨27〜29）

- **Tg・TgAb・カルシトニン**の干渉に注意。特に甲状腺癌の経過観察で重要（推奨27、ØØOO, S）。**Tg 測定時は全検体で TgAb も測る**
- **TRAb** はバセドウ病に感度・特異度が高いが、まれな干渉（ビオチン・抗ストレプトアビジン抗体で偽高値）で誤診がありうる（推奨28、ØOOO, S）。臨床像やホルモン値と合わなければ**ビオチン中止後の再検**か別の測定系
- 分化癌の Tg、髄様癌のカルシトニンが**臨床像に比べて意外に低い**ときはフック効果を考える（推奨29、ØOOO, S）
- TPOAb・TgAb が臨床像と合わなければ別の方法で再検、または他の自己抗体を測る

## 外来での使いどころ（自院メモ）

### よく出会うパターンと最初に疑うもの

本文の干渉の向きから整理した当院用の早見。確定は検査会社への相談と再検で行う。

| 検査値のパターン | まず疑うもの | 当院でやること |
|---|---|---|
| **FT4（±FT3）高値なのに TSH が抑制されていない**／症状がない | ビオチン、FDH などの結合蛋白異常、抗T4 自己抗体（橋本病で多い）、ヘパリン、M蛋白 | サプリ・処方の確認 → ビオチンなら中止して再採血。家族歴。検査会社に別法での FT4 再測定を相談。**TSH 産生腫瘍・不応症の精査に進む前に干渉を否定する** |
| **TSH 高値・FT4 正常で、症状がない** | **マクロTSH**、異好性抗体 | 潜在性低下症として治療を始める前に、合わない点があれば検査会社に希釈試験・別法・PEG を相談（[eta-subclinical-hypo-2013/summary.md](../eta-subclinical-hypo-2013/summary.md)） |
| **TSH 低値なのに FT4・FT3 が低め〜正常で症状もない** | TSHβ 変異、抗体干渉（ほかに中枢性・薬剤・非甲状腺疾患も） | 中枢性の評価と並行して別法で TSH（[eta-subclinical-hyper-2015/summary.md](../eta-subclinical-hyper-2015/summary.md)） |
| **TRAb 陽性なのに TSH 正常・甲状腺腫なし** | ビオチン、抗ストレプトアビジン抗体 | ビオチン中止後に TRAb を再検 |
| **前回と今回で値が飛ぶ**（症状変化なし） | 測定系の変更（検査会社・機種の変更）、造影剤直後 | 前回と同じ測定法か確認。時間をあけて再検 |

### 問診で必ず聞くこと

- **ビオチン**: 髪・爪・肌のサプリ、マルチビタミン。**皮膚科でビオチンを処方されていることがある**ので、他院処方も確認する
- **ヘパリン**（透析、自己注射、カテーテルロック）、フェニトイン、フロセミド高用量、抱水クロラール、アミオダロン
- 直近の**ヨウ素造影剤**、免疫グロブリン静注、抗体医薬
- **家族に同じ検査異常を言われた人がいないか**（FDH などの遺伝性）
- 妊娠・重い急性疾患

### 検査会社への頼み方

- 「臨床像と合わないので測定干渉を疑う」と書き、**どの項目が疑わしいか（TSH か FT4 か）**、ビオチン服用の有無を添える
- 頼める候補: **別の測定系での再測定**（FT4 は2ステップ法）、**TSH の希釈試験**、**PEG 処理**、TT4/TT3 の追加。対応できなければ専門施設（大学病院の内分泌内科）へ紹介
- **ビオチンの休薬期間は本 GL に数値の記載がない**。中止後に再採血し、期間は検査会社・試薬の添付文書で確認する

### 国内資料との関係

- 国内の TSH 基準範囲 **0.61〜4.23 mIU/L** は IFCC のハーモナイゼーション後の値（日本臨床検査医学会 2020、[README](../README.md)）。本 GL はハーモナイゼーションで機種間差は縮んでも**干渉は解決しない**としている。基準範囲の読み替えと干渉の有無は別に考える
- 国内の甲状腺疾患診断ガイドライン2024（[jts-diagnosis-gl2024/](../jts-diagnosis-gl2024/)）の診断基準は TSH・FT4 の値が正しい前提で組まれている。**値が臨床像と合わないときは、診断基準に当てはめる前にこのファイルの手順を通す**
- 干渉が確かめられた人には、**どの検査値が信頼できるかを書いた文書**を渡し、カルテにも残す
