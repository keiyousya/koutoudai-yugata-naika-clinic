## Q6-1 インスリン製剤にはどのような種類があるか

- 基本は健常者の分泌パターン（**基礎分泌＋追加分泌**）の模倣
- **基礎**: 主に持効型溶解、**追加**: 主に超速効型
- 2019年以降、**持効型溶解インスリン＋GLP-1RA の配合注射薬**が上市

### 表1 インスリン製剤の種類と主な特徴

| 種類 | 作用発現 | 最大作用 | 持続 | 特徴・用法 |
|---|---|---|---|---|
| 超速効型 | 10〜20分 | 約2時間 | ― | 食直前（一部製剤は食事開始後20分以内）。食後血糖上昇を抑制 |
| 速効型 | 皮下で約30分 | 約2時間後 | 約5〜8時間 | 皮下・筋注・静注が可能。食後血糖上昇を抑制 |
| 中間型 | 約1〜3時間 | ― | 約18〜24時間 | 硫酸プロタミン添加。均一に白濁するまで混和 |
| 混合型 | 各成分の発現時間 | ― | 中間型に準じる | 超速効型/速効型＋中間型を様々な比率で混合。均一に白濁するまで混和 |
| 配合溶解 | 各成分の発現時間 | ― | 持効型に準じる | 超速効型＋持効型溶解 |
| 持効型溶解 | ― | ― | ほぼ1日 | 基礎補充、空腹時血糖を抑制。食後高血糖には経口薬・GLP-1RA・超速効型を併用 |

※ 持効型/GLP-1RA 配合注射薬は表に含まない。（糖尿病治療ガイド2022-2023 より作成）

### 超速効型

- リスプロ、アスパルト、グルリジン（アナログ）。本文では発現10〜20分、**最大作用1〜3時間、持続4〜5時間**
- **新規超速効型（faster-acting insulin aspart、ultra rapid lispro）**
  - メタ解析: HbA1c 改善は従来と同程度、低血糖を増やさず**食後血糖 10〜20 mg/dL 程度改善**。TIR 増加が期待
  - **食事開始から20分以内の注射でも**従来品の食直前と同様の推移 → シックデイで使いやすい
  - 持続時間がより短い → 食間低血糖の予防にも期待
  - **フィアスプ®はインスリンポンプでゲル化事例** → ポンプでは可能な限り他の超速効型を使用（学会注意喚起）

### 持効型溶解

| 製剤 | 作用発現 | 持続 |
|---|---|---|
| デテミル | 1〜2時間 | 約24時間 |
| グラルギン U100 | 1〜2時間 | 約24時間 |
| グラルギン U300（U100の3倍濃度） | 1〜2時間 | 24時間超 |
| デグルデク | 1〜2時間 | 42時間以上 |

- グラルギンとデグルデクは明らかなピークがなく基礎補充によく使われる
- 中間型との比較（メタ解析）:
  - 2型（24 RCT）: HbA1c は差なし、**夜間を含む重症低血糖を減らす可能性**
  - 1型（26 RCT）: デテミルで重症低血糖リスク低下（中等度の確実性）、HbA1c は差なし
  - → 持効型は**血糖改善は同程度、重症低血糖の軽減で優れる**
- **インスリン イコデク**（半減期約1週間、週1回）: 臨床試験進行中（本GL時点）。導入の抵抗感軽減・介助者負担軽減に期待

### その他

- **バイオシミラー**: アスパルト BS、リスプロ BS、グラルギン BS。薬価が低く医療費抑制に寄与
- 剤形: バイアル、カートリッジ、プレフィルド（使い捨て）。適性・希望・費用で選択

## Q6-2 インスリン療法の適応

### 表2 インスリン療法の適応

| 区分 | 項目 |
|---|---|
| **絶対的適応** | ① インスリン依存状態 |
| | ② 高血糖性の昏睡（DKA、高浸透圧高血糖状態） |
| | ③ 重症の肝障害・腎障害の合併 |
| | ④ 重症感染症、外傷、中等度以上の外科手術（全身麻酔施行例など） |
| | ⑤ 糖尿病合併妊娠（食事療法だけで良好なコントロールが得られない妊娠糖尿病を含む） |
| | ⑥ 静脈栄養時の血糖コントロール |
| **相対的適応** | ① インスリン非依存状態でも著明な高血糖（例: **空腹時 ≧250 mg/dL、随時 ≧350 mg/dL**） |
| | ② 経口薬療法のみでは良好なコントロールが得られない |
| | ③ やせ型で栄養状態が低下 |
| | ④ ステロイド治療時の高血糖 |
| | ⑤ 糖毒性を積極的に解除する場合 |

（糖尿病治療ガイド2022-2023 より引用）

## Q6-3 インスリン療法の副作用

| 副作用 | 要点 |
|---|---|
| **低血糖・体重増加** | 過量で肝糖放出抑制・末梢糖利用促進 → 低血糖。同化作用で体重増加。**DCCT: 強化療法で重篤低血糖 約3.3倍、体重 平均+4.6 kg**。4-T study: 経口薬＋ボーラス（1日3回）は経口薬＋持効型より総インスリン量↑、低血糖・体重増加。UKPDS 33/34: SU薬群よりインスリン群で体重増加大 |
| **網膜症の悪化** | DCCT 二次介入群の強化療法で**開始後2年間に一時的悪化**（急速な血糖改善の影響の可能性） |
| **アレルギー・アナフィラキシー** | 注射部位の発赤・掻痒。ヒト/アナログ製剤で減少。きわめてまれに全身性即時型（アナフィラキシーショック） |
| **インスリン抗体** | ヒトインスリンでも陽性率 **57〜76%**。pH が低い・結晶サイズが大きい・皮下貯留が長いほど抗原性↑。通常は低結合能/高親和性で臨床的問題は少ないが、まれに高結合能/低親和性（インスリン自己免疫症候群様）で血糖不安定化 |
| **2型経過中の1型病態出現** | 約30年来の2型でインスリン開始後、高抗体価を伴うアレルギーと急激なβ細胞廃絶。膵島関連自己抗体陰性だが膵生検で膵島炎。同様例が複数報告 |
| **皮下硬結** | **リポハイパートロフィー**（皮下脂肪のスポンジ状肥大）、**インスリンボール**（アミロイド沈着）。痛みが少なく同部位に打ち続けがちだが**吸収障害で血糖が不安定化** → 硬結部位を避け、**毎回2〜3 cm ずつずらすローテーション**を指導 |
| **癌のリスク** | グラルギン中心に検討されたが一定の見解なし。DCCT/EDIC（28年）で使用量が多いほど癌発症率が高いと報告も、サンプル小・95%CI 広くエビデンスレベルは高くない |

## Q6-4 1型糖尿病のインスリン療法

- **強化インスリン療法**: 頻回注射（**3〜4回/日**）または CSII（インスリンポンプ）＋血糖自己測定等。血糖値・食事の糖質量に応じて追加インスリンを自己調整（根拠 DCCT）
  - 基本形: 追加＝超速効型、基礎＝持効型溶解（**1日4回注射**）
  - 分泌低下のある2型でも適応
  - 患者条件: 治療への十分な理解と、低血糖に正しく対処できること
- **インスリンポンプ**: 皮下カニューレから持続注入。基礎は時間ごとに注入速度設定、追加はボタン操作

### ポンプ機器の進化

| 方式 | 内容 |
|---|---|
| SAP 療法 | CGM＋ポンプ。1型で低血糖を増やさず HbA1c 低下 |
| ミニメド 640G | **低グルコース前一時停止機能**。低血糖リスク低減 |
| ミニメド 770G（2022年〜） | **HCL**。食事時は患者が追加注入、それ以外は SG 目標 **120 mg/dL** に基礎注入を自動調整（自動モード）。TIR（70〜180 mg/dL）増加に期待 |
| ミニメド 780G（2023年11月〜） | オート基礎注入に**自動補正**を追加。SG 目標値を **100／110／120 mg/dL** から選択。基礎＋補正の AID 機能を持つ **AHCL** |

## CQ6-5 1型糖尿病に対する強化インスリン療法は細小血管症の発症・進行抑制に有効か

- **ステートメント**: 1型に対する強化インスリン療法は、細小血管症（網膜症、腎症、神経障害）の発症予防や進行抑制に有効であることから推奨される
- **推奨グレード A**（合意率100%）
- **エビデンスレベル**: ステートメント自体に記載なし。根拠文献 DCCT（文献9）は **レベル1**（RCT）。推奨判定表では「質の高い RCT（エビデンスレベル1）」

### DCCT（1983〜1993年）

- 1型 1,441名（13〜39歳）
  - 一次予防群 726名: 罹病1〜5年、AER <40 mg/24時間、網膜症なし
  - 二次介入群 715名: 罹病1〜15年、AER ≦200 mg/24時間、軽度非増殖網膜症あり
- 強化群: **HbA1c <6.05% 目標**、1日3回以上注射またはポンプ。従来群: 目標なし、1日1〜2回
- 平均6.5年追跡、平均 HbA1c **7.2% vs 9.1%**

| アウトカム | 強化群のリスク低下 |
|---|---|
| 網膜症 新規発症（一次予防） | 76% |
| 網膜症 進行（二次介入） | 54%（ただし開始後2年は一時的悪化） |
| 微量アルブミン尿（AER ≧40 mg/24h） | 39% |
| アルブミン尿（AER ≧300 mg/24h） | 54% |
| 臨床的神経障害（5年後） | 60% |
| 末梢神経障害 / 心血管系自律神経障害 | 64% / 45% |

- AER カットオフ 28、70、208 μg/分でも腎症発症・進行リスクは強化群で有意低下
- 害: 重篤低血糖 約3.3倍、体重 平均+4.6 kg

### EDIC（DCCT 後の追跡、両群とも強化療法推奨）

- HbA1c の約2%差は4年で同レベル（8.0%程度）に収束したが、元強化群で抑制効果が持続

| 時点 | アウトカム | 元強化群のリスク低下 |
|---|---|---|
| 4年目 | 網膜症悪化 | 75%（差は7年・10年と拡大） |
| 18年 | 網膜症累積進行、増殖網膜症新規発症、光凝固/抗VEGF 介入、黄斑浮腫新規発症 | いずれも有意に低いまま |
| 3〜4年目 | 微量アルブミン尿 / アルブミン尿 | 53% / 86% |
| 5〜6年目 | 微量（AER 40〜299 mg/日）/ アルブミン尿 | 67% / 84% |
| 7〜8年目 | 微量 / アルブミン尿 | 59% / 84% |
| 16年目（通算22年） | eGFR <60 | 50% |
| 18年 | 微量（AER ≧30 mg/24h）/ 顕性 / eGFR <60 | 45% / 61% / 44% |
| 14年目 | 末梢神経障害 / 心血管系自律神経障害 | 30% / 31% |

- 平均6.5年の治療差が長期に影響 → **メタボリックメモリー**
- 判定: 4項目（エビデンス確実性・益害・価値観・費用）すべて「はい」。費用対効果は DCCT で強化療法が優れるとの試算、Kumamoto study（2型）でも優れる

## CQ6-6 1型糖尿病に対する強化インスリン療法は大血管症の発症予防に有効か

- **ステートメント**: 1型に対する強化インスリン療法は、大血管症の発症予防に有効であることから推奨される
- **推奨グレード A**（合意率100%）
- **エビデンスレベル**: ステートメント自体に記載なし。根拠文献（32, 43, 46）はいずれも **レベル2**（前向きコホート／RCT）。推奨判定表「エビデンスレベル2 の RCT と前向きコホート研究」＝エビデンス総体の確実性は高いとはいえない

### 根拠

| 研究・期間 | 結果 |
|---|---|
| DCCT（平均6.5年） | 心血管イベント抑制の傾向のみ（**p=0.08**、有意差なし） |
| DCCT/EDIC 平均17年（2005年） | 心血管イベント新規発症 **42%低下**、主要心血管イベント（非致死性MI、脳梗塞、心血管死）**57%低下** |
| DCCT/EDIC 最大30年・平均26年（2016年） | 心血管イベント **30%低下**、主要心血管イベント 32%低下傾向。**HbA1c 相対10%低下で心血管イベント28%低下** |
| DCCT/EDIC 平均29年（リスク因子解析） | 年齢に加え **HbA1c 1%上昇ごとに心血管イベント再発28%、主要心血管イベント再発89%増加** → 二次予防にも有効の可能性 |

- 大血管症でもメタボリックメモリーが示唆
- 判定: エビデンス確実性のみ「いいえ」、他3項目「はい」で A。若年対象の DCCT 単独では評価が非現実的なため、長期コホート DCCT/EDIC を重視
- DCCT はベースラインで心血管疾患既往者を除外 → **発症予防は評価できたが進行抑制は評価困難**

## Q6-7 2型糖尿病のインスリン療法

### ステップ

1. **経口薬や GLP-1RA（またはその併用）＋持効型溶解 1日1回**
   - 分泌能が比較的保たれた2型が対象
2. 不十分 → **basal-plus 療法**: 食後血糖が最も高くなる食事（夕食など）に**超速効型を1日1回追加**
3. なお不十分 → 超速効型の回数を段階的に増やし、必要に応じ**頻回注射法・強化インスリン療法**へ
4. 頻回注射・強化療法の適応とならない → **配合溶解製剤または混合型の1日2回**
5. 基礎分泌が十分保たれ食後高血糖の是正のみ必要 → **超速効型1日3回（毎食直前）**

### 根拠研究

- **GRADE 研究**（米国、ビグアナイド服用中の2型に4剤のいずれかを追加、平均5年）

| 追加薬 | HbA1c ≧7.0% の累積発生 | 重症低血糖 |
|---|---|---|
| グラルギン U100 | リラグルチドと同程度、SU・DPP-4より有意に低い | リラグルチド・シタグリプチンと同程度（わずかな体重減少も） |
| リラグルチド | 同上 | ― |
| グリメピリド | 高い | **有意に高頻度** |
| シタグリプチン | 高い | ― |

- 全被験者の **71% が HbA1c <7.0% を5年間維持できず** → 長期維持の難しさ
- **COMMIT-patient study**（日本人2型、経口薬使用中に持効型開始）: 「患者主導」タイトレーション群で自己効力感が有意増加、HbA1c・空腹時血糖の改善がより大きい。インスリン量は増えたが**低血糖・体重増加に差なし** → セルフタイトレーションは有用な可能性

### 1日2回注射法（配合溶解・混合型）

- 通常、朝食時と夕食時。朝 → 朝食後〜夕食前、夕 → 夕食後〜早朝の血糖上昇を抑える
- 厳密さは強化療法に劣る。分泌能がある程度保たれた2型が対象。**家人の介助を要し頻回注射が困難な例**でも選択
- 昼食後〜夕食前が抑えきれない場合、**昼に超速効型またはグリニド薬の併用**を考慮

### 1日3回注射法（超速効型）

- 4-T study: 経口薬＋持効型1回より HbA1c は低いが**低血糖と体重増加** → リスク・ベネフィットを勘案

## CQ6-8 2型糖尿病に対する強化インスリン療法は細小血管症の発症・進行抑制に有効か

- **ステートメント**: 2型に対する強化インスリン療法は細小血管症（網膜症、腎症、神経障害）の発症・進行抑制に有効である
- **推奨グレード B**（合意率100%）
- **エビデンスレベル**: ステートメント自体に記載なし。根拠 Kumamoto study（文献54）は **レベル2**（RCT）。判定表「エビデンスレベル2 の RCT に基づく結果であり、エビデンス総体の確実性は高いとはいえない」
- 判定: 3項目は支持するが、根拠が被験者数の少ない Kumamoto study のみのため弱い推奨（B）

### Kumamoto study

- インスリン療法中の日本人（非肥満）2型 110名、6年間
  - 一次予防群 55名: 網膜症・腎症なし（AER <30 mg/24時間）
  - 二次介入群 55名: 単純網膜症あり、AER <300 mg/24時間
- 平均 HbA1c **7.1% vs 9.4%**（強化 vs 従来）

| アウトカム | 強化群 | 従来群 |
|---|---|---|
| 累積網膜症発症（一次予防） | 7.7% | 32.0% |
| 累積網膜症悪化（二次） | 19.2% | 44.0% |
| 累積腎症発症 | 7.7% | 28.0% |
| 累積腎症悪化 | 11.5% | 32.0% |
| 正中神経伝導速度 | 運動・感覚とも有意改善 | 感覚神経が有意悪化 |

- **低血糖の発症率に差なし、両群とも BMI 増加なし**
- 細小血管症予防の閾値: **HbA1c <6.9%、空腹時血糖 <110 mg/dL、食後2時間血糖 180 mg/dL**
- 費用対効果も優れると報告

## 外来での使いどころ（自院メモ）

- **空腹時 ≧250／随時 ≧350、やせ・栄養低下、ステロイド高血糖、経口薬で未達**はインスリンの相対的適応。**インスリン依存状態・DKA/HHS・妊娠・重症感染症**は絶対的適応で即対応（多くは紹介）
- 2型の導入は **現行の経口薬/GLP-1RA に持効型1日1回**を上乗せが基本。**患者主導のセルフタイトレーション**を教えると HbA1c も自己効力感も改善しうる
- 持効型で空腹時が整っても HbA1c が下がらなければ、**食後血糖が最も高い食事に超速効型1回（basal-plus）**を足す
- 頻回注射が難しい高齢者・介助例は **配合溶解または混合型の1日2回**。昼食後の上昇にはグリニド併用も選択肢
- 血糖が理由なく不安定なら、**注射部位の硬結（リポハイパートロフィー／インスリンボール）を触診**し、2〜3 cm ずつのローテーションを再指導
- 網膜症のある例で急速に血糖を改善させると**一時的な網膜症悪化**がありうる → 眼科フォローを確認
- 低血糖が気になる例では中間型より**持効型**、食直前に打てない例（シックデイ等）には**食事開始後20分以内に打てる新規超速効型**を考える
