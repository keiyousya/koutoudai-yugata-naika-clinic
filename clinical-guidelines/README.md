## 運用ルール

- **1資料 = 1ディレクトリ**、**1章 = 1ファイル**（`NN-slug.md`）を基本とする
- 各ファイル冒頭に **出典・版・発行日・確認日** を書く
- 原文の要約と、自院での運用メモ（「外来での使いどころ」など）は見出しを分けて区別する
- 改訂が出たら、旧版ディレクトリは残したまま新版ディレクトリを追加し、各領域 README の版情報を更新する
- 原文の転載はしない（要約・表の要点抽出にとどめ、原文 URL を必ず併記）
