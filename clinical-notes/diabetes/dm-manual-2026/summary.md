# 糖尿病標準診療マニュアル2026（一般診療所・クリニック向け）（自院メモ）

- **ガイドライン要約**: [diabetes/dm-manual-2026/summary.md](https://github.com/keiyousya/clinical-guidelines/blob/main/diabetes/dm-manual-2026/summary.md)

## ガイドライン2024 との違い・新しい点（自院メモ）

マニュアル2026 はガイドライン2024 の後に出たため、新しいエビデンスや他学会の改訂が入っている。

| 項目 | ガイドライン2024 | マニュアル2026 |
|---|---|---|
| 薬剤選択 | 病態に応じて選ぶ（学会アルゴリズム、固定の第一選択なし） | **メトホルミン → SGLT2i/DPP-4i/経口GLP-1RA** の固定ステップ。コスト・心腎エビデンス重視 |
| 経口セマグルチド | CVOT（PIONEER 6）は MACE 有意差なし（12章） | **SOUL（2025）で MACE 減少** → CVD既往・肥満で積極的に |
| 心不全スクリーニング | 年1回の胸部X線・心電図、症状・所見があれば BNP。コンサルトは BNP ≧100／NT-proBNP ≧400（12・14章。2020年コンセンサスに基づく旧値） | **年1回 BNP/NT-proBNP＋心電図を定期検査に**、**BNP ≧35／NT-proBNP ≧125 で循環器へ紹介**（心不全学会2023改訂の「前心不全または心不全の可能性」の下限） |
| 血圧 | 130〜139/80〜89 は生活習慣修正を1ヵ月以内（高血圧GL2019） | 130〜140/80〜90 は **3〜6ヵ月**生活習慣改善（**高血圧管理・治療GL2025** を参考図書に採用）。家庭血圧 <125/75 を明記 |
| メトホルミン | eGFR に応じた最大量 | 加えて **75歳以上は原則新規投与しない** |
| 腎症 | ACEI/ARB 下でアルブミン尿が残ればフィネレノン（CQ9-3❷） | 同じ（処方例と K・eGFR の中止基準まで具体化） |
| 脂質（EPA） | REDUCE-IT・JELIS を根拠に記載（12・15章） | **RESPECT-EPA（日本人、2024）でスタチン上乗せ効果なし・心房細動増加**を追加 |
| 網膜症 | – | **フェノフィブラートの進展抑制（LENS 2024、適用外）** |
| 肥満症治療薬 | – | ウゴービ／ゼップバウンドの適正使用、自由診療でのダイエット処方への警告 |

### 外来での使いどころ

- 日常の処方は**このマニュアルのステップと処方例を基本**にし、背景の考え方はガイドライン2024 で確認する
- 年1回の定期検査セット（眼底、UACR/UPCR、eGFR、足、神経、**心電図＋BNP/NT-proBNP**、口腔）を院内のルーチンにする
- BNP は2段階で扱う: **≧100（NT-proBNP ≧300）は心エコーを含め早期に循環器へ**。**35〜99（125〜299）は前心不全を含む「可能性あり」**なので、症状・心電図・腎機能・年齢と合わせて紹介するか経過をみるか判断し、SGLT2阻害薬の優先度を上げる
- 微量アルブミン尿は **4ヵ月ごと・3回中2回**で確定し、**SGLT2i → ACEI/ARB → フィネレノン**の順で腎保護を足す
- ACEI/ARB・MRA 開始後は **2週〜1ヵ月で K と eGFR**（eGFR 30%低下または K ≧5.5 で減量・中止）
- **HbA1c ≧9.0% が2回以上続く、インスリンや注射 GLP-1RA が必要 → 専門医へ紹介**
- SGLT2阻害薬を出すときは「**シックデイは休薬、手術3日前から休薬**、だるさ・吐き気は血糖が正常でも受診」をセットで説明
- ウゴービ・ゼップバウンドや GLP-1RA の自由診療ダイエット処方には関わらない
- **使用期限は2027-03-31**。2027年4月の改訂版で差分を確認する
