# 慢性甲状腺炎（橋本病）の診断ガイドライン

- **出典**: 日本甲状腺学会「甲状腺疾患診断ガイドライン2024」慢性甲状腺炎（橋本病）の診断ガイドライン
- **原文**: https://www.japanthyroid.jp/doctor/guideline/japanese.html
- **発行**: 2024-11-21 改定（2022-03 に「抗マイクロゾーム抗体」試薬の販売終了を受けて抗体項目を改定）
- **確認日**: 2026-10-01

位置づけ: **「橋本病」と「甲状腺機能低下症」は別の軸**。橋本病は自己免疫性甲状腺炎という病名で、そのうち機能低下症になるのは約1割。

---

## 定義

自己免疫性甲状腺炎。組織ではリンパ濾胞形成・濾胞上皮の変性・間質の線維化・リンパ球のびまん性浸潤を認める。

## 特記事項

- **原発性甲状腺機能低下症の原因として最も多い**
- 橋本病のうち**機能低下症になるのは約1割**

## 診断基準

| 区分 | 項目 |
|---|---|
| 臨床所見 | びまん性甲状腺腫大（萎縮のこともある） |
| 検査所見 | ① **TPOAb 陽性** ② **TgAb 陽性** ③ 細胞診でリンパ球浸潤 |
| 除外規定 | バセドウ病 |

| 判定 | 条件 |
|---|---|
| 確実例 | 除外規定を満たし、臨床所見 ＋ 検査所見1つ以上 |
| 疑い例 | 次のいずれか |
| | 1. 機能異常も甲状腺腫大もないが、TPOAb または TgAb 陽性 |
| | 2. 他に原因のない原発性甲状腺機能低下症 |
| | 3. 臨床所見 ＋ **エコーで内部エコー低下・不均質**（リンパ球浸潤を示唆） |

## 付記の要点

- 阻害型TRAbなどで**萎縮性**になることがある（甲状腺腫がなくても否定できない）
- **甲状腺リンパ腫**はまれだが、ほとんどが橋本病を背景に発生する

---

## 外来での使いどころ（自院メモ）

- 抗体は **TPOAb と TgAb の両方**を測る（片方だけ陽性の例がある）
- **抗体陽性・機能正常なら治療は不要**。患者には「甲状腺に炎症の体質があるが、ホルモンは足りている」と説明し、**年1回程度 TSH を測る**
- 妊娠を希望する女性で抗体陽性なら、妊娠前と妊娠初期の TSH 管理が大事になる（妊娠編の手引き・ATA 2026 にまとめる予定）
- **ヨウ素の過剰摂取（昆布・海藻の多食）で機能低下が出やすい**。昆布だしの常用・海藻サプリを聞く
- **甲状腺腫が急に大きくなる・硬くなる**ときはリンパ腫を考え、エコーと専門医への紹介を急ぐ
- 橋本病の経過中に無痛性甲状腺炎（一過性の中毒症）が起こりうる（[03-painless-thyroiditis.md](03-painless-thyroiditis.md)）
