# ATA 2016 甲状腺中毒症GL：潜在性甲状腺機能亢進症（[S]）

- **出典**: Ross DS, Burch HB, Cooper DS, et al. 2016 American Thyroid Association Guidelines for Diagnosis and Management of Hyperthyroidism and Other Causes of Thyrotoxicosis. *Thyroid.* 2016;26(10):1343–1421. doi:10.1089/thy.2016.0229 — 本ファイルは [S] 潜在性甲状腺機能亢進症（推奨73〜77、表10）
- **原文**: https://journals.sagepub.com/doi/10.1089/thy.2016.0229 （Open access。PMC には未収載）
- **発行**: 2016-08-12 オンライン公開、Thyroid 2016年10月号。2026-10 時点で後継版なし
- **確認日**: 2026-10-01

位置づけ: 国内では[バセドウ病治療GL2019 の BCQ25](../jts-graves-tx-gl2019/summary.md)が「TSH <0.1 が持続する高齢者・リスクあり」の1行だけで、**TSH 0.1〜基準下限の扱い**や**再検の間隔**、リスクの数字はない。ATA は **TSH <0.1 と 0.1〜基準下限の2段階 × 年齢・合併症**で治療適応を表にしている。推奨は「推奨n（強さ・エビデンスの質）」で付記（定義は [01](01-etiology-initial-evaluation.md)）。原文の転載はせず要点のみ。

## 1. 定義・頻度・原因（[S1]）

- **TSH 低値（または感度以下）で、FT4 と T3（総T3 か FT3）が基準内**
- 米国の甲状腺疾患のない集団で、**TSH <0.1 mU/L が 0.7%、<0.4 mU/L が 1.8%**。女性・高齢で多い
- **診断の前に除外するもの**: 外因性の甲状腺ホルモン、非甲状腺疾患（病気による一過性）、薬剤の影響、下垂体・視床下部疾患
- 黒人（非ヒスパニック）は TSH が全体に低めで、甲状腺疾患なしに軽く低いことがある。健康な高齢者の一部は TSH 低値・FT4/T3 低めで、**下垂体–甲状腺系の設定点の変化**と考えられる
- 原因: **中毒性多結節性甲状腺腫（TMNG）が最多、特に高齢者**。次いで**バセドウ病**（若年に多く、ATD 治療歴のある人にも多い）。単発の機能性結節、各種甲状腺炎（厳密には「潜在性甲状腺中毒症」）

### 自然経過

- 年率 **0.5〜7% が顕性へ進行**、**5〜12% が正常化**。1研究では5年以内の初回再検で **51.2% が自然に正常化**していた
- 顕性への進行は **TSH 感度以下（<0.01）の方が、低いが測定可能（0.01〜0.4）より多い**
- バセドウ病が原因の方が TMNG より自然寛解しやすい

### 再検のタイミング

- **合併症リスクが高い人: 2〜6週以内に TSH と FT4 を再検**
- それ以外: 治療を考える前に **3〜6ヵ月後に TSH を再検**して、持続していることを確認する

## 2. 臨床的意義（[S2]）

| 領域 | 原文の要点 |
|---|---|
| 総死亡 | 個人データのメタ解析（10コホート 52,674人）で **24%増** |
| 心血管死亡 | 2つのメタ解析で HR **1.52**・**1.29**。年齢・性・心疾患の有無で相対リスクは変わらないが、**TSH <0.1 の方が 0.1〜0.4 よりリスクが高い** |
| 心不全 | 特に高齢者と TSH がより低い人で増える。左室重量増加・左室機能低下は治療で改善 |
| **心房細動** | 60歳超で 2.8倍（Sawin 1994）。最大の研究（586,460人）では**相対リスクは若年で高いが、絶対リスクは高齢で桁違い**: 65歳未満女性 2.3/1000人年（RR 1.89）、65歳以上女性 22.7/1000人年（RR 1.27） |
| 脳卒中 | 50歳超で HR 3.39 の報告。メタ解析ではイベント数不足で結論なし |
| 骨 | 閉経後女性で骨密度低下（男性・閉経前女性では見られない）。13コホートのメタ解析で**大腿骨近位部骨折 HR 1.36、全骨折 HR 1.28**。**TSH <0.1 と内因性**でリスクが高い。ATD・RAI で骨密度改善の小規模報告 |
| 認知・気分 | 認知症との関連は研究で半々で結論なし。うつとは関連なし |
| 身体機能 | 4研究中3研究で関連なし |

- まとめ: **高齢者は不整脈とその後の脳卒中を防ぐために治療する根拠が強い**。若年者は相対リスクは上がるが絶対リスクが非常に低く、利益と害のバランスは不明 → 個別判断

## 3. いつ治療するか（[S3]）

| 推奨 | TSH | 対象 | 推奨度 |
|---|---|---|---|
| **73** | **<0.1 が持続** | **65歳以上**、心血管リスク因子・心疾患・骨粗鬆症、**エストロゲンやビスホスホネートを使っていない閉経後女性**、亢進症状がある → **治療する** | **強・中** |
| **74** | <0.1 が持続 | 上記の危険因子がない無症状の **65歳未満** → 治療を**考慮** | 弱・中 |
| **75** | **基準下限未満〜0.1以上が持続** | **65歳以上**、心疾患、骨粗鬆症、亢進症状 → 治療を**考慮** | 弱・中 |
| **76** | 基準下限未満〜0.1以上が持続 | 心疾患・骨粗鬆症のない無症状の **65歳未満** → **原因検索も治療もせず経過観察してよい** | 弱・低 |

### 表10の要点（治療するか）

| 因子 | TSH <0.1 | TSH 0.1〜0.4（0.4 を基準下限とした場合） |
|---|---|---|
| 65歳超 | 治療 | 治療を考慮 |
| 65歳未満で心疾患 | 治療 | 治療を考慮 |
| 65歳未満で骨粗鬆症 | 治療 | 治療を考慮 |
| 閉経後でエストロゲン・ビスホスホネートなし | 治療 | 治療を考慮 |
| 亢進症状あり | 治療 | 治療を考慮 |
| **65歳未満・無症状** | 治療を考慮 | **経過観察** |

- 「持続」とは **3〜6ヵ月にわたる繰り返しの測定で同じ範囲**にあること。これで一過性の甲状腺炎をほぼ除外できる
- 治療の前に**原因疾患を診断する**（多くは TMNG・バセドウ病・機能性腺腫）。0.1〜下限の範囲では特に、急性疾患・薬剤などによる一過性の TSH 低値を治療しないように
- TSH <0.1 の治療は、介入試験（対照群あり）がなく、心構造・心拍数・期外収縮・骨密度・筋力が改善したという小規模な非対照研究に基づく
- **若年で 0.1〜下限**: 治療は勧めないが、**6〜12ヵ月ごとに経過を見て、<0.1 に下がり続けたら治療を考える**
- 亢進症状がある人は、まず **β遮断薬を試して**、対症療法で足りるかを見てもよい

## 4. どう治療するか（[S4]・[S5]）

### 推奨77（強・低）

**治療するなら原因疾患に応じて、顕性亢進症と同じ原則で。**

- **多くは RAI が適切**、特に TMNG の多い高齢者。高齢者で RAI 前に ATD で正常化する利益のデータはなく、増悪のリスクが低いので ATD の害が上回るかもしれない
- **バセドウ病による潜在性**では、特に若年者で **ATD のコースも妥当**（軽症ほど寛解率が高い）
- 若年のバセドウ病による潜在性は**自然寛解もある**ので、**3〜6ヵ月ごとの機能検査で無治療経過観察**も妥当
- 持続的に TSH が低いが真の甲状腺機能異常の証拠がない一部の高齢者は、特に **FT4・総T3 が基準の下半分**なら無治療で追ってよい
- **β遮断薬だけで心血管の合併症（特に心房細動）を抑えられる**こともある
- 圧迫症状や悪性の懸念がある TMNG では手術も
- 治療の目標: **年齢に応じた基準範囲内の TSH**。治療の理由に応じて症状や骨密度を追う

## 外来での使いどころ（自院メモ）

### 国内資料との違い・補える点

| 論点 | ATA 2016 | 国内資料 |
|---|---|---|
| TSH <0.1 の治療適応 | 推奨73（強・中）: 65歳以上、心血管リスク・心疾患・骨粗鬆症、**エストロゲン/ビスホスホネートなしの閉経後女性**、症状 | [GL2019 BCQ25](../jts-graves-tx-gl2019/summary.md): 65歳以上、または65歳未満で心血管リスク・心疾患・骨粗鬆症・症状 → **ほぼ同じ**。ATA は閉経後女性を明記 |
| TSH <0.1・65歳未満・無症状 | **治療を考慮**（推奨74、弱・中） | 記載なし |
| **TSH 0.1〜基準下限** | **65歳以上・心疾患・骨粗鬆症・症状なら治療を考慮（推奨75）**、若年無症状は経過観察（推奨76） | 記載なし（[GL2019 まとめ](../jts-graves-tx-gl2019/summary.md)の自院メモで「経過観察が基本」） |
| 再検 | 高リスクは **2〜6週**、他は **3〜6ヵ月**で持続を確認。若年の 0.1〜下限は **6〜12ヵ月ごと** | 記載なし |
| 基準下限 | 表10は **0.4 mU/L** を下限として例示 | 国内のハーモナイズ後の基準範囲は **0.61〜4.23 mIU/L**（README）→ **当院では「0.1〜0.61」を ATA の「0.1〜下限」の帯として読む** |

### 当院での進め方

1. **FT4・FT3 正常で TSH だけ低い**ときは、まず除外: **LT4 服用（過量なら減量）**、最近の急性疾患、TSH を下げうる薬、下垂体疾患の手がかり、**ビオチン**（[01](01-etiology-initial-evaluation.md)）
2. **再検の時期**: 心疾患・心房細動・高齢でフレイル → **2〜6週**で TSH＋FT4。それ以外 → **3ヵ月後**（ATA は3〜6ヵ月）。一過性の甲状腺炎ならこの間に戻る
3. **持続していたら原因を調べる**: TRAb、エコー（結節の有無・血流）。結節があり高齢なら TMNG・機能性腺腫を考え、**シンチ目的で専門医へ**（治療の中心は RAI で、院内ではできない）
4. **治療適応の判断**（上の表）: 
   - TSH <0.1 持続 ＋（65歳以上 / 心疾患・心血管リスク / 骨粗鬆症 / 閉経後で骨の薬なし / 症状） → **治療する**。バセドウ病なら MMI（[04](04-graves-treatment.md)）、結節性なら紹介
   - TSH 0.1〜0.61 持続 ＋ 65歳以上・心疾患・骨粗鬆症・症状 → 治療を**相談**（弱い推奨）。まず原因検索と心電図・骨密度
   - 65歳未満・無症状・TSH 0.1〜0.61 → **6〜12ヵ月ごとに TSH**。<0.1 になったら再評価
5. 治療しない高齢者でも、**心電図で心房細動を確認**し、骨粗鬆症の評価をしておく。動悸・頻脈があれば β遮断薬で様子を見る選択肢もある
6. 若年のバセドウ病による潜在性は自然寛解がある → **3〜6ヵ月ごとに検査して経過観察**も可。本人の希望で MMI も可
7. 欧州の ETA 2015 潜在性甲状腺機能亢進症GL（README の一覧、未作成）も ATA と概ね一致すると ATA 本文に書かれている
