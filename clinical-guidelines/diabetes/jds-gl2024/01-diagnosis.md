構成は「診断 → 境界型の判定 → 病態評価 → 成因分類 → 病期併記」。外来で頻用するのは Q1-1〜1-3。

## Q1-1 糖尿病の診断をどのように行うか

### 糖尿病型の基準（いずれか1つ）

| 検査 | 基準 |
|---|---|
| 空腹時血糖 | ≧126 mg/dL |
| 75g OGTT 2時間値 | ≧200 mg/dL |
| 随時血糖 | ≧200 mg/dL |
| HbA1c | ≧6.5% |

### 糖尿病と診断できる3パターン

1. **糖尿病型を別日に2回確認**（1回は必ず血糖値）
   - HbA1c のみの反復では診断不可
   - **同一採血で血糖値と HbA1c がともに糖尿病型なら1回で診断可**
2. **血糖値が糖尿病型（1回）＋ 以下のいずれか**
   - 典型的症状（口渇・多飲・多尿・体重減少）
   - 確実な糖尿病網膜症
3. **過去に糖尿病と診断された証拠がある**（現在の値が基準以下でも糖尿病として対応）

### 診断できなかった場合

- 片方のみ糖尿病型 →「糖尿病疑い」とし、**3〜6ヵ月以内に血糖値・HbA1c の両方を再検査**
- 初回が HbA1c で判定 → 再検査に血糖値を含めることが必須
- 初回が随時血糖で判定 → 再検査は他の検査方法が推奨
- **診断に使う血糖値は静脈血漿のみ**。POCT・簡易血糖測定器・CGM は不可

### HbA1c と平均血糖が乖離しうる状況（表1）

| 方向 | 疾患・状況 |
|---|---|
| 高値 | 鉄欠乏状態、急速に改善した糖尿病 |
| 低値 | 急速に発症・増悪した糖尿病、鉄欠乏性貧血の回復期、溶血、肝硬変、透析、EPO治療中の腎性貧血、失血後、輸血 |
| 両方あり | 異常ヘモグロビン症 |

→ 該当時は必ず血糖値で診断する。

## Q1-2 高血糖状態をどのように判定するか

| 区分 | 空腹時血糖 | | 75g OGTT 2時間値 |
|---|---|---|---|
| 正常型 | <110 | かつ | <140 |
| 糖尿病型 | ≧126 | または | ≧200 |
| 境界型 | 上記いずれにも属さない | | |

※ 随時血糖 ≧200 も糖尿病型。

- **IFG**: 空腹時 110〜125（かつ 2時間値 <140）。ADA は 100〜125
- **IGT**: 2時間値 140〜199（かつ空腹時 <126）
- 糖尿病への進行リスク: **IFG/IGT ＞ IGT ＞ IFG**
- **正常高値**: 空腹時 100〜109。日本人コホートでは 101〜102 mg/dL 付近からリスク上昇 → OGTT が勧められる
- 動脈硬化性合併症は**境界型の段階から増加**。境界型には生活指導＋定期検査
- HbA1c 6.5% ≒ 空腹時 126 ≒ OGTT 2時間値 200
- HbA1c は NGSP 認証機器で測定。遠心後測定法では **EDTA 採血管推奨**（NaF 管は望ましくない）

### 75g OGTT の適応

- **強く推奨**: 空腹時 110〜125／随時 140〜199／HbA1c 6.0〜6.4%（明らかな症状がある者を除く）
- **望ましい**: 空腹時 100〜109／HbA1c 5.6〜5.9%／濃厚な家族歴や肥満がある者

### OGTT 実施手順

- 糖質150g以上の食事を3日以上 → 10〜14時間絶食 → 早朝空腹時に 75g ブドウ糖（225〜350 mL）を5分以内に服用
- 検査中は水以外摂取禁止・安静・禁煙
- 0分・120分は必須。**30分・60分値とインスリン値も測ると発症リスク評価に有用**（1時間値高値は進行しやすい）

## Q1-3 インスリン分泌低下とインスリン抵抗性の評価

### 分泌能

| 指標 | 式・基準 | 解釈 |
|---|---|---|
| インスリン分泌指数 | ΔIRI(30−0分, μU/mL) ÷ ΔPG(30−0分, mg/dL) | **≦0.4** で分泌低下。境界型でも進行しやすい。肥満で値が大きく変わる |
| 空腹時血中 CPR | <0.6 ng/mL | インスリン依存状態の可能性が高い |
| 24時間尿中 CPR | ≦20 μg/日 | 同上 |
| **CPI** | 空腹時CPR(ng/mL)×100 ÷ 空腹時血糖(mg/dL) | **0.8〜1.0以下でインスリン療法を要することが多い** |
| グルカゴン負荷 CPR | 1.0 mg 静注、5〜6分値 <1.0 または ΔCPR <0.5 | インスリン依存状態の目安 |
| disposition index | 分泌指標×感受性指標 | NGT/IGT の発症予測因子 |

- 診断確定後・薬物治療中はインスリン値ではなく **C ペプチドで評価**
- **腎機能低下時は血中CPR↑・尿中CPR↓** となり評価困難

### 抵抗性

| 指標 | 式・基準 |
|---|---|
| 空腹時インスリン | ≧15 μU/mL で抵抗性あり（内因性分泌低下例では無効） |
| **HOMA-IR** | 空腹時IRI × 空腹時血糖 ÷ 405。**≦1.6 正常、≧2.5 抵抗性あり**。血糖 >140 やインスリン治療中は不正確 |
| Matsuda index | 10000 ÷ √(FPG × FIRI × meanPG × meanIRI)。クランプ法とよく相関 |

※ 血糖降下薬使用下での各指標の精度は十分検証されていない。

## Q1-4 成因分類

1. **1型**（β細胞破壊）: A. 自己免疫性 / B. 特発性
2. **2型**（分泌低下主体〜抵抗性主体）
3. **その他の特定の機序・疾患**: A. 遺伝子異常 / B. 他疾患・条件に伴うもの
4. **妊娠糖尿病**

- 分類不能なものは「分類不能」。**1人が複数の成因を持つこともある**
- 家族歴、発症年齢と経過、体重歴、膵島関連自己抗体、HLA、分泌能／抵抗性、遺伝子検査を総合して判断
- **妊娠糖尿病（GDM）**: 75g OGTT で次の1点以上 → 空腹時 ≧92／1時間値 ≧180／2時間値 ≧153。分娩後に正常化しても将来の糖尿病リスクが高い（詳細は17章）

## Q1-5 1型糖尿病の診断（表3）

| | 急性発症 | 緩徐進行（SPIDDM） | 劇症 |
|---|---|---|---|
| ケトーシス | 症状出現後 約3ヵ月以内 | 診断時は原則なし | **約1週間以内**（初診時ケトーシスあり） |
| 自己抗体 | GAD/IA-2/IAA/ZnT8/ICA のいずれか陽性 | 経過中どこかで**陽性が必須** | 原則陰性 |
| 内因性分泌 | 抗体陰性でも空腹時CPR <0.6 なら急性発症と診断 | 診断後3ヵ月（典型6ヵ月）以降にインスリン必要、CPR <0.6 で確定 | 尿中CPR <10 μg/日、または空腹時CPR <0.3 かつ負荷後 <0.5 |
| その他 | Honeymoon period あり得る | 抗体陽性のみ → probable（≒LADA）、①②③を満たせば definite | 随時血糖 ≧288 **かつ HbA1c <8.7%**。膵酵素上昇98%、上気道・消化器症状70%以上 |

- 保険で測定可能: GAD抗体、IA-2抗体、IAA。**IA-2抗体は GAD抗体陰性時のみ**
- 緩徐進行型の基準は 2023年改訂版
- 2型として治療中に**他の要因なく血糖コントロールが悪化**したら、**血中CPR と GAD抗体を測定**
- **免疫チェックポイント阻害薬**で劇症／急性発症様1型が起こりうる → 事前説明と、高血糖症状出現時の即時連絡を指導

## Q1-6 遺伝子異常による糖尿病（表4）

- **MODY の特徴**: 常染色体顕性遺伝、通常35歳未満発症、著明な肥満歴なし、分泌低下

| 遺伝子 | 表現型 | 治療・特徴 |
|---|---|---|
| GCK | MODY（本邦最多） | 軽症、薬物療法不要が多い |
| HNF1A / HNF4A | MODY | **低用量SU薬が有効な例**。HNF1A は尿糖が出やすい |
| HNF1B | MODY | 早期インスリン必要が多い。腎嚢胞、膵尾部低形成、生殖器奇形 |
| KCNJ11 / ABCC8 | PNDM（最多） | **高用量SU薬でインスリン離脱可能な例が多い**。DEND症候群 |
| INS | NDM / まれに MODY | 早期インスリン |
| 6q24 | TNDM | 18ヵ月までに寛解、約80%が思春期以降に再発 |
| WFS1 | Wolfram症候群 | 若年発症糖尿病＋視神経萎縮、難聴、尿崩症など |
| mtDNA A3243G | ミトコンドリア糖尿病 | 母系遺伝、両側感音性難聴。約3年でインスリン必要。母が糖尿病の日本人糖尿病の約1% |
| INSR / PIK3R1 ほか | 遺伝的インスリン抵抗症 | 黒色表皮腫、多毛、SHORT症候群 |

## Q1-7 他の疾患・条件に伴う糖尿病（表5）

- **膵外分泌疾患**: 急性膵炎（可逆的）、慢性膵炎（グルカゴンも低下 → 血糖変動大・低血糖を起こしやすい・必要インスリン量少・DKA になりにくい）、自己免疫性膵炎（ステロイドで約半数改善）、膵癌
- **内分泌疾患**: Cushing症候群、先端巨大症、褐色細胞腫（α遮断・摘出で改善）、グルカゴノーマ（体重減少・舌炎・壊死性移動性紅斑）、甲状腺機能亢進症（oxyhyperglycemia）、アルドステロン症
- **肝疾患**: NAFLD/NASH、C型慢性肝炎、肝硬変（脾機能亢進で HbA1c 低値）
- **薬剤**: グルココルチコイド、非定型抗精神病薬、インターフェロン、免疫チェックポイント阻害薬
- **感染症**: 先天性風疹、CMV、コクサッキーB、ムンプス、EBV
- **遺伝的症候群**: Down、Turner、Klinefelter、Prader-Willi、Werner、筋強直性ジストロフィーなど

## Q1-8 病態（病期）分類

- **成因と病期は別の軸**であり、併記する
- インスリン作用不足の程度で3段階:
  1. インスリン不要
  2. 血糖コントロールのためにインスリン必要（**インスリン非依存状態**）
  3. ケトーシス予防・生命維持のためにインスリン必要（**インスリン依存状態**）
- **インスリン療法中 ≠ インスリン依存状態**
- 減量・代謝改善手術: 日本人で術後1年に薬なし HbA1c <6.5% 達成は59%。長期の栄養評価・耐糖能フォローが必要
- 一度糖尿病と診断されたら、改善しても糖尿病として扱う

## 外来での使いどころ（自院メモ）

- 初診は **空腹時（or 随時）血糖＋HbA1c を同一採血**で測る → 両方糖尿病型ならその日に診断
- **HbA1c 6.0〜6.4% または空腹時 110〜125 → OGTT を検討**
- インスリン導入に迷ったら **CPI ≦0.8〜1.0** を目安にする
- **理由なく悪化した2型 → GAD抗体**を測る
- **鉄欠乏・透析・肝硬変・貧血治療中は HbA1c を過信しない**
- 体重減少を伴う急な発症・悪化（特に高齢者）では膵癌も念頭に置く
