# 睡眠薬の適正な使用と休薬のための診療ガイドライン（2013）：位置づけ・治療アルゴリズム・休薬の流れ

- **出典**: 厚生労働科学研究・障害者対策総合研究事業「睡眠薬の適正使用及び減量・中止のための診療ガイドラインに関する研究班」（主任研究者 三島和夫、H24-精神-一般-004）および日本睡眠学会・睡眠薬使用ガイドライン作成ワーキンググループ（委員長 三島和夫）編「睡眠薬の適正な使用と休薬のための診療ガイドライン ―出口を見据えた不眠医療マニュアル―」
- **原文**: https://jssr.jp/files/guideline/suiminyaku-guideline.pdf （別URL https://www.jssr.jp/data/pdf/suiminyaku-guideline.pdf 。どちらも同じファイル、PDF 37頁）
- **発行**: 2013-06-25 初版、2013-10-22 改訂（PDF はこの改訂版）。2026-10 時点で後継版は出ていない（後述の改訂作業中）
- **確認日**: 2026-10-02

位置づけ: 日本で睡眠薬の**始め方だけでなく「やめ方（出口）」まで**を扱った最初の公的な指針。国内外の既存 GL が診断と急性期治療に偏り、中長期の使い方・休薬の指針がないことを問題として作られた。不眠医療の各段階で出会う**40 の CQ**に、患者向け解説と治療者向け勧告をつけている。エビデンスレベルは Oxford CEBM、推奨グレードは Minds（A〜D）で付け、一部は GRADE で評価した。**オンライン版（この PDF）は患者向け解説と勧告のみ**で、根拠となるエビデンスの解説と文献は省かれている。

**2013年版なので、オレキシン受容体拮抗薬（DORA）は一切載っていない**（スボレキサント＝ベルソムラ 2014年発売、レンボレキサント＝デエビゴ 2020年、ダリドレキサント＝クービビック 2024年）。登場する新薬はラメルテオン（ロゼレム）とエスゾピクロン（ルネスタ）まで。日本睡眠学会は改訂に取り組んでいることを公表しており（じほう報道。内村理事長の発言）、**2026-09 時点でも改訂作業中で公開時期は未定**（Medical Tribune 2026-09-10）。改訂版が出たら別ディレクトリで追加する。

原文の転載はせず要点のみ。CQ ごとの推奨とグレードは 02〜05 にまとめた。

## 1. 背景（緒言の要点）

- 成人の **30%以上**に何らかの不眠症状があり、**6〜10%**が不眠症
- 2009年の日本の一般成人の睡眠薬の**3か月処方率は 4.8%**（20人に1人）。50歳以上で多い
- 最も多く使われる**ベンゾジアゼピン（BZ）系のリスク・ベネフィット比は不良**とメタ解析で示されている
- 認知症・発達障害などでは、エビデンスが乏しいまま抗精神病薬などが適応外で使われている
- 長期服用での依存（耐性・離脱・高用量・多剤併用）や乱用が社会問題になっている一方、**日本人は睡眠薬への心理的抵抗が世界でも突出して強く、アドヒアランスが低い**（図2: 不安の1位は「依存性があり止められなくなる」43.5%。「安心できる服用期間」は「1週間以内」30.0%、「わからない」30.6%、「一回だけでも安心できない」20.9%）
- 投薬期間や休薬の指針がはっきりしないことがその一因

## 2. 推奨グレード（Minds 準拠、一部変更）

| グレード | 意味 |
|---|---|
| A | 強い科学的根拠があり、行うよう強く勧められる |
| B | 科学的根拠があり、行うよう勧められる |
| C1 | 科学的根拠はないが、行うよう勧められる |
| C2 | 科学的根拠がなく、**行うよう勧められない**（Minds 原典は「行わないよう勧められる」。本 GL で表現を弱めている） |
| D | 無効性あるいは害を示す科学的根拠があり、行わないよう勧められる |

エビデンスレベルは Oxford CEBM（1a: RCT の SR 〜 5: 専門家の意見）。

## 3. 不眠症の診断基準

DSM-IV-TR、ICD-10、ICSD-II のいずれか（原発性不眠症、精神生理性不眠症、その他の二次性不眠症など）。本文に示されているのは **ICSD-II の一般診断基準**:

| 項目 | 内容 |
|---|---|
| A | 入眠困難、睡眠維持困難（中途覚醒）、早朝覚醒、慢性的に回復感がない・睡眠の質が悪い、という訴え |
| B | 眠るのに適切な状況・環境があるのに、しばしば起こる |
| C | 夜間の睡眠困難に関連した**日中の機能障害**が1つ以上: 疲労・不快感／注意・集中・記憶の低下／日中の眠気／社会・職業・学業機能の低下／気分障害・いらいら／意欲・活動性の低下／仕事のミスや運転事故の起こしやすさ／睡眠不足による緊張・頭痛・消化器症状／睡眠についての心配 など |

→ **夜の症状だけでなく日中の機能障害（QOL 障害）があって初めて「不眠症」**。この考え方が、治療の要否判定とゴール設定（寛解の判断）の両方の軸になっている。

| 慢性期 | ④ 難治性（慢性）不眠への対応（増量・併用・代替薬・CBT-I） | Q24〜30 | [02](02-drug-choice-and-use.md)（Q24〜29）、[04](04-cbti-adverse-effects.md)（Q30） |

## 5. 治療アルゴリズム（図3）と応用指針①〜⑨

```
不眠の訴え
 └ ①症状把握（不眠症状の特徴＋日中の機能障害。過覚醒／リズム異常／恒常性異常を見分ける）
    └ ②治療の要否判定 ── 不要 → 治療終了（睡眠衛生指導）
       └ 要 → ③睡眠衛生指導 → ④リスク評価
             └ ⑤薬物療法 1)非BZ系 2)メラトニン受容体作動薬 3)BZ系 4)催眠・鎮静系抗うつ薬
                 ├ 有効 → ⑧維持薬物療法 →（寛解）→ ⑨休薬トライアル（漸減法／CBT-I併用法）
                 │                                ├ 休薬成功 → 治療終了（睡眠衛生指導）
                 │                                └ 再燃 → 維持薬物療法へ戻る
                 └ 無効・部分寛解 → ⑥認知行動療法（刺激制御法／睡眠制限法／漸進的筋弛緩法／認知療法）
                                     ├ 有効 → 維持療法 → 治療終了
                                     └ 無効 → ⑦不眠の再評価 → ①へ戻る
```

| 段階 | 要点 |
|---|---|
| ① 症状把握 | 入眠困難・中途覚醒・早朝覚醒の別に加え、**過覚醒**（不安・抑うつによる緊張）、**リズム異常**（夜型・睡眠相後退、夜勤）、**恒常性異常**（昼寝のしすぎで夜の睡眠ニーズが減る）を見分け、薬剤選択に反映する |
| ② 治療の要否 | 夜間症状と**日中の QOL 障害を能動的に聴き取る**。重症度と QOL 障害は相関しない。生理的な加齢変化による不眠で QOL 障害がなければ、本当に治療が要るか慎重に判断。一方で不眠は生活習慣病リスクの増大と結びつくので、合併症があれば留意 |
| ③ 睡眠衛生指導 | 表4（下記）を指導する |
| ④ リスク評価 | 処方前に**長期服用に陥りやすいハイリスク群か**評価する（下記） |
| ⑤ 薬物療法 | 入眠困難型には半減期の短い薬、睡眠維持障害型（中途覚醒・早朝覚醒）には半減期のより長い薬（Q1）。**入眠困難と維持障害の両方があっても、半減期の違う睡眠薬を併用する科学的根拠はなく副作用を増やしうる**。少なくとも初期は**単剤（用量調整）**で。**リズム異常にはメラトニン受容体作動薬が第一選択**。**昼寝過多（恒常性異常）にはまず睡眠衛生指導**。H1・α1/α2・5-HT2 遮断作用のある抗うつ薬など、作用機序の違う薬を病態に合わせて選ぶ |
| ⑥ 認知行動療法 | 状況が許す限り**薬物療法と同時に早期から**心理・行動的介入を使う。本 GL のアルゴリズムでは薬が奏功しないときのセカンドラインに置いたが、第一選択・併用でも有効と明記 |
| ⑦ 再評価 | 薬・CBT-I が効かなければ診断と治療抵抗要因を見直す。特に**睡眠状態誤認**（脳波上は眠っているのに眠れていないと感じる）は、訴えのままに増量すると高用量・多剤併用に陥る。確定は睡眠日誌＋PSG・アクチグラフだが、検査できなくても定型的治療で改善しなければ疑う。**多くの慢性不眠症患者は程度の差はあれ睡眠状態を誤認している**。むずむず脚症候群・周期性四肢運動障害・概日リズム睡眠障害・睡眠時無呼吸など**不眠症と誤診されやすい睡眠障害**も再検討し、改善しなければ専門医のセカンドオピニオンを勧める |
| ⑧ 維持療法 | 改善したら維持療法をどれだけ続けるか患者ごとに検討（ゴール設定、Q38）。減薬・休薬の前提は**不眠症状と QOL 障害の両方の改善＝寛解**。寛解から減薬開始までは**再燃リスクを下げるのに十分な期間**をおく。一部の患者では安全性に留意しつつ長期服用も許容 |
| ⑨ 休薬トライアル | 適切な時期に適切な方法で減薬・休薬を試みる。方法は 1) 漸減法 2) CBT-I 併用 3) 補助薬物療法 4) 心理的サポート（Q40） |

### ④ リスク評価の項目

| 区分 | 原文が挙げる要因 |
|---|---|
| 長期服用に陥りやすい（処方前に評価） | 不眠が重度、**抗不安薬（主に BZ）の服用・服用歴**、高齢、合併症、ストレス、薬物依存歴、**アルコールとの併用**、性格特性（受動的・依存的・慢性不安・心気的） |
| 減薬・休薬を難しくする | 服用中の睡眠薬が**高用量・多剤併用**、うつ病や器質性脳障害などの精神神経疾患、**掻痒・疼痛・頻尿**など睡眠を妨げる身体疾患 |

→ 専門科との連携、心理カウンセリング、環境調整が必要とされる。

### ③ 睡眠衛生指導（表4の要点）

| 項目 | 指導の要点 |
|---|---|
| 運動 | なるべく定期的に。適度な有酸素運動で寝つきやすく、睡眠が深くなる |
| 寝室環境 | 音・光の対策（じゅうたん、ドアを閉める、遮光カーテン）、快適な温度 |
| 食生活 | 規則正しく。**空腹で寝ない**（就寝前の軽い炭水化物は助けになることがある）。脂っこい物・胃もたれする物は避ける |
| 就寝前の水分 | 摂りすぎない（夜間のトイレを減らす）。脳梗塞・狭心症など循環に問題がある人は主治医の指示に従う |
| カフェイン | **就寝4時間前から**避ける（日本茶・コーヒー・紅茶・コーラ・チョコレートなど） |
| 寝酒 | 逆効果。寝つきは一時的に良くなるが、効果は弱まり、中途覚醒が増え深睡眠が減る |
| 喫煙 | 夜は避ける（ニコチンの覚醒作用） |
| 寝床での考え事 | 悩みや翌日の計画は寝床に持ち込まない |

## 6. 休薬の流れ（Q38〜40 と⑧⑨をつなげたもの）

本 PDF には休薬専用のフローチャートはなく、図3の「維持薬物療法 → 休薬トライアル」の枝と Q38〜40 の勧告が休薬の指針にあたる。つなげると:

1. **寛解の確認**: 夜の不眠症状が十分に消えている＋**日中の QOL 障害も改善**している（患者向けには「夜眠れている」「日中の心身の調子が良い」の2点がそろうこと）
2. **再燃リスクを下げる期間をおく**（具体的な期間は本 PDF に記載なし）
3. **ハイリスク患者の同定**（④の要因）、誤った睡眠習慣や心理・身体面の過覚醒から抜け出せているかの確認
4. **漸減法**（例: 1種類を **1/4錠ずつ減らし、1〜2週間みて問題なければさらに 1/4錠**）。2錠以上・2種類以上・長期服用の人はより緩やかに。CBT-I 併用・補助薬物療法・心理的サポートを組み合わせるほど成功率が上がる（Q40、グレードA）
5. **離脱症状と再燃を区別**: 離脱症状は短期間で消える。休薬後に悪化した不眠が持続すれば**再燃と考えて治療を再開**（維持療法に戻る）
6. 長期服用が必要な患者では、安全な長期服用も選択肢として許容しつつ、**継続の是非を常に判断し、可能な限り休薬をめざす**（「出口を見据えた治療」）

詳細は [05-goal-tapering.md](05-goal-tapering.md)。

## 外来での使いどころ（自院運用メモ）

- **この GL の価値は「出口」の考え方**。処方を始める時点で「寛解したら減らす」「寛解＝夜の症状＋日中の調子の両方」と患者に伝えておくと、のちの休薬が進めやすい。日本人は睡眠薬への不安が強い（図2）ので、初診時に「依存」「ぼける」「死ぬ」への答え（Q34〜36）を先に話しておく
- **薬の序列が現在の国内実態と合わない**: アルゴリズムは 1)非BZ 2)メラトニン受容体作動薬 3)BZ 4)催眠・鎮静系抗うつ薬 で、**DORA が無い**。2026年の国内外来では、依存・転倒・健忘・せん妄リスクが低いことから**DORA（デエビゴ・ベルソムラ・クービビック）を最初の候補にする処方が広く行われている**。当院は**デエビゴを在庫**しており、実際の第一選択はデエビゴになる。この GL の「非BZ を第一に、BZ は後回し」という BZ 回避の方向性はそのまま使えるが、DORA の位置づけ・用量・併用注意（CYP3A 阻害薬など）は**添付文書と新しい GL（ESRS 2023 など、[../esrs-european-gl2023/](../esrs-european-gl2023/)）で補う**
- **DORA が無いことで抜けている論点**: DORA の頓用・漸減の要否、DORA から/への切り替え、DORA の悪夢・翌朝の眠気、BZ からの置き換えの手順。いずれも本 GL では判断できない。改訂版（作業中）で扱われる見込み
- 夕方〜夜診療で**勤労世代・運転する人が多い**。Q9（翌朝の運転はグレードD）と Q6（追加頓用は起床6〜7時間前まで）は処方時に必ず説明する
