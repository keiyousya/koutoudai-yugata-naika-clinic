- **原文**: https://human-data.or.jp/wp-content/uploads/2026/03/dm_manual_2026.pdf
- **公開**: 2026-04-01（**使用期限 2027-03-31**。毎年改訂）
- **確認日**: 2026-09-13
- **参考図書**: 糖尿病治療のエッセンス2022、糖尿病治療ガイド2024、糖尿病診療ガイドライン2024、CKD診療GL2023、**高血圧管理・治療GL2025**、動脈硬化性疾患予防GL2022

位置づけ: 学会ガイドラインを一般クリニックで実践するための橋渡し。同クラス薬は「血管合併症・低血糖・体重のエビデンスの量と質」→「保険適用」の順で選び、処方例まで具体的に示す。クラスター RCT（SEAS-DM）で本マニュアルの使用が診療の質を改善したことが示されている。

## 1. 診断

| 状況 | 判定 |
|---|---|
| 血糖値（空腹時 ≧126／OGTT 2時間 ≧200／随時 ≧200）のいずれか **＋** HbA1c ≧6.5% | 糖尿病 |
| 片方のみ糖尿病型 | 糖尿病型 → **再検査（1ヵ月以内）**。HbA1c のみの反復では診断不可 |
| 血糖値が糖尿病型 ＋ 典型的症状または確実な網膜症 | 糖尿病 |
| 過去に上記を満たした記録 | 糖尿病（または疑いとして対応） |

- ストレスのない状態で高血糖を確認する
- 初回が HbA1c のみ → 再検査に血糖値が必須。初回が随時血糖 → 再検査は別の方法が望ましい
- HbA1c と血糖が乖離しうる状況では必ず血糖値で診断

## 2. 診療目的

合併症（細小血管症・動脈硬化性疾患）の発症・進展を阻止し、**糖尿病のない人と変わらない寿命と QOL** を実現する。

## 3. 病歴・診察・検査とタイミング

### 初診時

- **病歴**: 受診動機、健診・ドック結果、高血糖症状、合併症症状（視力低下、下肢しびれ、間欠性跛行、ED、無月経、発汗異常、便秘・下痢、足潰瘍）、**体重歴（最大体重・20歳頃）**、妊娠出産歴（巨大児・GDM）、高血圧・脂質異常・大血管症・歯周病、家族歴（母系遺伝など濃厚なら特殊型を疑う）、悪性腫瘍・心血管の家族歴、生活習慣、**過去の受診中断とその理由**
- **診察**: 内科診察＋**口腔内（歯周病）**、BMI（≧25 で肥満）、血圧、頸動脈雑音・腹部血管雑音・足背動脈、皮膚、**足**（爪周囲炎・角化・水疱）、神経所見
- **検査**: 血糖、HbA1c、空腹時脂質（LDL-C は推算または直接法）、電解質、BUN・eGFR、AST/ALT/γ-GTP、血算、検尿（糖・蛋白・ケトン体）
  - 推算 LDL-C ＝ TC −（TG÷5）− HDL-C（**TG ≧400 は実測**）
  - 1型（緩徐進行・劇症含む）を疑えば **抗GAD抗体**

### 合併症精査（初診時）

- **網膜症**: 眼科受診（**できる限り血糖降下薬開始前に**）
- **腎症**: 試験紙法陰性なら **UACR**、陽性なら **UPCR**
  - 微量アルブミン尿陽性なら **4ヵ月ごとに再検し、3回中2回以上陽性で早期腎症**
  - 随時尿で可。血糖管理不良時・運動直後・急性合併症・尿路感染時は避ける
- **神経障害**: 自覚症状、圧触覚（モノフィラメント）、痛覚、振動覚、腱反射、筋力・筋萎縮、関節変形・拘縮、起立性低血圧
- **大血管症**: 安静時心電図、**BNP または NT-proBNP**

### 糖尿病性腎症病期分類2023 と CKD 重症度分類

| GFR区分 | A1 正常アルブミン尿（UACR <30） | A2 微量（30〜299） | A3 顕性（≧300 または UPCR ≧0.50） |
|---|---|---|---|
| G1〜G3b（≧30） | 第1期 | 第2期 | 第3期 |
| G4〜G5（<30） | 第4期（GFR高度低下・末期腎不全期） | 同左 | 同左 |
| 透析・腎移植後 | 第5期（腎代替療法期） | | |

### 腎臓専門医への紹介基準（糖尿病、日本腎臓学会）

| GFR区分 | A1（UACR <30） | A2（30〜299） | A3（≧300） |
|---|---|---|---|
| G1（≧90） | – | 血尿＋なら紹介、蛋白尿のみなら生活指導・診療継続 | **紹介** |
| G2（60〜89） | – | 同上 | **紹介** |
| G3a（45〜59） | 40歳未満は紹介、40歳以上は生活指導・診療継続 | **紹介** | **紹介** |
| G3b〜G5（<45） | **紹介** | **紹介** | **紹介** |

- 上記以外に **3ヵ月以内に30%以上の腎機能悪化 → 速やかに紹介**

### 再診時

| 頻度 | 項目 |
|---|---|
| **毎回**（薬物開始・変更・追加後は **2〜4週後**、安定期は **2〜3ヵ月ごと**） | 症状、体重（BMI）、血圧、血糖、食事、運動、飲酒、喫煙、HbA1c（**貧血・透析ではグリコアルブミン**）、脂質 |
| 薬物治療中に適宜 | 血清K、腎機能、アルブミン、AST/ALT、CK |
| **最低1年ごと**（異常あれば頻回に） | 足診察、神経所見、eGFR（<60 なら血算も）、UPCR（試験紙陰性なら UACR）、**安静時心電図、BNP/NT-proBNP**、眼底検査、口腔ケア |

### 循環器専門医への紹介基準

- **BNP ≧35 pg/mL または NT-proBNP ≧125 pg/mL**（日本心不全学会ステートメント2023年改訂版）
- 可能な限り紹介・連携できる体制を取っておく

> **補足（本マニュアル外）**: 日本心不全学会ステートメント2023年改訂版の区分（原文 https://www.jhfs.or.jp/statement-guideline/statement20231017.html 、2026-09-13確認）。2013年版の BNP 40 → 35、NT-proBNP 400 → 300 に改訂されている。
>
> | BNP (pg/mL) | NT-proBNP (pg/mL) | 意味 |
> |---|---|---|
> | ≦18.4 | ≦55 | 潜在的な心不全の可能性は極めて低い |
> | 18.4〜<35 | 55〜<125 | 直ちに治療が必要な心不全の可能性は低い |
> | **35〜<100** | **125〜<300** | 心臓の構造的・機能的障害があり、**無症状の前心不全、または心不全の可能性** |
> | **100〜<200** | **300〜<900** | **心不全の可能性が高い**。心エコーを含む心機能評価を早期に行い原因検索 |
> | ≧200 | ≧900 | 近い将来に入院・死亡などのイベントが起こりうる高リスク心不全の可能性が高い |
>
> 腎機能低下・高齢で高くなり、肥満では低くなる点に注意。

## 4. 治療目標

絶対的な値ではなく個別に設定する。**高齢者に対するエビデンスはない**。緊急性がなければ十分な非薬物療法を行い、効果不十分なら薬物療法。

| 項目 | 目標 |
|---|---|
| 体重 | BMI ≧25 なら **5%以上の減量** |
| 血圧 | 診察室 **<130/80**（家庭 **<125/75**） |
| HbA1c | **<7.0%**（グリコアルブミン 約20%未満） |
| 空腹時血糖 | <130 mg/dL |
| LDL-C | **<120**。冠動脈疾患合併は **<100**。非心原性脳梗塞・PAD・CKD・メタボ・主要危険因子の重複・喫煙合併では **<70 を考慮** |
| 早朝空腹時TG | <150 |
| HDL-C | ≧40 |

### 個別化の例（過度の血糖低下で大血管症・死亡が増える可能性あり）

| 厳格（HbA1c <6.0%） | 寛容（HbA1c <8.0%） |
|---|---|
| 罹病期間 短 | 長 |
| 低血糖リスク 低 | 高 |
| 治療の害・負担 小 | 大 |
| 心血管合併症 なし | あり |
| 併発疾患 少・軽度 | 重度・致死的 |
| 余命 長 | 短 |

- J-DOIT3: 強化療法（HbA1c <6.2%、BP <120/75、LDL-C <80）と本マニュアルの標準治療で、8.5年の主要評価項目に有意差なし

## 5. 血糖の治療

### インスリンの適応（導入時は専門医へ紹介が望ましい）

- **絶対適応**: 1型、糖尿病昏睡・DKA、重症の肝障害・腎障害・感染症、妊娠（計画期・妊娠中・授乳期）
- **相対適応**: 高血糖症状、著明な高血糖（約300 mg/dL 以上）、尿ケトン体陽性、経口薬で管理不十分（**HbA1c ≧9.0%**）

### 血糖降下のスピード

- 急速な降下・低血糖を避ける。**網膜症あり、または長期間 HbA1c 高値の場合は眼科と連携して降下スピードを制御**（網膜症の早期悪化、治療後有痛性神経障害のリスク）

### 食事療法

- 管理栄養士による支援が有用
- 過体重・肥満ではエネルギー摂取制限。BMI ≧25 は **5%以上の減量**が目標
- **75歳以上**は現体重を基に、フレイル・ADL・併発症・体組成・身長短縮・摂食状況を評価して判断（総エネルギー量の推算式や三大栄養素比率のエビデンスはない）
- **6〜12ヵ月以内の短期なら炭水化物制限は有効**
- 不規則な食事は高血糖の一因

### 運動療法

- 歩行なら **1回15〜30分・1日2回（約8,000〜9,000歩/日）・週3日以上**。日常の活動量を増やすだけでも長期継続で効果
- レジスタンス運動も有効、有酸素運動と併用で相加効果
- 座位時間を長くせず、合間に軽い活動
- **運動の禁止・制限**: 空腹時血糖 ≧250、尿ケトン体陽性、眼底出血、腎不全、心疾患、骨・関節疾患、壊疽、急性感染症、高度の自律神経障害

### その他の生活支援

継続受診、お薬手帳・糖尿病連携手帳・糖尿病眼手帳の携帯、禁煙、減塩、フットケア、口腔ケア・歯周病管理、十分な睡眠、自己管理教育（保険適用外だが注射薬を使わない人でも SMBG は有用）、心理的サポート、**新型コロナ・インフルエンザ・肺炎球菌ワクチン**、がん検診・人間ドックの確認、**災害時の備え**（避難所への持参物）

### 治療の流れ（3〜6ヵ月ごとに病態と目標を見直す）

| ステップ | 内容 |
|---|---|
| 0 | インスリン適応があれば（各ステップでも考慮）→ **専門医へ紹介** |
| 食事・運動 | 数ヵ月内に反応がなければ薬物療法へ |
| **1: 単剤** | **A. ビグアナイド**（eGFR ≧30）。処方できなければステップ2から |
| **2: 1剤上乗せ** | **B. SGLT2阻害薬**（CVD既往・心不全・微量アルブミン尿/蛋白尿・肥満なら積極的に）／**C. DPP-4阻害薬**／**D. 経口GLP-1RA**（CVD既往・肥満なら積極的に） |
| **3: さらに1剤** | 別種のステップ2薬を追加、または C と D の切り替え。あるいはステップ3オプション（α-GI・SU/グリニド・チアゾリジン・イメグリミン）を1剤 |
| **4: さらに1剤** | 他の1剤を追加 |
| **5** | 多剤併用、インスリン、GLP-1RA 注射、GIP/GLP-1RA を考慮 → **専門医へ紹介** |

- 各ステップは少量から開始し適宜増量、数ヵ月で反応をみる。上乗せ前に**目標未達の原因を探す**（悪性腫瘍・感染症に特に注意）
- 反応あり → HbA1c <7.0% を目指して継続。**経口薬は可能な限り漸減・中止を目指す**
- **DPP-4阻害薬と GLP-1RA・GIP/GLP-1RA の併用は避ける**
- **HbA1c ≧9.0% が続けばインスリン導入を積極的に考慮**。配合剤は服薬実行度の改善に適宜利用

### 薬剤ごとの要点と処方例

**A. ビグアナイド**
- 最少量から開始。**eGFR <30 は禁忌**。**75歳以上には原則として新規投与を推奨しない**
- ヨード造影剤（血管内）・全身手術時は一時中止
  - eGFR <60 または不明: 造影 **48時間前〜48時間後**休薬（緊急時を除く）。腎機能悪化が懸念されれば eGFR を確認してから再開
  - eGFR ≧60: **造影当日〜48時間後**休薬
- 経口摂取困難・寝たきりなど全身状態不良には投与しない。利尿薬・SGLT2阻害薬との併用は脱水に注意。過度の飲酒を避ける
- 長期服用で原因不明の貧血・神経障害 → **ビタミンB12 測定**、低値なら補充
- 処方例: **メトホルミン 500 mg 分2 〜 2,250 mg 分3**。最大量は eGFR 45〜60: 1,500 mg、30〜45: 750 mg

**B. SGLT2阻害薬**
- 最少量から開始。**eGFR <15 では新規開始しない**（継続中に <15 になれば副作用に注意して継続）。透析例には使わない（eGFR <20 での開始はエビデンスなし）
- CVD既往・心不全・微量アルブミン尿/蛋白尿・肥満では積極的に開始してよい
- 1型への使用はケトアシドーシスのリスクがあり専門医紹介が望ましい
- インスリン・SU薬併用時はそれらを減量し、低血糖教育を行う
- **75歳以上、または65〜74歳で老年症候群（サルコペニア・認知機能低下・ADL低下）あり → 慎重投与**
- 脱水対策を患者にも説明。**シックデイは必ず休薬。手術は3日前から休薬**し、食事が十分摂れてから再開
- 倦怠感・悪心嘔吐・体重減少があれば血糖が正常近くでも **正常血糖ケトアシドーシス**を疑い尿・血中ケトン体を確認（ステロイド併用中は特に注意）。極端な糖質制限はケトーシスを助長
- 皮疹は速やかに中止し皮膚科へ。フルニエ壊疽に注意。尿路・性器感染は問診・検査で見つけ泌尿器科・婦人科へ
- 処方例: **エンパグリフロジン 10〜25 mg 分1**／**カナグリフロジン 100 mg 分1**／**ダパグリフロジン 5〜10 mg 分1**

**C. DPP-4阻害薬**
- 腎機能に応じた通常量から開始。高齢者・腎機能低下者は SU 併用で低血糖に注意。**SU服用中に追加するときは SU を半減**
- 水疱性類天疱瘡・SJS・横紋筋融解症・間質性肺炎を疑えば中止

**D. 経口GLP-1受容体作動薬**
- **3 mg から開始 → 4週以上後に 7 mg → 効果不十分なら 4週以上後に 14 mg**。14 mg の代わりに 7 mg 錠を2錠使わない
- 服用直前にシートから出す。**空腹時に水 約120 mL 以下で服用し、30分は飲食・他剤を避ける**
- DPP-4阻害薬と併用しない。CVD既往・肥満では積極的に開始してよい
- 処方例: **セマグルチド（リベルサス）3〜14 mg 分1**
- 根拠に **SOUL 試験（NEJM 2025）**: 心血管ハイリスク2型で経口セマグルチドが MACE を有意に減少

**肥満症治療薬の適正使用**
- 2型糖尿病治療薬の GLP-1RA・GIP/GLP-1RA を美容・痩身・ダイエット目的に自由診療で処方するのは**適応外**
- **ウゴービ・ゼップバウンド**は最適使用推進ガイドラインと日本肥満学会ステートメントを遵守。不適切な広告・処方を厳に戒める

**E〜H. ステップ3のオプション**

| 薬剤 | 注意点 | 処方例 |
|---|---|---|
| α-GI | 最少量から。低血糖時は**ブドウ糖** | アカルボース 150〜300 mg 分3 毎食直前 |
| SU薬 | 最少量から。低血糖は高齢・腎障害・長時間作用型（グリベンクラミド、グリメピリド）で起こりやすい。**意識障害を伴う低血糖は必ず入院可能な施設へ**。**SUとグリニドの併用は不可** | グリクラジド 20 mg 分1〜80 mg 分2／グリメピリド 0.5 mg 分1〜2 mg 分2 |
| グリニド | 腎機能低下・高齢で低血糖が心配ならグリクラジドかグリニドを少量から | レパグリニド 0.75〜1.5 mg 分3 毎食直前 |
| チアゾリジン | 体重増加・浮腫に注意し最少量から。発癌リスクの可能性を説明。メトホルミン併用で体重増加は軽減 | ピオグリタゾン 15〜30 mg 分1 |
| イメグリミン | **eGFR <10（透析含む）は投与しない**。ビグアナイド併用で消化器症状が多い | 2,000 mg 分2。eGFR 15〜45: 1,000 mg 分2、10〜15: 500 mg 分1 |

### 低血糖・シックデイ

- 低血糖（≦70、または 70〜90 でも典型的症状）が頻繁なら**薬剤を逆順に減量**。単独で重症低血糖の原因になりうるのは特に **SU薬とインスリン**
- **重症低血糖が一度でも起きたら直ちに連絡**するよう指示し、速やかに来院させて減量・中止
- シックデイ（発熱・嘔吐などで摂食量が減る）は必ずかかりつけ医に連絡するよう普段から指示
- インスリン治療中: 普段の半量くらい食べられれば**食前の速効型/超速効型も半量**。自己判断で中止せず、**持効型は通常量**。それ以下の摂食なら輸液が必要なので受診

## 6. 合併症・併存症の治療

### 網膜症
- 眼科と密接に連携し、正常でも**少なくとも年1回**精査
- 厳格な血糖・血圧・脂質管理が発症・進行予防、軽症網膜症の改善に有効
- フェノフィブラートが初期網膜症の進展を抑制した RCT あり（LENS、NEJM Evid 2024、**保険適用外**）

### 腎症
- 厳格な血糖・血圧管理が発症進展阻止、軽症の寛解に有効
- 微量アルブミン尿・蛋白尿があれば **SGLT2阻害薬を積極的に**（eGFR <15 では新規開始しない）
- 腎症＋高血圧は **ACEI または ARB**。**両者の併用は効果がなく高K血症のリスク**。アリスキレンとも併用しない
- ACEI/ARB 開始・増量後は **2週〜1ヵ月以内に eGFR と K**。**eGFR が前値の30%以上低下、または K ≧5.5** なら減量・中止
- 処方例: エナラプリル 5〜10 mg／イルベサルタン 50〜200 mg／ロサルタン 50〜100 mg（ロサルタンは糖尿病性腎症に保険適用あり）
- **ACEI/ARB でも微量アルブミン尿・蛋白尿が続けば、非ステロイド型 MRA（フィネレノン 10〜20 mg 分1）を考慮**。開始・増量後1ヵ月以内に eGFR と K、中止基準は上と同じ
- **eGFR <45**: 塩分 6 g/日以下、K 2 g/日以下、蛋白 0.8〜1.0 g/kg/日、重労働を避ける
- SGLT2阻害薬の保険適用: カナグリフロジンは糖尿病性腎症、ダパグリフロジン・エンパグリフロジンは糖尿病の有無にかかわらず CKD と心不全

### 神経障害（有痛性の対症療法、いずれも最少量から、単独または併用）

| 分類 | 処方例 |
|---|---|
| 神経障害治療薬 | プレガバリン 150〜600 mg 分2 |
| 抗うつ薬 | デュロキセチン 20〜60 mg 分1／アミトリプチリン 10〜150 mg 分1 眠前（**開始前に心電図で QTc 延長がないことを確認**） |
| 抗てんかん薬 | カルバマゼピン 200〜800 mg 分1〜2 |

### 血圧

- **130〜140/80〜90**: **3〜6ヵ月**生活習慣改善と減塩（原則 6 g/日以下）。安定して <130/80 にならなければ降圧薬
- **≧140/90**: 生活習慣改善と同時に降圧薬
- 第一選択: **ACEI・ARB・Ca拮抗薬・サイアザイド系類似利尿薬**。微量アルブミン尿・蛋白尿があれば ACEI か ARB
- 高齢者は明確なエビデンスがなく、起立性低血圧（多くは無症状）に注意して過度の降圧を避ける

| 薬剤 | 要点 | 処方例 |
|---|---|---|
| ACEI/ARB | 開始後 2週〜1ヵ月で eGFR・K。併用しない。**冠動脈疾患合併でも第一選択、心不全合併は ACEI を優先** | エナラプリル 5〜10 mg／ロサルタン 50〜100 mg |
| サイアザイド系類似利尿薬（少量） | **eGFR <30 はループ利尿薬** | インダパミド 0.5〜1 mg |
| 持続型ジヒドロピリジン系Ca拮抗薬 | | アムロジピン 2.5〜5 mg |

### 脂質

- **高LDL-C**: 生活習慣改善で数ヵ月内に目標に届かなければ**スタチン**。届かない・使えない場合はエゼチミブやレジンを併用または単独
  - 処方例: ピタバスタチン 1〜4 mg 分1 朝食後（糖尿病リスクを増やさないというデータあり）
- **高TG**: 生活習慣改善でも **≧400 が持続すれば膵炎予防にフィブラート**（大血管症予防のエビデンスは乏しい）
  - スタチンとの併用は横紋筋融解症リスクが上がり、併用意義も認められていない → その場合は **多価不飽和脂肪酸製剤**を考慮
  - 処方例: ペマフィブラート 0.2 mg 分1（eGFR <30 は減量・投与間隔延長）／イコサペント酸エチル 1,800 mg 分3
  - 引用: PROMINENT（ペマフィブラートで心血管イベント差なし）、**RESPECT-EPA（日本人、スタチンへの EPA 上乗せで心血管イベント有意差なし、心房細動は有意に増加）**
- **低HDL-C**: 運動不足の解消と禁煙を支援

## 7. 糖尿病専門医・拠点病院への紹介

- 1型、妊娠、二次性糖尿病
- 急性合併症: DKA、高血糖・低血糖による意識障害、中等症以上の感染症
- **HbA1c ≧9.0% が2回以上、または断続的に持続**
- 頻回低血糖など管理不安定
- CGM（持続皮下グルコース測定）目的
- **インスリン（ポンプ含む）、GLP-1RA 注射、GIP/GLP-1RA の導入**
- 合併症・冠動脈疾患・PAD・足病変のハイリスク者の詳細な評価（頸動脈エコー、ABI/PWV、腹部エコーなど）と治療
- 治療抵抗性の高血圧・脂質異常症・肥満症
- 悪性腫瘍の精査
- 自己管理支援、フットケア、教育入院

## ガイドライン2024 との違い・新しい点（自院メモ）

マニュアル2026 はガイドライン2024 の後に出たため、新しいエビデンスや他学会の改訂が入っている。

| 項目 | ガイドライン2024 | マニュアル2026 |
|---|---|---|
| 薬剤選択 | 病態に応じて選ぶ（学会アルゴリズム、固定の第一選択なし） | **メトホルミン → SGLT2i/DPP-4i/経口GLP-1RA** の固定ステップ。コスト・心腎エビデンス重視 |
| 経口セマグルチド | CVOT（PIONEER 6）は MACE 有意差なし（12章） | **SOUL（2025）で MACE 減少** → CVD既往・肥満で積極的に |
| 心不全スクリーニング | 年1回の胸部X線・心電図、症状・所見があれば BNP。コンサルトは BNP ≧100／NT-proBNP ≧400（12・14章。2020年コンセンサスに基づく旧値） | **年1回 BNP/NT-proBNP＋心電図を定期検査に**、**BNP ≧35／NT-proBNP ≧125 で循環器へ紹介**（心不全学会2023改訂の「前心不全または心不全の可能性」の下限） |
| 血圧 | 130〜139/80〜89 は生活習慣修正を1ヵ月以内（高血圧GL2019） | 130〜140/80〜90 は **3〜6ヵ月**生活習慣改善（**高血圧管理・治療GL2025** を参考図書に採用）。家庭血圧 <125/75 を明記 |
| メトホルミン | eGFR に応じた最大量 | 加えて **75歳以上は原則新規投与しない** |
| 腎症 | ACEI/ARB 下でアルブミン尿が残ればフィネレノン（CQ9-3❷） | 同じ（処方例と K・eGFR の中止基準まで具体化） |
| 脂質（EPA） | REDUCE-IT・JELIS を根拠に記載（12・15章） | **RESPECT-EPA（日本人、2024）でスタチン上乗せ効果なし・心房細動増加**を追加 |
| 網膜症 | – | **フェノフィブラートの進展抑制（LENS 2024、適用外）** |
| 肥満症治療薬 | – | ウゴービ／ゼップバウンドの適正使用、自由診療でのダイエット処方への警告 |

### 外来での使いどころ

- 日常の処方は**このマニュアルのステップと処方例を基本**にし、背景の考え方はガイドライン2024 で確認する
- 年1回の定期検査セット（眼底、UACR/UPCR、eGFR、足、神経、**心電図＋BNP/NT-proBNP**、口腔）を院内のルーチンにする
- BNP は2段階で扱う: **≧100（NT-proBNP ≧300）は心エコーを含め早期に循環器へ**。**35〜99（125〜299）は前心不全を含む「可能性あり」**なので、症状・心電図・腎機能・年齢と合わせて紹介するか経過をみるか判断し、SGLT2阻害薬の優先度を上げる
- 微量アルブミン尿は **4ヵ月ごと・3回中2回**で確定し、**SGLT2i → ACEI/ARB → フィネレノン**の順で腎保護を足す
- ACEI/ARB・MRA 開始後は **2週〜1ヵ月で K と eGFR**（eGFR 30%低下または K ≧5.5 で減量・中止）
- **HbA1c ≧9.0% が2回以上続く、インスリンや注射 GLP-1RA が必要 → 専門医へ紹介**
- SGLT2阻害薬を出すときは「**シックデイは休薬、手術3日前から休薬**、だるさ・吐き気は血糖が正常でも受診」をセットで説明
- ウゴービ・ゼップバウンドや GLP-1RA の自由診療ダイエット処方には関わらない
- **使用期限は2027-03-31**。2027年4月の改訂版で差分を確認する
