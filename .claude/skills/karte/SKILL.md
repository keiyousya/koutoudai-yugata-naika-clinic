# カルテ記載・傷病名整理（helix 電子カルテ）

対象: $ARGUMENTS

診療が終わった日のカルテを、医師（田村慧人）と会話しながら1件ずつ仕上げる作業。
**臨床判断は必ず医師に聞く。カルテに書く内容を勝手に作らない。**

## 対象画面

受付一覧（対象日で絞る）:

```
https://koutoudai-yugata-naika.helix.keiyousya.com/reservations?page=1&pageSize=20&sortBy=preferred_time&sortDirection=asc&dateFrom=2026-09-20&dateTo=2026-09-20
```

- Chrome はログイン済みの前提。`navigate` の前に `tabs_context_mcp` で既存タブを確認する
- 患者カルテ: `https://koutoudai-yugata-naika.helix.keiyousya.com/medical-records/<カルテID>?openInsurance=false&openReservation=false`
  - カルテIDは受付一覧で患者名をクリック → 詳細ダイアログのヘッダー（`P0TLNT02_1ILBC_H` の形式）から取れる
  - 詳細ダイアログの「カルテを開く」でも開けるが、同じタブで遷移する

### ステータスの絞り込み

ページを開き直すと ステータス が初期値に戻り「0件」になることがある。
その場合は ステータス のドロップダウンを開いて **全選択**。`status=scheduled,arrived,awaiting_consultation,in_consultation,billing_confirmed,paid,cancelled` を URL に付けておくと安定する。

**キャンセルの行はカルテ対象外**。「全◯件」には入るので、残り人数を数えるときは除く。

## 進め方

1〜3人分のタブを同時に開き、tabId を指定して並行操作してよい（医師から「◯人ずつ進めて」と言われる）。
1人あたりの流れ:

1. `get_page_text` でカルテ全体（看護記録 受付シート＋医師記録）を読む
2. ヘッダーの「傷病名」から傷病名管理を開いて現状を確認する
3. **空欄と問題点を箇条書きでチャットに出し、埋める案を提示する**
4. 医師の返事（臨床情報）をもらってから、傷病名 → カルテの順に入力する
5. 版が上がったこと（例: 01版 → 02版）を確認して次の患者へ

### 医師に出す報告の型

```
**山谷 明子（000801・48歳）**
- カルテ記載あり：現病歴／O（flu/cov −）／P（トラネキサム酸、アセトアミノフェン）／処方区分 院内処方
- 空欄：**＃・主訴・A**
- 病名：発熱／インフルエンザの疑い／ＣＯＶＩＤ－１９（確定）← 陰性なら確定はおかしい。主病もなし
- 提案：ＣＯＶＩＤ－１９を「の疑い」に修正／★急性咽頭炎（9/20・主病）を追加
  ＃急性咽頭炎／主訴「咽頭痛 頭痛 発熱」／A「flu/cov陰性 局所所見乏しく急性咽頭炎として対症療法」
```

推測した箇所は推測だと明示する。検査していない所見（触診・聴診など）を勝手に書かない。

## 傷病名の決まり

- **レセプト上、主病（★）が必須**。疑い病名だけの患者には確定病名か症状名を主病として足す
- 検査で否定された疑い病名は転帰「中止」。終了日は作業日が自動で入るので**診療日に直す**
- 診療開始日も作業日が既定。**必ず診療日に直す**（医師が後日まとめて登録した病名は翌日付になっていることが多い。過去分も点検する）
- 自費診療（予防投与など）には病名を登録しない
- 病名マスタに無い名前は、近い標準病名を提示して確認を取る
  - 淋菌感染症 →「淋病」／頸部痛 →「頚部痛」／膣カンジダ症 →「腟カンジダ症」／急性細菌性前立腺炎 はそのまま存在する

### 傷病名管理ダイアログの操作

- ヘッダーの「傷病名」ボタン。**座標で押さない**（患者名の長さでボタン位置がずれる）。`find` で拾う
- 1回目のクリックはフォーカスが当たるだけでダイアログが開かないことがある。開いたか必ず確認する
- 新規登録: 「新規登録」→ 傷病名を検索 → マスタから選択 → 診療開始日（カレンダー）→ 転帰（継続／治癒／死亡／中止）→ 主病チェック → 登録
- 既存の行は右端の `⋯` から 編集／転帰設定／主病に設定／削除
- 疑い病名にするには、修飾語に「の疑い」を追加して更新する
- **主病のチェックは1回では入らないことが多い**。登録前に zoom で入ったことを確認する
- カレンダーの日付も押し間違えやすい。選択後に zoom で確認する
- 登録直後は「同期中」だが、しばらくすると「同期済」になる（ORCA連携）

## カルテ記載の操作

- 編集は記録カードを**ダブルクリック**。右パネルの見出しが「**診療記録を編集**」になったことを確認する
  - 「新しい診療記録を作成」のまま入力すると新規カルテができてしまう。気づいたら「リセット」→ OK、またはカードをダブルクリック →「新規カルテを破棄」→ OK
  - ダイアログを閉じた直後の1回目のダブルクリックは効かないことが多い。効かなければもう一度押す
- **既存記録の編集モードでは 診療日 欄は無効化**され、元の記録日時のまま。空欄に見えても触らなくてよい
- 新規にカルテを作る場合（再診でカルテが無いなど）は、**診療日を作業日から診療日に直す**
- **「検査結果」ボタンは未実装。押さない**
- お薬手帳は受付シートの画像サムネイルをクリックすると PDF ビューアで開く。他院処方が分かるので 内服・既往歴 に反映する

### 入力欄の扱い

- `ctrl+End` はキャレットが**先頭に飛ぶ**。追記のつもりが冒頭に入る
- 追記も修正も、**欄をクリック → `ctrl+a` → `Delete` → 全文を打ち直す**のが安全。医師の原文はそのまま残す
- 改行は `Return` キー。`type` に `\n` を混ぜない

### 漢字化け（必ず確認する）

`type` で一部の漢字が別字に化ける。入力後に zoom で確認し、化けたら別表記に書き換える。

| 打ちたい字 | 化ける例 | 回避 |
|---|---|---|
| 腺（前立腺肥大症） | 腰 | `BPH` |
| 頓（頓用） | 頑 | `発熱時に内服` |
| 錠 | 錐 | `1T` |
| 寒（寒気） | 實 | `悪寒` |
| 腟 | 腿 | 都度確認 |

## 記載の型

| 欄 | 書くこと |
|---|---|
| ＃ | `＃急性咽頭炎` のようにプロブレム名。病名と揃える |
| 主訴 | 患者の言葉に近い症状を全角スペース区切り（`咽頭痛　頭痛　発熱`） |
| 現病歴 | 発症時期・経過・周辺流行・前医処方 |
| 既往歴 | 他院加療中の疾患。お薬手帳から推定した場合は `（他院加療中　お薬手帳より）` と根拠を書く |
| 内服 | `（お薬手帳）` の行に続けて `医療機関名：薬剤 用量 1T、… 朝食後` |
| O | 身体所見と検査結果（`flu/cov −`、`BP 148/89mmHg HR73`）。**やっていない診察を書かない** |
| A | 診断の根拠 → 治療方針 → フォロー（`症状増悪・遷延時は再受診`）の順で1行ずつ |
| P | 処方薬と日数（`オセルタミビル`／`アセトアミノフェン５回分`） |
| 処方区分 | 院外処方／院内処方／院外・院内処方 併用／処方なし |

### 処方区分の決め方

- 既定は**院内処方**
- 院内在庫がない薬（吸入薬など）は**院外処方**
- 手持ちの薬で対応してもらった場合は**処方なし**
- 迷ったら医師に聞く

## 終わったら

- 版が上がったことを確認する（`02版 2026/09/24 13:17 更新: 医師）田村 慧人`）
- タブを閉じて次の患者へ
- 最後に、その日の全患者について「誰に何をしたか」を一覧でまとめて報告する
