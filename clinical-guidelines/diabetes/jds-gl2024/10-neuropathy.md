## Q 10-1 糖尿病性神経障害をどのように診断するか

- **ポイント**
  - 最も多い合併症のひとつ。**診察時は定期的に評価**する
  - 自覚症状＋痛覚・振動覚などの知覚機能＋アキレス腱反射で簡易診断。異常は**遠位優位かつ対称性**でなければならない
  - **神経伝導検査は確定診断に必須**、無症候性を含めた早期診断に有効
  - **心拍変動検査（CVR-R）** は自律神経障害の簡便で有効な評価法

### 除外すべき他疾患（問診・検査）

- 家族歴、**アルコール摂取量**、**胃切除術の既往（ビタミン B12 欠乏）**
- **甲状腺機能低下症** → 甲状腺ホルモンを一度は評価
- 比較的急速な進行 → **CIDP** など他の神経疾患を考慮

### 表1-a 糖尿病性多発神経障害の簡易診断基準（糖尿病性神経障害を考える会、2002年1月18日改訂）

- **必須項目**（2項目とも満たす）
  1. 糖尿病が存在する
  2. 糖尿病性多発神経障害以外の末梢神経障害を否定し得る
- **条件項目**（3項目中 **2項目以上** で「神経障害あり」）
  1. 糖尿病性多発神経障害に基づくと思われる自覚症状
  2. **両側アキレス腱反射の低下あるいは消失**
  3. **両側内踝の振動覚低下（C128 音叉で10秒以下）**
- **自覚症状の条件**: (1) 両側性、(2) 足趾先および足底の「しびれ」「疼痛」「異常感覚」、(3) **上肢のみの症状は取らない**
- **参考項目**（いずれかを満たせば条件項目を満たさなくても神経障害あり）
  1. 神経伝導検査で **2つ以上の神経**でそれぞれ1項目以上（伝導速度・振幅・潜時）の異常
  2. 臨床的に明らかな糖尿病性自律神経障害（自律神経機能検査で確認が望ましい）

### 表1-b Toronto Diabetic Neuropathy Expert Group の診断基準（DSPN）

| 診断 | 項目 | 適用 |
|---|---|---|
| **Possible**（可能性あり） | 自覚症状（両側足趾・足・下肢中心の知覚低下 or 陽性症状: ジンジン・チクチク・刺す・ヒリヒリ・うずく痛み）**あるいは**他覚所見（遠位対称性の知覚低下、両側アキレス腱反射の明白な低下・消失） | 臨床 |
| **Probable**（ほぼ確実） | ①神経障害性自覚症状 ②遠位側の知覚低下 ③両側アキレス腱反射の明白な低下・消失 のうち **2つ以上** | 臨床 |
| **Confirmed**（確定） | **神経伝導異常**＋1つ以上の自覚症状 or 他覚所見。伝導正常なら小径線維障害の有効な評価法（class 1）を用いてよい | 臨床・研究 |
| **Subclinical**（潜在性） | 症状・所見なし、神経伝導異常 or 小径線維評価法（神経生検・皮膚生検・角膜共焦点顕微鏡）の異常 | 研究 |

DSPN: chronic, symmetrical, length-dependent sensorimotor polyneuropathy

### 検査

| 評価対象 | 方法 |
|---|---|
| 知覚機能 | アキレス腱反射、**音叉による振動覚**、**モノフィラメントによる圧触覚**、爪楊枝・竹串による痛覚 |
| 自律神経 | 心電図 **CVR-R** |
| 確定診断 | **神経伝導検査**（異常あれば糖尿病性神経障害と診断可） |
| 早期（小径線維） | 皮膚生検で表皮内神経線維密度低下があれば存在すると考えてよい |

### 評価頻度・重症度

- **軽症者: 半年〜1年間隔**。下肢痛覚低下や自律神経症状が明らかな進行例はさらに頻度を上げる
- 重症度診断にコンセンサスを得た基準はない
- 経過の傾向: **知覚低下が先行 → 自律神経障害 → 筋力低下・筋萎縮**
- 自覚症状は病期の進行を忠実に反映しない → 質問票での重症度診断は困難

## Q 10-2 糖尿病性神経障害を臨床的にどのように分類するか

- **ポイント**: 遠位性対称性の**多発神経障害**と局所性の**単神経障害・神経根症**に分けられる。前者が最多で感覚・運動神経障害と自律神経障害を含む

### 表2 分類と主な症状

| 分類 | 主な症状 |
|---|---|
| 多発神経障害: 感覚運動神経障害 | しびれ感、錯感覚、冷感、自発痛、アロディニア、感覚鈍麻 |
| 多発神経障害: 自律神経障害 | 瞳孔機能異常、発汗異常、起立性低血圧、胃不全麻痺、便通異常（便秘・下痢）、胆嚢無力症、膀胱障害、勃起障害、無自覚性低血糖など |
| 単神経障害: 脳神経障害 | 外眼筋麻痺（動眼・滑車・外転神経麻痺）、顔面神経麻痺など |
| 単神経障害: 体幹・四肢 | 手根管症候群、尺骨神経麻痺、腓骨神経麻痺、体幹部の単神経麻痺など |
| 神経根症／多発神経根症 | 糖尿病性筋萎縮症など（典型例は片側〜両側性の臀部・大腿部筋萎縮・筋力低下、疼痛を伴う） |

- 感覚・運動神経障害: 下肢末端から発症し上行、次いで上肢末端にも出現
- しびれを含む神経障害性疼痛を訴えれば**有痛性糖尿病性神経障害**と診断し疼痛管理も行う
- **約半数は疼痛などの陽性症状がないまま潜行性に進行**。陰性症状・陽性症状いずれも QOL を低下させる
- 運動神経障害は目立たないが、進行すると**足内在筋の萎縮や足の変形**
- 自律神経障害: 心臓神経障害で**突然死・無痛性心筋梗塞**も
- 神経根症: 糖尿病性筋萎縮（腰仙部根神経叢神経障害）など

## Q 10-3 糖尿病性神経障害の発症と進行のリスクファクターは何か

- **ポイント**: ①血糖コントロール不良 ②罹病期間 ③高血圧 ④脂質異常 ⑤喫煙 ⑥肥満

| 研究 | 知見 |
|---|---|
| EURODIAB IDDM Complications Study（1型 3,250人、横断） | 高血糖、年齢、罹病期間、身長、網膜症、喫煙、HDL-C、心血管疾患、拡張期高血圧、高 TG 血症、微量アルブミン尿と関連 |
| EURODIAB Prospective（1型 1,172人、平均7.3年） | 神経障害なしの **23.5％が新規発症**。HbA1c・罹病期間と関連。補正後も TC、LDL-C、TG、BMI、von Willebrand 因子、尿中アルブミン、高血圧、喫煙、心血管疾患が有意 |
| 2型 132人 vs 対照 142人（10年） | 疼痛、感覚異常、アキレス腱反射消失、振動覚低下が有意に増加。高血糖と低インスリン血症が関与 |
| 糖尿病 264人（約7年） | HbA1c×罹病期間、HbA1c、病型 |

- **最も重要なのは血糖コントロール不良**。有病率は罹病期間とともに増加

## CQ 10-4 血糖コントロールは糖尿病性神経障害の発症・進行抑制に有効か

- **ステートメント**: 糖尿病性神経障害の発症・進行抑制に厳格な血糖コントロールが推奨される
- **推奨グレードA**（合意率100％）
- 根拠文献レベル: DCCT［レベル1］、Kumamoto study［レベル2］、ACCORD（Ismail-Beigi 2010）［レベル1］

### 主要試験

| 試験 | 対象・HbA1c | 結果 |
|---|---|---|
| **DCCT** | 1型 1,441人、6.5年。強化 約7.0％ vs 従来 約9.0％ | 神経障害発症 **5.0％ vs 13％、約60％抑制** |
| Reichard（Stockholm） | 1型 96人 | 強化療法で有意に発症抑制。7.5年後に脛骨神経運動 NCV・腓腹神経感覚 NCV の悪化抑制 |
| **Kumamoto study** | 日本人2型 110人、6年。強化 7.5％ vs 従来 9.8％（NGSP） | **神経伝導速度と振動覚閾値の悪化を有意に抑制**（起立時血圧低下度・RR 間隔は差なし） |
| **ACCORD** | 2型 10,251人、1年後 HbA1c 中央値 6.4％ vs 7.5％ | 神経学的異常所見（MNSI ＞2、触覚消失、アキレス腱反射消失）の発現抑制 |
| VADT、ADDITION-Denmark | 2型 | 発症に差なし |
| **EDIC**（DCCT 後13〜14年、HbA1c 両群約8％） | 1型 | 旧強化群で神経症状・感覚低下・伝導異常率が有意に低く、新規発症も阻止 |

### 総括

- **1型**: 厳格な血糖管理で**発症抑制は明らか**、進行抑制は明らかでない
- **2型**: 発症抑制は相反する報告、進行抑制は十分検証されていない（Callaghan の SR も同見解）
- サブ解析では HbA1c が低いほど発症・進行が少ない → できる限り厳格な血糖コントロール維持が必要
- 「進行抑制」の定義・評価法が定まっていない
- 害: 低血糖の増加。無症候性例が多く患者が有益性を実感しにくい

## Q 10-5 感覚神経障害の薬物療法はどのように行うか

- **ポイント**
  - **エパルレスタット**で進行抑制効果を得られる場合がある
  - 有痛性でも**軽症**は血糖コントロールと生活習慣改善で軽快。**NSAIDs は軽症例でのみ有効**
  - **中等症以上の第一選択薬**: **三環系抗うつ薬、プレガバリン、ミロガバリン、デュロキセチン**

### 進行抑制（病態に対する治療）

- **エパルレスタット**（日本で唯一臨床使用のアルドース還元酵素阻害薬、ポリオール代謝亢進を抑制）
  - 日本人 196人の RCT で有効
  - サブ解析: **神経障害が中等度以下・罹病期間3年以内で有効**、重症・長期罹病例では無効
  - 軽症 594人・3年の RCT: 正中神経運動 NCV 遅延・F 波最小潜時延長を抑制、自覚症状改善。**血糖良好・細小血管症軽微ほど効果顕著**
  - 自律神経機能改善の可能性（小規模研究）
- **メチルコバラミン**: 日本で高頻度に使用されるが **RCT で有意な成績なし**
- プロスタグランジン製剤・抗血小板薬: 臨床効果は明らかでない

### 有痛性糖尿病性神経障害

- 長期持続で不眠・日常生活障害・抑うつにつながる → **早期から適切に治療**

| 薬剤 | 作用機序 | 注意点 |
|---|---|---|
| **三環系抗うつ薬**（アミトリプチリン、イミプラミン） | 神経末端のノルアドレナリン再取り込み抑制（鎮痛効果は抗うつ作用によらない） | 眠気・注意力低下、抗コリン作用（口渇・排尿排便障害・眼圧亢進）。**緑内障・排尿排便困難例には好ましくない** |
| **プレガバリン／ミロガバリン** | Ca チャネル α2δ サブユニットに結合し痛覚伝導抑制 | **腎排泄 → 腎機能障害で減量**。めまい、浮腫 |
| **デュロキセチン**（SNRI） | 下行性抑制系の増強 | 傾眠・悪心（頻度高いが高度でない） |
| カルバマゼピン、ガバペンチン | 抗痙攣薬 | 有効の報告あるが**保険適用なし** |
| **メキシレチン** | 抗不整脈薬（主に日本の試験で承認） | **不整脈**。心疾患例で注意 |
| 徐放性オキシコドン | オピオイド | 疼痛・QOL 改善の報告。耽溺性。日本では DPN 疼痛へのコンセンサス・保険適用なし |
| **トラマドール／アセトアミノフェン合剤** | 弱オピオイド | 近年認可。悪心・嘔吐・傾眠・便秘が高頻度。有用性評価は今後 |

## Q 10-6 自律神経障害の治療はどのように行うか

- **ポイント**: 軽症は**血糖コントロールと生活習慣の改善**で改善することが多い。進行し日常生活を障害する場合は症状に応じた対症療法

| 病態 | 対応 |
|---|---|
| **起立性低血圧** | 血圧低下をきたしやすい**薬剤を中止**、急な体位変換を避ける、**食事の少量頻回摂取**（食後低血圧予防）、**弾性下着**で下肢・下腹部を圧迫。塩分摂取・フルドロコルチゾンも有効だが浮腫・心不全に注意。昇圧薬は臥位高血圧に注意 |
| **胃不全麻痺** | 少量頻回食、脂肪・繊維の摂取制限（軽症はこれで改善多い）。薬物は**メトクロプラミド、ドンペリドン**（長期使用で**錐体外路症状**）。エリスロマイシンは本邦で未承認 |
| **勃起障害** | 原因となる薬剤を中止。**シルデナフィル、バルデナフィル**が有効。**ニトログリセリン・亜硝酸薬使用中は禁忌**（重篤な血圧低下）。無効なら泌尿器科へ紹介 |
| **無自覚性低血糖** | 長期罹病・進行例でリスク。頻回 SMBG で低血糖を極力回避。**重篤な低血糖直後は無自覚性低血糖を起こしやすい → しばらく目標血糖をやや高めに** |

## Q 10-7 単神経障害の治療はどのように行うか

- **ポイント**: 単神経障害は**血糖コントロールとは無関係に自然軽快することが多い**

- 多くは**栄養血管の閉塞**が原因で動脈硬化と関連が強く、罹病期間や血糖コントロールとは必ずしも相関しない
- ただし多くの例で感覚・運動神経障害や自律神経障害を伴う → 血糖コントロールと生活習慣改善を指導

## Q 10-8 糖尿病性神経障害はその他の合併症のリスクファクターとなるか

- **ポイント**: 神経障害は網膜症・腎症のリスクファクター

- **IGT／IFG**（AusDiab）: 神経障害ありで**網膜症 約4倍、アルブミン尿陽性 2倍**
- 末梢性感覚神経障害ありで網膜症の重症度が増す
- 1型（EURODIAB）: 神経伝導速度・振幅の低下が細小血管症と強く相関
- 神経障害の重症度は網膜症・腎症の進行と有意に関連（**OR 2.13**）
- → 3大細小血管症は相互に関連し、神経障害が他合併症の誘因になる可能性

## 外来での使いどころ（自院メモ）

- 定期診察で**アキレス腱反射（両側）＋ C128 音叉の内踝振動覚（10秒以下で低下）＋足趾・足底の症状問診**をルーチン化 → 3項目中2項目で簡易診断。モノフィラメントも併用
- 評価は**軽症でも半年〜1年ごと**。進行例はもっと頻回に
- 神経障害を疑ったら一度は **B12（胃切除歴）・甲状腺機能・飲酒歴**を確認。**上肢のみ・非対称・急速進行**は糖尿病性以外（CIDP、手根管症候群など）を考える
- 有痛性で中等症以上は**プレガバリン／ミロガバリン（腎機能で減量、めまい・浮腫）かデュロキセチン**から。高齢者・緑内障・前立腺肥大には三環系を避ける。メキシレチンは心疾患に注意
- メチルコバラミンは RCT で有効性なし、エパルレスタットは**軽症・罹病3年以内**に絞って検討
- ED 相談で PDE5 阻害薬を出す前に**硝酸薬の併用を必ず確認**
- 起立性低血圧があれば降圧薬・利尿薬など原因薬を見直し、少量頻回食・弾性ストッキングを指導
- 重症低血糖を起こした後は**しばらく血糖目標を緩める**。神経障害がある患者は網膜症・腎症の進行リスクも高いと考え眼科・尿アルブミンのフォローを徹底
