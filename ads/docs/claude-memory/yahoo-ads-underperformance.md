**LINEヤフー広告（検索_内科_全日）は Google に対して一貫して分が悪い。**

| | 直近7日 | 8/22(土)当日 |
|---|---|---|
| 費用 | 14,295円 | 934円 |
| クリック | 223 | 15 |
| CTR | 4.1% | 3.8% |
| 平均CPC | 64円 | 62円 |
| CV | 6件 | **0件** |
| CPA | 2,383円 | — |

同じ日のGoogle（土日キャンペーン）が CPA 1,096円・CTR 7.9% なので、**CPAは倍以上・CTRは半分**。
損益分岐3,850円は下回っているので即赤字ではないが、同じ金をGoogleに置いたほうが取れる。

## ✅ 8/20に入れた除外キーワード68件は効いている

7日間の検索クエリーレポートには「仙台市 休日当番医」「名取市 休日当番医」など当番医系や
競合指名が大量に残っているが、**これは8/20より前の期間ぶん**。8/22当日だけで引き直すと
当番/救急/整形/皮膚/眼科/泌尿/名取/富谷/石巻 の**素通りは0件**だった。PHRASE一致で正しく効いている。
7日集計を見て「除外が効いていない」と判断しかけたので注意。

## 残っている構造的な問題

- **96%のクエリが0クリック**（7日で2,993種中2,862種、表示の93%）。Googleの8/10分析（0クリック63%）
  より格段に悪い。ヤフーの部分一致はGoogleより緩い
- **キーワード「クリニック 予約」が競合指名の受け皿になっている。** ここからのクリックは
  ほぼ全部が他院名（くすのき/さはた/めざき/シリウス/中山医院/小泉内科/原クリニック/桜ヶ丘 …）で
  14クリック中CV1件。**このキーワード自体を止めるのが一番効く**
- **診療科違いが「◯◯科 + 地名」の形で抜ける。** 8/22当日も「仙台 呼吸器内科」「脳神経内科 仙台」で
  クリックが付いた。除外は科名単体しか入っていない
- **圏外が地名なしで抜ける。** 7日間に「北島 内科 早良 区」（福岡市）。地域ターゲティングを
  LOCATION_OF_PRESENCE にしても、検索語に他地域が入るケースは止まらない

## 検索クエリーレポートは全量ではない

7日間のクエリレポート合計が 4,067表示/9,472円 なのに対し、キャンペーンレポートは 14,295円。
**費用ベースで66%しか出てこない**（低頻度クエリが匿名化で落ちる）。クエリレポートの合計を
「その期間の全実績」として扱わないこと。当日ぶんも 301表示/634円 vs 396表示/934円 で同様。

## 2026-08-22に実施した対応

**「クリニック 予約」と「病院 近く」を一時停止**（`lyads keyword pause`、オーナー了承）。
7日で合計2,114円＝15%で、どちらもクリックの中身が他院指名と診療科違いに偏っていた。
競合名は次々に新しいものが出るので、除外キーワードの継ぎ足しでは追いつかないと判断した。
残り61語はACTIVE。

**「休日 病院」「仙台 休日診療」は合計3,581円・CV0だが、あえて残した。** この2語が食っていた
当番医クエリは8/20の除外で既に止まっており、除外後の実力をまだ1日ぶんしか観測していない。
ここを同時に触ると8/20の除外の効果が測れなくなる。**8/29前後に再評価する。**

診療科違いの除外追加（緊急外来・脳神経内科など）は見送り。8/20の68件が入ったばかりで、
重ねるとどれが効いたのか分からなくなるため。

**How to apply:** 次の再評価は8/29前後。「休日 病院」「仙台 休日診療」がCV0のままなら停止する。
それでもCV0が2週続くなら、日予算1,500円をGoogle土日側に寄せて停止してよい。
