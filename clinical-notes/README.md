# clinical-notes（診療ガイドラインの自院メモ）

当院（勾当台夕方内科）での運用メモ。ガイドラインそのものの要約は別リポジトリ [keiyousya/clinical-guidelines](https://github.com/keiyousya/clinical-guidelines) にあり、ここには当院の事情（在庫、設備、紹介先、診療時間帯など）に依存する部分だけを置く。

## 構成

- ガイドライン側と**同じパス**にメモを置く（例: `insomnia/esrs-european-gl2023/02-cbt-i.md` ⇔ ガイドライン側の同名ファイル）
- 各ファイル冒頭に、対応するガイドライン要約へのリンクを書く
- 領域ごとの早見（不眠・TSH異常）は `insomnia/README.md`・`thyroid/README.md`

## 運用ルール

- ガイドラインの要約・原文の読み取りは clinical-guidelines 側に書く。**当院の判断・運用はこちら**に書く
- 新しい資料をまとめたら、ガイドライン側に要約、こちらに同じパスで自院メモを足す
