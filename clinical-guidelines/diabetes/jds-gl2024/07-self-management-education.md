## CQ 7-1 組織化された糖尿病自己管理教育と治療支援は糖尿病治療に有効か

- **ステートメント**: DSME／DSMES は糖尿病治療に有効であり推奨される
- **推奨グレードA**（合意率100％）
- 根拠文献レベル: He 2017 MA［レベル1＋］、Pillay 2015 ×2・Bekele 2021・Tanaka 2020［レベル2］

### 概念

- **DSME**（self-management education）／**DSMES**（DSME and support）: 知識・技術・自己管理能力を持続的に促進し、行動を継続支援
- **エンパワーメント**: ①疾患理解 → ②個人目標の設定 → ③日常での実践
- **クリニカルイナーシャ**: 最善の医療（患者側の目標実践も含む）を保留すること。その期間に合併症が進行しうる

### エビデンス

| 対象・項目 | 結果 |
|---|---|
| 2型・HbA1c | RCT 132件の NMA: **11時間以上の介入**で通常ケアより有意に改善。**対面式**がビデオ・電話より効果大 |
| 2型・総死亡 | RCT 42件の MA（13,017人）: **総死亡リスク26％抑制**（RR 0.74）。多職種チーム・看護師主導とも有効 |
| 1型・HbA1c | 前向き比較試験36件の MA: 6ヵ月で改善、**12ヵ月で効果消失**。BMI・身体活動・QOL は有意差なし（バイアス大） |
| 1型・DAFNE | 炭水化物量に合わせたインスリン調整・低血糖対処などを学ぶプログラム。糖代謝・合併症・心理社会面の改善報告。DAFNEplus で拡張中 |
| 低血糖 | DSME の低血糖予防 MA はない。1型の観察研究で**12年間**低血糖リスク抑制 |
| 電話診療 | 1型・2型とも HbA1c 改善の MA あるがバイアス大、評価不定 |
| 携帯アプリ | 服薬アドヒアランス・食事運動・HbA1c 改善の報告あるが確定的研究乏しい。1型はさらに乏しい。GDM は SR でエビデンス乏しい（新生児合併症軽減の報告あり） |
| 医療コスト | Look AHEAD（米国）では医療費削減せず。一方 DSME は糖尿病関連入院を抑制、12件の MA で長期には費用対効果に優れる |

- 知識テスト: Diabetes Care 発表の糖尿病知識テスト（合併症・食事運動・治療・シックデイ）、日本人版もあり
- 費用（令和6年3月）: 生活習慣病管理料として **190〜240円/日**

### 心理社会的背景（DAWN / DAWN2）

- **DAWN（2001、13ヵ国）**: 通院・薬物のアドヒアランスは高いが食事・運動は低い。自己評価の全般的アドヒアランスは 1型46％・2型39％、医療者評価は各 17％・5％と乖離。医療者は心理的問題に十分対処できていない
- **DAWN2（2012、17ヵ国）**:
  - うつ病疑い 13.8％、糖尿病関連の心理負担高度 44.6％、全般的 QOL 低値 12.2％
  - 40％が薬物治療が日常生活の妨げと回答。医療者の1/3が患者は社会的差別を受けていると感じる
  - **日本**: 家族のサポートを負担と考える家族 57％、家族が支援的と答えた患者 **20％以下（調査国中最下位）**。教育プログラム受講は日本 76％（17ヵ国平均 59％）。HbA1c 検査は高頻度だが心理状態評価はあまりなされていない

## CQ 7-2 集団教育と個別教育は糖尿病治療に有効か

- **ステートメント**: 集団教育と個別教育はどちらも糖尿病治療に有効である
- **推奨グレードB**（合意率100％）
- 根拠文献レベル: Shiferaw 2021・Odgers-Jewell 2017・Mannucci 2022・Nkhom 2020 いずれも MA［レベル2］。組入れ研究の多くが中等度〜高度バイアス

- 2型への集団・個別教育: 通常治療比 **HbA1c 約0.5％低下**、知識増加
- **集団 vs 個別で HbA1c 改善に差なし**（Mannucci MA）→ どちらを選んでもよい。集団のほうが QOL・知識を高める傾向
- 集団教育は HbA1c のほか空腹時血糖、体重、ウエスト径、中性脂肪を低下させ知識を向上（最大48ヵ月）
- **携帯アプリ・Web 遠隔教育**: 2型では HbA1c 改善、1型では改善なし。国内でも研究進行中（UMIN000030905）
- **日本糖尿病協会のカードシステム**: インスリン療法中2型で医師が使用すると、体重・QOL は不変だが HbA1c 改善・インスリン減量例が多い。協会研修会修了者が使用可能
- 費用: 集団栄養指導料 **27円/日**、生活習慣病管理料 190〜240円/日

## CQ 7-3 血糖自己測定（SMBG）は糖尿病治療に有効か

- **ステートメント❶**: SMBG は **1型およびインスリン療法中の2型**の血糖コントロールに有効であり推奨される
  - **推奨グレードA**（合意率100％）。根拠文献レベル: DCCT［レベル1］、Miller 2013・Ziegler 2011・DOVES 2003・TODAY 2019［レベル2］
- **ステートメント❷**: **インスリン非使用2型**では SMBG の血糖改善効果について一定の見解が得られていない
  - **推奨グレードU**（合意率100％）。根拠文献レベル: Young 2017 RCT［レベル2］

### 1型

- **DCCT**: 強化インスリン療法＋SMBG 1日4回以上＋カーボカウントで HbA1c **約2％改善**（強化 7.0％ vs 従来 9.0％）、網膜症・腎症の発症・進行抑制
- 18歳以下 26,723人（Ziegler）: SMBG 頻度は HbA1c 低下と関連、**1日5回を超えると頭打ち**。1回追加で HbA1c 0.20％低下（調整後）
- 20,555人（Miller、年齢制限なし）: 回数が多いほど HbA1c 低下、DKA 抑制
- **保険は1日4回まで**。1日5回以上を勧める場合は保険適用の **CGM が推奨**される

### インスリン使用中の2型

- 主に1日2回インスリンの2型（DOVES）: 1日4回 SMBG で52週 HbA1c 低下（8週で0.36％）。調整後は**導入前 HbA1c ＞8.0％ または SMBG アドヒアランス 75％以上**の患者でのみ効果
- 若年発症2型（TODAY、基礎インスリン導入時平均15.8歳）: 1日1〜2回 SMBG、**アドヒアランス80％以上**でのみ1年以内に HbA1c 低下
- **Kumamoto study**: SMBG 下の強化インスリン療法で HbA1c 改善・細小血管合併症抑制

### インスリン非使用の2型（議論あり）

| 研究 | 結果 |
|---|---|
| RCT（Young 2017） | 1日1回 SMBG ± フィードバックメッセージで 12ヵ月後 HbA1c・QOL に効果なし |
| Cochrane MA | 6ヵ月では改善、12ヵ月では有意差なし |
| 別の MA | 6・12ヵ月とも改善 |
| 構造化 vs 非構造化 MA | **構造化 SMBG（測定タイミングを教育・指定）でのみ**有意改善 |
| 回数の MA | **週8回以上**の研究でのみ改善 |

- 目的意識をもって（治療効果判定として）行うことが肝要
- 費用: 血糖自己測定器加算 **117円（1日1回以下）〜497円（1日4回以上）/日**。インスリンや GLP-1 製剤非使用の2型は**保険収載なし（全額自己負担）**
- SMBG 導入で QOL 低下の報告もあり、患者の価値観は一様でない

### 妊娠

- **GDM**: SMBG vs 外来血糖測定で帝王切開・巨大児・新生児低血糖に差なし。インスリン必要な GDM では**食後血糖測定で調整**するほうが母 HbA1c 改善、出生体重軽く、帝王切開・新生児低血糖が少ない（RCT）
- **糖尿病合併妊娠**（1型・2型）: SMBG は母 HbA1c・帝王切開・出生体重に有意な効果なし（MA）

## CQ 7-4 CGM はどのような点で糖尿病治療に有効か

- **ステートメント❶**: rtCGM は小児・思春期および成人1型で**低血糖頻度低下・血糖改善効果**を有する — **推奨グレードB**（合意率100％）
- **ステートメント❷**: rtCGM は**1型糖尿病合併妊娠**で血糖コントロールを改善し周産期異常を減少させ有効 — **推奨グレードB**（合意率100％）
- **ステートメント❸**: isCGM は1型・2型で SMBG よりも血糖コントロール改善に寄与し得る — **推奨グレードB**（合意率100％）
- 根拠文献レベル: GOLD（Lind 2017）・CITY（Laffel 2020）・HypoDE（Heinemann 2018）・ALERTT1（Visser 2021）・CONCEPTT（Feig 2017）RCT［レベル1］、Teo 2022・Castellana 2020 MA［レベル2］。❶❷は質の高い MA で未証明、❸は MA のバイアス大のため B

### CGM の種類（2023年9月現在）

| 種類 | 特徴 |
|---|---|
| **rtCGM**（リアルタイム） | 間質液グルコースを常時表示。**低・高血糖アラートあり**。一部は SMBG 較正が必要 |
| **isCGM**（間歇スキャン式、別名 FGM） | 患者が操作したときのみ表示。較正不要。**低血糖時の表示値が不正確との報告**あり。呼称は isCGM に統一推奨 |
| **retroCGM**（プロフェッショナル CGM） | 装着中は患者に見えず、医療機関でのみ表示。較正不要 |

### エビデンス

- **1型（各種 CGM vs SMBG、21 RCT の MA）**: HbA1c 低下は明確、**特に HbA1c ≧8％で顕著**。低血糖・DKA 予防効果は乏しい
- GOLD（1型 161例、クロスオーバー）: rtCGM で HbA1c 低下・低血糖減少・治療満足度上昇
- CITY（14〜24歳 153例）: rtCGM で HbA1c 低下（重症低血糖は差なし）。本文では低血糖頻度減少と記載
- HypoDE（無自覚性／重症低血糖既往の1型 153例）: rtCGM で低血糖減少、HbA1c は有意差なし
- **ALERTT1**（isCGM 使用中の1型 269例）: **rtCGM へ変更で HbA1c 改善・TIR 増加・TBR/TAR 低下・低血糖不安減少** → 1型では rtCGM が isCGM より有効な可能性が高い
- アラーム付 isCGM（国内未発売）: 1日4回程度の SMBG 比 HbA1c 約0.5％低下、低血糖減少
- **CONCEPTT**（妊娠中／妊娠予定の1型 325例）: rtCGM で HbA1c 低下・TIR 増加、**巨大児・新生児低血糖減少**（TBR は差なし）→ 妊娠計画時は rtCGM が望ましい
- **インスリン療法中2型**: 基礎インスリン中の rtCGM で HbA1c 改善（低血糖は減らず）。強化インスリン中の isCGM で低血糖を増やさず HbA1c 低下・満足度高い。isCGM MA（12 RCT、2,173名）で HbA1c・TBR 低下（バイアス大）
- **retroCGM**: 単独効果の研究は乏しい。妊娠関連 MA で巨大児・HbA1c に影響なし。一般診療の2型 RCT（GP-OSMOTIC）で半年後は改善、**1年後は差なし**

### 費用（令和6年3月）

| 機器 | 費用 |
|---|---|
| rtCGM | センサー2個/月以下 440円/日 〜 5個/月以上 1,100円/日 |
| isCGM | 417円/日 |

## Q 7-5 糖尿病治療上の心理課題は何か

- **ポイント**: 自己管理の負担から不安障害・うつ病の頻度が高い。社会から負わされる差別類似の心理的負担（**スティグマ**）もあり、医療者は**アドボカシー活動**で取り除く努力をすべき

### diabetes distress（DD）

- 診断時から生じる。**1型および2型の約1/3が DD を感じている**
- 1型の DD 軽減プログラム（T1-REDEEM）で DD 低下 → HbA1c 低下
- 2型（REDEEM）で DD 低下、食事・運動・服薬アドヒアランス改善
- 2型の心理学的介入 RCT の MA（Cochrane）: 自己効力感・HbA1c がわずかに改善する可能性

### 不安障害・うつ病

- 米国調査: 糖尿病患者の**約20％が生涯に不安障害**、非糖尿病の約2倍。原因は高血糖、インスリン注射、低血糖、合併症進行など
- **合併症進行を伝えるとき・インスリン開始を提案するとき**は不安障害をきたしうることに留意
- うつ病リスクは一般集団の**約2〜3倍**。罹患でアドヒアランス低下 → 疑えば精神科介入

### スティグマ

| 種類 | 内容 |
|---|---|
| 社会的スティグマ | 就職・結婚で不利になる等 |
| 乖離的スティグマ | 体重管理できないとき等に医療者から向けられる（模範的患者像からの乖離） |
| セルフスティグマ | 自尊感情の損失。コンプライアンス不良と関連 |

- **23％の労働者が上司に2型糖尿病を隠している**
- 生活習慣の格差には社会的格差が関与し、すべてを自己責任にすべきでない
- ADA は 2015年に Standards of Care でアドボカシーを独立章化。日本糖尿病学会・日本糖尿病協会は **2019年から**アドボカシー活動を展開

## CQ 7-6 心理的・行動科学的アプローチは糖尿病治療に有効か

- **ステートメント❶**: 心理的・行動科学的アプローチは**2型の HbA1c 改善に寄与し得る** — **推奨グレードB**（合意率100％）
  - 根拠文献レベル: Winkley 2020（2型、70 RCT・14,796人の MA）［レベル2］。HbA1c **0.19％**有意改善
- **ステートメント❷**: **1型**への血糖改善効果は不定 — **推奨グレードU**（合意率95％）
  - 根拠文献レベル: Winkley 2020（1型成人24 RCT・小児23 RCT の MA）［レベル2］。HbA1c 変化なし、Risk of bias 高い

- 内容: 知識 → 目標設定 → 具体的行動 → 医療者のフィードバック → 自己効力感 → 習慣化 → 血糖改善・DD 軽減
- 2型では複数の MA でわずかだが有意に HbA1c 改善
- **DD の高い1型・2型**では、ストレス軽減と HbA1c 改善（MA）。その後も DD 低下の RCT 多数 → 血糖改善以上に **DD 低下・QOL 向上のために必要**
- **家族を交えた介入**（MA）: 1型・2型とも HbA1c 改善、体重・血圧低下、自己効力感増加、DD 減少。**アジア地域で血糖改善効果が高い**。ただし家族の干渉でストレスが増える可能性があり慎重に

## Q 7-7 糖尿病治療にうつ病のスクリーニング・治療は重要か

- **ポイント**: 1型・2型ともうつ病の有病率は高く、自己管理行動が不十分になりうるため、スクリーニングと治療は重要

### 有病率

| 対象 | 有病率 |
|---|---|
| 日本の地方病院内科外来（うつ病スクリーニング） | 約14％ |
| 日本の統合失調症（参考） | 約0.2〜1.8％ |
| アジア人の不安障害（参考） | 5％程度 |
| **アジア人2型糖尿病のうつ病** | **30％程度** |
| 1型糖尿病（非アジア） | 同程度 |

- 糖尿病患者のうつ病リスクは非糖尿病の約2〜3倍。機序は DD、高血糖による慢性炎症（日本人2型で hs-CRP 高値とうつ病が関連）
- 逆方向: 非糖尿病うつ病患者でインスリン抵抗性上昇

### 治療上の問題と介入

- うつ病併発 → 治療アドヒアランス低下、セルフケア行動減少、血糖コントロール悪化（MA）
- 2型合併うつ病への**認知行動療法**でうつ病改善＋HbA1c 改善
- **抗うつ薬**（nortriptyline、fluoxetine の RCT）がうつ症状と血糖の改善につながる可能性
- → **定期的なうつ病スクリーニングと治療**が非常に重要

## Q 7-8 ガイドラインと実践的マニュアルはどのように活用されるべきか

- **ポイント**: 実践的マニュアルはガイドラインを実地診療に適用する手引き。医療チーム・患者間の情報共有と個別化医療を促進

- 実践的マニュアル: 検査頻度、薬剤の優先度、**専門医・拠点病院への紹介の適応とタイミング**を明記。一般公開・逐次改訂
- 本邦クラスター RCT（SEAS-DM）: マニュアル介入で**尿中アルブミン測定率が改善**
- クラスター RCT（Diabetes Manual、26週）: HbA1c 変化量は差なし、DD と自己管理の自信はより改善
- 課題: エビデンスの周知不足、研究の不均一、治療選択の複雑化、費用対効果の考慮不足、日本人エビデンスの不足
- ガイドラインは**強制ではない**。最終決定は医療者と患者の合意による。**ガイドラインから大きく外れる選択をした場合は経過・根拠を診療録に明記**

## 外来での使いどころ（自院メモ）

- 教育は**集団でも個別でも効果は同等** → 夕方外来では短時間の個別指導を積み重ね、日本糖尿病協会カード等で漏れなく伝える
- **インスリン非使用2型に SMBG を出すなら「構造化」**（何のために・いつ測るかを指定、週8回以上が目安）。保険外で自己負担になる点も説明
- インスリン使用中でも SMBG の効果は **HbA1c ＞8％やアドヒアランス良好例**で出やすい。1日5回以上必要なら CGM へ
- 1型は **rtCGM を優先検討**（isCGM から変更で改善・低血糖不安軽減）。妊娠希望の1型は rtCGM を強く勧め専門施設と連携
