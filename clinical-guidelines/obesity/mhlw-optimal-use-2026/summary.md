## 2026年の変化

| 時期 | 内容 |
|---|---|
| 2026-05 | ゼップバウンドに**中等症以上の OSAS（BMI ≧27）** の適応追加。肥満症の効能も「BMI ≧27 かつ健康障害2つ以上、または BMI ≧35」と明記する形に一部変更 |
| 2026-06 | ウゴービに**肝硬変を伴わない MASH（中等度以上の線維化）** の適応追加。肥満症GLも改訂 |

## 肥満症（ウゴービ・ゼップバウンド共通）

### 施設要件（①〜③をすべて満たす）

| 項目 | 要件 |
|---|---|
| 標榜科 | 内科・循環器内科・内分泌内科・代謝内科・糖尿病内科のいずれか |
| 常勤専門医 | **日本循環器学会・日本糖尿病学会・日本内分泌学会いずれかの専門医が常勤で1人以上**（肥満学会専門医が望ましい）。所属しない領域の専門医とは他施設と連携 |
| **教育研修施設** | 上記いずれかの学会の**教育研修施設に認定された施設** |
| **管理栄養士** | **常勤**の管理栄養士による栄養指導体制。指導内容を診療録に記録 |
| 医師の経験 | 初期研修後に高血圧・脂質異常症・2型糖尿病と肥満症の診療 5年以上（または卒後7年以上で うち5年以上） |
| その他 | 医薬品情報管理体制、副作用に直ちに対応できる体制（近隣医療機関との連携可） |

### 患者要件（すべて満たす）

1. **高血圧・脂質異常症・2型糖尿病のいずれか1つ以上**があり、かつ
   - **BMI ≧27 で肥満関連健康障害が2つ以上**、または
   - **BMI ≧35**
2. **投与する施設で**食事・運動療法の治療計画に基づく治療を**6か月以上**行っても効果不十分。その間 **2か月に1回以上、管理栄養士の栄養指導**を受けている（患者の記録を確認し管理記録に残す）
3. 投与する施設で、合併する高血圧・脂質異常症・2型糖尿病に**薬物療法を含む治療が行われている**

肥満関連健康障害（治験の組入れ基準）: 耐糖能障害、脂質異常症、高血圧、高尿酸血症・痛風、冠動脈疾患、脳梗塞、非アルコール性脂肪性肝疾患、月経異常・不妊、OSAS・肥満低換気症候群、運動器疾患、肥満関連腎臓病

### 継続・中止

| 項目 | ウゴービ | ゼップバウンド |
|---|---|---|
| 最大投与期間 | **68週** | **72週** |
| 投与中の栄養指導 | 2か月に1回以上（管理栄養士） | 同左 |
| 効果判定 | 毎月 体重・血糖・血圧・脂質。**3〜4か月で改善傾向なし → 中止** | 同左 |
| 効果ありの場合 | 以後2〜3か月ごとに確認。十分な減量（5%以上が指標）なら期限前でも中止を考慮 | 同左 |
| 再投与 | 中止後に悪化 → 再び食事・運動療法（栄養指導含む）を原則6か月以上行ってから | 同左 |

- 治療計画の作成時点で「期限までに中止できるよう指導する」ことを組み込む

### 主な留意事項

- 美容・痩身・ダイエット目的に使わない。**2型糖尿病の治療を主目的に使わない**（ウゴービ）
- 他の GLP-1 受容体作動薬との併用不可（オゼンピック等が処方されていないか確認）。DPP-4阻害薬併用のデータなし
- インスリン依存状態には投与しない（インスリンからの切り替えで DKA の報告）
- 妊婦には投与しない。**2か月以内に妊娠を予定する女性は中止**（ウゴービ）
- 膵炎、胆道系疾患、脱水 → 急性腎障害、糖尿病網膜症の悪化、甲状腺（C細胞腫瘍の動物データ）に注意

## MASH（ウゴービ、2026-06〜）

| 項目 | 内容 |
|---|---|
| 効能 | 肝硬変を伴わない MASH（中等度または高度の線維化） |
| 対象の確認 | **肝生検で NASH CRN の F2〜F3**。生検が適さなければ非侵襲的検査（VCTE・2D-SWE・MRE・血液マーカー等）で**肝臓専門医または消化器病専門医が総合判断** |
| 除外の目安（参考値） | F0〜1: VCTE <8 kPa・FIB-4 <1.3（66歳以上 <2.0）・血小板 ≧20万をすべて満たす／F4: VCTE ≧15 kPa または 血小板 <15万 |
| BMI | <19 は投与しない。原則 ≧23 |
| 施設・医師 | 消化器内科・肝臓内科・内科を標榜。**(1) 肝臓・消化器病専門医 と (2) 内分泌・糖尿病・循環器専門医の両方の関与**が必要（片方は連携先でも可）。教育研修施設、常勤管理栄養士 |
| 継続判定 | 3〜4か月で改善傾向なし → 中止を検討。**12か月後を目安に生検または NIT** で評価し、改善なし・F4 進行なら原則中止 |

## OSAS（ゼップバウンド、2026-05〜）

| 項目 | 内容 |
|---|---|
| 効能 | **中等症以上の OSAS、BMI ≧27**（原則 ≧30） |
| 重症度 | **PSG で AHI ≧15**、または簡易検査（OCST）で **REI ≧30** |
| 前治療 | 投与施設で食事・運動療法を**3か月以上**行っても体重減少が不十分、その間に管理栄養士の指導を**最低1回**（CPAP でも改善しない肥満低換気症候群・心不全は例外あり） |
| 施設・医師 | 循環器内科・呼吸器内科・耳鼻咽喉科・内科を標榜。**(1) 循環器・呼吸器・耳鼻咽喉科頭頸部外科専門医 と (2) 内分泌・糖尿病専門医の両方の関与**。教育研修施設、常勤管理栄養士 |
| 期間・判定 | **最大52週**。3〜4か月で減量傾向なし → 中止。**6〜7か月で PSG** を再検し改善なし → 中止 |

## 外来での使いどころ（自院メモ）

- **当院は保険でウゴービ・ゼップバウンドを処方できない**。3つの適応すべてで「学会の教育研修施設」「常勤の管理栄養士」「常勤の専門医」が必須で、当院はこれを満たさない（2026-09 時点の体制による自院の判断。体制が変わったら見直す）
- 当院の役割は**適応がある患者を拾い上げて紹介すること**。紹介状には次を書くと受け手の6か月の前治療の判断に役立つ
  - BMI・腹囲の推移、合併する高血圧・脂質異常症・糖尿病と現在の処方
  - 肥満関連健康障害の数（11疾患のどれに当たるか）
  - これまでの食事・運動療法の内容と期間
  - ただし「投与する施設で6か月」が要件なので、**当院での前治療期間は通常カウントされない**と患者に説明しておく
- OSAS 適応は **PSG（AHI ≧15）が前提**。いびき・日中の眠気がある肥満患者は、まず簡易検査・PSG ができる施設へ
- MASH 適応は**肝線維化 F2〜F3 の確認が前提**。当院の肥満・糖尿病患者で FIB-4 が高い人は、消化器内科紹介の理由がひとつ増えたと考える
- 2型糖尿病がある人は、糖尿病の適応で GLP-1RA・チルゼパチド（マンジャロ）を当院で使える。**ウゴービ・ゼップバウンドを「糖尿病治療目的」で使うことはできない**
- 他院で投与中の患者が当院に通院している場合: **オゼンピック・マンジャロ・DPP-4阻害薬の重複処方をしない**、SU・インスリンの減量を相談する
- 自費の「医療ダイエット」目的での処方はしない（各GLが美容・痩身目的の使用を明確に否定している）
