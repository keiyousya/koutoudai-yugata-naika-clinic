2026-07-16〜2026-07-31 はクリニック休診。これに合わせて Google 広告の稼働キャンペーン
「2026年06月リスティング広告」（唯一の ENABLED / 日予算1,800円）に配信終了日時
`2026-07-15 23:59:59` を設定済み（2026-07-14 実施）。7/16以降は自動的に配信停止した。

**2026-07-30に再開済み:**

```
gads campaign end-date --campaign-id <CAMPAIGN_ID> --clear --yes
```

終了日を解除し、8/1からの配信再開を確認。設定変更（予算・スケジュール・キーワード）は
7月のパフォーマンスが良好だったため不要と判断し、既存設定のまま再開。

**Why:** 休診中に広告を出すと来院できない患者のクリックに費用が出るだけで無駄。ただし
7/15（水）は通常診療日なので、即PAUSEDにせず終了日方式にして7/15分の配信は残した。

**How to apply:** 次回の休診停止でも同じ終了日方式が使える。再開忘れ防止のため、休診最終日
あたりで `--clear` を予定しておくこと。
