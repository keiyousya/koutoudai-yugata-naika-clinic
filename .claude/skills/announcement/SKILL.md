# お知らせ作成（helix 電子カルテ）

依頼内容: $ARGUMENTS

## 対象画面

- URL: https://koutoudai-yugata-naika.helix.keiyousya.com/system-admin/announcements
- Chrome はログイン済みの前提。ログイン画面が出たら、ユーザーにログインしてもらう（パスワードは入力しない）
- ここで保存したお知らせは患者向けに公開される

## 手順

1. **材料を集める**
   - 自費診療や検査など、ホームページにページがある内容は `frontend/src/pages/*.astro` と `frontend/public/llms.txt` を読み、料金・対象・条件をそこに合わせる
   - 既存のお知らせの文体は、一覧画面のテキストを読んで確認する
   - 日付の曜日はカレンダーで確認する（`date -j -f %Y-%m-%d 2026-09-16 +%a` など）
   - 分からないこと（対象年齢、予約の要否、税込表記など）は勝手に決めない。案の中で「要確認」として挙げる

2. **フォームに入力する（保存はしない）**
   - 「新規作成」ボタン → ダイアログ「お知らせの作成」
   - 入力欄: `タイトル`（必須）、`掲載開始日`（必須・既定は今日）、`本文`（必須・プレーンテキスト、改行はそのまま反映）
   - **下書き機能はない。「保存」を押すと、掲載開始日から即公開される**
   - ダイアログは前回入力した値が残っていることがある。各欄をクリックして `cmd+a` → `Delete` してから入力する
   - ダイアログは一度に1件しか開けない。複数件あるときは1件ずつ入力 → 公開 → 次へ

3. **ユーザーに見せて承認をもらう**
   - タイトル・掲載開始日・本文をチャットにそのまま貼る
   - 推測で書いた箇所、あえて書かなかった箇所を挙げる
   - ユーザーがフォームを直接手で直すことがある。修正を反映させる前に、必ず今の入力値を読み直す:
     ```js
     const d = document.querySelector('[role="dialog"]');
     JSON.stringify([...d.querySelectorAll('input,textarea,button')].map(e => e.value || e.innerText))
     ```
   - 「公開して」など明確な指示があるまで保存しない。ユーザーが自分で保存することもある

4. **公開後に確認する**
   - 一覧（公開中タブ）の先頭に出ていること、掲載開始日が正しいことをページのテキストで確認して報告する

## 文面の決まり

- 1つのお知らせには1つの話題だけを書く（例: ワクチン接種と予防投与は別々のお知らせにする）
- タイトルは1文で、「。」で終える。例: `9月16日（水）よりインフルエンザワクチン接種を開始します。`
- 日付は `9月16日（水）` の形式にする。年は必要なときだけ付ける
- 本文の構成:
  - 冒頭に要旨を1〜2文で書く
  - 空行を入れ、`■ 見出し` の下に `・項目：内容` の箇条書きを並べる
  - 詳細ページがあれば「詳しくは当院ホームページをご覧ください。」の次の行に URL を書く（`https://koutoudai-yugata-naika.clinic/...`）
- 料金は `3,300円` のように書く。「税込」は付けない（ユーザーが削除した）。診察料込みなら `（診察料込）`
- 自費診療の対象条件は本文に細かく書かず、「重症化リスクの高い方」程度にとどめて、詳しい条件はホームページに任せる
- 予約・来院の案内は `■ ご予約・ご来院について` にまとめる。当院は**予約制**（2026年9月〜）。予約なしでも来院できるが、予約の方を優先する:
  ```
  LINE予約の問診で「〇〇希望」とご記入ください。お電話（022-393-8689）でのご予約も可能です。
  ご予約なしでもご来院いただけますが、ご予約の方を優先してご案内するため、お待ちいただくことがあります。
  ```
- 時間帯の指定があるものは添える: 発熱外来 →「発熱外来の時間帯（平日19:00〜21:00／土日17:00〜21:00）にお越しください」、インフルエンザ予防接種 →「原則として一般内科外来の時間帯（平日17:00〜19:00／土日14:00〜17:00）にお越しください」
- 下の例は公開当時の文面のまま。「混雑状況により」の書き方は予約制になる前のもので、上の文面に置き換える
