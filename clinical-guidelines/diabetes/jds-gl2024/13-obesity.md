## Q13-1 肥満・肥満症の診断

### 判定・定義

| 区分 | 基準 |
|---|---|
| 肥満 | BMI ≧25（肥満だけでは直ちに疾病・治療対象ではない） |
| 高度肥満 | BMI ≧35 |
| **肥満症** | BMI ≧25 かつ ①肥満関連健康障害を合併、または ②健康障害の合併が予測される**内臓脂肪型肥満**（内臓脂肪面積 ≧100 cm²）で、医学的に減量が必要な病態 |
| 高度肥満症 | 肥満症のうち BMI ≧35 |

- **肥満関連11疾患**: 耐糖能障害（2型糖尿病含む）、脂質異常症、高血圧、高尿酸血症・痛風、冠動脈疾患、脳梗塞・TIA、脂肪肝、月経異常・女性不妊、睡眠時無呼吸症候群・肥満低換気症候群、運動器疾患、肥満関連腎臓病
- **ウエスト周囲長 男性 ≧85 cm、女性 ≧90 cm** で内臓脂肪蓄積（≧100 cm²）を疑う。IAS/ICCR コンセンサスでも腹囲は「highly responsive vital sign」
- BMI は除脂肪量も反映 → 浮腫性疾患・サルコペニアでは体脂肪を正確に反映しない
- 体脂肪測定: DXA（高精度、少量被曝）、BIA（簡便・反復可、体水分量の影響あり）
- 高度肥満症: OSAS、運動器疾患、肥満関連腎臓病、心不全、静脈血栓、皮膚疾患が相対的に多い。**肺胞低換気症候群・心不全・肺塞栓症は生命予後に直結 → 速やかな減量**。小児期からの肥満、精神・心理的要因、二次性肥満の関与あり

### 二次性肥満

1. 内分泌性: Cushing症候群、甲状腺機能低下症、性腺機能低下症、成人GH分泌不全症、PCOS、インスリノーマなど
2. 遺伝性: Prader-Willi症候群など（幼少時からの肥満歴、特徴的顔貌、精神遅滞、性腺機能低下が端緒）
3. 視床下部性
4. 薬剤性: ステロイド、向精神薬

### 体重目標

| 項目 | 値 |
|---|---|
| 標準体重 | BMI 22 × 身長(m)² |
| 目標体重 | 65歳未満: BMI 22／前期高齢者・後期高齢者: BMI 22〜25（フレイル、ADL、合併症、体組成、身長短縮、摂取状況を踏まえ判断） |
| **肥満症の減量目標** | **現体重の3%** |
| **高度肥満症の減量目標** | **現体重の5〜10%** |

- 肥満を伴う糖尿病は肥満症であり、二次性肥満を検索しつつ**第一に減量による代謝改善**を図る

## CQ13-2 肥満2型糖尿病への行動療法は減量や血糖コントロールに有効か

> **ステートメント**: 行動療法は、短期的には減量や血糖コントロールに有効であり考慮してよい。
> **推奨グレード B**（合意率100%）／エビデンス: 質の高い SR（レベル1+）を含む

### 背景

- 短時間睡眠・夜更かし等の生体リズム障害、シフトワーカーで肥満症・MetS が多い
- 肥満症とうつ病は互いの発症リスクを増加 → 精神科医・臨床心理士・公認心理師との連携を考慮
- ADA 2023: **1日500〜750 kcal のエネルギー減**を目指す食事療法＋身体活動＋高頻度カウンセリング。DSMES、心理社会的ケア、必要に応じ禁煙カウンセリング
- 日本肥満学会の行動療法7つの留意点: ①セルフモニタリング ②ストレス管理 ③先行刺激のコントロール ④問題点の抽出と解決 ⑤修復行動の報酬による強化 ⑥認知の再構築 ⑦社会的サポート
- **毎日の体重測定と記録（視覚的フィードバック）で減量効果増**。モバイルツールは紙より遵守率が高く、6ヵ月以内の短期で顕著な減量

### エビデンス

| 研究 | 対象 | 結果 |
|---|---|---|
| Look AHEAD（RCT） | 肥満2型 5,145人 | 体重 1年 **−8.6% vs −0.7%**、8年 −4.7% vs −2.1%。8年時 ≧5%減量達成 50.3% vs 35.7%、≧10% 26.9% vs 17.2%。HbA1c 低下は1年目の群間差が最大で以後縮小。**複合心血管アウトカムは差なし** |
| Terranova メタ解析（6 RCT） | 12週以上の生活介入 | 体重 **−3.3 kg**（有意）、HbA1c −0.29%（p=0.07、有意差なし） |
| Moncrieft（RCT） | うつ症状を伴う肥満2型 | 12ヵ月で体重 −1.22 kg、HbA1c −0.45%、うつ症状改善。セッション参加率が高いほど効果大 |
| PREDIMED-Plus サブ解析 | MetS 626名 | 糖尿病・前糖尿病248名で HbA1c 群間差 **−1.13%**、インスリン抵抗性改善 |
| POWER（RCT） | 減量後の維持 | グループ認知行動療法の併用でもリバウンドに差なし |

- 精神疾患（うつ病・双極性障害・統合失調症）合併例でも減量・うつ症状改善
- まとめ: 減量と体重維持に一定の効果、**1年以内の血糖改善に寄与**。長期の糖尿病への効果はエビデンス不十分
- 費用: 英国研究では行動療法の中で低強度が最も費用対効果が高い。Look AHEAD の9年間集中介入では費用対効果の明らかな有意性なし

## Q13-3 肥満2型糖尿病への薬物治療

### ポイント

- **インスリン・SU薬は必要最小限**（肥満を助長）
- **SGLT2阻害薬、GLP-1受容体作動薬は体重減少を期待できる**

### 薬剤選択（JDS 2023 アルゴリズム ステップ1: 肥満の有無で選択）

- 肥満（インスリン抵抗性想定）の候補: **ビグアナイド薬、SGLT2阻害薬、チアゾリジン薬**、分泌促進系では **GLP-1受容体作動薬**、抵抗性改善作用を併せ持つ**イメグリミン**
- 食後高血糖に α-GI、ビグアナイド薬を避けがちな高齢者では DPP-4阻害薬も候補
- アジア人は BMI <25 でも内臓脂肪蓄積によるインスリン抵抗性あり → **腹囲も測定**

### 各薬剤の体重への影響

| 薬剤 | 体重への影響 |
|---|---|
| インスリン、SU薬、グリニド薬 | 食事運動療法不十分なまま使うと増加しやすい |
| チアゾリジン薬 | 食事療法を遵守できない例で増加しやすい |
| DPP-4阻害薬、α-GI | 有意な変化なし |
| メトホルミン | 影響なしの報告もあるが、24週以上のRCTメタ解析で 1 kg 未満の有意な減少 |
| イメグリミン | データ蓄積待ち |
| SGLT2阻害薬 | クラス効果で **約2 kg 減**、52週以上でも維持 |
| GLP-1RA | デュラグルチド・リキシセナチド 約1 kg、**セマグルチド・エキセナチド・リラグルチド 2〜3 kg**。アジア人と非アジア人で差なし。消化器症状（悪心・嘔吐・便秘）に留意 |
| GLP-1RA＋SGLT2i 併用 | SGLT2i 単独よりさらに −1.6 kg |
| チルゼパチド（GIP/GLP-1） | GLP-1RA より強い HbA1c 低下・体重減少（メタ解析）。日本人エビデンス蓄積待ち |

### 抗肥満薬

- **マジンドール**: 日本で唯一保険適用の中枢性抗肥満薬。**BMI ≧35 の高度肥満症のみ、投与期間3ヵ月まで**。口渇、便秘、悪心、睡眠障害。依存性の懸念（臨床エビデンスなし）。食事・運動療法で不十分な高度肥満2型糖尿病でのみ併用検討
- **セマグルチド 2.4 mg 週1回**: 肥満症治療薬として 2024年2月発売。非糖尿病肥満者で対照比 −12.4%。東アジア人（STEP 6）で68週 **−13.2% vs −2.1%**

## CQ13-4 外科療法は高度肥満症を伴う2型糖尿病に有効か

> **ステートメント**: 減量・代謝改善手術は、手術前後の適切なサポート体制と安全性が確保されれば、減量に難渋する高度肥満を伴う2型糖尿病患者の血糖コントロール、体重、死亡を含む予後の改善に有効であり推奨される。
> **推奨グレード A**（合意率100%）／エビデンス: 質の高い SR（レベル1+）を含む

### 保険適用（腹腔鏡下スリーブ状胃切除術）

| 時期 | 要件 |
|---|---|
| 2014年〜 | 6ヵ月以上の内科治療で効果不十分な **BMI ≧35** ＋ 糖尿病・高血圧・脂質異常症・睡眠時無呼吸症候群のうち1つ以上 |
| 2022年改定で拡大 | 6ヵ月以上の内科治療で効果不十分な **BMI 32〜34.9** の糖尿病（**HbA1c ≧8.0%**）＋ 以下のうち**2つ以上**: ①高血圧（6ヵ月以上薬物治療でも SBP ≧160）②脂質異常症（6ヵ月以上スタチン等でも LDL-C ≧140 または non-HDL-C ≧170）③重症 OSAS（AHI ≧30） |

- スリーブバイパス術（スリーブ状胃切除＋十二指腸空腸バイパス）: 残胃を内視鏡観察しやすく日本人に適合。現時点で先進医療A

### 3学会合同コンセンサスステートメント（2021）

- **BMI ≧35 の2型糖尿病**: 専門医による6ヵ月以上の治療でも BMI ≧35 が継続 → 血糖コントロールにかかわらず外科療法を**推奨**
- **BMI ≧32 の2型糖尿病**: 専門医治療で6ヵ月以内に **5%以上の減量が得られない**、または得られても **HbA1c ≧8.0%** → 外科療法を**検討**

### アウトカム

| アウトカム | 主な結果 |
|---|---|
| HbA1c・寛解 | 10件のメタ解析で HbA1c 低下、寛解（薬なし HbA1c <6.5%）率高い。5年以上でスリーブ ＝ ルーワイ胃バイパス。**アジア人は術後2年寛解率が高い**。J-SMART（日本人322名、スリーブ）: 術後2年 総体重減少率 **29.9%**、寛解率 **75.6%**。罹病期間が短いほど寛解率高いが、どの術式でも経時的に低下。SOS study: 寛解 OR 6.3、ただし2年以降 72.3% → 30.4% |
| 細小血管症 | SOS study 19年で HR 0.56。神経障害の発症抑制・症状改善。網膜症の発症・進行抑制（**進行網膜症は術後1年以内に悪化例が多い**）。微量アルブミン尿新規発症 OR 0.18。GFR・Cr・ESKD は有意差なし |
| 大血管症 | 心血管イベント HR 0.52、心筋梗塞 HR 0.40、心不全 HR 0.5 |
| 総死亡 | 糖尿病患者で HR **0.41**、平均余命 **+9.3年**。心血管死 OR 0.35、癌死 OR 0.31、糖尿病関連死 OR 0.25。**自殺を含む外因死は増加の可能性（OR 1.72）** |
| QOL | STAMPEDE 5年: 身体機能・一般的健康感・糖尿病関連 QOL 改善。精神的より身体的 QOL の改善が大 |

- 術後も心理社会的フォローを含む多職種チームの長期関与が必要
- 費用: メタ解析で cost-effective（23,320 USD/QALY）、韓国 674 USD/QALY。日本での報告はなし

## Q13-5 メタボリックシンドロームとは何か

### 診断基準（表1）

| 項目 | 基準 |
|---|---|
| **必須**: 内臓脂肪蓄積 | ウエスト周囲長 男性 ≧85 cm／女性 ≧90 cm（内臓脂肪面積 ≧100 cm² 相当） |
| ＋以下のうち**2項目以上** | |
| 脂質 | TG ≧150 かつ/または HDL-C <40 mg/dL |
| 血圧 | SBP ≧130 かつ/または DBP ≧85 mmHg |
| 空腹時高血糖 | ≧110 mg/dL |

- ウエストは立位・軽呼気時・臍レベルで測定（臍が下方偏位していれば肋骨下縁と前上腸骨棘の中点）
- 各項目の**薬物治療中はその項目に含める**。糖尿病・高コレステロール血症があっても除外しない
- MetS と診断されたら糖負荷試験が薦められる（必須ではない）。**空腹時血糖 ≧100 なら必要に応じ 75g OGTT を追加検討**
- 非肥満でも内臓脂肪蓄積例が相当数（男性健診で全体の17.2%、非肥満者の26.8%）→ 初診時の内臓脂肪評価が重要
- 海外基準では腹囲は必須項目でない。日本の MetS は内臓脂肪減少を目指す介入を見据えた概念
- 禁煙、高血圧・高LDL-C 対策は MetS の有無にかかわらず重要

### 病態・リスク

- 内臓脂肪の過剰蓄積 → 脂肪酸・グリセロールの肝流入 → 脂質異常・インスリン抵抗性。脂肪組織の炎症、低アディポネクチン血症
- 特定健診 664,926人: MetS の心血管死 HR **1.39**
- 日本の10コホートメタ解析: 40〜64歳男性で MetS の心血管疾患リスク **2.95倍**。**BMI <25・腹囲増大なしでも危険因子2つで 2.41倍** → 内臓脂肪蓄積のない危険因子集積例も高リスク

### 介入

- 個々のリスク因子の治療より先に、**生活習慣改善で内臓脂肪減少**（異所性脂肪も減少し複数因子を包括改善）。不十分なら個別治療を追加
- DPP: 7%減量目標の生活介入で MetS 新規発症を抑制
- Look AHEAD: 1年 −8.6%、腹囲・身体活動・HbA1c 改善も CVD 抑制は証明されず（対照群への一定介入、減量が持続しなかったことなどが理由）

## Q13-6 NAFLD/NASH を伴う肥満2型糖尿病への対応

### ポイント

- **肥満2型糖尿病には腹部超音波検査と肝機能検査を行うことを提案**
- 食事・運動療法による体重減少は NAFLD/NASH の肝機能・組織像を改善

### 概念

- NAFLD: 脂肪肝あり、アルコール性・ウイルス性・薬物性などを除外。飲酒上限 エタノール **男性 30 g/日未満、女性 20 g/日未満**
- NAFL（ほぼ進行しない）と NASH（線維化→肝硬変・肝癌）に分類
- **PNPLA3 rs738409 マイナーアレル**: 日本人は保有割合が高く、発症・進行が早く肝癌発生率も高い
- 糖尿病患者の NAFLD 有病率 約55%（東アジア52%）、NASH 約37%
- 2023年9月29日、日本消化器病学会・日本肝臓学会が **MASLD/MASH** への名称変更を発表（日本語訳検討中）

### スクリーニング（NAFLD/NASH 診療GL 2020 の2ステップ）

1. **First step**: 肝逸脱酵素／腹部超音波で異常
2. **Second step**: **FIB-4 index**（年齢・血小板・AST・ALT）や NAFLD fibrosis score（年齢・BMI・耐糖能異常・AST/ALT・血小板）で絞り込み → 消化器専門医紹介を検討
- 専門医ではエラストグラフィ（エコー・MRI）で肝生検適応を絞り込む
- ※ FIB-4 のカットオフ値は本章に記載なし

### 予後

- CVD 発症 OR 2.05（Musso）、発症/死亡 OR 1.64、線維化など重症例で OR 2.58
- 日本人 NAFLD 1,398例（平均4.6年）: 死亡48例中 肝疾患関連22例・心血管3例、肝関連イベント77例・心血管イベント72例
- 日本人2型糖尿病で MAFLD 合併により冠動脈疾患 HR 1.29

### 治療

- **7%以上の減量で NASH 組織改善、10%以上で線維化も改善**（達成・維持のハードルは高い）
- 減量・代謝改善手術: RCT（BRAVES）で1年後 NASH 組織学的寛解が標準治療の約3.6倍
- NAFLD 特異的治療薬はない（2022年4月現在）。糖尿病合併 NAFLD の半数以上は NASH の可能性 → 積極的な糖尿病治療
- **チアゾリジン薬**: 脂肪化・炎症・線維化の組織学的改善のエビデンス確立
- GLP-1RA、SGLT2阻害薬: 肝機能・肝組織改善の報告あり（蓄積待ち）

## 外来での使いどころ（自院メモ）

- 糖尿病初診時は **BMI に加え腹囲を必ず測定**。BMI <25 でも腹囲 男85/女90 cm 以上なら内臓脂肪型として扱う
- 肥満症の減量目標は**まず現体重の3%**（高度肥満は5〜10%）と具体的数字で伝え、**毎日の体重測定と記録**を指導
- 肥満2型の薬剤選択は **メトホルミン／SGLT2i／GLP-1RA** を軸に、インスリン・SU は最小限
- **BMI ≧35（または ≧32 で HbA1c ≧8.0% が持続・6ヵ月で5%減量できない）→ 減量・代謝改善手術の相談先へ紹介**を検討
- 肥満2型には**腹部エコー＋肝機能**、異常があれば **FIB-4 を計算**して消化器内科紹介を判断
- 急速な体重増加・特徴的身体所見があれば二次性肥満（Cushing、甲状腺機能低下、薬剤性）を確認
- 空腹時血糖 100 以上の MetS 例は OGTT を検討（境界型から動脈硬化リスク）
