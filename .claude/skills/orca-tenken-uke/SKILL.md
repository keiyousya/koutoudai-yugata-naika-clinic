# 点検用UKEファイルの出力（WebORCA）

対象月: $ARGUMENTS

OASCIS には請求用ではなく、院外処方の医薬品も含んだ**点検用レセプト**の UKE ファイルを登録する。1か月ごとに「A. 42 明細書で点検用レセプトを作る」→「B. 44 総括表・公費請求書で社保・国保のファイルを出す」を繰り返す。

出典はアルファシステムのマニュアル「点検用レセプト出力方法 (2).pdf」（`G:\マイドライブ\勾当台夕方内科クリニック\アルファシステム\`）。2026-10-02 に R8.4 分で実際に通して手順を確認した。

## 前提

- WebORCA: https://weborca.cloud.orcamo.jp/ 。**ログインはユーザーが手動で行う**（パスワードは入力しない）。新しいタブで開いてログインを頼み、終わったら進める
- ユーザーが別タブで WebORCA を開いていると処理がぶつかるので、閉じてもらう
- 画面の座標はウィンドウの大きさで変わる。**ボタンはラベルで探し、毎回スクリーンショットで位置を確かめてからクリックする**
- 処理中はスクリーンショットがタイムアウトしやすい。数秒 `wait` してから撮り直す
- 日付欄は `R8.5` のように入力して Tab で確定する（表示は `R 8. 5` に整形される）

## 手順（1か月分）

### A. 42 明細書（点検用レセプトの作成）

1. マスターメニュー「01 医事業務」→ 業務メニュー「42 明細書」
2. 右上のプルダウンを **「2 点検用レセプト（院外処方含）」** に切り替える。**初期値は「1 提出用レセプト」なので必ず変える**
3. 「一括作成」・医保「全件」のまま、**診療年月** に対象月を入れる
4. 右下「確定」→ 確認画面に「【点検用レセプト】令和X年X月 入院外分新規作成処理を行います」と出ることを確かめて OK
5. 処理結果を見る
   - 「処理は正常に終了しました」→ F1「戻る」
   - 赤字「主科未設定分又は種別不明分がありますので印刷画面で確認して下さい」→ 下の「種別不明の確認」をしてから F1「戻る」で抜ける
6. 「戻る」で業務メニューへ戻る

#### 種別不明の確認

種別不明のレセプトは UKE ファイルに入らない。対象の患者さんと理由をチャットでユーザーに報告する（**患者登録や保険の修正はユーザーの判断なしに行わない**。請求済みの月なので、直すかどうかはユーザーが決める）。

1. 処理結果で F12「印刷」→ 印刷指示画面（総件数が出る）
2. 左上「全件印刷」を押して **「指定印刷」** に切り替える（全チェックが外れる）
3. 一覧の最下部までスクロールし、**「レセプト種別不明」** だけにチェック（件数欄に件数が出ている）
4. 右下「印刷」→ 確認画面で **F10「プレビュー」** → 処理結果で **F12「プレビュー」**
5. プレビュー選択画面の左に患者番号の一覧、右にレセプトが出る。レセプト上部の赤字コメントが理由（例: 「保険組合せ0001は適用開始日が令和8.6.11となっています」＝受診月に有効な保険組合せがない）。患者番号・氏名・理由を控える（報告用。ファイルには書かない）
6. 「戻る」を2回でレセプト作成画面へ戻る

### B. 44 総括表・公費請求書（UKEファイルの出力）

1. 業務メニュー「44 総括表・公費請求書」
2. **診療年月を対象月に書き換える。初期値は直近の請求月（例: R8.9）になっていて、そのままだと別の月が出る**
3. 画面下「レセプト電算システム提供データ・公費CSV提供データ」のプルダウンを **「2 点検用（院外処方含）」** に切り替える（初期値「1 提出用」）。ファイル出力先は「5 クライアント保存」のまま
4. 下段「社保レセ電」→ 確認画面「【点検用】社保分（入院外）のレセプト電算データを作成します」→ **F11「印刷しない」**
5. 処理結果「処理は正常に終了しました　レセプト N件」の件数を控えて F1「戻る」
6. **ブラウザのダウンロード確認ダイアログが開くので、ユーザーに確認と OK を押してもらう**（Claude からは操作できない／しない）。押してもらうまで次へ進まない
7. `C:\Users\tamur\Downloads\TENKENRC.UKE` ができたら、検証（下記）してから `YYYY-MM_社保_TENKENRC.UKE` にリネームする。**社保・国保とも同じファイル名で落ちてくるので、次を出す前に必ずリネームする**
8. 「国保レセ電」で 4〜7 を繰り返す（確認画面は「国保・広域分」＝国保と後期高齢者がまとめて1ファイル）。リネームは `YYYY-MM_国保_TENKENRC.UKE`
9. 複数月なら診療年月を書き換えて B を繰り返す前に、その月の A を先に済ませる

### ファイルの検証

```bash
f=/c/Users/tamur/Downloads/TENKENRC.UKE
iconv -f CP932 -t UTF-8 "$f" | head -1                                   # IR,1,... = 社保（支払基金）/ IR,2,... = 国保連
iconv -f CP932 -t UTF-8 "$f" | grep '^RE' | cut -d, -f4 | sort | uniq -c  # 全件が対象の診療年月（例: 202605）
```

- RE の件数が B-5 で控えた件数と一致すること
- 社保 + 国保 の件数 ＝ A の総件数 − 自費 − 種別不明 になっていること
- IR の請求年月（202610 など）は出力した月なので気にしない

## 報告

月ごとに表でまとめる: ファイル名 / 区分（IR） / レセプト件数 / 種別不明の患者番号・氏名・理由。最後に「OASCIS へのアップロードは未実施」と書く（アップロード手順はこのスキルの範囲外）。
