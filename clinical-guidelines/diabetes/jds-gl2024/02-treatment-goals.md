- **確認日**: 2026-09-13

## Q2-1 糖尿病治療の目標は？

- 目標: 代謝異常の改善＋合併症・併発症の発症/増悪予防 → **糖尿病のない人と変わらない QOL と寿命**
- 慢性高血糖は細小血管合併症（網膜症・腎症・神経障害）と大血管合併症（脳梗塞・心筋梗塞）の危険因子
- 併発しうる病態: 悪性腫瘍、感染症、歯周疾患、骨折、認知機能障害、サルコペニア、フレイル、糖尿病性心筋症
- 身体面だけでなく**心理面の負担軽減**も目標に含む
- わが国では糖尿病患者の平均死亡時年齢は一般の平均寿命より短いが、治療の進歩で差は縮小しつつある
- スウェーデンの報告: **診断時年齢が若いほど**死亡年齢の期待値が一般より低下 → 年齢・生命予後に応じた血糖管理が重要
- **スティグマ・差別・偏見**への対応も求められる（学会・協会のアドボカシー活動）

### 図1 糖尿病治療の目標（構成）

| 階層 | 内容 |
|---|---|
| 基盤 | 血糖・血圧・脂質の良好なコントロールと適正体重の維持、禁煙の遵守 |
| 中間 | 細小血管合併症と動脈硬化性疾患（虚血性心疾患・脳血管障害・末梢動脈疾患）の発症・進展阻止／併存症（サルコペニア・フレイル・認知症・悪性腫瘍など）の予防・管理／スティグマ・社会的不利益・差別の除去 |
| 最終目標 | 糖尿病のない人と変わらない寿命と QOL |

## Q2-2 糖尿病の基本的治療方針をどう考えるべきか？

### ポイント

- 治療目標は **年齢・罹病期間・臓器障害・低血糖の危険性・サポート体制** を考慮して個別に設定
- **インスリンの絶対的適応**: インスリン依存状態、高血糖性昏睡、妊娠時、全身管理が必要な外科手術、重症感染症、静脈栄養時など
- **インスリンの相対的適応**: 経口薬や GLP-1 受容体作動薬のみで良好なコントロールが得られない、やせ型で栄養状態低下、ステロイド治療時など
- インスリン非依存状態: **食事・運動療法を2〜3ヵ月**行っても目標未達なら経口薬や GLP-1RA。代謝障害の程度によっては最初から薬物療法を併用
- 継続的治療とチーム医療による糖尿病教育が治療の根幹

### 基本的治療方針

- インスリン依存状態（多くの1型、代謝障害が著しい2型）→ **直ちにインスリン療法**
- インスリン非依存状態でも、重篤な感染症・全身管理が必要な手術・肝腎合併症の程度によってはインスリン
- 妊娠時・妊娠糖尿病 → インスリンで厳格なコントロール
- 代謝障害の程度で初期対応を分ける:

| 代謝障害 | 目安 | 初期対応 |
|---|---|---|
| 高度 | 随時血糖 **250〜300 mg/dL 程度またはそれ以上** | 最初から経口薬・インスリン・GLP-1RA を食事・運動療法に加えて開始 |
| 中等度以下 | 随時血糖 250〜300 mg/dL 程度またはそれ以下 | まず食事・運動療法と生活習慣改善の情報提供 → 2〜3ヵ月で未達なら薬物療法 |

- 薬物は**少量から開始し漸増**。減量・生活習慣改善で減量〜中止できることがある（詳細は5章・6章）
- 日常臨床の不確実性に対し **shared decision making（SDM）** が有効。よりよい SDM は治療満足度を向上させる

### 図2 インスリン非依存状態の治療（初診時フロー）

| 初診時所見 | 担当 | 治療と対応 |
|---|---|---|
| **急性代謝失調／尿ケトン体陽性** | 糖尿病専門医と協議 | 十分な水分補給とインスリン注射開始、血糖・尿ケトン体測定、以後の処置を専門医と協議 |
| いずれもなし・**HbA1c ≧9.0%** | 糖尿病専門医による治療・管理（かかりつけ医と継続的連携） | 食事・運動療法・教育＋経口薬併用療法や GLP-1RA、インスリンとの併用療法 |
| いずれもなし・**HbA1c <9.0%** | かかりつけ医による継続治療・管理 | 食事・運動療法・教育 → 目標未達なら低血糖リスクの少ない経口薬（治療ガイド p.40 表6 参照）や GLP-1RA → さらに未達なら併用療法 |

※ 各段階で目標達成なら治療継続、不達成なら次の段階へ。HbA1c 9.0% は参考指標で個別に判断。
※ 注3: 施設・地域の医療状況や患者背景により専門医紹介、教育入院も考慮。

### 糖尿病専門医への紹介を考慮する場合（図2 注）

1. 口渇・多尿・体重減少などの症状がある
2. 低血糖を頻回に繰り返し治療の見直しが必要
3. 急性増悪、ステロイド使用・膵疾患・感染症に伴う血糖の急激な悪化
4. 周術期・手術に備えて厳格なコントロールが必要
5. 患者教育が改めて必要
6. 内因性インスリン分泌が高度に枯渇している可能性

- 専門医・認定教育施設は日本糖尿病学会ホームページで都道府県別に検索可能

### 継続的治療と糖尿病教育

- 患者の自己管理を支えるチーム医療: 糖尿病療養指導士・看護師・管理栄養士・薬剤師＋必要に応じ眼科・腎臓内科・循環器・神経内科・産科・歯科。**主治医が主導**
- 患者の価値観とニーズを尊重し、治療法の選択に関与させる
- 地域連携: 各都道府県の**糖尿病対策推進会議**、**糖尿病性腎症重症化予防プログラム**（日本健康会議「健康づくりに取り組む5つの実行宣言2025」で推進）
- **かかりつけ医など小規模医療機関**: 看護師・管理栄養士と教育を企画し、眼科など他分野と緊密に連携。コントロール悪化・合併症進行・急性代謝失調時は専門医療機関と連携
- 家族の協力も大切

## Q2-3 血糖コントロールの目標はどう設定すべきか？

### ポイント

- 可能な限り正常な代謝状態を目指す。個別に設定した目標を**治療開始後早期に達成・維持**すれば長期予後の改善が期待できる

### 根拠となる主な試験

| 試験 | 示されたこと |
|---|---|
| DCCT、UKPDS、Kumamoto study | 厳格な血糖コントロールの有効性（細小血管症の抑制には空腹時血糖と HbA1c の是正が重要） |
| DECODE、Funagata Diabetes Study | 75g OGTT 2時間値高値・IGT が心血管疾患のリスク因子 |
| DCCT/EDIC、UKPDS 追跡 | 早期の良好なコントロールが長期の細小・大血管合併症を抑制（**metabolic memory / legacy effect**） |
| ACCORD、ADVANCE、VADT | 罹病期間が長く CVD 既往・リスク因子を有する例では、急激な是正・厳格すぎるコントロールは CV イベントを減らさず重症低血糖を増加。**ACCORD では強化療法群で全死亡・心血管死が有意に増加** |
| Kumamoto study | HbA1c **6.9% 未満**なら細小血管症の出現可能性が少ない |
| J-DOIT3 | 強化療法群 HbA1c 6.8%（標準群より0.4%低い）＋血圧・脂質低下で合併症抑制の可能性 |
| スウェーデン1型コホート（1万人超） | HbA1c **7.0% 超**で細小血管症リスク増加 |
| UKPDS（罹病期間の短い例） | HbA1c 6.0% 程度まで細小・大血管症とも発症リスク低下 |
| DCCT | HbA1c **8.0% 超**で網膜症進行リスク増大 |
| UKPDS 従来療法群 | 細小血管症が有意に多く、HbA1c 中央値 **7.9%** |

→ 目標は年齢・罹病期間・合併症・低血糖リスク・サポート体制で**個別に設定**（ADA/EASD の "Patient-Centered Approach" と一致）

### 図3 血糖コントロール目標（成人・妊娠例除く）

| 目標 | HbA1c | 対応する血糖値の目安 | 適用 |
|---|---|---|---|
| 血糖正常化を目指す際の目標 | **<6.0%** | 空腹時 <110、食後2時間 <140 mg/dL | 食事・運動療法のみで達成可能、または薬物療法中でも低血糖などの副作用なく達成可能な場合。罹病期間が短く心血管系に異常のない若年者など |
| **合併症予防のための目標** | **<7.0%** | 空腹時 <130、食後2時間 <180 mg/dL | 基本の目標 |
| 治療強化が困難な際の目標 | **<8.0%** | — | 低血糖などの副作用その他で強化が難しい場合。**最低限達成が望ましい** |

- 65歳以上は「19章 高齢者の糖尿病」を参照
- **HbA1c 8.0% 以上が続けば治療変更を考慮** → 変更後 **約2〜3ヵ月**観察し、改善がなければ介入を強化

### 図4 目標の個別化（Patient-Centered Approach, ADA 2024 より作成）

HbA1c 7% を中心に、左ほど「より厳格」、右ほど「より寛容」。

| 因子 | より厳格 | より寛容 |
|---|---|---|
| 低血糖・その他の副作用のリスク | 低 | 高 |
| 罹病期間 | はじめて診断された | 長期にわたる |
| 予想される余命 | 長い | 短い |
| 重大な併存疾患 | なし | 重篤 |
| すでに診断された血管症 | なし | 重篤 |
| 患者の選好 | 優秀な自己管理能 | 負担の少ない治療 |
| 社会的資源・支援体制 | 容易に利用可能 | 利用が難しい |

※ 上5因子（低血糖リスク〜血管症）は「通常は改善できない」、下2因子（患者の選好・社会的資源）は「改善の余地あり」。併存疾患・血管症には中間段階「少ない/軽度」あり。原典 p.33 の図の画像で照合済み。

### CGM 指標

- CGM は SMBG に比べ HbA1c を有意に低下させ、低血糖を減少（DIAMOND trial、HypoDE study ほか）
- **target range 70〜180 mg/dL**、**TIR（14日間）70% 以上**を目指す
- TIR 70% ≒ HbA1c 7% 弱に相当。合併症との大規模前向き研究はまだなく、現時点では TIR ≧70% を「ひとつの目安」とする
- 理想: 空腹時も食後も高血糖・低血糖がなく血糖変動が小さい状態を維持し、結果として HbA1c が正常化すること

## 外来での使いどころ（自院メモ）

- 初診で**尿ケトン体陽性・急性代謝失調 → 補液＋インスリン開始し専門医へ即連携**。夕方診療では当日搬送先の確保を優先
- 初診 **HbA1c ≧9.0% は専門医紹介・併診の目安**、<9.0% は自院で食事・運動療法から開始
- 随時血糖 **≧250〜300 mg/dL** なら2〜3ヵ月待たず初回から薬物療法を併用
- 目標は原則 **HbA1c <7.0%**（空腹時 <130、食後2時間 <180）。若年・短罹病・低血糖リスクなしなら <6.0%、高齢・低血糖リスク高・併存症重篤なら <8.0%（65歳以上は19章）
- **HbA1c ≧8.0% が続く患者は治療変更 → 2〜3ヵ月後に再評価**。漫然と同一処方を続けない
- CVD 既往・長期罹病例での急激な HbA1c 是正は避ける（ACCORD）
- CGM 使用例は **TIR ≧70%（70〜180 mg/dL）** を目標として共有
- 紹介基準（症状あり・頻回低血糖・ステロイド/膵疾患/感染での急激な悪化・周術期・再教育・分泌枯渇疑い）をカルテテンプレート化しておく
