# 電話番号の変更届（東北厚生局）

コード内容別医療機関一覧表に載っている当院の電話番号を、開設時の携帯番号から
固定番号へ直すための届出。

| | |
|---|---|
| 提出先 | 東北厚生局 指導監査課 |
| 様式 | 保険医療機関・保険薬局届出事項変更（異動）届 |
| 変更内容 | 電話番号 070-8564-8516 → 022-393-8689 |
| 変更年月日 | 令和8年3月5日（楽天ひかりの利用開始日） |
| 添付書類 | 不要 |
| 提出方法 | 郵送または窓口持参 |
| 状態 | **提出待ち**（提出日を記入して投函する） |

## 経緯

- **2026-09-12**：当院の携帯番号がファストドクター等の医療機関ポータルに出回っている
  出どころを特定。厚生局が毎月公表する「コード内容別医療機関一覧表」に電話番号の列があり、
  宮城県・医科版の項番992（医療機関コード 0415119874）に携帯番号が載っていた。
  ただし届出事項変更届にも仙台市の変更届にも**電話番号の欄がない**ため、
  厚生局のお問い合わせフォームから手続き方法を照会した。
- **2026-09-15**：厚生局から「県別の疑義照会フォームから出し直すように」と回答があり、
  宮城県の疑義照会専用フォームから再送信した。
- **2026-09-17（電話）**：厚生局から電話で回答。**届出事項変更（異動）届の「その他の変更」欄に
  変更前後を書いて提出すればよい**。変更年月日は実際に変更した日。**添付書類は不要**。
- **2026-09-17**：様式を最新版で取得し、届出書と送付状を作成。

## 記入内容

- 標題は「保険医療機関」のみを残した（保険薬局・生活保護法指定医療機関は削除）。
  生活保護法の指定は未取得のため、その欄のチェックもしていない。
- 医療機関コード欄は**7桁**なので `5119874` を記入（10桁は 0415119874）。
- その他の変更：変更前「電話番号　変更 / 070-8564-8516」、変更後「022-393-8689」、
  変更年月日「令和8年3月5日」。
- 開設者の氏名及び住所はクリニック所在地を記入。押印欄はないので印鑑は不要。

## 提出前にやること

1. 届出書の「上記のとおり届け出します」の下の**提出日（令和　年　月　日）が空欄**。手書きで記入する。
2. 送付状の日付も同じ日に揃える（HTMLを直すか、印刷後に手書き）。
3. 届出書1枚＋送付状1枚を封入し、下記へ郵送する。

```
〒980-8426
仙台市青葉区花京院1-1-20 花京院スクエア21階
東北厚生局 指導監査課 御中
```

## この後

一覧表は毎月1日現在で更新される。月内に処理されれば翌月版から携帯番号が消える。
元データが直ったら、各ポータル（ファストドクター等）へ修正依頼を出す。
仙台市の医療機能情報は 2026-09-14 にG-MISから新規報告済み。
