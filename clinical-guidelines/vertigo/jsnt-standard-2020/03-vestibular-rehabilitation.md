# 総論 III めまい（前庭）リハビリテーション：非特異的なリハビリテーション

- **出典**: 日本神経治療学会「標準的神経治療：めまい（2020）」神経治療 37(5):769–811, 2020 — A 総論 III（p.782–785、執筆：山中敏彰）
- **原文**: https://www.jstage.jst.go.jp/article/jsnt/37/5/37_769/_pdf/-char/ja
- **発行**: 2020
- **確認日**: 2026-09-14

末梢前庭が障害されると、中枢の可塑性による「前庭代償」でめまいは徐々に改善する。代償が止まると症状が慢性化し、薬の効果にも限界がある。その慢性化した状態に対する非特異的なリハビリテーションを解説した章。

---

## 1. 対象と控える場合

| 対象 | 例 |
|---|---|
| 代償が止まった一側・両側の高度前庭障害 | 前庭神経炎、進行したメニエール病、めまいを伴う突発性難聴、Hunt 症候群、聴神経腫瘍術後、特発性前庭障害、薬剤性前庭障害 |
| 特定の刺激で誘発されるめまい | BPPV、視性めまい（体位変換や視環境の変化で起こる） |

**控える場合**：自発性のめまいや悪心・嘔吐がある急性期／運動が禁止されている心疾患・脳血管疾患／疲労、睡眠不足、感冒のとき

## 2. 3つの治療コンセプト

| コンセプト | 病態 | 主な対象 | 使うトレーニング |
|---|---|---|---|
| **平衡適応の促進** | 前庭代償の遅延・不全 | 前庭神経炎、めまいを伴う突発性難聴、Hunt 症候群、特発性前庭障害、聴神経腫瘍術後、両側前庭障害 | 眼運動系 A・D（B・C）、姿勢・歩行 E・F・G・I・J |
| **平衡感覚の置換・代用** | 代償不全が長引き、視覚や深部知覚への依存が偏った状態 | PPPD、上記疾患が進行した状態 | 姿勢・歩行 H・K |
| **慣れ（耐性）の獲得** | 誘発性めまい | BPPV、起立性めまい、視性めまい | 体位変換 L |

- **平衡適応**：前庭眼反射（VOR）の利得が落ちると、頭を動かしたときに視界がぶれてふらつく。頭を回しながら視標を捉える練習で VOR と視性眼球運動を協調させる。姿勢では前庭脊髄反射と下肢の伸張反射を鍛える
- **置換・代用**：視覚依存が強いと暗い所で、深部知覚依存が強いと凸凹道や坂道でふらつく。偏った依存を補正する
- **慣れ**：誘発される頭位や体位を繰り返し、中枢の感受性を下げる

## 3. トレーニングメニュー（図1）

### 1) 前庭・視性眼運動トレーニング（1日2〜3回）
| | 内容 | 回数 |
|---|---|---|
| A 注視維持 | 眼前 50 cm の視標を見つめたまま、頭を左右に30度回す／上下に30度曲げ伸ばし | 各10往復（1往復2秒） |
| B 急速眼運動 | 頭を動かさず、左右・上下の視標を交互に見る | 各10往復 |
| C 緩徐眼運動 | 頭を動かさず、左右・上下に動く視標を目で追う | 各10往復 |
| D 頭–眼協調 | 側方・上下の視標へ頭を回して視線で捉える（**先に視標を見て、それから頭を止める**のがコツ） | 各10往復 |

慣れてきたら速度を2〜3倍に、振り幅を45度に、立位で行うなど負荷を上げる。D は買い物や洗濯物干しなど、頭を動かすときのふらつきに効く。

### 2) 姿勢・歩行制御トレーニング（1日2〜3回、各5分）
| | 内容 |
|---|---|
| E 姿勢保持（基本） | 閉脚・継ぎ足で立つ。体の中心点の動きを意識する |
| F 姿勢保持（前庭刺激） | 頭を30度左右に回す・上下に動かす・左右に傾けながら正中を保つ |
| G 立ち直り | 体を左右・前後に傾け、足を踏み直して素早く正中に戻す |
| H 感覚依存の調整 | ①閉眼で硬い床 ②開眼で柔らかい床（フォームラバー） ③閉眼で柔らかい床 で立つ |
| I 基本歩行 | まっすぐ歩く |
| J 条件歩行（前庭刺激） | 頭を左右や上下に動かしながら／加速・減速しながら歩く |
| K 条件歩行（感覚依存の調整） | サングラスで硬い床、開眼で柔らかい床、サングラスで柔らかい床を歩く |

最終目標はスーパーや駅の人混みを歩けること。歩行は下肢筋力の強化にもなる。

### 3) 馴化（体位変換）トレーニング
- **L**：①臥位⇔座位（寝起き） ②左右の側臥位（寝返り） ③座位⇔立位（起立・着席） を、めまいが軽くなるまで繰り返す。次の動作までは間隔を置き、気分が悪くならないようにする。眼振が繰り返しで減衰する症例に効果がある

### 実施方法
- **1回10〜20分、1日2〜3回、3〜6か月、自宅でのホームトレーニング**として行う
- 始める前に意義・理論・方法を十分に説明し、動機づけを高めることが成功の鍵
- 能力の向上に合わせて段階的にレベルを上げる

## 4. エビデンス

- 眼運動・姿勢歩行・馴化の3カテゴリーを組み合わせたプログラム：**エビデンスレベル I、推奨度 A**（Cochrane レビューと米国理学療法士協会の臨床ガイドライン）
- B・C を単独で行う効果は乏しい（ただし VOR 適応の準備としての意義はあると執筆者は考えている）
- 1日3回・1日20分以上が必要で、改善がプラトーになれば中止：**エビデンスレベル V、推奨度 C1**
- 効果の乏しい難治例もあり、感覚代行など新しい手法が検討されている

## 外来での使いどころ（自院運用メモ）

- **前庭神経炎の急性期が過ぎたら早期に離床させ、A・D と E・I から始める。** 「安静にしていれば治る」とは説明しない
- **慢性のふらつきで、中枢性・心因性・薬剤性を除外した例**に、ホームエクササイズとして紙で渡しやすい（A・D・E・I・L が分かりやすい）
- **高齢者は転倒に注意**：閉眼や柔らかい床での練習は、壁際や手すりのそばで行うよう指導する（[加齢によるめまい](08-aging.md) も参照）
