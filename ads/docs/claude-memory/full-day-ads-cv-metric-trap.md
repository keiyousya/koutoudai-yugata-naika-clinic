オーナーが「予約いっぱい、広告止めていいかも」と言ったら**止める**。CV数やCPAを根拠に
「採算が合っているので続けましょう」と止めるのを思いとどまらせない。

**Why:** GoogleのCVは「LINE友だち追加＋電話」。**満席で断った電話もCVに計上される。**
つまり満席の日ほどCPAは良く見え、一番無駄な日に一番良い数字が出る。指標が構造的に壊れている。
2026-09-20（日）にこれをやった。14:08に「止めていいかも」と言われたのに
「CPA ¥1,455 は損益分岐 ¥3,850 の4割だから続けるべき」と提案し、上限CPCを2回下げただけで
19:58まで走らせた。実際にはオーナーは終日電話で予約を断り続けており、Google ¥11,719 +
Yahoo ¥1,409 が無駄になった。「クリックは翌日以降の枠に流れる」という理屈も外れで、
断られた人は次のクリニックに電話する。

**How to apply:**
- 満席・休診・キャパ制約の話が出たら、CV/CPAは判断材料から**外す**。procyonの
  `reservationCount` も created_at ベースで枠の空きは見えない（[[reservation-count-reading-traps]]）
- 枠の空きはこちらからは見えない。**オーナーの「いっぱい」は一次情報として、数字より優先する**
- 「絞る」と言われても、満席が理由なら上限CPCの小刻みな引き下げでは足りない。止めるかどうかを先に確認する
- 止めるのは `gads budget status --campaign-id <ID> --state PAUSED --yes`。即時・可逆
