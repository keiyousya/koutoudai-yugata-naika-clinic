# 第14章 糖尿病に合併した高血圧

- **出典**: 日本糖尿病学会『糖尿病診療ガイドライン2024』14章（p.301–317）
- **原文**: https://www.jds.or.jp/uploads/files/publications/gl2024/14_1.pdf
- **発行**: 2024-05-30
- **確認日**: 2026-09-13

構成は「大血管症・細小血管症のリスク → 降圧目標（CQ）→ 第一選択薬（CQ）→ 併用薬 → 心不全」。外来で頻用するのは CQ14-3、CQ14-4、Q14-5 と図1。
※ 2024版の CQ ステートメントには推奨グレードと合意率のみ記載。エビデンスレベルは各引用文献ごとに付与されており、下記では推奨判定表の記載を併記する。

## Q14-1 糖尿病に合併した高血圧は大血管症のリスクファクターか

- 糖尿病と高血圧はいずれも大血管症（冠動脈疾患・脳血管疾患・PAD）の確立したリスク。**合併で発症頻度はさらに増加し予後悪化**
- 糖尿病患者は高血圧の合併が多く、高血圧患者も糖尿病の合併が多い

| 研究 | 主な結果 |
|---|---|
| MRFIT（米国男性34万人、12年） | 大血管症死亡は糖尿病群で3.7倍。糖尿病例で SBP は脂質・喫煙と独立した予知因子 |
| NIPPON DATA | 糖尿病群では血圧が高いほど大血管症死亡の絶対リスク増加 |
| APCSC（環太平洋39万人） | 糖尿病集団で **SBP 10 mmHg 上昇ごとに大血管症死亡 18%増** |
| UKPDS 36 | 平均 SBP 上昇とともに大血管・細小血管症増加。SBP ≧160 は ≦120 に比し有意に増加。平均 SBP 10 mmHg 低下で心筋梗塞が有意に低い |
| 日本人59万人コホート | 糖尿病の有無・耐糖能にかかわらず SBP・DBP 上昇とともに大血管症増加 |

## Q14-2 糖尿病に合併した高血圧は細小血管症のリスクファクターか

- 高血圧は神経障害・網膜症・腎症のリスクファクター（1型・2型とも）

| 合併症 | 要点 |
|---|---|
| 神経障害 | **1型**: 最も強い予測因子。高血圧で6年間の発症相対リスク **4.1倍**、血糖・罹病期間と独立。**2型**: 関連は明確でなく、UKPDS の厳格降圧でも神経障害の悪化は軽減せず |
| 網膜症 | 内皮障害・血流調節障害・VEGF 活性上昇を介し進行。WESDR（1型955人、25年）: **SBP 10 mmHg 上昇で増殖網膜症リスク 14%増**。GoDARTS（2型4,758人、16年）: SBP 1SD（約17 mmHg）低下で網膜症消失 20%増、DBP 1SD（約10 mmHg）上昇で非増殖性網膜症顕性化 87%増 |
| 腎症 | **1型**: 蛋白尿のない段階の高血圧合併は3.9%（一般人口4.4%）→ 腎症進行に伴い高血圧が増える。**2型**: 診断時点で半数以上に高血圧 → 高血圧が腎症に先行。いずれも CKD 進行とともに高血圧合併が増え、末期腎不全ではほぼ全例 |

## CQ14-3 大血管症の発症予防に血圧を130/80 mmHg 未満にコントロールすることが有効か

> **ステートメント**: 心血管イベントおよび脳卒中の発症予防には**診察室血圧130/80 mmHg 未満**を目標とした降圧療法が推奨される。
> **推奨グレード A**（合意率100%）／エビデンス: 質の高い RCT（レベル1）からなるメタ解析

### 糖尿病合併高血圧の治療計画（図1、高血圧治療GL 2019 より）

**治療開始血圧 130/80 mmHg 以上** → 生活習慣の修正・血糖管理と同時に降圧治療を開始

| 血圧 | 対応 |
|---|---|
| **≧140/90** | 降圧薬を開始 |
| **130〜139/80〜89** | 生活習慣修正で降圧が見込めれば**1ヵ月を超えない範囲**で試み、なお ≧130/80 なら高血圧と判断し降圧薬開始 |

| ステップ | 微量アルブミン尿・蛋白尿 あり | なし |
|---|---|---|
| 第一選択 | **ARB または ACE阻害薬** | ARB、ACE阻害薬、Ca拮抗薬、利尿薬（少量サイアザイド系） |
| 効果不十分 | 用量増加 または 2剤併用 | 同左 |
| さらに不十分 | 3剤併用: ARB/ACE阻害薬＋Ca拮抗薬＋利尿薬 | 同左 |

- **降圧目標 130/80 mmHg 未満**
- **ARB と ACE阻害薬の併用は避ける**
- 動脈硬化性冠動脈疾患、PAD 合併例、高齢者では降圧に伴う臓器灌流低下に十分配慮
- ※ 原典 p.303 の図の画像で照合済み

### 目標値の根拠

- 従来のメタ解析では 130/80 への積極的根拠は明確でなかったが、以下が採用理由:
  - **日本人は脳卒中の発症頻度が欧米人より高い**
  - **ACCORD-BP**: 厳格群（達成 119/64）は標準群（134/71）に比べ**脳卒中を有意に低下**（HR 0.59）。一次アウトカムは HR 0.88（有意差なし）
  - **J-DOIT3** 事後解析: 強化療法群（達成 123/71）は従来群（129/74）に比べ脳血管イベントを有意に減少
- **STEP**（中国、60〜80歳、糖尿病約19%）: SBP 110〜130 目標は 130〜150 目標に比べ複合心血管イベント **HR 0.74**（95%CI 0.60–0.92）。糖尿病合併例 HR 0.77（0.50–1.17）

### 系統的レビュー（HOT、ABCD、ACCORD、SPS3、RESPECT、J-DOIT3、STEP の7 RCT）

| アウトカム | 結果 |
|---|---|
| 心血管イベント | **有意に低下**（J-DOIT3 の組み入れにかかわらず） |
| 脳卒中 | **有意に低下** |
| 心筋梗塞 | 低下傾向、有意差なし |
| 全死亡 | 有意な低下なし |
| 重篤な有害事象 | ACCORD 厳格群で増加（低血圧・失神・不整脈・低K血症など）。J-DOIT3 では増加なく、非一貫性が大きいため結果の信頼性は乏しい |

- UKPDS など厳格群の目標が 130/80 より高い試験は除外
- HOT: 糖尿病例で DBP ≦80 群は ≦90 群に比べ心血管イベントがほぼ半減

## CQ14-4 ACE阻害薬・ARB はアルブミン尿のない糖尿病合併高血圧の第一選択薬か

> **ステートメント**: アルブミン尿のない糖尿病合併高血圧患者における第一選択薬としては、**ACE阻害薬、ARB のみならず、Ca拮抗薬、サイアザイド系利尿薬がいずれも推奨**される。
> **推奨グレード U**（合意率100%）／エビデンス: 16編の質の高い RCT からなるメタ解析
> ※ アルブミン尿を有する例は9章参照

- 2019年以降の新規論文なし → 前回と同じ16報でメタ解析
- 同等の降圧下で、全死亡・心血管死・心血管疾患発症とも **RA系阻害薬が優れる傾向はあるが有意差なし**。腎機能障害（Cr 倍化、ESRD）も優劣なし
- → **同等の降圧が得られれば RA系阻害薬を第一選択として推奨するエビデンスはない**
- 腎機能障害の有無別の検討は、Cr ≧1.7 などの除外基準や eGFR 感度分析の欠如により十分できず、腎機能正常例に限った検討は論文が少なく推奨を検討できなかった

### 薬剤ごとの留意点

- **サイアザイド系利尿薬**: インスリン抵抗性増悪を介した糖・脂質代謝への悪影響、低K血症、高尿酸血症 → **使うなら少量**
- **LIFE**: 2型糖尿病で ARB が β遮断薬より心血管病発症を有意に抑制 → 心血管イベント予防の立場からは ACE阻害薬・ARB・Ca拮抗薬が選択される
- RA系阻害薬で不十分 → Ca拮抗薬 or 少量サイアザイド併用 → さらに3剤。配合薬も考慮
- **微量アルブミン尿以上の蛋白尿を伴う場合は ARB・ACE阻害薬を選択薬として推奨**（RA系阻害薬の有用性は明らか）

## Q14-5 併用療法での選択薬は Ca拮抗薬か利尿薬か

- 1剤で不十分 → **ACE阻害薬または ARB ＋ Ca拮抗薬 あるいは 少量サイアザイド系利尿薬**、さらに必要なら3剤（日本高血圧学会・日本糖尿病学会合同委員会）

| 試験 | 対象 | 結果 |
|---|---|---|
| ACCOMPLISH 糖尿病サブ解析 | ハイリスク高血圧 | ACE阻害薬＋**Ca拮抗薬**が利尿薬併用より心血管イベントを有意に抑制 |
| COLM（日本） | ハイリスク高齢高血圧（糖尿病26%） | ARB＋CCB と ARB＋低用量利尿薬で主要評価項目に差なし。**75歳以上の脳卒中・有害事象は CCB 併用で低値** |
| GUARD | 糖尿病性腎症、ACEI/ARB 使用中 | **蛋白尿減少は利尿薬、eGFR 保持は Ca拮抗薬**の併用が有効 |
| COAT（日本人） | 同上 | GUARD と同様の結果 |

- → 臨床背景・基礎疾患を考慮し、**Ca拮抗薬・利尿薬いずれの選択も可**

## Q14-6 糖尿病に合併した心不全の診断・治療

### ポイント

- 糖尿病は高血圧・冠動脈疾患と独立した心不全の危険因子で重要な予後規定因子。積極的に診断し、**心不全あるいは心不全高リスクでは SGLT2阻害薬を推奨**（日本糖尿病学会・日本循環器学会合同委員会）

### 疫学・病態

- 心不全発症リスク: 非糖尿病比 **男性2倍、女性5倍以上**。耐糖能異常の段階から 1.2〜1.7倍
- 糖尿病患者の初回入院は心不全が最多との報告。日本人2型の初発心血管腎イベントは CKD（39.3%）に次いで**心不全（30.6%）**
- 60歳未満の新規発症、女性や HFpEF の再発への影響が大きい
- HFrEF: 冠動脈疾患由来が多い。HFpEF: インスリン抵抗性を基盤とする代謝異常、微小血管内皮障害 → 心筋肥大・伸展性低下
- 心不全歴のない2型糖尿病の精査で **25%以上に心不全が新規診断、大部分が HFpEF**

### 診断（図2 フローチャート）

1. 定期受診時に確認
   - **自覚症状**: 労作時息切れ、動悸、倦怠感、夜間発作性呼吸困難、夜間頻尿（起坐呼吸、下腿浮腫も）
   - **身体所見**: ラ音、頻脈、脈不整、III音、頸静脈怒張、下腿浮腫、心雑音
   - **胸部X線**: 心胸郭比拡大、肺うっ血
   - **心電図**: 異常Q波、左室肥大、心房細動、ST-T 変化
2. どれか1項目以上 → **BNP または NT-proBNP** 測定

| マーカー | 心不全の可能性あり | 治療対象の可能性が高い → 循環器専門医コンサルト |
|---|---|---|
| BNP | ≧40 pg/mL | **≧100 pg/mL** |
| NT-proBNP | ≧125 pg/mL | **≧400 pg/mL** |

> **補足（本章外）**: 日本心不全学会ステートメント2023年改訂版では BNP 100 に対応する NT-proBNP が **400 → 300 pg/mL** に、「心不全の可能性」の BNP 下限が 40 → 35 pg/mL に改訂。区分表は [標準診療マニュアル2026 のまとめ](../dm-manual-2026/summary.md) を参照。

- コンサルト後は心エコー（LVEF、左房サイズ、左室肥大、壁運動異常、拡張能）
- 所見なしの場合は年1回 BNP/NT-proBNP・胸部X線・心電図でフォロー
- ※ 本文では NT-proBNP の単位が「mg/dL」と誤記されている箇所あり（図2では pg/mL）。図2（p.310、画像で照合済み）の No 側: 所見なし → **年1回 BNP/NT-proBNP・胸部X線・心電図** → 異常所見があれば BNP 判定へ。BNP <100／NT-proBNP <400 → そのまま経過観察し年1回検査へ戻る

### 治療

- ACE阻害薬/ARB、ARNI、β遮断薬、MRA、SGLT2阻害薬はいずれも**糖尿病の有無にかかわらず同等の効果** → 標準的心不全治療を非糖尿病と同様に
- β遮断薬は糖代謝への影響が少ない**カルベジロール・ビソプロロール**が心不全治療薬として承認
- 心不全予防の HbA1c 目標は未確立 → 薬剤の心不全エビデンスに基づき個別設定
- CVOT で**エンパグリフロジン、カナグリフロジン、ダパグリフロジン**の心不全予防効果

### 心不全予防（図3）

| 状態 | 対応 |
|---|---|
| 心不全なし かつ 低リスク | 生活習慣改善＋包括的介入、病態に応じ糖尿病治療薬を選択 |
| **心不全あり、または高リスク** | **SGLT2阻害薬を推奨** |

- **心不全高リスク**: BNP ≧100 pg/mL または NT-proBNP ≧400 pg/mL、心筋梗塞既往、eGFR ≧30 の CKD など
- 低リスク糖尿病での SGLT2阻害薬の心不全予防効果は今後の解明待ち

## 外来での使いどころ（自院メモ）

- 糖尿病患者の血圧は **130/80 未満**が目標。**140/90 以上は即薬物開始**、130〜139/80〜89 は生活修正を最大1ヵ月試して判断
- 第一選択前に**尿アルブミンを確認**: 陽性なら ARB/ACEI、陰性なら ARB/ACEI/CCB/少量サイアザイドのどれでもよい
- 併用は ARB（or ACEI）＋ CCB or 少量サイアザイド、次いで3剤。**ARB＋ACEI は併用しない**。配合剤でアドヒアランス確保
- 高齢者・冠動脈疾患・PAD では下げすぎ（ふらつき・失神）に注意
- 定期受診で息切れ・浮腫・夜間頻尿を問診し、疑わしければ **BNP（≧100 で循環器紹介）**
- BNP 上昇・心筋梗塞既往・CKD がある糖尿病には **SGLT2阻害薬を優先**
