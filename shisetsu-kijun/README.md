## ディレクトリの決まり

```
shisetsu-kijun/
  README.md                   この台帳（届出済み・検討中の一覧）
  <基準の英語スラッグ>/
    README.md                 要件・自院の充足状況・届出/受理の経緯・掲示先
    original/                 通知・疑義解釈・様式の入手時の版（証跡）
```

- 1施設基準 = 1ディレクトリ。スラッグは英語（例 `jikangai-taio-taisei-3`）。
- **届出書そのもの（提出物・送付状・控えPDF）は `filings/kouseikyoku/` に置く**。
  ここは「何を満たしているか」を管理する場所、`filings/` は「いつ何を出したか」を残す場所。
  各基準の README から該当する案件ディレクトリへリンクする。
- 要件は改定されるので、根拠にした通知・疑義解釈は `original/` に版ごと残す。
- **口頭で確認した解釈は日付つきで README に書く**。厚生局の電話回答はここにしか残らない。

## 施設基準に特有の運用

- **受理通知は郵送されない**。R7.8.1 算定開始分以降、東北厚生局HPの
  「施設基準の受理状況」掲載が唯一の受理通知。掲載は毎月20日・月末、受付から約1か月遅れ。
  → 確認は `.claude/skills/shisetsu-kijun/`（`/shisetsu-kijun`）で行う。
- **毎年7月に定例報告**（施設基準の届出状況の報告）がある。対象基準と様式は年度ごとに変わる。
- **掲示要件**のある基準は、院内掲示とウェブサイト掲示の両方が必要なことが多い。
  掲示ページは `frontend/src/pages/` にあり、基準ごとの README に掲示先を明記する。
- **体制が変わったら届出をやり直す**（連携医療機関の変更、診療時間の変更など）。
  変更・辞退は `filings/kouseikyoku/` に案件を立てる。
